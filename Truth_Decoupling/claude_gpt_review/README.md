# Claude × GPT 交叉审核目录

## 目的

Claude 负责实验执行与写作，GPT 负责独立审核与红队（red team · 专门挑毛病的一方）。两边的材料都放在这里，保证审核有据可查、可以复现。

## 结构

| 子目录 | 放什么 | 谁写 |
|---|---|---|
| `from_claude/` | 给 GPT 看的材料：审核提示、实验方案与规则、数据切分与选层协议、结果快照、关键代码 | Claude |
| `from_gpt/` | GPT 的审核意见，一次审核一个文件，文件名带日期，例如 `review_20261031.md` | GPT |

## 使用方法

1. 把 `from_claude/` 里的审核提示和当期材料一起交给 GPT。
2. GPT 的回复原样存入 `from_gpt/`，不改写。
3. Claude 逐条核验 GPT 的意见：先查支撑结论的代码和原始数据，确认是真问题再改；不盲从，也不硬顶。
4. 核验结论与后续改动写回 `from_claude/` 的对应文件，并在本 README 的更新记录里加一行。

## 约定

- 不含任何凭证、密码、API key、服务器地址。
- 结果数字以 `from_claude/` 内文件为准，README 只做索引。
- 每个英文术语首次出现带中文和一句大白话解释。
