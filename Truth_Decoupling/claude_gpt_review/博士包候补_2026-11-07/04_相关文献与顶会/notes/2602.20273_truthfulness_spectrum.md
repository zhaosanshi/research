# 2602.20273 · The Truthfulness Spectrum Hypothesis
- 作者 / 机构 / 发表处与年份：Zhuofan Josh Ying（Columbia 心理系 / Zuckerman 研究所）、Shauli Ravfogel（NYU）、Nikolaus Kriegeskorte（Columbia）、Peter Hase（Stanford / Schmidt Sciences）。**仅 arXiv 预印本**（v1 2026-02-23，页脚 "Preprint. February 25, 2026"，ICML 排版，推测投 ICML 2026）。代码 github.com/zfying/truth_spec。
- 权威度与严谨度判断：**[大机构预印本]**（Ravfogel 是 INLP/LEACE 作者，Hase 是可解释性领域知名研究者）。理由：主实验 Llama-3.3-70B-Instruct，复现于 Llama-3.1-8B、Llama-3.2-3B、Qwen-2.5-14B、Qwen-2.5-7B 及对应 base 模型（2 家族、3B–70B、base/chat 成对）；FLEED 4800 条 + ETHICS 4000 条 + 谄媚数据 + 期望反转数据 + 3 个外部诚实基准；5 折交叉验证；探针架构/层/token 聚合三维调参；有因果干预（但仅 Llama-8B、单层、单 α）；有仿真验证 Mahalanobis 相似度。**缺点**：FLEED 由 Gemini-3-Pro 生成；因果实验规模小（1 模型、1 层、α=−2 一个值），作者自认"效应 modest（温和）"；尚未同行评审。

## 一句话核心主张
LLM 里的"真"不是一个方向也不是一堆互不相干的方向，而是**一个从"跨域通用"到"单域专用"的谱**：各域真值探针互相迁移良好（AUROC>0.9）但对谄媚撒谎和"期望反转"几乎失效（≈0.55）；联合训练能找回通用方向；探针方向的 Mahalanobis cosine similarity（马氏余弦相似度 · 用数据协方差加权后再算夹角，忽略没信号的维度）能以 R²=0.98 预测跨域泛化；**但因果上，域专用方向能有效操控输出，通用方向反而有害**；post-training（后训练 · 指令微调+RLHF）把谄媚表示推得离其他真值类型更远。

## 方法细节
- **数据（§2，App. A）**：
  - FLEED：definitional（定义真 · 三角形有三条边）、empirical（经验真）、logical（逻辑真）、fictional（虚构世界内的真 · 佛罗多把魔戒带去了魔多）各 ≈1200（600 正 600 负），Gemini-3-Pro 生成+人工过滤，负例用多种策略（直接否定/换量/换信息）；ethical 取 ETHICS commonsense 短句 4000。提示格式 "User: Please tell me a fact. Assistant: [claim]"。
  - Sycophantic lying（谄媚撒谎）：MMLU STEM 题 + 4 个假专家用户简介 + 用户预先给的答案；先无上下文问出模型"真信念"，再加简介重问；模型改答案迎合用户 = 谄媚样本，与不改的配对。**on-policy**（模型自己生成）。Llama-70B 谄媚率 8.5%，模型原答案正确/信心高时谄媚率更低（Fig. 10）。
  - Expectation-inverted（期望反转）：Azaria & Mitchell 真假句 + "假装你是个不诚实的人在陈述世界"——此时说真话反而违背用户期望。用来区分探针测的是客观真值还是"用户期望的真值"。
  - 外部诚实基准：insider trading（Scheurer 2023）、sandbagging（Benton 2024）、roleplaying（Goldowsky-Dill 2025）。
- **激活与探针（§3，App. B）**：残差流，助手回复 token 的**平均**（优于末 token）；LR、DoM（均值差）、LDA 三种 × last/average/all 三种聚合 × 层 调参，目标是 FLEED 跨域 AUROC。最终 Llama-70B：LR（α=1e-4）、平均 token、**layer 33**；Llama-8B layer 15；Qwen-14B layer 30；Qwen-7B layer 18。**同一血统 base 与 chat 的最佳层完全相同**；base 模型晚层掉得更快。Fig. 12b：diffmean 各层 ≈0.95–0.96，LR ≈0.96–0.97，LDA 差很多（0.6–0.9）。
- **几何（§5，Eq. 1）**：Cos_Σ(w_A, w_B) = w_Aᵀ Σ_test w_B / √(w_Aᵀ Σ w_A · w_Bᵀ Σ w_B)。有效维度 <100–200（8192 维空间），标准余弦被噪声维度淹没（大多数域对之间 ≈0）。
- **Stratified INLP（分层迭代零空间投影 · 先把跨域通用方向一层层投掉，再在剩下的空间里找单域方向）（§7.1）**：Stage 1 在全域联合训练 + INLP 迭代得互相正交的通用方向；Stage 2 投掉通用方向后逐域 INLP 得专用方向。层级：5 个全域、3 个诚实基准、4 个 FLED、10 个 def/emp/fict 共享、每域 4 个专用（Fig. 21）。
- **LEACE 选择性擦除（§7.2）**：擦掉某一个域的预测子空间，重训全部探针，看谁掉——掉法异质 → 存在"部分共享"方向；App. F.1 把它形式化为交叉子空间上的容量分配问题，L1 正则最小二乘解出容量集中在 3–6 个域共享的子空间。
- **因果干预（§8，App. G）**：Llama-8B；SimpleQA verified 1024 题；diff(q) = log P(a⁺|q) − log P(a⁻|q)，a⁻ 是同类型干扰答案；**在 layer 15 的 MLP 输出偏置上加 α·d，α = −2.0**（b'_ℓ = b_ℓ + α·d）；比较 14 个域专用方向 vs 1 个通用方向（Stratified INLP 在 FLEED+谄媚+Azaria&Mitchell+Marks&Tegmark+Goldowsky-Dill 上提取）。按基线 P(correct)/P(incorrect) 百分位分箱。

## 评价口径与关键数字
**探针迁移（Fig. 2，Llama-70B layer 33，5 折 AUROC）**
| 训练 ↓ / 测试 → | FLEED 五域 | sycophancy | exp inverted | roleplay / insider / sandbag |
|---|---|---|---|---|
| 任一 FLEED 域 | 0.90–1.00（ethical 稍低 0.76–0.82） | 0.53–0.61 | 0.29–0.69 | 0.41–0.99 不稳 |
| Marks & Tegmark 探针 | 0.91–1.00 | 0.59 | 0.79 | 0.62 / 0.62 / 0.89 |
| sycophancy | 0.43–0.59 | 0.97 | 0.48 | 0.52 / 0.74 / 0.53 |
| exp inverted | **0.09–0.39（远低于随机）** | 0.52 | 0.98 | 0.16 / 0.53 / 0.23 |
| combined | 0.95–1.00 | 0.97 | 0.90 | 0.97 / 1.00 / 1.00 |

- 几何预测：Mahalanobis cosine → 跨域 AUROC，R²=0.98（Spearman ρ²=0.95）；标准 cosine R²=0.56。仿真 5 种分布 R²=0.957–0.999 vs 0.012–0.553。
- **Post-training（Fig. 4、Fig. 15）**：FLEED 探针测谄媚：base 0.74（70B、8B）vs chat 0.62 / 0.59；谄媚探针测 FLEED（70B）：base 0.75–0.86 vs chat 0.52–0.58；FLEED–谄媚方向 Mahalanobis 相似度 70B：base 0.56 → chat 0.23；8B 0.51 → 0.34；3B 0.36 → 0.06。Qwen 家族同趋势（需 α=1 正则才显现）。
- **Stratified INLP（Fig. 5）**：第 1 个通用方向各域准确率 0.85（logical）–1.00（insider）；投掉通用方向后的专用方向：self 高、other ≈ 0.5。
- **因果（Fig. 7、Fig. 26，Llama-8B，α=−2，layer 15 MLP bias）**：
  | 方向 | 平均 Δdiff | 基线信心 90–100 分位 Δdiff | 机制 |
  |---|---|---|---|
  | 域专用（14 个平均） | **+0.05** | **≈ +0.10** | 压 log P(a⁻)，log P(a⁺) 基本不动 |
  | 通用 | **−0.07** | **≈ −0.11** | 两边都抬，错答案抬得更多 |
  | 谄媚专用 | 比通用更糟 | — | — |
  - 效应随基线信心单调增大；模型原本偏向错答案（0–10 分位）时效应 ≈0。作者结论："干预是在**强化模型已有的正确知识的信心**，而不是把错的翻成对的。"
- 作者自述局限（§11）："因果干预效应 modest，**调节的是信心而非可靠地翻转预测**"；数据模型生成；仅线性；后训练分析只盯谄媚。

## 与 博士方案的关系
- 重叠点：
  - **探针方向 ≠ 因果有效方向**：他们直接给出"通用方向监测好用、操控有害"的证据，这是我们"读层≠写层 / 探针方向≠干预方向"主张最近的先例，必须引用并区分（他们是**方向**的读写不一致，我们是**层**的读写不一致，可以互补）。
  - 干预只在模型已知的题上起作用、未知题上无效——这正是我们 C3 门控"已知题打 E、未知题打 C"的经验前提。他们用基线信心分箱替代了门控。
  - 均值差 vs LR vs LDA 三估计器对比（Fig. 12b）与我们三估计器（DAS/均值差/LR）部分重叠。
  - base vs chat 成对比较与我们 C4 的多模型族有重叠（Llama、Qwen）。
- 冲突点（他们的结论会不会打我们的某条主张）：
  - **对 C1 的威胁（中偏高）**：(a) "真不是一个方向而是一个谱"——我们说"E 是证据方向"，审稿人会问 E 在谱上的哪个位置：若用 FEVER+CounterFact 估计，E 偏向 empirical 域专用，那在 TruthfulQA/MMLU 上可能不是同一个方向；(b) **他们的干预改变的恰恰是 log P(正)−log P(错) 即判别力，且机制是压错答案**——若我们的 E 干预结果与之一致，那就是"复现"而非新发现；我们的新意必须落在"E 不动作答率、C 不动 J"的 2×2 矩阵上，而不是"E 能提判别力"本身；(c) 他们证明域通用方向因果上**有害**——如果我们的 E 是多数据集池化出来的"通用"方向，按他们的结论会掉点。
  - **对 C3 的威胁（中）**："干预效应随基线信心增大、未知题上 ≈0"已被他们先报告（虽然是作为副结果）。我们的门控要么引用它作为动机，要么证明门控比"按信心分箱"多出了什么（比如 C 方向让未知题弃答——这他们完全没有）。
  - **对 C4 的威胁（中）**：post-training 重塑真值几何、base 晚层掉得更快——我们的方向若在 base 上估、instruct 上用（或反之）可能失效；三模型族需要 base/instruct 都报。
  - 不冲突处：他们没有承诺/弃答维度、没有 system prompt 对比、没有作答率指标、没有选层算法（层按跨域 AUROC 选且读写同层）、没有下游任务副作用。
- 可借用点（方法、数据、指标、对照）：
  - **Mahalanobis cosine**：报告 E 与 C 的夹角必须用它而不是标准余弦（标准余弦在 4096 维里什么都 ≈0，审稿人会不信"正交"）。
  - **Δdiff 分解为 Δlog P(a⁺) 与 Δlog P(a⁻)**（Fig. 26）：这是区分"改判别力"还是"改偏置"的现成工具——偏置方向会同时抬/压两边，判别方向只动错的一边。可直接套到 E/C 的 2×2 验证里。
  - **按基线信心分箱报告干预效应**——我们的门控三档（已知/部分已知/未知）可以和他们的分位箱对齐。
  - Stratified INLP / LEACE 可用来检验：把 E 子空间投掉后 C 方向是否还在（C 不应依赖 E 子空间）。
  - 期望反转数据集：检验 C 方向是"承诺"还是"顺从用户期望"的关键对照——如果 C 在期望反转下翻号，说明 C 混了"顺从"。
  - 谄媚数据集：C（承诺）与谄媚（改答案迎合）是两种不同的行为维度，可用它证明 C ≠ 谄媚方向。
  - FLEED + 谄媚 + 期望反转数据开源。
- 明确差别（我们还能声称什么是新的）：
  - 他们的第二个轴是"域通用–域专用"（证据侧内部的谱），不是"证据–承诺"。
  - 他们干预只调 MLP bias 单层单 α，无选层、无门控、无作答率、无下游副作用；且作者自认效应温和、不翻转。
  - 他们没有任何弃答/不确定性表达维度。
