# 2312.06681 · Steering Llama 2 via Contrastive Activation Addition

- 作者 / 机构 / 发表处与年份：Nina Panickssery（原名 Rimsky，Anthropic）、Nick Gabrieli（Harvard）、Julian Schulz（Göttingen）、Meg Tong、Evan Hubinger（Anthropic）、Alexander Matt Turner（CHAI）。**ACL 2024 主会长文**（arXiv v4 2024-07-05）。代码：github.com/nrimsky/CAA（MIT）。
- 权威度与严谨度判断：**[顶会已发表]**。理由：Llama-2-Chat 7B/13B（+7B base 迁移实验）两个尺寸同一族；7 种行为各 290–1000 对训练、50 题测试；有 system-prompt 与 finetuning 两类基线；报 MMLU（570 题）与 TruthfulQA；开源。短板：测试集每行为只 50 题；开放生成用 GPT-4 打分（作者自述有噪声、仅人工抽查）；只一个模型族；作者自述 prompting/finetuning 基线未充分调优、向量范数未跨层归一化故层最优性结论可能有偏；**没有随机方向对照**。

## 一句话核心主张
用多选题（A/B 答案字母位置）正负样本的残差流激活做 Mean Difference（均值差 · 正例平均减负例平均）得到 steering vector，在提示之后所有位置按倍数加回去，就能在 RLHF 过的 Llama-2-Chat 上稳定调节 7 种对齐相关行为（含幻觉、拒答、谄媚），效果叠加在 system prompt 与微调之上，且对 MMLU 几乎无损。

## 方法细节
- **方向估计**：v_MD = (1/|D|) Σ [a_L(p, c_p) − a_L(p, c_n)]，在**答案字母 token 位置**取第 L 层残差流；正负提示仅差一个 token（A vs B），作者称这样能抵消其它混杂变量。数据来自 Anthropic "Advanced AI Risk" 人写多选集（Perez et al. 2022）；幻觉、拒答两类用 GPT-4 生成（Appendix C/D）。训练集大小（Table 9）：AI Coordination 360、Corrigibility 290、Hallucination 1000、Myopic Reward 950、Survival Instinct 903、Sycophancy 1000、Refusal 408；测试各 50。
- **干预层与位置**：单层；向量加到**用户提示之后的所有 token 位置**（含生成 token），乘倍数 m（多选评估 ±1，开放生成 ±2）。**选层 = 全层扫描**：每层做 m=±1 的 CAA，在 50 题 held-out 上看效果幅度；7B 最优 L13 及邻层，13B 最优 L14/15，且**各行为峰值层相近**（Fig 3）。PCA 可视化显示"行为聚类"在约 1/3 深处突然出现（refusal 在 7B 的 L10），比最优 steering 层 L13 略早。Fig 8：L13 向量迁移到其他层注入，**部分更早层效果更大**，约 L17 后陡降。
- **干预公式**：h_L ← h_L + m · v_MD（跨行为归一化范数，但**不跨层归一化**，作者自述可能影响层最优判定）。
- **推理协议**：多选评估 = 对符合行为的答案字母的平均 token 概率；开放生成 = GPT-4 按 0–10 打分（提示在 Table 15），50 题。

## 评价口径与关键数字
- **Table 3（13B Chat，L13，多选平均概率，与 system prompt 交互）**：以 Hallucination 为例：无提示 −1/0/+1 = 0.42/0.54/0.78；正向提示 0.47/0.52/0.87；负向提示 0.42/0.47/0.68。Refusal：无提示 0.56/0.78/0.86。→ CAA 在 system prompt 之上仍能推动。
- **Table 4（7B Chat，L13，开放生成 GPT-4 0–10 分，与 finetuning 交互）**：Hallucination 无微调 2.60/3.28/3.84；Refusal 4.60/4.62/4.62（开放生成上 refusal 向量几乎无效）。
- **Table 5 MMLU（13B Chat，L14，m=±1，570 题改成 A/B 二选，报正确答案平均概率）**：基线 0.63；+1 范围 0.59–0.65；−1 范围 0.57–0.64。最大降幅：Hallucination −1 → 0.57、Sycophancy −1 → 0.58（约 −0.05/−0.06 概率，**非准确率**）。
- **Table 12 TruthfulQA（13B，L14，谄媚向量，A/B 概率）**：无干预 0.60；+谄媚 0.57；−谄媚 0.62。7B：−0.05 / +0.01。效应小。
- **Table 13**：微调 1 epoch 测试准确率 44%–100%（谄媚正向只 44%，微调在开放生成上失败而 CAA 成功）。
- 层间向量余弦相似度（Fig 7）：相邻层高、后半段衰减慢；base 与 chat 向量相似度在 L7–15 有峰（Fig 9）。

## 与 博士方案的关系
- 重叠点：均值差估计器就是 CAA；"system prompt vs steering vs 叠加"的比较格式（Table 3）正是我们 prompt-only 对照要的格式；MMLU/TruthfulQA 损伤报告；全层扫描选层是我们 C2 要替代的昂贵基线（也是我们算"≤10% 成本"的分母）。
- 冲突点：
  1. CAA 的 **Hallucination 向量**正负样本（Table 7）是"接受错误前提并编造" vs "指出前提错误并拒绝回答"——**这恰好把 E（知道前提为假）和 C（愿不愿意顶回去/拒答）揉在一起**。他们把这当成一个行为，我们说这是两个方向——这不是冲突，而是我们 C1 的最佳反面例证（"均值差方向混淆多个概念"）。
  2. 他们报告"所有行为的最优层几乎相同（7B 全在 L13 附近）"——若我们声称 E 与 C 的写层 W* 不同，需要正面解释为何与 CAA 的"统一最优层"观察不一致（可能原因：他们只看效果幅度不看副作用、未跨层归一化范数）。
  3. 他们在 Limitations 里承认 prompting 基线未调优、"更用力找提示可能达到同样效果"——这给 AxBench 的结论留了口子，也提醒我们的 prompt-only 对照必须认真调优，否则不可信。
- 可借用点：① A/B 单 token 差分的配对设计（最小化混杂）可用于我们 C 方向的估计（"确定/不确定"二选）；② 跨层迁移实验（Fig 8：一层向量注到别层）可作为我们"写层 W*"稳健性的补充实验；③ TruthfulQA 按类别拆分报告；④ PCA 行为聚类出现层 vs 最优 steering 层的差异（L10 vs L13）作为"读≠写"的早期旁证引用。
- 明确差别：CAA 只做单方向、单层、无解耦分析、无门控、无选层器、无随机方向对照、无 Youden's J/作答率分离口径。我们可以说 CAA 风格的 hallucination/refusal 向量是"E+C 混合向量"，用 2×2 矩阵把它拆开是新的。

## 对四条主张的威胁等级
| 主张 | 威胁 | 理由 |
|---|---|---|
| C1 解耦 | 低 | 不做解耦；其 hallucination 向量天然是 E/C 混合，反而是我们的论据。但其"谄媚向量微调 TruthfulQA"显示行为向量彼此纠缠，需我们用余弦相似度/干预交叉表证明 E⊥C 不是巧合。 |
| C2 选层 | 低 | 全层暴力扫描 = 我们要替代的基线；其"各行为最优层一致"的观察需我们在 E/C 上复核并解释差异。Fig 8 跨层迁移是弱旁证。 |
| C3 门控 | 无 | 全局无条件加向量。 |
| C4 泛化 | 低 | 仅 Llama-2 一族 7B/13B；MMLU 以 A/B 概率报（−0.05 量级），我们以准确率≤1 分报，口径不同需说明。 |
