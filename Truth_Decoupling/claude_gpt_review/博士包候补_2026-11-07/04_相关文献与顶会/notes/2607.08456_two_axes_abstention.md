## 一句话核心主张
选择性作答不能只卡一个置信阈值：在同一批决策上，correct-answerable（C，可答且答对）/ wrong-answerable（W，可答但答错）/ unanswerable（U，不该答）三类呈"交叉 L 形"几何——输出层 answer-confidence（答案置信 · 生成答案的平均 token log-prob）分得开 C vs W/U 却分不开 W vs U（可答性 AUROC 0.54–0.67，不随规模改善），隐状态线性探针分 U vs C/W 到 0.97–0.99 却几乎分不开 C vs W；因此应把弃答形式化为三类选择性接受、给"答了不该答的"和"答错了"各设独立风险预算（α_U=0.15、α_W=0.50），用 Clopper–Pearson（克洛珀-皮尔逊 · 精确二项置信上界）双阈值证书——8B 上因子化双阈值策略在 0.75 覆盖率同时过两项预算，单置信阈值只有 0.31。

## 方法细节
- **数据与标注**：SelfAware（Yin et al. 2023）每模型 150 可答 + 150 不可答，一次贪心生成（24 token），对错按别名匹配（可答题准确率仅 0.28–0.42）；CREPE（Reddit ELI5 真实用户问题，约 1/4 含假前提）500+500，只提供可答性轴（长答案无法判对错）。
- **信号**：输出侧 = 贪心答案平均 token log-prob + 首 token 预测熵（为公平也训同容量 L2 逻辑回归读出）；隐状态侧 = 最后 prompt token 在 0.4/0.6/0.8 深度的残差流，L2 逻辑回归（层在嵌套校准集上选）。另有 P(IK)（"你能答对吗？"yes 概率）、P(True)、premise-check 诱导，与 Lavi et al. 式 difference-of-means（均值差）方向。
- **几何量**：校准标准化单位下三类均值；gap 比值（输出：W−U gap ≤ C−W gap 的 0.35；隐状态：C−W ≤ W−U 的 0.07）。
- **标签伪影检查**：只用 C vs U 训练可答性方向（不含 W），留出 W 仍落在 C 侧（W–U AUROC 0.97–0.98，W 位于 U→C 的 0.71–0.85 处）。
- **表面混淆**：哈希词袋逻辑回归仅凭问题文本预测 SelfAware 可答性 AUROC 0.87（CREPE 0.59）→ 作者承认 SelfAware 上的 0.97–0.99 大部分是表面可得的；跨构造迁移（SelfAware→虚构国家模板 0.76，反向 0.64；→CREPE 0.65–0.70）证明有共享的非表面成分。
- **修复 pilot（探针路由）**：Llama-3.1-8B / Qwen2.5-7B，120 假前提 + 120 正常；"若含假设错误请指出而非作答"的 challenge prompt 让模型对 74% 假前提提出质疑，但也对 57% 正常题乱质疑；用留出隐状态探针（可答性分低才切到 challenge prompt，预算 35%）→ 42%/14%（随机门控 26%/20%）。NLI 验证的正确纠正 47%（Llama）/61%（Qwen）。
- **双风险证书**：R_U=P[emit|U]、R_W=P[emit|W]、Cov_C=P[emit|C]；在 tuning 集选 (τ_A, τ_C) 冻结，在独立 certification 集用 Clopper–Pearson 单侧上界（δ/2 各一，Bonferroni 合 1−δ=0.90），test 集报经验率；100 次重切分审计证书违反率。
- **匹配关系门（§8）**：首都/官方语言/货币三关系，每组 TRUE/FALSE/UNKNOWN 三项（UNKNOWN 为真实但冷门实体如 Nauru），Gemma Scope SAE 特征电池（top-16）或 Qwen 探针做读出，组级证书。

## 与 博士方案的关系
- 重叠点：(1) "两轴"= 我们问答级"按已知/未知拆分、分别报纠正/损伤/转弃答"的理论依据；C/W/U 三态正是我们门控的三分（已知→不干预、答错/部分已知→打 E、未知→打 C）；(2) 探针路由（probe-routed prompting）= 一个"按输入门控、未知题切到弃答倾向"的行为版实现，已证明随机门控不行、探针门控把质疑精度提高约 3 倍；(3) 双风险预算 ≈ 我们"纠正率 vs 损伤率 vs 转弃答率"的证书化版本。
- 冲突点：(a) **门控的新颖性被削**：输入依赖的"探针决定要不要改变行为"已有先例（虽然切换的是 prompt 而非激活方向）；(b) SelfAware 词袋基线 0.87——若我们的知识探针 / C 方向在 SelfAware 类数据上估计，审稿人会要求同样的表面混淆对照；(c) 隐状态几乎分不开 C vs W（2B 仅 0.64）——意味着我们"部分已知"门控分支在小模型上信号可能不足；(d) "W 与 U 在输出置信上重叠"→ 我们若用 log-prob 定义"作答率/偏置 B"，可能把答错和弃答混在一起，需明确区分"弃答"与"低置信作答"。
- 可借用点：① C/W/U 三态在"输出置信 × 可答性探针"平面上的散点图作为门控动机图；② 词袋表面基线、P(IK)/P(True) 诱导基线作为必备对照；③ CREPE 作为无表面混淆的自然假前提数据集；④ 四路无泄漏切分 + Clopper–Pearson 双风险证书 + 100 次重切分审计——可直接套在我们"转弃答率 / 损伤率"上给出可认证数字；⑤ "只用 C vs U 训练仍把 W 放到 C 侧"的标签伪影检验，对我们用真/假陈述对训练 E 方向同样适用。
- 明确差别：(1) 我们做因果干预（steering），他们纯观测 + 阈值策略（自认 "we do not intervene causally"）；(2) 我们的门控切换的是激活方向而非 prompt；(3) 我们的两轴是残差流里两条方向而非"输出置信 vs 隐状态探针"两种信号源；(4) 陈述级 J/B；(5) 选层。

## 对四条主张的威胁等级
| 主张 | 威胁 | 理由 |
|---|---|---|
| C1 解耦 | 低 | 只是观测几何（输出 vs 隐状态），无方向、无因果；反而给"两轴独立"提供行为学支撑 |
| C2 选层 | 无 | 仅在 0.4/0.6/0.8 深度取探针，不涉及干预层 |
| C3 门控 | 中 | 输入依赖的探针门控（切 prompt）与双阈值因子化策略已成文，且证明随机门控无效；我们须把门控定位为"方向级干预的门控"并与 prompt 路由、双阈值直接比 |
| C4 泛化 | 低 | 5 模型 2B–14B；但其 SelfAware 词袋 0.87 的教训迫使我们在四数据集上都报表面基线 |
