# 2406.11717 · Refusal in Language Models Is Mediated by a Single Direction

- 作者 / 机构 / 发表处与年份：Andy Arditi*（Independent）、Oscar Obeso*（ETH Zürich）、Aaquib Syed（UMD）、Daniel Paleka（ETH）、Nina Panickssery（Anthropic）、Wes Gurnee（MIT）、Neel Nanda（主导师）。**NeurIPS 2024 主会**（arXiv v3 2024-10-30）。代码 github.com/andyrdt/refusal_direction。MATS/SPAR 项目产出。
- 权威度与严谨度判断：**[顶会已发表]**。理由：**13 个开源 chat 模型、5 个族、1.8B–72B**；训练仅 128 有害 + 128 无害指令，验证各 32，与评估集严格不重叠；两套评估指标（关键词拒答分 + Llama Guard 2 安全分）并讨论二者分歧案例；HarmBench 标准 ASR 与 GCG/PAIR 等越狱对比；**MMLU/ARC/GSM8K/TruthfulQA/WinoGrande/HellaSwag** 六项能力评估（lm-eval-harness）+ 三类 CE loss；与 LoRA 微调对照。短板：方向提取靠启发式（作者自称"存在性证明而非最优提取"）；对抗后缀分析只一个模型一个后缀；n=100 的评估集；作者承认"拒答方向"语义可能其实是"伤害/危险"。

## 一句话核心主张
在 13 个 chat 模型里，拒答行为由残差流中**一个一维方向**介导：用 128 对有害/无害指令的 difference-in-means（均值差）在"指令后模板 token"位置得到方向 r，在**所有层所有位置**把 r̂ 分量投影掉（directional ablation · 方向消融）模型就不再拒答有害请求；在单层**加**上 r 则对无害请求也拒答；等价地把所有写入残差流的权重矩阵对 r̂ 正交化即得一个几乎不掉能力的白盒越狱（MMLU/ARC/GSM8K 平均掉 <1%），但 **TruthfulQA 一致下降 1–6 分**。

## 方法细节
- **数据**：D_harmful 训练 128 条（AdvBench / MaliciousInstruct / TDC2023）、验证 32 条（HarmBench val）；D_harmless 训练 128、验证 32（Alpaca）。评估：JailbreakBench 100 条有害（§3.1）、Alpaca 100 条无害（§3.2）、HarmBench 159 条 standard behaviors（§4.2）。
- **方向估计**：对每层 l 与每个 post-instruction token（指令后的模板 token，如 Llama-3 的 `<|eot_id|>…\n\n`）位置 i，r_i^(l) = μ_i^(l) − ν_i^(l)（有害均值 − 无害均值）。得到 |I|×L 个候选。
- **候选选择（Appendix C）**：在验证集上计算 bypass_score（消融后有害集的拒答度量均值，越低越好）、induce_score（加法后无害集的拒答度量均值）、kl_score（消融前后无害集末 token 分布 KL）；取 bypass_score 最小且满足 induce_score>0、kl_score<0.1、**l < 0.8L**（避开太靠近 unembedding 的层，防止只是压掉"I"这类 token）。拒答度量 = 首个生成 token 落在该模型拒答起始 token 集 R（如 "I"）的概率的 logit。≤14B 模型选方向约 5 分钟，72B 约 1 小时。
- **选出的层（Table 5）**：Qwen 1.8B 15/24；Qwen 7B 17/32；Qwen 14B 23/40；Qwen 72B 62/80；Yi 6B 20/32（pos −5）；Yi 34B 37/60；Gemma 2B 10/18（pos −2）；Gemma 7B 14/28；Llama-2 7B 14/32；13B 26/40；70B 21/80；Llama-3 8B 12/32（pos −5）；Llama-3 70B 25/80（pos −5）。多数在归一化深度 0.26–0.78，集中 0.4–0.65。
- **干预公式**：① 加法 x^(l) ← x^(l) + r^(l)，**只在提取层 l**、所有 token 位置（诱导拒答）；减法 x − r 用于绕过（Appendix I.1）；② 方向消融 x ← x − r̂r̂ᵀx，在**每一层**的 attention 后与 MLP 后两处、所有位置；③ 权重正交化 W_out ← W_out − r̂r̂ᵀW_out（embedding、attention out、MLP out 及偏置），与②严格等价（Appendix E）。
- **推理协议**：贪心解码，最多 512 token；默认 chat 模板；HarmBench 评估报告有/无系统提示两种。

## 评价口径与关键数字
- refusal_score：回复含任一拒答子串（"I'm sorry"、"As an AI"、"I cannot"…）即 1。safety_score：Llama Guard 2 判 safe 为 1。
- **Fig 1 / Fig 3**：消融后 13 个模型的拒答率与安全分大幅下降；单层加法让无害指令拒答率升至接近 1。
- **Table 2 HarmBench ASR（有系统提示 / 无系统提示）**：Llama-2 7B Ortho 22.6 (79.9)，GCG 34.5；Llama-2 13B 6.9 (61.0)；Llama-2 70B 4.4 (62.9)；Qwen 7B 79.2 (74.8)，GCG 79.5；Qwen 14B 84.3 (74.8)；Qwen 72B 78.0 (79.2)。Llama-2 对系统提示极敏感（12 个系统提示下 ASR 均值 30.0%、SD 23.3%），Qwen 不敏感（76.7%、SD 5.9%）。
- **Table 8 能力（正交化 / 基线 (差)）**：MMLU 变化 −2.0 … +0.2，多数 |Δ|<1；GSM8K 除 Qwen 7B（−6.3）外 |Δ|≤1.6；**TruthfulQA 全部下降**：Qwen 1.8B −4.6、Yi 6B −5.9、Gemma 2B −5.4、Llama-3 8B −3.4、Llama-3 70B −2.3。作者解释：TruthfulQA 的 misinformation/stereotypes/conspiracies 类题与拒答"领地"重叠。
- **Table 9 CE loss**：方向消融几乎不增 loss；**加法（减 r）明显增 loss**（on-distribution Qwen 1.8B 0.284→0.293 消融 vs 0.586 加法），Fig 22 显示加法把无害激活推出分布。
- **Table 10 Llama-3 8B**：无干预拒答 0.95/安全 0.97；消融 0.01/0.15；加法 0.01/0.16；LoRA 微调 0.00/0.08。
- Appendix J：基座模型对该方向的表达与 chat 模型相似 → 方向是预训练已有、微调时被"挂上"拒答。
- §5：对抗后缀压低末 token 在拒答方向上的投影，并劫持写入该方向的注意力头（Qwen 1.8B，H12.10/H14.2 等）。

## 与 博士方案的关系
- 重叠点：均值差 + 多层多位置候选 + 验证集选层，是我们 C 方向估计与选层的直接先例；"加法推出分布、消融更外科"的发现对我们干预公式的选择有直接影响；MMLU/GSM8K "<1% 平均掉分" 的报告格式与我们 C4 的"≤1 分"口径一致；l<0.8L 的约束是"晚层不适合写"的早期实践。
- 冲突点：
  1. **C 方向 ≈ 拒答方向？** 我们用"不确定就说不知道 vs 必须给确定答案"估的"承诺方向"，其行为表现（"I don't know / I cannot"）与 Arditi 的拒答方向高度相似（CAST 的拒答关键词表甚至直接含 "don't know"）。若 cos(C, r_refusal) 很高，审稿人会说 C 就是拒答方向的翻版，C1 的"新方向"主张会被质疑。**必须报告 C 与 Arditi 拒答方向的余弦相似度及交叉干预（加 C 是否诱发对有害请求的拒答变化；加 r 是否改变弃答率）**。
  2. **TruthfulQA 与拒答纠缠**：去掉拒答方向 TruthfulQA 一致掉 1–6 分，说明"真实性评测"的一部分分数来自"愿不愿意反驳/回避"。这正是我们 E/C 框架的论据（TruthfulQA 混了 E 和 C），但也意味着我们若用 TruthfulQA 做 E 的指标，J 的变化可能来自 C 泄漏。
  3. 作者自己承认拒答方向语义不清（可能是"harm/danger"）——我们声称 C 是"承诺"，同样需要防止它其实是"话题危险度"或"问题难度"。
- 可借用点：① 候选选择三指标（bypass / induce / KL）+ 层上限约束，可改造成我们 LA-Score 的**验证口径**（LA-Score 预测 vs 这种暴力验证选出的层）；② 末 token 拒答 token 概率 logit 作为免生成的快速代理——可做"弃答代理指标"（"I don't know" 首 token 概率）加速门控阈值标定；③ 方向消融 vs 加法的 CE loss 对比表；④ 基座 vs chat 模型方向表达对比（我们可查 E/C 是否在 base 模型就存在）；⑤ 13 模型 1.8–72B 的覆盖范围与"<1% 掉分"的表述。
- 明确差别：Arditi 是单方向、单行为（拒答）、不涉及真实性/证据、不做解耦、不做门控、不做选层预测器（暴力搜索）。我们的新意是把"拒答/回避"这类承诺行为与"知不知道"分开，并证明两者可独立控制；但前提是先证明 C ≠ r_refusal 或至少说明关系。

## 对四条主张的威胁等级
| 主张 | 威胁 | 理由 |
|---|---|---|
| C1 解耦 | 中 | 我们的 C（承诺/弃答）方向很可能与其拒答方向高度共线，需正面比较；其 TruthfulQA 随拒答方向消融而下降，说明真实性评测本身混有 C，支持我们的动机但也威胁"E 改 J 不改作答率"的干净性。 |
| C2 选层 | 低 | 暴力搜索 |I|×L 候选 + 验证集，是我们要替代的基线；l<0.8L 约束与"晚层不可写"一致，可引用为先例。 |
| C3 门控 | 低 | 明确指出加法会无差别诱导拒答（CAST 据此做门控），不构成威胁，构成动机。 |
| C4 泛化 | 中 | 其 13 模型 1.8–72B 的覆盖远宽于我们 3 族 0.6B–8B；"MMLU <1%"口径一致但 TruthfulQA 的 1–6 分下降提示我们的 C 干预也可能在 TruthfulQA/校准类指标上有副作用，需单独报告。 |
