# 2311.09677 · R-Tuning: Instructing Large Language Models to Say 'I Don't Know'
- 作者 / 机构 / 发表处与年份：Hanning Zhang*、Shizhe Diao*、Yong Lin*（共同一作，HKUST）、Yi R. Fung、Qing Lian、Xingyao Wang、Yangyi Chen、Heng Ji、Tong Zhang（UIUC）。**NAACL 2024 主会**（我记忆中获 Outstanding Paper，需核实）；arXiv v3 2024-06。
- 权威度与严谨度判断：**顶会已发表（方法简单、实验面广，但指标口径有坑）**。理由：3 个模型（OpenLLaMA-3B、LLaMA-7B、LLaMA-13B）、9 个数据集、单任务 + 多任务 + 3 个"不可答"基准；有无监督变体、替换变体、min-loss 变体等消融；代码开源（github.com/shizhediao/R-Tuning）；无人工评估；主指标"愿答题上的准确率"是选择性预测指标，必须配合 answer rate 读，论文正文图 3 只报前者，answer rate 藏在附录表 8。

## 一句话核心主张
幻觉的一个根源是指令微调逼模型对每道题都作答、包括它参数里根本没有的知识；**R-Tuning（Refusal-Aware Instruction Tuning · 拒答感知指令微调 · 先查模型哪些题本来就会，不会的题就教它说"我不确定"）**：先让预训练模型做一遍训练集，答对的归"已知"D1、答错的归"未知"D0，然后在答案后面补一句 "I am sure / I am unsure" 微调；结果模型学会拒答未知题、愿答题的准确率上升、AP 提高、校准更好，且拒答能力是跨任务迁移的"元技能"。

## 方法细节
- **已知/未知切分（§2.1，监督版）**：对训练集每个 (q, a)，用原始预训练模型 M 生成答案；**生成的前几个 token 包含真答案 → 已知 D1，否则 → 未知 D0**（不用 exact match）。多选题限制只生成一个 token，取候选项 logits 的 argmax。注意：**单次贪心、一次判定**；MMLU 四选一随机猜中 25% 也会被归"已知"，切分有系统噪声，论文未校正。
- **无监督版 R-Tuning-U（§5.1）**：同一题温度 0.7 采样 k=10 次，按答案频率算熵 u = −Σ p(aⱼ|q) ln p(aⱼ|q)；**熵最高的 50% 归 D0**（硬性对半切）。
- **数据构造（§2.2，padding 法）**：模板 `Q: {Question}, A: {Answer}. Are you sure you accurately answered the question based on your internal knowledge? I am sure` / `I am unsure`。D0 **仍保留真答案**，只是后缀改成 unsure。替换法 R-Tuning-R（附录 A.3）：D0 的答案直接换成 16 条不确定表达之一（"The answer is unknown." "I'm not sure." 等，来自 SelfAware）。Min-loss 变体（附录 A.8）：loss = min(L(预测, 真答案), L(预测, IDK))，两阶段训练。
- **训练**：LMFlow，1 epoch，lr 2e-5，batch 4，A100-40GB；只对答案与不确定表达部分算交叉熵。
- **推断**：先让模型答题，再追加 "Are you sure…? I am" 让它输出 sure/unsure；**置信度 = 答案概率与 sure 概率的加权组合**，用于算 AP。
- **数据（附录表 6）**：ParaRel（改写成 QA，25,133 对、31 个领域；前 15 领域为 ID：训练 5,575 / ID 测试 5,584；后 16 领域 OOD 测试 13,974）、MMLU（训练 2,448 / ID 测试 2,439 / OOD 9,155）、WiCE（3,470 / 958，三选一）、HotpotQA（抽 10,000 训练 / 7,405 dev 测试）、**FEVER（抽 10,000 训练 / 9,999 测试，改成三选一 supports / refutes / not enough info，给证据）**、HaluEval-QA（10,000，仅作多任务 OOD 测试）、SelfAware 不可答 1,032、FalseQA 2,365、NEC 2,078。
- **基线**：Pretrain-T（原模型全测试集）、Pretrain-W（原模型只在 R-Tuning 愿答的题上评，用来验证愿答题确实在参数知识内）、Vanilla（全量标准指令微调）；§5.2 另加 Vanilla-C（Vanilla 训练后测试时采样 10 次取多数、以一致性当置信过滤）、Vanilla-U（Vanilla-C 的答案 + R-Tuning-U 的 sure 概率）。

## 评价口径与关键数字
指标定义：
- **accuracy（式 3）= 答对数 / 愿答数**——分母是模型自己选的，纯 precision 型；
- **answer rate** = 愿答题占比（附录表 8 才有）；
- **AP（式 4–6）**：按置信度从高到低排序，precision–recall 曲线下的平均精度，无需阈值；
- **refusal rate**：不可答集合上拒答比例；
- **ECE**（附录表 16）。

## 与 博士方案的关系
- 重叠点：
  1. 我们问答级评测按"baseline 是否答对"切"已知题/未知题"——**就是 R-Tuning 的 D1/D0 监督切分**，必须引用并说明我们怎么处理其噪声（单次贪心、多选猜中）。建议：多次采样一致性（他们的 R-Tuning-U 思路）+ 贪心双重判定，或报告切分对采样种子的稳定性。
  2. 我们的"转为弃答"= 他们的 refusal；"纠正/损伤"= 愿答题准确率变化。他们的 **accuracy-on-answered + answer rate + AP + 不可答集拒答率** 四件套是弃答类工作的标准口径，我们至少要报前两项，否则审稿人会问 answer rate。
  3. 他们的 Pretrain-T 基线显示：**只靠 prompt 允许拒答，原模型在不可答题上只拒 2–28%**——这是我们 C 方向用 system prompt 估计时要面对的事实：prompt 对拒答的行为效应在未微调模型上可能很弱，C 方向的信号量可能不够，需要先验证 prompt 对比确实改变作答率。
- 冲突点（他们的结论会不会打我们的某条主张）：
  1. **§5.2 的发现打 C1**：训练模型表达不确定性之后，愿答题的准确率也上升了（R-Tuning-U > Vanilla-C，表 14），作者假说是"预测不确定性把置信信息嵌入隐藏表征，使答易题时隐藏状态更自信"。这意味着在微调层面"承诺"和"证据/作答质量"是耦合的。我们声称 C 方向只改作答率不改 J，必须给出与此相容的解释（例如：微调改的是整个表征，我们的 rank-1 干预只动一个方向）并用数据证明 C 干预后愿答题 J 不变。
  2. **C3 的竞争基线**：R-Tuning 是训练式的"按输入门控"（模型自己决定答不答）。我们免训练的门控要么与 R-Tuning（或至少其 Pretrain-T 允许拒答 prompt 基线）对比，要么明确声明不同赛道（无需训练数据、不改权重、可逆）。他们表 8 的 MMLU-3B answer rate 5.79% 是"门控把作答率压没"的反面教材，我们报门控结果时要把作答率贴在旁边。
- 可借用点（方法、数据、指标、对照）：
  1. AP 指标：无阈值、衡量"置信度能否把对错排开"，与我们的 J 同属判别力口径，可作为问答级的判别力指标；配合 answer rate（准则侧）就是 SDT 分解的问答版。
  2. 16 条不确定表达列表（附录 A.5）可作我们判定"弃答"的字符串匹配词表。
  3. 不可答基准 FalseQA（2,365，违常识题）、NEC（2,078，虚构概念）、SelfAware（1,032 不可答 + 2,337 可答）可测 C 方向在"本就该拒答"题上的效果，比 TruthfulQA 更干净。
  4. FEVER 的三选一改造（给证据 + supports/refutes/NEI）是我们如果把 FEVER 当问答集的现成格式；注意他们是**带证据**的 NLI 口径，不是闭卷真假判断。
- 明确差别（我们还能声称什么是新的）：他们改权重、靠微调数据学"知道自己不知道"；我们在残差流找一个承诺方向、推理时按输入门控、不改权重。他们没有分开"判别力"与"准则"——AP 与 accuracy 都受两者影响。我们的 J/B 口径可以重新解读他们的结果：R-Tuning 到底是提高了判别力（AP 升）还是只是移动了准则（answer rate 降）？表 1 ParaRel ID 的 AP 几乎不动但表 8 的 accuracy 大升，暗示主要是准则移动。

## 对四条主张的威胁等级
| 主张 | 威胁 | 理由 |
|---|---|---|
| C1 解耦 | 中 | §5.2：学不确定性连带提升作答准确率，说明微调层面承诺与证据耦合；我们需在干预层面证明 C 只动作答率。 |
| C2 选层 | 无 | 不涉及内部层。 |
| C3 门控 | 高 | 直接竞争基线（训练式按输入拒答）；其 accuracy/answer-rate 权衡表明"门控优于全局 α"的比较必须固定作答率或报 AP 曲线，否则审稿人会说门控只是多弃答。 |
| C4 泛化 | 低 | 他们的拒答元技能跨任务迁移是正面先例；但 3B 模型在 MMLU 上近随机（AP 24.96）提醒我们 0.6B 模型在多选集上可能没有可用的 E/C 信号。 |

## 值得引用的原句（≤3 句，标注 section/页）
1. "Training a model exclusively on correct answers inadvertently teaches it to guess rather than admit its ignorance." （§1，p.2）
2. "If the model's prediction matches the label, the question is assigned to the certain set D1, and otherwise, it belongs to the uncertain set D0." （§2.1，p.3）
3. "When the model is proactive in answering more questions, it will inevitably make more mistakes. As the intrinsic parametric knowledge of the model is limited, there is no method to fine-tune a model with both high accuracy and a high answer rate." （Appendix A.8，p.15）
