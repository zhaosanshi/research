# 2603.22161 · Causal Evidence that Language Models use Confidence to Drive Behavior

- 作者 / 机构 / 发表处与年份：Dharshan Kumaran（通讯）, Nathaniel Daw（Princeton）, Simon Osindero, Petar Veličković, Viorica Patraucean。Google DeepMind。**Nature Machine Intelligence (2026)，doi:10.1038/s42256-026-01293-x**；arXiv v3 2026-09-18。数据与代码在 OSF（view-only 链接）。
- 权威度与严谨度判断：**[顶刊已发表 + 大机构]**。理由：4 个模型做行为学（GPT-4o、Gemma 3 27B、DeepSeek-V3 671B、Qwen3-Next-80B），每阶段 n=1000 题；统计极严（嵌套逻辑回归 + AIC/LRT、并行中介分析（mediation analysis · 把"干预→结果"的总效应拆成走哪条路的分量）+ 聚类 bootstrap、难度/RAG/句向量三组对照协变量）。弱点：**activation steering 只做了 Gemma 3 27B 一个模型**；steering 向量只用 25+25 条试次的均值差构造；**没有随机方向对照**；没有通用能力副作用检测；全是 4 选 1 多选题（MCQ），不是自由生成。

## 一句话核心主张
LLM 决定"答还是弃答"走的是一条两阶段通路：阶段 1 形成内部置信度表示，阶段 2 把它跟一个阈值比较（σ((T−C)/τ)）。证据：(a) 校准后的 logprob 置信度预测弃答的效应量比题目难度、知识可检索性、句子语义特征大一个数量级；(b) 在 Gemma 3 27B 中间层加/减"高置信度向量"能把弃答率从 66.5% 拉到 7.0%，中介分析显示 67% 效应走"置信度重分配"、26% 走"策略阈值移动"；(c) 指令阈值 T 从 0 到 100 扫，模型按 Phase 1 置信度与 T 的差来弃答，说明阈值只动阶段 2 不动阶段 1；(d) **口头置信度（verbal confidence · 让模型用另一次前向传播自评"我有多大把握"）判别对错的能力更差（AUROC 0.53–0.60 vs 0.63–0.75），却在全部 4 个模型中独立于 logprob 置信度预测弃答**，两者相关只有 r≈0.3–0.4——说明内部置信度表示是多维的，有"生成性"和"评价性"两个可部分分离的读出通道。

## 方法细节
**数据**：SimpleQA 转成 4 选 1（金标 + 相似干扰 + 不相似干扰 + 无关干扰，由 Gemma 3 12B 生成），1000 题校准集 + 1000 题主实验集。全部题目都可答。

**四阶段范式**
- Phase 1：无弃答选项，取答案 token 的 logprob → temperature scaling 校准（GPT-4o τ=4.1, ECE 0.046, AUROC 0.90；Gemma τ=5.1, AUROC 0.81；DeepSeek τ=29.3；Qwen τ=4.9）。另一遍前向传播要口头置信度（10 档，"No chance"…"Almost certain"）。
- Phase 2：加第 5 项"没有明显正确答案就选 5"。GPT-4o：30.0% 对 / 13.4% 错 / 56.6% 弃答；Gemma 27.2% 弃答；DeepSeek 82.0%；Qwen 43.8%；**Llama 3.1 70B 只有 4% 弃答，被剔除**。
- Phase 3（仅 Gemma 3 27B）：steering 向量 = Phase 2 下 prompt 最后 token 的残差流，取"答对且选了真选项"的试次，按置信度边际 m = max C_i − C_abstain 排序，取 25 条高边际与 25 条低边际（按所选选项位置平衡），`v_high = μ(H) − μ(L)`，`v_low = −v_high`。向量**缩放到该层残差范数的 3%**，再乘 α∈{0.5,1,1.5,2}；`r̃(l) = r(l) + α v(l)` 加在单层上。500 道 held-out 题。
- Phase 4：指令"先在心里给 0–100 置信度，若高于 T% 就答，否则输出 5"，T 从 0 到 100 步长 10。Gemma 对 GPT-4o 版 prompt 不响应（T<80% 时弃答 <5%），改用 Gemini 2.5 Pro 生成 20 条改写挑弃答率最高的一条。

**中介分析（Phase 3）**：X = 带符号的 steering 强度；M1 = 净置信度移动（Δmax 真选项置信度 − Δ弃答置信度）；M2 = 策略移动（固定置信度时，steered vs baseline 校准曲线预测弃答概率之差）；逐题 within-item 基线校正；聚类稳健标准误 + 1000 次聚类 bootstrap。

**激活解码（§4.5.1）**：Gemma Phase 1 "Answer:" 冒号 token（AC）的激活上做 ridge 回归（5 折）预测口头置信度与校准置信度。

## 与 博士方案的关系
- 重叠点：
  1. **两阶段框架 = 我们 E/C 的行为学版**：阶段 1"置信度形成"≈ E（证据强度），阶段 2"阈值策略"≈ C（承诺/愿不愿意下结论）。他们用指令阈值证明阶段 2 可独立于阶段 1 被操控（Phase 1 置信度在所有 T 下保持预测力），这是"证据与承诺可分离"在行为层面的顶刊级证据，我们可直接引用作前提。
  2. 口头置信度 ≠ logprob 置信度（r≈0.3–0.4）且各自独立驱动弃答——"模型嘴上说的把握"与"证据"是两个信号。
  3. 他们的 steering 协议（3% 残差范数归一化、单层加、500 题 held-out、按层扫描 30–40）可作为我们 C 方向干预的参照实现。
- 冲突点：
  1. **他们的 steering 方向是"置信度"而非拆开的 E 或 C**：同一向量既改变弃答率（59.5 pp）又改变已答题正确率（59.2→53.7），即它同时动了"答不答"和"答得对不对"——这正是我们说"现有干预把两个方向混了"的实例。但审稿人也可能反过来问：既然一个方向就能做到 67% 走置信度、26% 走策略，你们凭什么说能把它干净拆成两个正交方向？我们必须用交叉效应（推 C 不改 J、推 E 不改作答率）回答。
  2. **Llama 3.1 70B 几乎不弃答（4%）**：我们用 system prompt 对比在 Llama 族上估 C 方向时，"不确定就说不知道"那一侧可能根本激发不出弃答行为，C 方向估计会很弱——与 2607.05013 里 Llama 上 steering 无效遥相呼应。C4 要预先验证 Llama 在我们 prompt 下有足够弃答率。
  3. 他们发现正确性 probe 的残差不预测弃答（AUROC .51）——即模型弃答不依赖"对答案正确性的特权访问"，只依赖置信度。若我们的 E 方向只是"正确性/真伪"方向，按他们结论它对弃答没有独立影响——这其实支持我们 2×2 里"E 不改作答率"那一格，可借用。
- 可借用点：
  1. **中介分析框架**：把我们干预对弃答/正确率的效应拆成"证据重分配"与"阈值移动"两条路，直接量化 E 推了多少走 C 的路（泄漏）。这是比 cos 更有说服力的解耦证明。
  2. 对照协变量套路：题目难度（多次采样正确率）、RAG 可检索分、句向量主成分——证明效应不是题目表面特征。
  3. 他们的"读层≠写层"数据：校准置信度在最后一层（61）读得最好（R² .74），口头置信度在 37–40 层读得最好，但 steering 效果峰在第 31 层——**读与写的最佳层明确不同**，他们没当主张；我们可以引为外部佐证。
  4. SimpleQA→MCQ 的数据构造与 Phase 1/2/4 协议，可作为我们 C4 的第五个数据集。
- 明确差别（我们还能声称什么是新的）：
  1. 他们没有在激活层面找"阈值/承诺"方向，阶段 2 只靠指令操控；我们的 C 方向就是阶段 2 的激活层实现。
  2. 他们没有分离 E 与 C 两条方向并做交叉干预。
  3. 他们 steering 单模型、无随机方向对照、无自动选层、无门控、无通用能力检测；我们全有。
  4. 他们只做 MCQ 单 token；我们做自由生成 + 事实陈述真伪。

## 对四条主张的威胁等级
| 主张 | 威胁 | 理由 |
|---|---|---|
| C1 解耦 | 中 | 顶刊已证明"置信度形成"与"阈值策略"行为上可分，但他们的激活方向把两者混在一起（同时改弃答率与正确率）。概念先占，激活层拆分未做；我们要用交叉效应和中介分析证明真拆开了。 |
| C2 选层 | 低 | 他们按层扫描选峰（第 31 层），无自动分数；但数据里读写最佳层不同，可作我们主张的佐证而非威胁。 |
| C3 门控 | 低 | 无门控；Phase 4 指令阈值是行为层门控，不是激活层。 |
| C4 泛化 | 低-中 | steering 仅 Gemma 27B；但 Llama 70B 弃答 4% 的事实是我们 Llama 族 C 方向估计的预警。 |
