# 2610.08559 · Latent space bias directions in LLMs capture confidence, not fairness

- 作者 / 机构 / 发表处与年份：Stephanie Buttigieg（剑桥大学天文所，Visa 实习期间完成）, Maeve Madigan, Parameswaran Kamalaruban, Stuart Burrell（Visa Inc. Risk and Security AI Lab, UK）。arXiv v1 2026-10-06，ACM 模板（带 CCS Concepts）——应为 FAccT/ACM 系列投稿稿，**目前仅 arXiv**。无代码链接。
- 权威度与严谨度判断：**[普通预印本（企业实验室 + 高校），实验较扎实]**。理由：4 个模型族 × base/instruct = 8 个 7–9B 模型；BBQ 15,960 条 + StereoSet 2,106 + CrowS-Pairs 1,018 + MMLU 10k 子集 + OpenBookQA 全集；70/30 切分、配对题不跨切分；有 OOD 迁移测试（偏见方向在无偏见数据集上分高/低似然）、有独立构造的置信度方向做余弦比对、有通用能力副作用（MMLU/OBQA 准确率与熵）。弱点：无随机方向对照；无人工评估；只测多选题概率而非生成；一作背景是天体物理（非 NLP 主流圈）。

## 一句话核心主张
用"有偏 vs 反偏提示"均值差 / 逻辑回归估出来的"去偏方向"，实际上**主要编码的是模型置信度**（从高似然 token 指向低似然 token）而不是偏见：同一个分类器分 BBQ 消歧题的有偏/反偏只有 AUROC 0.57，分"模型最偏好/最不偏好的选项"却到 0.94，在毫无社会偏见概念的 MMLU/OBQA 上也能到 0.7–0.9；沿它 steering 看似降低偏见分，其实是**让模型整体不自信——有弃答选项就弃答，没弃答选项就把概率摊平（熵升）**，连 MMLU/OBQA 的熵也一起升，BBQ 消歧题正确率掉（Llama-Inst 0.87→0.52）。

## 方法细节
**数据**：BBQ（有歧义/消歧两种上下文；歧义题正确答案是"不知道"，消歧题有确定答案且有偏/反偏各正确一半）、StereoSet 句内填空子集、CrowS-Pairs（只保留一词之差的对，转成填空选择）；MMLU 10k、OpenBookQA ~6k 作无偏见对照。

**模型**：Llama-3.1-8B、Falcon3-7B、Ministral-3-8B、Qwen3.5-9B，各 base + instruct，共 8 个。贪心解码。

**读取位置**：把候选答案字母追加到 prompt 后，取**最后一个 token（答案字母）**的隐藏状态；每个候选一次前向传播。答案概率另用不追加字母的 prompt 读 next-token logits。

**偏见分类器（§4.2）**：逻辑回归，只用有偏/反偏两类（排除中性/弃答选项，因为那是"模型弃答"的平凡信号）；只在歧义上下文上训练；逐层训练取 held-out AUROC 最高层为"最佳层"（Llama-3.1-8B-Inst BBQ 第 14 层 AUROC 0.75；StereoSet/CrowS-Pairs 可达 0.91–0.95；Qwen3.5-9B-Base 最佳层是最后一层 26–30）。

**去偏方向（§5.1）**：CAA（Contrastive Activation Addition · 对比激活加法 · 两类提示激活均值相减当方向）`v_b = (1/N) Σ (h_anti-biased − h_biased)`，在最佳层。另在同层用 MMLU/OBQA 构造**置信度方向** `v_c` = 最偏好选项 − 最不偏好选项的均值差，与 v_b 比余弦。

**干预公式**：`h' = h + α v̂_b`（单位向量），α ∈ [−1, 2] 步长 0.5；"自然幅度" α_nat = ‖v_b‖（Llama-Inst BBQ 0.18、StereoSet 0.79、CrowS 0.90；Falcon 高达 10–20）；报表取 α̃ = max(α_nat, 1)。

**评价**：AUROC；BBQ 偏见分 s_DIS = 2·n_biased/(n_biased+n_anti) − 1，s_AMB = (1−acc)·s_DIS；StereoSet/CrowS 偏见答案百分比；准确率（仅有金标数据集）；答案熵。每个偏见数据集都做"有弃答选项"与"无弃答选项"两个版本。

**分类器到底在分什么（Llama-3.1-8B-Inst, BBQ 消歧测试集）**
| 标签 | AUROC |
|---|---|
| 有偏 vs 反偏 | 0.57 |
| 模型最高概率选项 vs 最低概率选项 | 0.94 |

**Table 2：偏见分类器在无偏见数据集上分高/低似然选项的 AUROC**（BBQ 歧义训练）：Llama-8B-Inst MMLU 0.72 / OBQA 0.88；Qwen3.5-9B-Base 0.80 / 0.87；8 个模型在 BBQ 消歧上 0.79–0.95。

**作者自述局限/讨论**：偏见提示本身就自带似然差（有偏句在预训练语料里更常见），所以置信度不是"混进来的"，是这类对比对的固有特征；未来要找独立于置信度的偏见方向；呼吁检查其他基于线性表示假设的 steering 向量（尤其安全领域）是否同样被置信度主导。

## 与 博士方案的关系
- 重叠点：
  1. 他们发现的"置信度方向"（从高似然指向低似然 token），沿它推会让模型弃答或摊平概率——**这就是我们的 C 方向在多选题上的样子**。他们的 Fig. 1 右图（弃答概率随 α 单调上升、有偏/反偏同降）就是"C 改作答率"的图。
  2. 他们证实 steering 方向在 MMLU/OBQA 上"准确率几乎不变但熵大涨"——这是我们 C4"MMLU 掉分 ≤1"口径的直接参照，也是警告。
- 冲突点（**本组最大的方法学威胁**）：
  1. **E 方向可能也是置信度方向**：真/假陈述对（FEVER、CounterFact）里真陈述几乎必然比假陈述似然高——和"有偏句比反偏句似然高"是同一种混杂。按他们的逻辑，我们用均值差/逻辑回归估出来的 E 很可能与 C（也是置信度轴）高度共线，cos 可能像他们一样达到 0.5–0.9。**若不排除，"两个不同方向"的 C1 直接不成立。**
  2. 他们的 Spearman 诊断（分类器分数与答案概率的相关在"事实决定置信度"的消歧题上反而更强）是审稿人会拿来打我们的现成工具：如果我们的 E probe 分数与 token 概率在 MMLU 上强相关，E 就是置信度而非证据。
  3. 他们展示**不门控的置信度方向干预会让模型在信息充足的题上也弃答**（BBQ 消歧 0.87→0.52）——这是 C3 要防的失败模式，但也意味着我们"全局 α 基线"会很惨，对比门控时要公平报告基线最佳 α 下的结果。
  4. **"MMLU 掉分 ≤1"不够**：他们 8 个模型准确率基本都 ≤1 点变化，但熵翻倍——仅报准确率会被指为掩盖副作用。我们必须同时报答案熵/置信度分布变化。
- 可借用点：
  1. **置信度混杂的三件套诊断**，我们必须对 E 和 C 都做：(a) 把 E/C 分类器拿到 MMLU/OBQA 上分"最高概率选项 vs 最低概率选项"，AUROC 接近 0.5 才算干净；(b) 在同层用 MMLU 构造 v_conf（最偏好−最不偏好），报 cos(E, v_conf) 与 cos(C, v_conf)；(c) 报 E probe 分数与答案概率的 Spearman。
  2. 把 E 方向对 v_conf 做正交投影后再测 J 的变化——如果投掉置信度分量后 E 仍改 J，才是真证据方向。
  3. "有弃答选项 / 无弃答选项"双格式评价：C 方向在有弃答选项时增弃答、无弃答选项时增熵——可作为 C 方向的行为签名。
  4. Qwen3.5-9B-Base 最佳读层 = 最后一层，steering 无效——**读层≠写层的鲜活反例**（读得最好的层写不动），可直接引为 C2 的动机。
- 明确差别（我们还能声称什么是新的）：
  1. 他们只有诊断没有解法；我们若能给出"去置信度后的 E 方向"（DAS 以行为而非似然为目标，或对 v_conf 正交化），就是对他们问题的正面回答。
  2. 他们研究社会偏见域；我们研究事实真伪域，但混杂机制同构，可引为跨域证据。
  3. 他们没有门控；我们的知识探针门控恰好是防"信息充足题也弃答"的机制。

## 对四条主张的威胁等级
| 主张 | 威胁 | 理由 |
|---|---|---|
| C1 解耦 | 高 | 真/假对与有偏/反偏对一样自带似然差，E 很可能被置信度主导而与 C 共线；他们的三件套诊断是审稿人现成武器。必须报 cos(E, v_conf)、MMLU 高/低似然 AUROC、正交化后的 J 变化。 |
| C2 选层 | 低 | 按 AUROC 选最佳层；Qwen-Base 最佳层=末层导致 steering 失效，反而支持我们"读层≠写层"。 |
| C3 门控 | 中 | 不门控的置信度干预让可答题弃答（0.87→0.52）——支持门控必要性，但他们没做门控，不构成占坑；需确保我们全局 α 基线公平。 |
| C4 泛化 | 中 | 8 模型显示准确率≤1 点但熵翻倍——我们的"MMLU 掉分≤1"必须加熵/置信度分布指标，否则被指掩盖副作用。 |
