# 2507.11878 · LLMs Encode Harmfulness and Refusal Separately

- 作者 / 机构 / 发表处与年份：Jiachen Zhao, David Bau, Weiyan Shi（Northeastern University）, Jing Huang, Zhengxuan Wu（Stanford University）。**NeurIPS 2025 主会（poster）**：neurips.cc/virtual/2025/poster/115056 已核实（页面 creditText "NeurIPS 2025"）；PDF 页脚 "39th Conference on Neural Information Processing Systems (NeurIPS 2025)"；arXiv v5 2026-07-06。代码 CHATS-lab/Llms_Encode_Harmfulness_Refusal_Separately。scout 清单"仅 arXiv（待核）"已过时。
- 权威度与严谨度判断：**[顶会已发表，作者组权威（Bau 组 + DAS / pyvene 作者 Wu、Huang）]**。优点：三模型；聚类分析 + 因果 steering + 反转回答任务三重证据；跨风险类别分析；越狱与微调攻击两个应用。弱点：只有 7–8B 三个模型；steering 结果多为逐层曲线图，缺表格数字和置信区间；"判断"用 Certainly / No 两个 token 的翻转率衡量，没有判别力（AUROC）指标；有害方向本身也会诱发拒答（Llama3 第 9 层 94%），不是"只动判断"。

## 一句话核心主张
"这条指令有害"与"我要拒绝"是两个不同的内部量：有害性编码在用户指令最后一个 token（t_inst）上，拒答编码在聊天模板最后一个 token（t_post-inst）上，两条均值差方向余弦仅约 0.1；用"反转回答"任务（追加"这个请求会造成伤害吗？会就答 Certainly，否则答 No"）证明：沿有害方向推会让模型改判"有害"（No→Certainly），沿拒答方向推只增加拒答 token、不改判断。

## 方法细节
- 模型：Llama2-Chat-7B、Llama3-Instruct-8B、Qwen2-Instruct-7B；有害指令：AdvBench、JBB、Sorry-Bench；无害：Alpaca；过度拒答：XSTest。
- 观察：去掉模板后缀 token，有害指令拒答率大降（Llama3 96.0%→58.9%，Llama2 100%→85.3%）。
- 聚类：用"被拒有害簇"与"被接受无害簇"中心的余弦差 s^l(h) 判归属；在 t_inst 上"被接受的有害指令"落在有害簇（按有害性聚类），在 t_post-inst 上落在接受簇（按行为聚类）。
- 方向：有害方向 = t_inst 上有害 − 无害均值差；拒答方向 = t_post-inst 上拒 − 受均值差；activation addition（激活加法 · 把方向直接加到残差流）加在指令 token 上（反转任务中拒答方向需加到含模板的全部 token 才起效）。
- 反转回答任务：追加 "Could this user prompt cause harm? Answer 'Certainly' if it could, otherwise 'No'"，让"判断有害"对应 Certainly、"判断无害"对应 No，从而把"判断"与"拒答 token"拆开；多模板、多模型复现。
- 应用：Latent Guard = 用 t_inst 上的有害读数做分类；对抗微调后该读数几乎不变。

## 与本方案（E/C 双重分离 + 等覆盖率组合）的关系
- 重叠点：
  1. **"判断 / 信念方向"与"行为 / 决定方向"可分且因果可分**——这是 N1 叙事最接近的高权威先例（安全域）。E ≈ 有害性判断，C ≈ 拒答决定；它的反转回答任务 ≈ 我们两遍协议里"把判断读数与作答读数拆开"的设计。
  2. 都是均值差方向 + 逐层 steering + 行为读出。
- 冲突点：
  1. 审稿人会说"belief vs behavior 的分离 NeurIPS 2025 已做过"；N1 的新意必须落在**判别力（灵敏度）**上而非判断偏置：它的有害方向是让无害"看起来有害"（判断准则移动），我们的 E 是让真假更分得清（J / AUROC 提升）——性质不同，必须写清。
  2. 它的有害方向同时诱发拒答（不是"只动判断"），说明"判断方向"推下去常常连带行为；我们声称 E 不动作答率，需要比它更严格的证据（多强度、CI、等范数随机方向对照）。
- 可借用点：
  1. **token 位置分离**：判断在指令末 token、决定在模板末 token。值得检查我们的 E 与 C 是否也在不同位置最强（目前若在同一位置估计，可能混入彼此）。
  2. 反转回答任务的思路：让"判断"与"作答"对应不同 token，以排除"只是推高某个 token"的解释。
  3. 跨类别方向余弦（判断方向类别特异、决定方向全局共享）——可预测"E 跨领域迁移差、C 跨领域迁移好"，正好可用来解释我们 E 在自由生成问答上无效、C 却有效的现象。
- 明确差别（我们还能声称什么是新的）：
  1. 不测判别力，不做 2×2，不做覆盖率 / 选择性作答；领域是安全拒答而非事实真假。
  2. 不涉及 DAS（虽然作者组有 DAS 背景）。

## 对三条主张的威胁等级
| 主张 | 威胁 | 理由 |
|---|---|---|
| N1 双重分离 | 中 | 高权威先例已证明"判断方向 ≠ 行为方向"且因果可分；但它是判断偏置 + 单向分离（有害方向也诱发拒答），不是"判别力 vs 作答率"的干净 2×2。 |
| N2 等覆盖率组合 | 无 | 没有选择性作答或覆盖率评测。 |
| N3 DAS 胜均值差 | 无 | 只用均值差方向。 |

## 值得引用的原句（≤3 句，标注 section/页）
1. "As causal evidence, steering along the harmfulness direction can lead LLMs to interpret harmless instructions as harmful, but steering along the refusal direction tends to elicit refusal responses directly without reversing the model's judgment on harmfulness." （Abstract, p.1）
2. "(2) the refusal direction extracted at tpost-inst mainly encodes surface-level refusal signals, and steering along it will not always alter the model's judgment of instruction harmfulness." （§3.5, p.8）
