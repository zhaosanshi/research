## 1. 研究问题

模型常常"内部知道、嘴上说错"或"不知道却硬答"。我们的假设是：这两件事由残差流里两个不同的低秩方向分别控制——**E（证据）**决定判得准不准，**C（承诺）**决定答不答。如果成立，就能分别调：提高判别不增加拒答，调拒答不伤判别。

## 4. 放弃的线与原因

| 线 | 原因 |
|---|---|
| 知识类数据集（FEVER、CounterFact、GoT） | 模型内外没有差距，E 没有可提的空间 |
| SimpleQA 自误解集 | 训练对数从 96 加到 740、加思维链都救不回来（符号准确率 0.58 → 0.59），是模型能力限制 |
| Mistral-7B | 旧协议：两种估计器都没有 E 效果，增益只是门槛漂移。**统一协议（11-08）下不再是放弃的线：E 行成立——L13 ΔJ +0.055 [+0.026, +0.085]、ΔAUROC +0.018、作答率不动，胜均值差；2×2 两行成立（`10`）** |
| Gemma-3-12B | 中层没有可交换的方向；秩 4 / 16、全句写入、双向目标都试过 |
| 大模型（Gemma-3 12B / 27B、Qwen3-14B / 32B、Mistral-Small-24B） | 陈述级 19 / 20 正，但问答级 12B 以上变差；Qwen3-32B 无差距 |
| LA-Score 免训练选层 | 写层误差 5–10 层 |
| 低损伤变体（小强度、约束损伤） | 损伤少了，收益也没了 |
| 估计集扩样 96 → 288 对 | 没有检出显著收益；方向余弦 0.96–0.99 |
| Gemma-4B 巨激活维度的处理 | 只解释均值差一个配置的崩溃；赵磊判断"没有进论文的必要" |
