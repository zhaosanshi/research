## 2. DAS怎么选层：我的明确意见

**每层独立训练自己的DAS方向，再用DAS自身的实际干预效果选写层。保留全层搜索，不用均值差最佳层替代，不用探针最准层或最低训练损失替代。**

DAS（分布式对齐搜索 · 交换内部表示的一小部分，训练能改变指定反事实输出的方向）这里有三件不同的事：

- **探针读层**：哪层容易读出真假，只用于分析或以后门控。
- **DAS训练层**：来源和基础样本在同一层交换，各层各训一条方向。
- **DAS写层**：按准备部署的写入方式，在哪层真正改善调参集表现。

“读写层分开”不等于把第13层的原始向量直接搬到第11层，也不等于当前代码已经学了跨层变换。

Claude现有**真假任务**的全层DAS已经按正确原则实现，旧96对主协议的结果是：

| 模型 | 探针读层（有下述分折局限） | DAS单层调参选出 | 均值差自己选出 | 加入预定三层窗口后，DAS选出 |
|---|---:|---|---|---|
| Llama-3.1-8B，32层 | 13 | **11层，α3** | 16层，α3 | **10–11–12层，α2** |
| Qwen3-8B，36层 | 26 | **18层，α3** | 20层，α3 | 仍为单层18 |
| Gemma-3-12B，48层 | 22 | 20层，α3，**无稳定收益** | 25层，α2 | 仍为单层20，无稳定收益 |

来源：第4轮全层报告、第5轮窗口报告及其JSON，详见[选层代码审计](das_audit_20261104/layer_audit.md)。这些是陈述判断结果，**不能直接把11/18层定成问答DAS的最终层**；它们最多作为三题线路核验的起始层。

问答版的正式选层规则建议固定为：

1. 模型有多少层，就分别训练多少条单层DAS；首轮种子42。均值差同题同位作对照，不能先按均值差筛掉DAS层。
2. 在192道调参问题上，按将来实际使用的无来源写入方式，逐层比较共同强度网格。主比较使用连续写入，强度沿用E25的1/2/3，零强度为基线。
3. **最终写层按无自评后缀的实际问答效果选。** 以真实自由回答的净纠正为目标，建议预先采用实际作答率变化不超过±3个百分点的约束——数值沿用旧规则，测量对象改为真实回答，不能说旧实验已经检验过这个约束。同分优先损伤更少，再取较小强度、较浅层。自评交换成功率和候选答案概率仅作诊断／代理，不能直接宣布找到最佳生成层。
4. 所有层若只做便宜的候选概率评测、真实生成只测少数层，必须明确称为“代理筛选后的最佳候选”，不能写“全层生成最优”。这是预算取舍，不偷偷混用指标。
5. 没有合格配置就记录没有找到；测试结果不用于换层。正式测试前冻结规则和配置。

**单层与多层都要有位置，但按顺序做。** 先把单层主链做完整，随后做预先写明的连续三层窗口对照；每层用自己的方向，重新在调参集选择窗口和强度，DAS与均值差使用同样的窗口候选。当前窗口是“各层独立训练后组合”，不是联合训练多层DAS。相同α不等于单层与三层的总扰动相同，应记录实际扰动，不能把强度增加误写成多层机制的必然优势。

## 3. 问答DAS方法：支持Claude路线A作为第一版，补齐具体定义

**推荐实现路线A，名称明确为 `qa_das_ptrue_ce_bidir_v1`：问答答案末位交换、后置真假自评读出、双向反事实标签监督。** 均值差是匹配对照，不是替代DAS的论文主方法。ReFT式全答案微调暂不引入这一个版本。

这修正了上一轮“暂不采用A”的优先级建议；保留的科学判断是：**A是否改善自由回答仍需测，不能把自评成功当作生成成功。** 选择A是因为它能承接现有配对数据、DAS交换原语和问答方向代码，形成一个清楚可查的第一版，不是因为文献已保证它成功。

| 要素 | 第一版具体做法 |
|---|---|
| 数据 | 原96道估计题，剔除个人拒答后使用合格真假答案对，不跨集合补题；当前清理后是92对。DAS与均值差用完全相同的问题和答案 |
| 输入 | **保留现有问答提示＋候选答案的完整前缀**，只在答案后追加固定真假自评后缀；不把前文重排成另一套提示 |
| 训练读取 | 来源答案最后一个内容词元、第ℓ层残差流 |
| 训练写入 | 基础答案最后一个内容词元、同一第ℓ层；两条答案长度不同，分别保存索引 |
| 监督位置 | 自评后缀末端预测真假标签的位置，**与交换位置分开** |
| 正向目标 | 错答案作为基础、对答案作为来源，交换后自评目标为True |
| 反向目标 | 对答案作为基础、错答案作为来源，交换后自评目标为False；同一条方向同时满足两向 |
| 损失 | 双向金标CE（交叉熵 · 提高干预后应有标签的概率），完整词表计算；不复制源模型可能错误的自然自评分布 |
| 参数预算 | 秩1、冻结底座；先沿用当前学习率1e-3、10轮、每对更新、种子42及裁剪设置，不同时搜索新的训练参数。旧KL模型仍单独保留 |
| 无来源部署 | 沿用E25中心化投影放大，提示末位及随后每个预测下一词的位置写入；提示阶段和答案阶段使用各自中心，DAS/均值差共用这些中心 |
| 对照 | 问答DAS与问答均值差同题、同位置、同层候选、同算子、同中心、同强度、同生成设置；另外保留同层比较与各自择优比较 |

双向训练的意思是检查“被换入的真假相关状态能否改变后续自评”，**不是把原来的错误答案变成现实真话**。记录模型未干预时是否会判断这两个答案；不要悄悄只保留模型本来答对的题，再把训练集合变化藏起来。

位置与标签再明确两点：这里的“答案末词元”是答案区间最后一个实际词元，**包含原答案标点、排除回合终止符和自评后缀**，与均值差取法一致。`label_position` 指自评后缀末端、**预测下一标签词元**的输出位置。标签须在实际前缀下核验完整编码；不能直接取`(A)/(B)`的首词元，把两者共同的括号当成真假监督。若标签为多个词元，就计算完整标签序列的条件交叉熵。

训练目标可写为：

```text
h'_base = h_base + u uᵀ(h_source − h_base)，||u|| = 1
loss = 0.5 × CE(错答案 ← 对答案，True)
     + 0.5 × CE(对答案 ← 错答案，False)
```

已有DAS论文支持定义明确的反事实监督；答案自评是已有读出部件。**这个组合本身仍是我们的实验方案。** Knob已有直接问答内容监督的DAS先例，说明自评并非唯一必需形式；它控制上下文/先验取舍且使用短答案，因此也不能直接替我们证明真实性提升。全文与页码沿用[第13轮文献核验](audit_20261104/literature_verified.md)。

当前 `train_das` 是来源输出的多步KL匹配，和上述新目标不同。A同时改变上下文、目标、双向性和索引定义，不能写成“旧DAS只换了上下文”。本版主比较回答的是：**相同问答配对与部署条件下，训练得到的方向是否优于均值差方向。**

## 4. 代码究竟审到了哪里，发现了什么

### 已验证的核心

真实生产函数在冻结的小型CPU网络上验证了：秩1/2、KL/JSD、固定/移动锚点、单位置/全位置共16组合。梯度有限差分最大误差约 `5.94e-5`，双向分别反传与合并目标一次反传得到相同更新；底座未被训练。当前单卡、秩1、seed42、固定T8主链，没有发现“根本没训练”“梯度断了”“源与基础写反”这类错误。

这只是明确排除这些实现错误，不能证明优化已达到最优，更不能保证任一目标的DAS一定胜出。

多种子合并错误已由主审独立调用实际加载器复现，见 [`loader_reproduction.json`](das_audit_20261104/loader_reproduction.json)。对E的放大来说正负号没有意义，**不应让均值差参照控制DAS子空间合并的有效性**。正式三种子阶段优先分别报告各seed，不按测试挑seed；若需要合并，采用固定、符号不敏感的规则并重新验证。

## 5. 接下来代码应改什么，执行到哪停

下一次实现应是**让问答DAS成为真正可运行的主臂**，而不是只把均值差E-only修通就结束。改动清单明确为：

1. 修会进入新主链的加载/来源与选层问题，保留旧结果。
2. 新增双向标签CE训练入口，显式传递 `source_answer_end`、`base_answer_end`、`label_position`。不能把旧 `anchor=prompt` 原样套到完整自评输入——那会写在自评末位。
3. 把逐层QA-DAS权重接入E25方向库、调参、独立E冻结与生成。保留旧真假DAS和问答均值差作分别命名的对照。
4. 先做离线梯度/索引检查并推送，让Claude审核。审核后才做两模型各1–3题真实线路核验；查看双向交换、无来源放大、去掉自评后的候选概率和自由输出。**三题不用于决定最佳层，也不证明效果成立。**
5. 看懂并确认这一小步后，再执行预先冻结的逐层训练与验证；单层之后再做窗口对照。Gemma保留在主线，不因当前均值差结果更好就宣布DAS任务结束。

本轮交付是**完整DAS链审计与明确方案**，没有修改生产训练代码，没有启动真实训练。DAS作为主线是工作方向；优势要在同任务、同约束的对照中取得，不能让评价程序预设胜负。
