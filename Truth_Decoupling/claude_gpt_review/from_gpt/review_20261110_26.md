# 第26轮：4f8700b审核与DAS路线决定

审核提交`4f8700b9d2d79410983c5ae0b012268381634d91`，重点是方案21第7节第0问与六个后续问题。该提交只改方案/回复/索引，没有新实验。本轮直接阅读原DAS、CDAS、ITI、TruthX、LoFiT、AxBench的相关方法、实验和限制，核作者实现；正文依据与阅读范围在[证据目录](audit_20261110_round26/README.md)。没有改生产代码或启动训练。

## 1. 我的决定：首轮选修订乙

**在三项选择中，我选“只跑乙”作为首轮；准确说是保留乙的回答前来源设计，C采用当前版格式一致的果断/谨慎提示，目标跟随两端真实冻结回答。暂不把甲乙两套同时全层展开。**

乙没有因为用了指令对比，就失去作为E/C候选的资格。金标仍进入E的正向训练目标和评价，并未放弃真实性监督。选择乙的理由是：来源状态在答案尚未出现时就能取得，训练/部署的可用信息较一致，也减少甲直接从目标答案读入内容的通道。**这是优先级判断，不是论文保证乙更强。**

必须分开三件事：

| 问题 | 现在能下的结论 |
|---|---|
| 是不是DAS方法家族？ | 甲乙都冻结模型、学习方向并通过来源坐标交换训练，可称“DAS式交换干预训练”。当前方案不是原论文完整因果抽象验证，也不是照搬CDAS |
| 学出来是不是E/C？ | 两者现在都只是候选。E需实测质量改善且作答行为近似保持；C需实测作答倾向可控且内容质量没有不可接受变化。训练材料的名字不能代替这个验证 |
| 是否已经找到模型原生的两个独立因果变量？ | 没有。即使得到有用控制，仍需额外机制证据；不能把学习到的控制器自动写成发现了原生机制 |

原DAS用高层因果模型给出交换后的预期输出，再验证高低层交换效果的一致程度；不是“用某类标签训完就自动获得该变量”。CDAS更明确说明，它追求可用引导特征，不应当作因果变量定位方法。[原DAS §3.5–3.6](https://arxiv.org/html/2303.02536#S3.SS5)、[CDAS §3.3的说明](https://arxiv.org/html/2602.05234v2#S3.SS3)

所以对用户顾虑的直接回答是：**乙仍可以用于DAS式E/C研究；但不能在训练前保证乙已经学到E/C，甲也不能。** 论文暂称“真实性候选方向”和“作答倾向候选方向”，通过功能检验后再使用更强的E/C结论，不必因为来源是指令就换研究目标。

## 2. 为什么不把甲定为本轮主线

### 新D−不再犯上一版的同一个错误，但任务变成了答案重构

甲的负来源确实读过错答案，再要求输出该答案，比上一版“普通提示就应该答指定错答”自洽。**我不沿用第25轮的旧理由直接否掉它。**

但甲训练的是从“问题+答案”的状态中取坐标，再从问题重生成那条答案。它可能学习真实性，也可能学习答案身份、否定句式或监督训练中的记忆。它与TF交换一个真假变量后预测一个标签，不是已经证明的因果同构。

方案第96行“一个数带不了答案具体内容，只能带共有东西”需要删除。一个标量不是一个比特；一个方向本身也有数千个可训练参数。CPU构造中，单一坐标1/2/3可分别选择Paris/Rome/Lima，换成均值2就全部选择Rome。这不是Llama实测，只足以反驳“秩1天然排除内容通道”的推理。冻结大模型也不意味着新学的方向参数不可能记住监督信息。[构造证据](audit_20261110_round26/protocol_examples.json)

原DAS自己的NLI实验也发现，看似关系变量的表示可以分解成词身份，说明需要检查学到的究竟是什么。[原DAS §5.3](https://arxiv.org/html/2303.02536#S5.SS3)

### 均值部署增加了需要验证的环节

甲训练用每题看过答案后的坐标，部署改用训练题全局均值，并写到问题/生成位置。这是可研究的方案，但同题重构成功不保证均值也能工作。平均可能丢掉逐题信息，位置尺度也可能变化；两极均值输出一样，只能说本设置未观察到差异，不能断言方向不含对错。

乙同样需要检验每题来源到均值的近似，也可能过拟合；它的优势是少了一项“答案已给出→答案尚未出现”的来源落差。甲以后可以保留为诊断，但没有理由仅因用了金标就优先全面重跑。

### ITI与TruthX没有替甲证明这条链

ITI确实利用问题加正误答案提取方向，但使用的是多个选定注意力头、尺度归一的加法；项目残差流单方向钳制只能叫均值差同算子对照，不能直接叫ITI。TruthX还做同词元配对和语义/真实性分离，交换目标是隐藏状态重构，并非让冻结模型输出整句错答。[ITI §3](https://arxiv.org/html/2306.03341v6#S3)、[TruthX §3](https://arxiv.org/html/2402.17811v2#S3)

这些论文支持探索金标对错监督，不能给任何采用金标的干预自动授予“纯E”身份。更多核对见[真实性论文审阅](audit_20261110_round26/truthfulness_papers_review.md)。

## 3. 把修订乙写成能执行的最小设置

### 来源与目标

| 项目 | 首轮固定设置 |
|---|---|
| 模型与方向 | Llama先行；E/C各学习一个单位方向，大模型冻结；不重启C+E组合实验 |
| E来源 | 普通提示x，与只增加如实/纠正常见误解一句的x_E；其余长度、格式、是否允许拒答保持一致 |
| E目标 | 正向用完整金标正确回答；反向用x下模型自己的冻结回答。正确题不因两端都正确就一律剔除，它们也约束恢复与保护已有正确行为 |
| C来源 | 格式一致的问答版x_conf/x_caut，保留同一弃答词；不搬会同时改长度与“Unknown”措辞的TF版本 |
| C目标 | 先生成并冻结两端真实回答y_conf/y_caut，再用对应来源的回答训练；报告其中真正发生作答/拒答切换的对数，不把所有谨慎提示都标成固定IDK |
| 读/写位 | 来源取作答前的固定提示末位；训练和推理用同一实际内容位置掩码；预测y[t]只能读y[:t] |
| 目标函数 | 首轮保留整句交叉熵，两向同权。准确称受监督交换训练；它不是原生因果变量定位证明，也不是CDAS分布匹配复现 |
| 推理 | 强度恒1，目标值用对应训练端点均值；保留每题来源坐标诊断。普通端点叫恢复基线，不预设它等于“错误端点” |
| 层 | 按用户要求32层：先L16–L31，后L0–L15。先通过一层一对样本读写/目标位置验收和1–3题原文检查，再批量 |
| 对照 | 普通模型、直接提示、均值差同算子、实际写入量匹配随机；保留全部结果，不预设DAS必胜 |

**C这一改动是必要的自洽修正。** “不知道才说不知道”的提示在已知题上本来会回答，不能把它所有来源状态都强行配成弃答。这可以训练一个额外的拒答开关，但不等于恢复来源自然行为。如果两端几乎没有行为差别，先如实报告，而不是用手写弃答补造极性。

E正向仍有金标监督，因而不应把乙描述成“只学指令文字”。但监督可能教入新控制策略；本轮先验证可用效果，不宣称发现模型已有的证据机制。

质量容忍范围、筛题方式和两家裁判的选择规则在生成结果前固定；不把“没有显著变坏”当作“已经证明不变”。可沿用先前讨论的±3个百分点等价界作预先声明的质量检查，区间不足以支持等价时记未证实，不据此隐藏该层结果。

### 为什么先不把目标换成DPO或JSD

DPO（直接偏好优化·提高好答案相对坏答案的概率）与JSD（输出分布匹配·让干预后的预测分布接近来源）都是有文献依据的候选。但LoFiT关于SFT的说法引自ITI特定的全参数实验；该实验部分指标实际有改善，不能推出本项目的单方向整句交叉熵必败。先固定一种来源、写法和目标，才能解释结果。[LoFiT §4](https://arxiv.org/html/2406.01563v2#S4)、[ITI §4.2](https://arxiv.org/html/2306.03341v6#S4.SS2)

因此，交叉熵是首轮可核对的基线，不是我认定的最终最优目标。如果训练只拟合目标表述、部署恢复或流畅性不好，再固定来源/位置比较JSD；若做甲的正误偏好比较，再考虑DPO。CDAS在不同任务中也有不同结果，不能把安全拒答上的成功率当知识问答收益预测。[CDAS方法与实验](https://arxiv.org/html/2602.05234v2#S3)

均值目标、强度1也只是清楚的起点。CDAS一般概念实验中，均值单位力度常弱于调参力度；首轮单位力度无效不等于方向无效。先看真实写入量与每题来源诊断，再决定是否改力度，避免再靠过量写入换取表面变化。

## 4. 第0问的另外两个顾虑

**如实指令会不会只让模型更不敢答？** 有风险，但E42旧提示同时改变了拒答措辞，不能把拒答23→63全归因于如实要求。新x与x_E只改变那一句，并同时报告质量、含糊、实质作答和拒答；若只多拒答而质量优势不成立，就不认作已验证E。

**叙事是否必须改？** E/C可继续作为希望分离的功能名。训练来源是手段，效果验证是资格；“原生证据变量/承诺变量已被定位”是更强结论。甲乙都应遵守这一区别，不能为保住名称预先授予甲资格或排除乙。

## 5. 对方案甲第1–6问的逐项回答

1. **错答极可以作为监督重构候选，但不自动等于TF真值变量。** 新来源确实带错答，旧逻辑问题已变化。不能用一维容量论断排除内容；否定词分层也仅是混杂提示。若以后做甲，增加少量同义改写/同真值不同答案来源核查，比仅观察“否定组有效”后宣布根因更有力。暂不因此展开新的全层矩阵。
2. **绝对钳制确有位置/刻度风险；加法也不自动修好。** 加法保留当前坐标，但仍需实际尺度校准。优先乙减少来源位置落差；若甲继续，先比较同题来源、均值与实际改变量，不能凭ITI的跨位置加法直接证明本钳制正确。
3. **新末层可训练，完整目标的结束符监督合理。** 必须在预测答案词的位置写入。完整目标使用真实聊天回合结束词元；24词元截断后不能伪造自然结束。作者CDAS的前缀长度来自其模板，本项目有system轮，需按实际编码建立掩码，不能照搬常数。
4. **C用问答版果断/谨慎提示，先用真实冻结回答。** 若想训练无条件拒答，应另列目标，不冒称条件谨慎行为的恢复。相同输出对可约束不该改变的内容；真正切换对数要明确报告。
5. **支持32层探索，曲线全报不等于统计校正。** 两家各选层可预先声明，但两家选出的候选都应由两家交叉评估，不能只展示各家自己的赢家。调参层结果与历史529题回归均如实命名；独立确认仍需要未参与设计的数据。同作答数的筛题规则不能使用测试正确标签。
6. **单裁判模式应有显式出口。** 按用户决定Pro与AllenAI各报各的，不调用GPT、不合票；保留各自无判决与覆盖范围，不能把另一个裁判补来的票冒充单裁判结果。两家结果都保存，事后更换论文主口径要披露选择过程，不能只留下有利的一家。

## 6. 为什么旧DAS没效果，现在能说到哪一步

已经确认：旧E25优化答案给出后的自检判词，部署却要改答案生成；旧放大算子、读写位置及训练目标与新方案不同。旧层内生成未显示稳定正收益，E42的提示控制又曾被误解为整层交换。上述问题支持重新设计，但没有哪项单独被实验确定为唯一原因。

新甲修正了目标与写入位置，却保留了答案条件化来源到全局均值的转换；新乙更接近部署时可获得的信息。**这就是我先选乙的理由，不是因为指令听起来更好，也不是保证这次一定赢。** 如果乙同样失败，应据已冻结的训练/生成/剂量证据继续定位，而不是把所有失败都归为代码错，或反过来宣布DAS理论无效。

为避免再陷入反复调参，首轮按下面的证据决定下一步；这些是定位线索，不是单凭一行就确定唯一根因：

| 实际看到什么 | 接下来优先核什么 |
|---|---|
| 梯度或真实写入为零、无干预也不能复现基线 | 先修目标移位、掩码、钩子与精度；不把它算方法负结果 |
| 每题来源臂有效，均值臂弱或无效 | 固定方向，优先核均值近似与实际剂量；不立刻重训全部方法 |
| 训练损失下降，真实生成却只多拒答、改句式或退化 | 检查目标/来源行为与自由生成的差距；源分布本身有目标行为时，再固定位置比较分布匹配目标 |
| 所测层与完整对照均没有可靠正收益 | 报告这次设置的负结果，不强行命名为成功E，也不自动推广到所有DAS或所有模型 |

首轮保持这一条主线，不同时展开甲、乙、偏好目标和多个模型；之后需要改哪个变量，由这些记录来决定。
