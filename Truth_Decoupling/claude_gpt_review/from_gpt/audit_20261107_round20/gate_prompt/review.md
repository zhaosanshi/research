# E33：先把 C 的问题问清楚

**旧门控有明显真假偏置；明确“能判真或能判假都回答 Yes”后偏置减轻，但它仍不是好的正确性筛题器。问题级共用分数虽按构造消除了真假差异，实际筛题更差，不能作为默认修法。**

原系统提示让模型当事实核查员，用户提示却问“你知道这句话是真是假吗”，只收 Yes/No。本轮固定模型、固定原真假预测、固定调参题，先检查 3 对原始输出，再按提前冻结的四种提示跑完整 192 对。没有重估方向、没有调整旧主表。

四条件依次为：旧系统+旧提问；只把系统换成可答性角色、用户提问原封不动；保持该角色并明确判真/判假都回答 Yes；同一原始问题只打一次可答性分数，映射给两条真假陈述。最后一种改变了要判断的信息，不能当作仅换措辞。这里“可答性角色”是有内容的任务指令，并不是空白系统提示。

## 1. 不是两个标签概率很低造成的假象

全部真实输出的首词首选都是规范的 Yes 或 No。旧 Llama 的两标签总概率平均 0.950533、最低 0.525161；明确版平均 0.999930。Qwen 各条件均接近 1。每个输入都保存了完整提示、实际批量词元编号/掩码、Yes/No 原始分数、全词表概率、两者总概率、条件比例及首选词元和前五词元。

只看 Yes/No 内部比例可能虚构清晰门控，因此测试专门包含“两个标签概率都很低、条件比例却接近 1”的反例。本次完整数据未出现该现象，问题不能归咎于这种归一化错误。

## 2. 对真假标签和对正确性的区分能力不同

AUC（排序区分度 · 1 是完全区分，0.5 类似随机，低于 0.5 表示分数顺序反着来）。真假标签区分度高，并不说明模型更知道自己是否能答对；更不能要求所有合理信心分都与真假标签严格无关，因为两类题难度可能不同。

| 模型 | 提示条件 | 真假标签 AUC | 正确性 AUC | 每对真陈述减假陈述的平均分差 |
|---|---|---:|---:|---:|
| Llama | 旧事实核查角色 + 旧提问 | 0.7394 | 0.4428 | +3.520 |
| Llama | 可答性角色 + 旧提问 | 0.6951 | 0.4491 | +2.618 |
| Llama | 可答性角色 + 明确判真/判假都算能答 | 0.5680 | 0.4891 | +0.539 |
| Llama | 原始问题可答性，同对共用分数 | 0.5000 | 0.3694 | +0.000 |
| Qwen | 旧事实核查角色 + 旧提问 | 0.7923 | 0.4684 | +12.917 |
| Qwen | 可答性角色 + 旧提问 | 0.7520 | 0.4436 | +10.039 |
| Qwen | 可答性角色 + 明确判真/判假都算能答 | 0.7126 | 0.4961 | +5.724 |
| Qwen | 原始问题可答性，同对共用分数 | 0.5000 | 0.3870 | +0.000 |

只换系统角色有一定影响，进一步明确回答含义才明显减轻偏置。该干预证明提示会影响这种偏置，不能据此声称已经完全识别模型内部把 No 当成 False 的机制。Qwen 的明确版仍有相当的真假关联，说明把文字问清楚不等于获得了纯粹、可靠的能力读数。

问题级版本的真假 AUC=0.5、每对分差=0，是共用输入和共用分数的构造结果；它对正确性的区分度只有 Llama 0.3694、Qwen 0.3870，实际比旧门控更差。对“能否回答原问题”的自报，不能直接替代“能否判断给定陈述”的能力。

## 4. 推荐并已落地的修法

未来 TF 的 C 门控使用已冻结的可答性系统提示和明确版用户提问，保留实际陈述信息，并明说能判真或能判假都算 Yes。不采用把两条真假强行共用问题分数的方案。选择依据是任务定义更准确且避免丢掉给定陈述信息，不是声称它的筛题能力已经超过简单置信。

配置和完整文字写入新 bank 元数据，词元审计覆盖新提示；旧 bank 仍按自己保存的旧 system/user 重放。修正后的 TF 主表需重新估 C、重新调参冻结、重新测试，不能把新分数偷塞回旧表。该实际修复实验已在本轮独立 `tf_ability/` 目录完成，QA 旧表不冒充重跑。

## 5. 验证与界限

- 两模型完整旧门控分数逐条完全复现，最大差值为 0。
- 独立审计采用按分数分组累计负例的另一种排序计算，核对每模型 1344 个真实模型输入、33 个配额/同 K 控制格；所有数字一致。
- 7 项测试通过：小标签总概率的反例、全词表概率计算、单变量模板对照、并列/退化 AUC、同对共享分数的逻辑、坏概率与条件比例/首词标记/掩码的拒绝。
- `artifacts.tar.gz` 包含试点、完整结果、源码快照与原始输入/输出；`results/` 为解包内容。
- 所有结果都来自已用过的调参题，不是新测试集；没有按这批完整结果继续改词、增加模板或挑例子。
