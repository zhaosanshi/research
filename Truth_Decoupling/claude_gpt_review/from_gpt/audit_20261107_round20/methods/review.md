## 2. E26 测到了什么，尚未测到什么

**已有主表应保留。** 固定交付数量排除了“只因多答了题而多答对”的混淆；它公平检验当前候选生成、当前排序器、当前调参规则组成的整套系统。若 C 只把分数变成同一严格递增函数而不改候选答案/拒答，交付集合确实完全不变。这是数学性质，不是要修掉的错误。

**“无参考”的范围要说准。** 排序分不看参考答案，但 QA 的精确配额先按语义裁判标注排除“未尝试回答”。这位裁判收到问题、正确/错误参考与预测，提示中还明确用参考区分“客观未知”与“个人不知道”。因此主表是“以离线语义标注识别实质回答的等实际覆盖率比较”，不是已验证的完全无参考在线精确填 K 策略。正确 A 与错误 B 都可入选，只有未尝试 C 被排除；把 A/B 对换而 C 固定时，入选题目不变，所以这不是按答对挑题的证据。原生固定门控则可以在线按分差正负发候选，之后用外部标注测量实质作答率；它不承诺恰好 K 题。未来若需线上精确填 K，需另验只看问题和候选的拒答识别器。本轮后来修复了明确的完整个人拒答误判并追加证据式盲审侧表；原有标签没有覆盖，这些修复也不等于已验证通用的无参考拒答识别器。

但当前代码有四个解释边界：

1. **问知道不知道，与决定交不交答案是两件事。** C 在另问“你能准确回答吗”的提示中估计，按该提示上的相关性选层；同一个向量还被写到实际答案提示。后一种跨提示迁移没有由前一种读出相关性得到保证。`intervention_specs()` 自己也明确说效果要靠实验验证。
2. **现有交付规则不是首词 Yes/No 的原生门控。** E26 把分数排序后凑固定份额；没有把 `Yes−No > 0` 作为是否交付的决定。因而“把 C 注入自由生成后实际作答仅变几个点”，不能拿来断言 C 门控的实际覆盖范围也只能变几个点。
3. **向量正交不是跨层干预独立。** 当前做的是每层 C 去掉同层 E 分量；选中的 E 实际写入层可能不同于 C 层。不能说已经实现了老师字面上的跨层正交，也不能从点积零推出后续非线性计算互不影响。
4. **E+C 与 E 各自调参，是系统比较，不是固定 E 的 C 消融。** 两者可选到不同 E 配置。需要再做固定同一 E、只改 C 的比较，才能把差异归给 C。

补充核查：真假陈述每题恰有一真一假时，`mean(h_true)-mean(h_false)` 与 `mean(h_true-h_false)` 完全相等；不能仅因代码先求两组均值，就说没有做配对均值差。当前 E26 的 C 已是连续 Yes−No 分差协方差，并非 `03` 仍描述的旧二分均值差 C。

**直接实施的最短诊断**：固定旧调参集选中的 E 和现有 C 层，扫预先写定的 C 剂量；区分只写门控提示、同时写门控与答案提示两种范围。每个条件用首词分差正负决定是否交付，模型自己拒答不算实质作答；再与原模型/同一 E 在相同实际题数下按简单置信、按门控分筛题比较。原 E26 主表原样保留。这能区分“C 没接入交付”“C 的提示迁移不工作”“C 起作用但没有挑题优势”，不能凭曲线看起来好看就宣布老师贡献成立。

## 3. 自由生成下一步：真实源交换，先三题

**推荐优先试跑第 19 轮设计的真实来源交换，而不是继续训练 E27 或补结束符。** 这里的 DAS（分布式对齐搜索 · 学出内部哪一小块可交换）只提供待检验的方向；实际部署改成 `h′ = h + wwᵀ(s−h)`，`w` 单位长度、力度 1，`s` 是同一道题、固定准确作答指令、同一已生成前缀下的冻结模型状态。它直接去掉已定位的“固定中心乘三倍外推”机制，但不保证源一定知道真相，也不保证生成一定正确。

先不训练，比较原模型、来源提示单用、现有 DAS 方向交换、真正不训练的随机方向交换，以及等权两次前向分数混合。来源提示不得含题目金答案；两条生成流消费同一串实际选中的答案词元，缓存分开。源/基完全相同时应恒等；理想高精度运算必须交换选定坐标、保留正交补；低精度舍入单独记录，不能用错误的严格范数上界拒绝合法计算。至少保存三题每步源/基词元、写入量、原始输出，再决定是否训练与扩大。

若之后对正/负答案训练交换方向，固定“说假话”指令并不唯一指定那条错误参考答案。可把这种目标叫受监督交换训练，不能叫已验证的普适真/假因果变量。优先证实源指令实际提供了什么行为信号，再判断训练目标是否对齐。

这一实现是新变体，不是 CDAS 原论文复现。CDAS（概念分布式对齐搜索 · 借用交换来学可控制的概念）采用源提示单位置到基础序列多位置的交换，匹配反事实输出分布，部署使用夹值；作者也明确不把它宣称为因果变量定位。我们的每步同前缀源交换须单独验收。[CDAS 原文 §3.3](https://arxiv.org/html/2602.05234v1)

## 6. 上述建议的实际执行结果与后来暴露的问题

原生 C、预设层位、补齐 E+C 简单筛题，以及修正真假门控语义后的完整主表均已实跑，详见 [新真假表](../tf_ability/summary.md)和[原生诊断](../native/review.md)。它们排除了“只因 C 没写进去所以负结果”的简单解释，但尚未证实同作答率下组合优于 E。老师主张仍是待支持的假说。

自由问答已完成真实源交换、固定旧层和预设中层的单位方向训练；正答案交叉熵使 Qwen 第 17 层拒答大量减少，但多答对同时也多答错，不能只看总答对增加。随后锁住 Llama 第 15 层/Qwen 第 17 层、训练题/初值/力度/优化器，仅将目标改为相对原模型的正负答案序列偏好。共有前缀的非目标词归一化项可以抵消，分叉后不能；实际拒答率仍可能改变。数学小例、算子与训练约束见 [固定损失审计](E34_fixed_loss_protocol.md)。
