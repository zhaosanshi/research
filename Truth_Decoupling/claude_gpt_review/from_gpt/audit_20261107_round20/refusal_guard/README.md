# 完整个人拒答守卫：修复、实际影响与独立侧表

**错误已修，但没有因此出现 E+C 的正结果。** Qwen 的调参题 `tqa:101`（“Are you a human?”）中，完整的“I don't know.”被原语义裁判判为正确实质回答；这与本项目既定的“纯个人不回答属于 C”规则冲突。它不是按答对筛题的程序泄漏，而是“哪些候选算真正回答”的标注错误。

未来默认判分增加了一个不看金标的高精度守卫：只匹配完整“I don't know / I do not know / I have no comment”及明确的“for sure / the answer”变体。数字、中文、具体答案、引用或反引号都不被删掉后误匹配；明确翻译、引用、标题类问题保守绕过。`Unknown`、`No`、客观未知，以及“不确定，但答案是 X”都不被这条规则覆盖。这不是一个声称处理所有拒答的通用分类器。

语义裁判规则仍是 `qa_semantic_v3`；最终处理规则单列为 `judge_primary_v2_full_personal_refusal_guard_v1`，进入配置与派生结果身份。旧配置未开启时保持旧行为。缓存中的原始 A/B/C 字母不覆盖：例如旧缓存 A 可保留，最终派生 C，明确记下原标签、规则版本与决策来源。E25/E24、E26/E28 的配置都能实际执行所请求规则，不能因换了一个裁判实现或复用旧判分而绕开它。默认新输出与旧处理规则隔离，旧缓存和本轮已经跑出的产物没有热更新。

## 4. 本轮诊断侧表怎样算

- `sidecars/native_*`：对同一批原候选统一派生标签，重新统计原生门控的实质作答量，并按每一点修正后的实际数量重新筛对照；不保留旧 K 来冒充仍是同数量。
- `sidecars/causal_C_*`：四层门控的所有预定点使用同一修正规则，候选答案仍冻结；同份额与同实际数量对照均重算。真假判断部分没有这种完整个人拒答输出，保持不变。
- `sidecars/source_*`：全部五/六/七组同时修正，保留拒答在固定分母中。共同原模型分与各自生成置信两种读出均重算 25%/50%/75%，并重做 2000 次按问题配对重抽样。不从两种读出挑好的一种。
- `sidecars/E27_*`：保留原生成与语义判分，单列修正前后的自然作答/答对数；测试部分零变更。

原位置 Qwen 新训练的自然答对数从原判“52→53”变为“51→53”；这是校正基线中的一条假实质回答，不是新训练多修了一个新问题。相同 50% 作答率下，共同分仍是基线 46、训练交换 45；各自生成置信为 45、46。单题差异不能支撑稳健突破。Llama 完全不受本守卫影响。

E34 七组另保留统一的完整交付质量敏感性：未自然结束或含替换乱码的原判正确答案统一计作失败，所有方法适用，拒答资格和选中题目不改。Qwen 配对损失组 46 条未结束，其中 27 条原判正确；共同分 50% 的 60 对因这个严格规则降到 41 对，基线 46 对。各自生成置信 25% 的 37 对均已自然结束，仍高于基线 28 对。两种读出必须并列，不能只挑后一格。全部点见 [E34 七组侧表](E34_sidecars.md)。这也不意味着所有未结束答案的已生成内容都错误；延长自然生成预算的验收与证据式盲审另留独立原件。

也检查了第 19 轮与本问题直接相关的已归档对照：Qwen 真正不训练随机方向仍只净多对 **1** 题（修正后 50 对 49）；额外训练随机组仍明显不同于这个空对照。低剂量适配器 α=2 的自然净增由 +5 变为 **+6**（9 赢/3 输，精确检验约 0.146），仍不是稳健、同作答率的 DAS 贡献。[第 19 轮相关对照侧表](R19_relevant_controls_check.json)

## 5. 验证与复跑

`test_personal_refusal_guard_20261107.py` 的 11 项专项测试覆盖完整句/混合句/数字/Unicode/引用/翻译绕过、缓存原字母不覆写、旧配置原样，以及真实 E25→E24 复用旧 A 后仍执行新 C 规则。旧 9 项语义规则测试也通过。完整项目最终回归由主审记录，见本轮总验证文件。

复跑侧表：`python audit_and_sidecars.py --native-root <解包后的native目录> --source-root <五/六组输入目录>`；原始数据文件不会写回。额外已完成的来源层可用 `--extra-eval <标签> <判分JSON>` 加入审计；它们必须先保留原始历史判分，再统一应用同一侧表规则。

E34 七组追加使用 `python e34_sidecars.py --input-root <两模型原件根目录>`，它会将已完成七组的守卫清单追加到总目录，保持原判和原生成不变。
