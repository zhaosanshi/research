# E31：固定答案，实际改 C 的写入层

**两模型的完整 192 道调参题已跑完。预设层中有些层比原先按相关性选的层多答对 1 题，但没有补上与同一 E 加简单筛题的差距。**

这次解决的是“用哪一层写入 C”是否被旧代码的读出相关性误导。E 固定为旧 E26 在 50% 配额选中的配置，原模型与 E 的候选答案完全冻结。C 只写另一个 Yes/No 门控提示，不再同时改变答案。模型输入不含答案、参考答案或正确性标签。

DAS（分布式对齐搜索 · 用内部表示交换学习方向）和配对均值差都保留。每个模型、任务、方法预设 25% / 50% / 75% 深度的层，加原先选中的 C 层；每层使用自身原始估计向量与尺度，力度为 −1/+1，0 复用未加 C 的控制。不默认遍历所有层，未因结果不好临时替换层。

每个模型 70 个条件、210 个配额格、70 个原生门控点与 276 个同实际交付数对照均由独立脚本从原始分数重新核对。完整运行中的原模型/E 控制分数也按原批量复现。

## 原生门控也按相同实际作答数比较

每点先用首个 Yes−No 分数大于 0 决定是否交付冻结的候选，再统计实质回答数 K。随后把原模型/E 的门控排序、简单筛题都精确选到相同 K；不能把“多答了一些”偷换成更准。不足 K 的控制明确不可行。

配额与实际作答率属于离线评估：候选是否实质作答由旧语义裁判的拒答标签决定，该裁判看过参考答案；答对/答错标签不参与排序。这不是无需裁判的在线精确配额服务。

## 执行与证据

- 两模型先各跑 3 对真假/3 道问答并逐条检查，再用提前冻结的计划跑完整 192 道调参题。
- 9 项针对性测试通过，包含固定 E/冻结答案、不把参考答案送入模型、缺失层不替换、门控零分处理、不可行配额、每个原生点必须比较同 K 控制。独立审核者另运行 9 项，全部通过。
- `llama_artifacts.tar.gz`、`qwen_artifacts.tar.gz` 保存试点与完整运行、源代码快照、计划、原始分数、报告与退出状态；解压目录是 `results/`。
- `analyze_causal_layers.py` 不导入实验统计实现，从分数与原固定答案重算全部表格。

## 结论限度

这排除了“仅仅没给预设其他写层机会”的一部分解释。它没有扫描答案生成提示中的所有 C 位置，也没有证明所有 C 都无效；只凭同一批调参题选出的最高值，不能宣称有泛化收益。

另一个更上游的问题已从旧数据确认：真假任务的门控分数更擅长区分基准真假标签，而不是区分模型是否答对。本轮 E33 已按预设提示完成核查：改清楚问法确实减轻偏置，但没有超过简单筛题；详见相邻 gate_prompt/review.md。
