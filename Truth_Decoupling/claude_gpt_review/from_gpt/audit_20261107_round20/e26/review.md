# E26：本轮逐项复审与修复

审核基准：GitHub `63e3674`。范围包括报告 13、14 的 E26 部分、两模型主运行、Qwen 适配器探索运行、剂量探测与启动/分析脚本。旧的无关矩阵实验不重跑。

**原表算账没有发现错误，但“所以 C 没有用、只可能通过答案副作用起效”的解释超出了证据。主实验还少了组合使用同一种简单筛题规则的版本。** 这次保留旧结果，修复分析入口、剂量探测与启动脚本，并冻结补齐同筛题表所需的测试条件。

E 是证据方向，C 是承诺方向。DAS（分布式对齐搜索 · 通过交换模型内部表示来学习干预方向）与配对均值差分别保留。Holm（多重比较校正 · 同时做很多检验时收紧显著门槛）沿用原来声明的比较家族。

## 1. 哪些数字核对通过

新的 `e26_independent_recount.py` 不导入实验脚本或核心统计模块。它从原始逐题数据重算，而不是读报告数字再相减。

| 核查 | 结果 |
|---|---:|
| 三个运行的配额格 | 244 格一致 |
| 调参集冻结选择 | 225 个一致 |
| 可行的按题成组精确检验 | 1848 个一致 |
| 真实交付文本、交付掩码、作答数、答对数 | 一致 |
| 调参门槛重建、原样用于测试后的实际作答率 | 一致 |
| 参考答案只含个人拒答的六道测试题 | 独立核对后固定排除，所有方法一致 |
| 全部按题成组、每次重新筛题的 2000 次误差估计 | 区间及不可行抽样次数一致 |

最后一项使用 bootstrap（自举 · 把整道题重复抽样来估计误差），独立实现按“每题抽中几次”加权排序；原代码使用展开后的重复行再排序，两种实现给出相同结果。

证据：`recount.json`、`recount.log`。这里只核了判分记录与输出的一致性，**没有声称所有语义判分都是正确的**。各运行内部未发现同一道题、同一答案被判成不同类别；Qwen 主运行与适配器探索运行之间，调参题 `tqa:292` 的同一答案有一个判分冲突，见 `grading_consistency.json`。旧文件与冻结选择都未改。

E26 的“原模型·随机”是把原模型已生成的实质回答随机排序后筛题，完全不训练方向。其按题编号生成的随机分数已逐条核对；不能与 E27 的“随机起步后再训练”混为一谈。

这里的精确配额属于离线评估：筛题分数不读正确性标签或参考答案，但“是否实质作答”的资格取自看过参考答案的语义裁判拒答标签。答对/答错不参与排序，仍不能称整套流程无需裁判即可在线部署。

因此，旧主对比“12 个事先指定格子里，没有一格经校正显著为正”可保留；其中 Qwen 自由问答 75% 无法填满配额，不能写成该格效应等于零。不显著也不能当作已经证明两种方法相等。

## 2. C 的解释哪里说过头

第一，C 并没有完全保持排序不变。各格 C 与原模型的实际交付题目换了 2–16 道。高秩相关只是大多数题的相对顺序接近，不能推出筛题完全相同。

第二，原表给 E 与 E+C 各自独立调参，这适合比较两套完整方法；但不能把所有差值都归因给 C。11 个可行的 DAS 主格中，有 3 个格子的 E 配置不同：Llama 真假判断 75%、自由问答 25% 和 50%。

第三，使用已保存的对应 E-only（只加 E）条件，固定 E 后，可以分别更换答案和筛题分数。这里是代数拆分，不是新训练，也不宣称证明了因果中介机制：两种更换次序分别计算，再取平均。

| 模型、任务、作答率 | 原主表差值 | 固定 E 后差值 | 其中换排序贡献 | 其中换答案贡献 |
|---|---:|---:|---:|---:|
| Llama 真假 25% | +1 | +1 | +1 | 0 |
| Llama 真假 50% | 0 | 0 | −3 | +3 |
| Llama 真假 75% | +7 | +4 | +2 | +2 |
| Llama 问答 25% | +2 | +2 | +1.5 | +0.5 |
| Llama 问答 50% | +3 | +4 | +1.5 | +2.5 |
| Llama 问答 75% | +9 | +9 | +3 | +6 |
| Qwen 真假 25% | −1 | −1 | −1 | 0 |
| Qwen 真假 50% | −3 | −3 | −2 | −1 |
| Qwen 真假 75% | 0 | 0 | 0 | 0 |
| Qwen 问答 25% | +3 | +3 | −1 | +4 |
| Qwen 问答 50% | −3 | −3 | +2 | −5 |

证据与可执行重算：`decompose_c.py`、`decomposition.json`。这张诊断表不能替代旧主检验，也不把这些小变化包装成稳定正收益。它直接说明，“结果只能来自 C 对答案的副作用，不能来自排序”不成立；有些零差值恰好是两个路径互相抵消。

还要注意：旧 E26 真假判断强制输出 True/False，原始回答数始终是全题。25% / 50% / 75% 来自模型之外的筛题程序。它没有测真假任务中“C 让模型自己答或拒答”的效果。自由问答的 C 则从另一个“你知道吗”的提示中估计，再施加到回答提示上；自报分数被推动，不能自动证明同一方向已可靠控制实际拒答。

## 3. 实验少了哪一臂

旧代码为 E、C 提供简单置信筛题，但没有为 E+C 冻结同样的简单筛题版本。这能检验“当前组合加承诺分筛题”是否够好，却不能把组合本身与筛题器的差异分开。

本轮新配置补 `include_joint_simple`；旧运行没有这个字段，仍按原协议验证，不能借修复改写旧主表。

本目录 `joint_simple_extension_manifest.json` 是对旧主运行的探索性补齐：只看原调参集，对 E+C 也按简单分数重新选配置；原模型、E、C 使用原来的简单筛题选择。冻结清单包含银行文件、题集、原冻结选择、调参输出的哈希；`joint_simple_extension.py freeze` 能独立重建它。文件 SHA256 为：

`86c12164889ddfc34738776a150a099d614ce7ded78fc0f8557e6a0383317f24`

本轮已补齐 11 个此前未在测试集生成的条件：Llama 真假 3 个、问答 3 个，Qwen 真假 3 个、问答 2 个。**不是看测试后挑其中好看的条件。** Qwen 问答 75% 在调参时仍不可行，保留这个格子。

补齐后的报告必须同时满足：完整测试题集、原始生成与判分一致、同问同答沿用同一判分、冻结清单未改变、相同实际交付数。每类 12 格继续校正，不删除不可行格；误差区间仍按整道题重复抽样并重新筛题。测试集早已看过，因此整个补齐表明确标探索性，不能称新的确认实验。

## 7. 当前结论边界

保留：旧主表数值和统计核对通过，当前已测配置未证实 E+C 比单方向更好。

撤回过强解读：不能据旧表直接断定所有 C 无效、所有自由问答方向无效，或把所有变化都归因给答案副作用。不能把未显著写成效应为零，也不能用同一套已经反复看过的数据证明新的确认性结论。

同筛题组合表已完整生成、判分并复算，见 `joint_simple_extension_report.md/json`。DAS 的组合减 E：Llama 真假 −1/−6/+3，问答 −1/+4/−1；Qwen 真假 −1/+2/+1，问答 −2/+1/不可行。DAS 与均值差两种方法的组合对 E 都没有经校正显著为正的格子。修好漏项后，当前 C 仍没有稳定额外收益证据。

Qwen 自由问答 50% 的组合有 2/2000 次自举无法填满配额，按原协议不出该区间，不能把这两次抽样丢掉。新增与原有条件同问同答没有判分冲突；所有补齐产物都通过完整题集与来源核验。真实作答曲线、实际写层诊断、提示语义核查和修正后的 TF 完整表均已在同轮完成。旧结果和新结果都保留，详见相邻 causal_C/、gate_prompt/ 与 tf_ability/。
