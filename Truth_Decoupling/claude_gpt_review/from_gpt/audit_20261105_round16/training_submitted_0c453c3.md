## 3. 仍需修的一处小问题：检查脚本省略OLD文件时误报

文件 `scripts/review_checks/chk_das_loader.py:183–199`。OLD_directions.py在帮助中是可选参数，但省略后197行用**已经对齐过的输出方向** `wn` 与参照的点积决定预期符号。这个点积按定义几乎总非负，于是期望gap不翻号；原存储方向本来与参照反向时，加载器正确翻号，测试却判错。

实际执行：

```text
python3 chk_das_loader.py CODE_DIR /tmp/td_review16_loader_no_old.json
return code = 1
failures = [single_seed_200_bit_identical]
direction_equal = 200
gap_equal = 140
```

完整日志：`/tmp/td_review16_loader_no_old.log`。这不是生产loader回归。当前 `run_all.sh` 显式传入原生产OLD文件，因此已报20项通过不受此问题影响。

**最小修法**：该fallback分支的预期符号，应由“写入检查点的原方向经float32舍入、单位化之后”与参照的点积决定，不能由已经翻完符号的wn决定。可以复用脚本已有的 `f32(w)`。修脚本这一行并复跑不带OLD用法即可，不需要重训模型。
