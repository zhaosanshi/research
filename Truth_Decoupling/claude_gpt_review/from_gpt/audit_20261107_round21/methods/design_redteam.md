# 第21轮固定设计：先后顺序、层位与C的实际作用

本轮真正测试的是：**固定同一个E，在它之前或之后的预设层写入该层的C，是否产生更好的组合。** 这是层位与方向一起变化的组合诊断，不能叫两个完全相同算子的纯先后交换。没有重新训练E，也没有按测试结果挑层或剂量。

## 1. 冻结的配置

以下都是代码从0起算的层号。

| 任务/模型 | 固定E | C前 / C后 | 生成/样本范围 |
|---|---|---|---|
| QA Llama | E34实际来源交换，15层、力度1 | 7 / 23 | 48词元，192调参题 |
| QA Qwen | E34实际来源交换，17层、力度1 | 8 / 26 | 256词元，192调参题 |
| TF Llama DAS / 均值差 | 11层力度3 / 13层力度3 | 7 / 23 | 192调参题，每题真/假两陈述 |
| TF Qwen DAS / 均值差 | 16层力度3 / 21层力度2 | 8 / 26 | 同上 |

TF继承修正能力门控下50%调参选择的E，不能偷换成另一组E。Qwen按简单置信另选的DAS E在最后35层，已经没有更后的解码块；若使用它，必须明确“没有C后层”，不能把8/26层写成E后。本轮用16层作为已声明的固定诊断锚点，不声称它是Qwen最优的所有E。

每种E保留原模型、E单独，以及每个C层的C单独/E+C、正负两方向；QA每模型10组，TF两估计器共享原模型共19组。C单独与对应E+C严格使用相同C向量和系数。QA使用有题目来源的E34，不能把上一轮较强的Llama遮题控制暗中换成此处E。

## 2. 同层为什么可能根本没有“顺序效果”

令 `P=wwᵀ` 为固定E投影，C是固定加法 `C(h)=h+d`。原TF放大为 `E(h)=h+αP(h−c)`，则：

`E(C(h))−C(E(h)) = αPd`。

真实来源交换在同一前缀、来源不受C直接干预时为 `S(h)=h+αP(s−h)`，则：

`S(C(h))−C(S(h)) = −αPd`。

如果C确实正交于**当前使用的E**，`Pd=0`，理想数值下两种先后完全相同。固定中心不改变这个结论。低精度逐次舍入可以出现小差异，但不能把舍入差说成强机制证据。本轮银行里的C只对旧同层DAS方向做过正交；不能据此声称它与新E34方向或跨层功能正交。

不同层由模型实际层号决定顺序，交换Python规格列表不会逆转网络前向。中间经过非线性层后，局部向量正交也不保证两个干预可交换。改变C层同时改变了方向、原始尺度及其下游计算路径，因此只能比较这两套明确配置，不能推出普遍的“E必须先做”定律。

## 3. 为什么不能只比较名义±1

读取修正银行后，原C尺度除以对应答案中心范数的预检如下。这只是中心范数代理，不是实际运行的中位数：

| 任务/模型 | 前层 | 后层 |
|---|---:|---:|
| QA Llama | 1.87% | 19.75% |
| QA Qwen | 1.05% | 11.81% |
| TF Llama DAS / 均值差 | 1.82% / 1.84% | 9.35% / 9.18% |
| TF Qwen DAS / 均值差 | 1.14% / 1.15% | 8.00% / 7.47% |

直接使用各层原标准差，会把后层C的扰动放大约5–11倍。正式192题因此改用**只在训练集做一次的实际写入量校准**：QA固定E34的92个训练问题（不是能力银行里的96个）；TF固定192训练陈述/96对。捕获不加干预的答案提示末位状态，保留真实残差数据类型。分别模拟正负C的FP32相加和原精度存回，取所有训练题×两符号的相对实际写入量中位数。两层原中位数较小者为共同目标；每层只用固定48步二分求一个系数，正负以及C单独/E+C都共用它，误差必须小于冻结的 `0.005*rho+1e-7`。

校准没有生成答案、使用正确性标签或挑选输出。原标准差档只作三题诊断。主评估不再按当前E+C状态重新调剂量，因此不能制造一个状态自适应的额外算子；同时也不能宣称每条自然轨迹都精确等量。实际每步请求/存入范数、相对残差变化和舍入误差继续记录。

已独立重算保存的原精度状态，未调用生产校准函数：QA目标为Llama约1.8419%、Qwen约1.0587%；TF为Llama DAS1.8257%、均值差1.8452%，Qwen DAS1.1705%、均值差1.1784%。逐符号完整剖面与记录差小于1e−7，匹配误差全部在冻结容差内。[TF复算](tf_calibration_and_pilot_audit.json)、[QA复算](qa_calibration_and_pilot_audit.json)

**等幅不等于等功能。** 每层C还要看同题下能力门控的Yes−No变化、两词总概率及正负响应，不能只报写进去多少。早层C若反应很弱或正负不稳定，说明这套读出方向没有表现出同样的可控作用；不能把“同名C”当成已验证的同一个功能。

这里有一个严格的数学边界。当前估计器为 `c∝P_E Cov(h,m)`；投影不为零时，拟合坐标与m的协方差按构造就是正的，这不是独立的写入验证。反例：二维状态协方差 `[[1,2],[2,5]]`、`m=h₁`、移除方向 `E=(1,1)/√2`，得到 `C=(-1,1)/√2`。读相关为 `+1/√2`，实际加C却让m减少 `1/√2`。[数值复核](read_write_counterexample.json) 这撤销了“正相关保证正向控制”的隐含前提，但不证明真实早层不稳定就是这个原因。

随后追加的E39只检查预设相邻前层L14/Q16、92个训练问题和E37已冻结的写入目标，不改变已跑E37主族，也不新开192题。预定每符号至少90%方向一致且中位绝对门分变化至少0.1；无论通过与否都记录。它仍只是能力门控的功能核查，不自动证明该方向迁移到答案提示后形成独立承诺机制。

## 4. 最小真实三题验收

1. 新生成原模型/E与同预算旧参照逐词元、全文、自然结束标记严格一致；不通过就不扩大。
2. 在真实模型前向里记录层事件：前层C确为C→E，后层为E→C。不能只把计划顺序写进日志。
3. QA的C只进入基础分支。来源先前向时不得安装C，也不能让来源消耗 `max_calls=1`。缓存解码只有第一次在原提示末位写C；全前缀参考每次在**原提示末位**重放C，并重放全部历史E，不写当前末位冒充等价。
4. 原始C向量/系数和模型参数保持不变；每次写入的坐标、请求量、实际量、相对量、舍入误差均保存。对应C单独/E+C必须同系数。
5. C单独的能力门控报告成对分差和Yes/No总概率。当前QA含E的门控将能力base与回答任务source交换，是跨提示诊断；主答案不依赖它，不能把它等同已训练过的E能力判断。
6. 读原始输出而非只看分数；新循环、未自然结束和乱码完整保留。不能为通过验收补结束符或改预算。全部方法统一拒答规则和质量侧表。

现有真实三题中，TF两模型共456个答案/门控上下文、384个C请求强度核验通过；QA两模型555个生成步、48个首段C写入的实际层序/位置/幅度及后续零C写入通过，原模型/E逐词复现通过。新增缓存重放逻辑的CPU因果测试通过；报告不把未执行的其他精度/全样本测试说成已经完成。

## 5. 判读边界

全量保留所有预设点，用同一批问题配对；TF一真一假必须按原问题成组重抽样。主要比较是同实际作答数量下组合对固定E，同时检查是否超过相同C和原模型。不能只挑一个正方向、一个层、一个读出或一个覆盖率。

QA精确配额的实质回答资格仍来自离线语义判分；排序分不看参考，不代表整套资格判定无参考在线可执行。裁判的已知错例和未决范围仍保留。题集早已暴露，本轮不宣称未见题确认；当前输出质量失败也不能自动归为源码错误。具体统计族与主次视图以本轮已冻结的分析计划为准。
