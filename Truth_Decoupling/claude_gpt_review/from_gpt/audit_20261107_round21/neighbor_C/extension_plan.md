# 邻近前层C：限定的训练功能检查与Llama扩展

此项在E37的早层C门控方向不稳定已被观察后新增，属于明确标注的探索补充，不改E37主要24项比较。

只检查唯一预定邻层：Llama E15之前的C14，Qwen E17之前的C16。不搜索其他层，不看答案正确率。C方向来自同一个已估计银行；仅用92个E34训练问题匹配各模型E37已经冻结的相对写入目标，随后在训练问题上检查C单独作用的能力门控。

预定通过标准：正负符号各至少90%（83/92）题朝预定方向改变Yes−No，且各符号中位绝对变化至少0.1。格式概率与实际写入分布另报。这检验训练题上的能力门控，不等于实际回答或层间功能独立。

真实结果：Llama C14正负均92/92、约0.20，通过；Qwen C16仅60/92与59/92，未通过。不为Qwen扩候选或换符号。

因此只给Llama追加四个生成条件：C14正/负单独，以及固定来源E15加C14正/负。E方向、来源、预算48、训练校准目标和语义政策不变，先3题验收后192题。原E37十臂作为绑定来源的父控制保留，新增四臂独立生成；父判分按同问同文及统一拒答规则锁定，不因条件名换标签。

新增两个组合×三个实际作答率为单独六项比较族，统一Holm；主要仍用全臂完整质量规则、共同原模型平均词元对数概率，其他读出完整并列。不得将它替换E37原主族、将训练功能验收称未见题确认，或只摘有利档位。Qwen没有合格邻层C，不用未执行的组合填表。
