# E38：固定 E 前后写 C 的真假判断诊断

**两个模型完整 192 对已跑完，独立统计核查已通过。** 结果见 [results.md](results.md)，全部四臂数字见 [all_matched_counts.csv](all_matched_counts.csv)。大体量原件集中在 [raw_artifacts.tar.gz](raw_artifacts.tar.gz)，完整成员摘要见 [delivery_manifest.json](delivery_manifest.json)。

DAS（分布式对齐搜索 · 用内部表示交换估计证据方向）与 mean-diff（配对均值差 · 用配对样本表示差估计方向）分别保留。

本轮固定第 20 轮修正版能力筛题 50% 的 E：Llama 的 DAS 在 L11、均值差在 L13，强度均为 3；Qwen 的 DAS 在 L16/强度 3、均值差在 L21/强度 2。C 固定在模型深度的 25% 和 75%：Llama L7/L23、Qwen L8/L26。每个 C 层使用自身方向，保留正负两号，不按结果换层。层号从 0 开始。

每模型 19 组：共用原模型；两个 E 单独；每种估计器的两层×两符号 C 单独及 E+C。答案前向和独立 Yes/No 能力前向都真实写入，逐题保存实际执行层序、请求写入范数、低精度写回后的实际范数及其占原状态范数的比例。没有只改门控而复用不变答案。

`results_sigma` 是原来每层一个投影标准差的三对执行诊断，原件保留。它显示深层实际相对写入量约为浅层的 5–7 倍，不能把这个量差解释成纯顺序差。

`results_calibrated` 使用全部 192 个训练陈述/96 个原问题，在未干预答案提示的末位收集两个 C 层的真实 BF16（脑浮点数 · 模型实际使用的低精度表示）状态。两符号实际写回量合并，取两层较小中位数为共同目标，仅在已收集状态上二分每层一个正系数。没有用答对数选剂量。原状态、题号、提示、词元及每次二分记录均保留；单 C 与组合使用同一系数。两符号分别的分布已包含在校准原件中。

两模型校准后三对均已真实运行，19 组×6 个陈述完整。原始预测逐句检查；Llama 六句均正确，Qwen 在 Feynman 真句上判 False，其余五句正确，各组原样保留。C 的实际相对写入量早晚接近，但晚层对能力分数的作用仍较大；这并不表示“相同相对力度等于相同功能”。完整运行不得据此挑选方向或符号。

可执行入口：`from_claude/code/scripts/e38_tf_commitment_order.py`。阶段顺序为 `calibrate → prepare → collect → report`。校准运行目录与三对、完整运行目录分开；完整运行复用已经冻结的校准原件，不重新校准。三对加 `--limit 3`；完整运行省略该参数。二者均显式提供 `--dose-mode train_relative --calibration-run ...`。原标准差只允许三对诊断，不允许扩成主比较。

独立核查入口：

```bash
python3 independent_recount.py --results results_calibrated --phase full192 --output full_independent_recount.json --n-boot 2000
```

该脚本不调用 E38 或其配额统计函数，自行按分数和稳定题号散列排序，核全部配额计数与入选题号，并从保存的原始 BF16 状态重算校准量。按原问题对进行 2000 次重抽、每次重新筛题；固定观察交付集合的成组精确检验另报。按照根目录 `analysis_plan.md`，每种读出跨两模型、两估计器、两 C 层、两符号、三配额的 48 项 E+C 对固定 E 比较统一做 Holm（多重比较校正 · 防止试得多偶然显好）校正。

本轮使用已经看过的调参题，只是固定网格的探索诊断。移动 C 同时改变层位和该层方向；训练中位相对尺度对齐也不保证 E 介入后的每条轨迹等量。不能把结果写成没有混杂的抽象算子交换实验。Qwen 主表简单筛题的最优 E 在末层 L35，没有更深 C，本轮内部层 E 明确是既有能力筛题选择，不能冒称测试了 L35 的后层组合。

`runtime_archives` 保存原标准差三对 v1 与校准版 v2 的完整代码归档、启动命令及仅调度层的双卡切换记录。科学代码在实跑期间不热改；完整运行使用 Llama GPU0、Qwen GPU3，三对及训练状态校准均在 GPU0 串行完成。

独立红队已直接从两模型原始记录与原 TF 标签，自写排序及题号散列，复核 50% 简单筛题的全部 38 个条件格、入选题号及 16 个组合比较，全部吻合；未调用生产或本目录配额函数。证据见 [独立代表格复核](../methods/tf_full50_independent_recount.json)。此项不冒称重跑全部 2000 次重抽区间。
