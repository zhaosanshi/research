# 真实问答突破：八条方法线的原文与作者代码核验

2026-11-06。针对本项目“真假判断改善、自由生成未改善”的现象，检索覆盖到当前日期；以正式论文或作者预印本、作者仓库为依据。旧的DAS、ReFT、ITI、TruthX沿用第13轮全文记录并复核关键实现；本轮新增重点阅读BiPO、ACT、FASB、YaPO的方法、评测和相关代码，**不声称八篇都在本轮重新逐页读完，也未运行作者真实模型实验**。

**首选行动：把现有DAS方向作为初始化，直接用正确答案内容训练，并在训练时使用部署时实际使用的写入位置和算子。第二候选是有界的一次检测、回退、重生成。两者分开做，先检验前者。文献支持这些尝试的动机与实现方式，不保证本项目一定获得正结果。**

术语：DAS（分布式对齐搜索 · 交换内部表示的一部分，学习哪个子空间能控制目标行为）；CE（交叉熵 · 让正确答案的每个词获得更高概率）；teacher forcing（教师强制 · 训练时给出正确前文，让模型学习预测下一个词）；DPO（直接偏好优化 · 让好回答相对坏回答更受模型偏好）；token（词元 · 模型一次生成的一小段文字）。

## 2. 最优先候选：让DAS初始化直接学习“下一步该说哪个词”

当前代码的事实是：在**已经给出完整答案后**交换答案末位的表示，监督后面的真假自检；部署却在**答案尚未说完时**，对生成位置做无来源放大。即使两边都使用问答模板，监督对象、读写位置和操作仍不一致。这个差异是可测试的设计问题，尚不能直接断言就是全部失败根因。

推荐第一版如下，属于我们受DAS、ReFT、BiPO启发的组合方案，不是对任何一篇的逐字复现：

1. **沿用已有题目划分、提示和底座。** 只用原有估计题的正确答案训练；先固定一个既有候选层，别同时增加层数、换提示和扩大数据。
2. **从已训练DAS单位方向初始化，底座仍冻结。** 第一对照是原DAS不继续训练；另保留均值差／随机方向在相同目标和预算下训练的对照。否则即使改善，也只能证明“内容训练有效”，不能证明DAS初始化有贡献。
3. **目标首先用完整正确答案CE。** 提示和填充不算损失；实际训练每个被预测的答案词，而不是回答后追加的True/False。真实生成是否变好决定去留，训练损失下降本身不算突破。
4. **写入位置与部署逐位一致。** 预测第一个答案词时写提示末位；预测后续词时写当前答案前缀的末位。完整序列训练中，这些是`prompt_length−1`到`prompt_length+answer_length−2`，不能误写为答案自身的下一位置。模型缓存解码与完整序列前向使用同一规则。
5. **训练时就用部署算子。** 若部署是相对提示／解码中心的放大，训练也必须是同一中心、同一掩码、同一放大函数；不得训练交换、测试时才突然换放大。若改成可学习加法或低秩仿射变换，另起方法名与独立对照。
6. **CE通过后再单独增加偏好项。** 成对回答的概率差应统一处理长度，可参考BiPO减去原模型的正负回答概率差；正答案CE锚住内容，避免仅压低坏答案就把好坏答案概率一起压低。具体混合系数、归一化与参考项属于我们的实验选择，不能写成BiPO原方。

名称建议：`DAS-initialized generation adaptation`（DAS初始化的生成适配 · 用现成方向起步，继续直接训练回答内容）。保留原始DAS结果，不能把后续生成适配的效果追溯成原始交换训练已经证明有效。

**多层怎么加：** 单层内容监督确认有作用后，再试一个小窗口，单层与窗口使用相同训练题、目标和选择预算，记录每层实际相对改动大小。几层共用同一个数值强度不等于总干预量相同；TruthX的模块数量也不是本项目该叠多少残差层的答案。

## 3. 第二候选：在首次疑似出错时，回退一小段重新生成

依据主要是FASB，而非“所有动态方向都会更好”。建议先固定已验证的方向与强度，只改变生成时机：正常生成→用不读测试金标的检测分数判断→最多一次回退→带方向重生成。初版可以固定回退短窗口，阈值只用调参题选择。

要保持名字诚实：用DAS替换作者的头探针方向，是**受FASB启发的DAS修订器**，不是官方FASB复现。必须有“相同生成预算、但不加方向”的重生成对照，以区分方向效果和多试一次的效果。缓存中被回退词及其后续状态必须清除或重建；只删文本、不回退模型缓存会造成伪实验。

已有“先核验再弃答”的正结果可以帮助挑检测分数，但它只证明筛题有用，不能代替这里的改写成功。也不能把答案末位的检测器未经检查就当作每一个生成前缀上的可靠检测器。

## 4. 最小试跑与判读

先1–3题逐词验执行：正确／错误答案都覆盖多词，确认词元位置、梯度、模型底座不变、原方向恢复、缓存与无缓存前向的关系。然后用少量训练题做内容训练可学性检查；只有调参集自由输出出现真实内容改善才扩大。固定记录每题原回答、干预后回答、正确／错误／拒答、是否打满长度、实际写入位移。

主实验的同实际作答率表与生成适配的机制检查分别保留：前者回答“交付同样多答案时谁更准”，后者还必须报告**未经筛题的正确数以及原错→现对、原对→现错**，才能证明答案内容本身发生了收益。选择题偏好、自评更准、拒答更多都不能单独充当自由生成突破。

对当前优先级的判断：先完成生成内容监督与部署位置一致的DAS初始化版本；若没有可复验收益，再考虑有界回退。暂不把稀疏自编码器、多头重构、更多模型和多个新提示一起引入。
