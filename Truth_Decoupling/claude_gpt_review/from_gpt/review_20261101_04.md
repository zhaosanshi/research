## 改了什么

1. `code/scripts/e1_directions.py` 新增 `--das-all-layers`：从已加载模型读取实际层数，训练全部层，含第 0 层和最后一层。它与手工指定层、按评分预选层的选项互斥。保存实际训练层清单、层数及提示选项。读层沿用现有探针的区分分数；原有评分建议的写层字段保留兼容，新增说明明确它不是实测写层。
2. `code/scripts/e23_knob_sweep.py` 新增 `--all-layers`：逐层独立干预、使用同一强度列表。缺少指定变体的任何方向文件，立即报错，不再跳过该层。保存层数和调参协议信息。顺手用字典副本设置问法，避免原先 `clear()` 误清空默认问法本身。
3. 新增 `code/scripts/report_read_write_layers.py`：从同一轮 E1 和完整 E23 输出生成单层读写对照表。读层取现有探针分数最高的层（保留并列）；写层候选只按调参集效果选择，列出其测试结果和读写距离。首层、末层或某层的强度结果缺失时拒绝报告。

当前配置对应 Llama 32 层、Qwen 36 层、Gemma 48 层；程序从实际模型取数，不写死这些数值。

**选层口径保持现有约定：**先满足自报作答比例变化绝对值不超过 0.03，再取判别指标 J 提升最大的配置。偏置、排序判别指标同时列出。找不到合格候选就报无；选中候选但调参增益不为正，会明确标记。这是读写层对照，不是新一轮 2×2 成功宣告；报告不计算置信区间。

## 你审核后怎样运行

这些文件属于实验代码快照，需要更新到你的完整实验工程。仓库快照缺少 `core.config`、`core.io_utils`、`core.layer_score` 等原工程依赖，GPT 没有伪造这些模块来宣布整个实验入口已跑通。

按约定先做真实模型小样本验收，输出放单独目录；正式 96 对训练另开目录。通过后，完整流程如下（以 Llama 为例，其他模型更换模型名，各有自己的输出子目录）：

```bash
export TD_RESULTS_DIR="$PWD/results_das_tf_prompt_full"
TD_REVIEW_MODEL=llama3.1-8b

python3 scripts/e1_directions.py \
  --exp E1_directions_tqa --model "$TD_REVIEW_MODEL" \
  --direction-prompt tf --das-anchor prompt \
  --das-tags E --das-pairs 96 --das-all-layers

python3 scripts/e23_knob_sweep.py \
  --exp E2b_tqa --model "$TD_REVIEW_MODEL" \
  --all-layers --e-estimator das \
  --das-dir "$TD_RESULTS_DIR/E1/$TD_REVIEW_MODEL" --das-variant tf \
  --tune-pairs 192 --no-cs --tag das_tf_full

python3 scripts/report_read_write_layers.py \
  --e1-dir "$TD_RESULTS_DIR/E1/$TD_REVIEW_MODEL" \
  --sweep "$TD_RESULTS_DIR/E23/$TD_REVIEW_MODEL/knob_sweep_das_tf_full.json" \
  --out "$TD_RESULTS_DIR/E23/$TD_REVIEW_MODEL/read_write"
```

本命令逐层分别干预，未添加三层联合候选。C 仍用现有提示对比方向，`--no-cs` 关闭另一套自评分组估法。报告采用 A=192 对调参、B=529 对测试；层选择不读取 B。

读层依据是**现有估计集探针测量口径**，本轮不把它扩张为“已经证明模型拥有完整事实知识”。读取方向文件时按上述同一独立目录操作；报告比较模型、层数、提示选项、样本数、变体和种子，但未做权重文件来源哈希核验。
