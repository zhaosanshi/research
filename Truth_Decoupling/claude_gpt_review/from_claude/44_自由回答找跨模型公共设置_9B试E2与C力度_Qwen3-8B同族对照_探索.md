## 2. 先用已有数据找两个模型的公约数（Llama、9B；Qwen3-8B 的第 0 步在跑）

### 2.1 如实句：E2 在两个模型上表现一致，E1 不一致

只换提示、不写入（第 0 步）。E 方向是照着"必须作答 → 必须作答 + 如实句"这一对提示学的，所以这一对提示本身的副作用会被方向一起学走（`results/12_…` 第 9.2 节）。

| 只换提示、不写入 | Llama + E1 | Llama + E2 | 9B + E1 | 9B + E2 |
|---|---|---|---|---|
| 必须作答问法加如实句：Pro 判答对增加 | +21 | **+28** | +17 | **+22** |
| 同上，AllenAI | +20 | +29 | +25 | +24 |
| 同上，平均每个回答的词数 | 3.4 → 4.4 | 3.4 → 4.0 | 3.1 → **6.4** | 3.1 → 2.8 |
| 谨慎问法加如实句：作答数变化（Pro / AllenAI） | −2 / −6 | −8 / −9 | **+14 / +16** | −9 / −8 |
| 普通问法加如实句：作答数变化（Pro / AllenAI） | −5 / −7 | 没冻结过 | **+10 / +9** | 没冻结过 |

- E1 的副作用在两个模型上方向相反：9B 上回答长一倍、更敢答；Llama 上几乎不变长、更爱弃答。
- E2 在两个模型上都更好：答对增加更多，回答不变长；副作用方向也一致——两个模型在谨慎问法下作答都少 8–9 题。
- **所以 E2 是两个模型的公约数，E1 不是。**改设计时只改这一处：把 E 的上档句子从 E1 换成 E2（积极，线索）。
- 普通问法和"写成完整句"问法上加 E2 会怎样，没冻结过。这次补上（第 3 节，只换提示的诊断）。

### 2.2 C 往谨慎推：力度 1 在两个模型上都过头，0.5 在两个模型上都不改坏

C 的冻结判据里有"保持"一条：两次都作答的题上，正确率变化要在 ±3 个百分点内。下表是 Pro 判的这项变化（普通问法 x）：

| C 往谨慎的力度 | Llama 第 19 层 | Llama 第 31 层 | 9B 第 12 层 | 9B 第 16 层 |
|---|---|---|---|---|
| +0.25 | 作答 −6，+1.3 pp | 作答 −10，−0.7 pp | 作答 −17，0.0 pp | 作答 −18，0.0 pp |
| +0.5 | 作答 −12，−1.3 pp | 作答 −15，−0.7 pp | 作答 −34，0.0 pp | 作答 −33，0.0 pp |
| +1（冻结的力度） | 作答 −43，**−4.3 pp** | 作答 −39，**−3.3 pp** | 作答 −73，**−4.4 pp** | 作答 −72，**−5.5 pp** |

- **Llama 往谨慎推到力度 1，Pro 下也改坏了已答题（−3.3 到 −4.3 个百分点）**。所以 Llama 首轮的 C 也只在往果断一向两家都满足（`31`）。力度 1 往谨慎在两个模型上都过头，0.5 在两个模型上都没有改坏，效果也都超过 3%。
- 原因的线索：普通问法 x 本来就靠近谨慎问法（不写入时，两家裁判下 x 弃答 23–25 题，谨慎问法 27–30 题，必须作答 1–4 题）。力度 1 等于把 x 再往谨慎方向推一整段"必须作答 → 谨慎"的距离，推到了训练时没见过的地方。
- 0.5 这两档是看了结果才挑的，还没有随机对照。这次补上（第 3 节）。

### 2.3 C 往果断推：9B 的"必须作答"提示本身就会改坏已答题

| 只换提示、不写入：普通问法 → 必须作答 | 作答数 | 两次都作答的题上正确率变化 |
|---|---|---|
| Llama，Pro / AllenAI | +20 / +23 | −1.9 / −2.4 pp |
| 9B，Pro / AllenAI | +24 / +21 | **−4.3** / −1.8 pp |

- 9B 上"必须作答"这个提示本身在 Pro 下就让两次都作答的题里 9 题由对改错、2 题由错改对，净 −7 题，超出 ±3 个百分点。C 往果断推是照着这个提示学的：第 12 层力度 −1 时也是 9 题改错、2 题改对（−4.3 pp），和提示本身一模一样；第 16 层 −6.1 pp。
- 也就是说，9B 的 C 往果断推不过"保持"这一条，主要不是方向学歪了，而是模型本身"被逼着多答时，已答的题也会答得差一点"。力度降到 0.25 时 Pro 下 −1.8 / −2.5 pp，作答 +6（刚过 3%）。（中性）
