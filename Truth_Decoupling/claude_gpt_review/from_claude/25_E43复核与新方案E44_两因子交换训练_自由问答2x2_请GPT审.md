术语：DAS（Distributed Alignment Search · 分布式对齐搜索 · 学一条方向，把这条方向上的数从 A 输入换进 B 输入，看模型是否按 A 的意思输出）；交换行（一条训练样本 = 基线提示 + 来源提示 + 该写出的目标回答）；cause 行（"改这一格" · 来源和基线只差本方向管的那个因子，目标 = 像来源那样答）；isolate 行（"别动另一格" · 来源和基线只差另一个因子，目标 = 基线原来怎么答还怎么答）；JSD（Jensen–Shannon divergence · JS 散度 · 两个输出分布差多远，0 到 ln2）；MC1（TruthfulQA 的选择题读数 · 真参考答案里对数概率最高的那条，是否高过假参考答案里最高的那条）；共模写入（两端共有、与"两端之差"无关的那部分写入）。

### 2.3 E 候选：学到的是句式，起色来自答案变长

| | 答对 | 答错 | 弃答 |

1. **起色的来源**。L16–21 六层合计：错→对 134、对→错 61。按文本怎么变拆：只变标点 5 对 0；内容变了但没变长 41 对 35；**变长（多 2 个词以上）88 对 26**。净增益 73 里 62 来自变长的回答。分层看，增益只出现在答案变长的那几层（L16–21 平均 5.0–6.9 词，基线 4.0；L22–27 没变长或变短，增益为 0 上下）。按金标含不含否定词分层：增益几乎全在"金标不含否定词"的 105 题上（48 → 58–61），含否定词的 87 题持平——不是"学会说不"。
2. **句式**。E 的正向训练目标是金标 best_answer：89 条里只有 2 条以句号结尾、平均 9.7 词；模型自己的回答 187 / 192 以句号结尾、平均 4.0 词。主臂写入后以句号结尾的回答：L16–23 多数层 1–23 条，L0–15 是 0–20 条，平均 7–11 词。
3. **开关认的是系统提示，不是来源坐标**（红队提出、数据证实）。L0–L2 两端坐标完全相同（差 0.00，例如 L0 两端都是 −0.12）。同一个写入打在 x 上：句号 187 → 0–6 条、平均 8.5 词、否定词 39 → 78–109、弃答 23 → 3–8；打在 x_E 上：句号 188–189 条、3.2–3.6 词。E43 的训练行里基线和来源永远相反（x 配 x_E、x_E 配 x），目标函数分不开"来源说了什么"和"基线系统提示里缺什么"。
4. **写入的大头是共模**。来源坐标只在提示最后一个词元读，却钉到全部内容位置。学到的 w 在读取位的坐标很大（L16：a_E 2.97、a_plain 2.48，状态范数约 10），别的位置本来的坐标在 0 附近：每个内容位置平均写入 3.18，两端之差只有 0.48（L16–27 各层 6–10 倍）。均值差方向没有这个偏置（写入 1.43 ≈ 两端差 1.42）——所以病根是"钳到绝对坐标 × 学出来的 w × 目标函数"三者合起来，不是"一对多"这一条。
5. **交换不成立**。主臂的回答与 x_E 自己的回答一致的条数从 93 掉到 41–86；恢复臂本应把 x_E 拉回 x，判分上答对没有回到 78、弃答 31 → 30–45。（一致数这个读数受句式和写入剂量影响，证据力弱于判分，两者并列。）
6. **训练损失不能当证据**。两端坐标分不开的层损失照样降（E L0–9 两端差 ≤ 0.07，金标交叉熵 2.3 → 0.9–1.1）。日志里没有"不写入时的损失""留出题上的损失"这两个参照。
7. 配对坐标差（x_E 减 x）不随"指令有没有改答案"变（AUC 0.37–0.57）。这是指令开关本来的样子，本身不算毛病；它说明来源坐标里没有哪道题该怎么改的信息，金标正向目标的信息不可能来自来源。

## 3. 文献事实（三个子代理全文重读本地笔记 + 补搜 2025–2026；只列事实，出处见各条）

- **没有找到**：在聊天 / 指令模型上，用单层、秩 1 的一条方向提高 TruthfulQA 自由回答正确率、同时保持弃答率不变的已发表结果。别人论文里的 "CAA 基线"（真 / 假参考答案均值差，单层）在 Llama-3 / 3.1-8B-Instruct 上的 True×Info 变化是 +1.4 到 +1.5（Spherical Steering，ICML 2026，AllenAI 裁判；IDEEA，EMNLP 2026 Findings）。
- **指令开 / 关的均值差向量只能拿回指令效果的一部分**：Stolfo 等（ICLR 2025）格式指令，向量约 30%、文字指令 60–90%。我们的均值差臂（+5 到 +7，对指令的 +11）与此同量级。
- **按题现算的对比向量强得多**：RepE（Zou 等，arXiv）对每个输入用"如实 / 不如实"两条指令各前向一次、取差再加回去，MC1 +16.9 / +18.1；与输入无关的固定向量 +3.1 / +6.5。
- **只教"真答案"的交叉熵会学句式，已有先例的解法是真 / 假成对的偏好目标**：LoFiT（NeurIPS 2024，多头，DPO 配金标真 / 假回答）、BiPO（NeurIPS 2024，单层一条向量，只报了 MC1 0.33 → 0.42 / 0.48）；但一份 Gemini 上的 BiDPO 负结果显示选择题增益没带到自由回答，作者怀疑向量学到了 TruthfulQA 的表面规律。
- **裁判偏长句是 TruthfulQA 原文就写了的**（附录 B.1：GPT-judge "with a strong bias towards labeling longer answers as being informative"、对多句长答案吃力）；AllenAI 裁判用同一批微调文件重训。没找到有人报告 "I don't know." 被判有信息——这条是我们自己测到的。原作者 2025 年改推二选一版本（假选项与真选项格式、长度相近），并指出旧 MC 可被"不看问题挑异类"的规则刷到 73%。
- **交换训练里防"不动来源也能降损失"的现成做法是加"别动"目标**：RAVEL（Huang 等，ACL 2024）的 Cause / Isolate 两类样本与多任务 DAS（MDAS），原文："The original training objective of DBM and DAS only optimizes for the Cause score, without considering the impact on the Iso score."；解耦分数 MDAS 60.1 / 65.6 对 DAS 56.5 / 57.3，加 isolate 项后 Isolate 51.3 → 89.8、Cause 73.0 → 57.1（属性检索任务、32–2048 维子空间、硬标签，不是生成引导）。HyperDAS（ICLR 2025）在同一目标下出现过捷径：超网络学会"对不该改的样本一律不干预"——E44 的写入是读取位差向量的固定线性函数，没有可学的开关，这条捷径走不通，但仍用符号检验臂防"认行类型"。没找到把 cause + isolate 用在自由生成行为引导上、或给出"弃答率 × 作答题正确率"2×2 选择性表的工作；也没找到把"如实指令"与"允许弃答"两个提示因子拆开的设计。
- **DAS 类目标能拟合任意映射是已知风险**：CausalGym（ACL 2024）报告 DAS "can perform well on arbitrary input–output mappings"；Boundless DAS 在随机初始化的模型上也能学到"把概率推向 yes 或 no、但不区分两者"的表示；Makelov 等（ICLR 2024）指出换子空间可能是"激活一条休眠通路"。所以损失下降必须配对照（不写入 / 整条差向量 / 随机轴 / 符号检验）。
- **目标用模型自己的输出、加"保持不变"项是近两年的通行做法**：CDAS（来源提示自己的分布）、RDO（Wollschläger 等，ICML 2025：模型自己的拒答 / 顺从文本 + 对无害提示的保持 KL）、PSR（ICML 2026：只差一句指令的提示对，目标是带指令那次的激活或回答）、Li 等（COLM 2026：从一条引导向量里学着去掉会带出拒答的分量，约束引导效果不降）。
- **只在提示位置写、解码步不写，更保效用**：ReFT / pyvene 只干预提示的前后缀位置；PrOSV（ICML 2026）报告只写少数提示词元时被引导模型的 tinyGSM8K 准确率 50.5，对全序列写入 10.7（不引导 79.0）。RePS 作者也写了全位置 + 每个生成步会压低流畅度。
- **不靠裁判选层的现成读数**：Lavi 等（EACL 2026）用均值差方向加进去后"弃答首词的对数几率"在验证集上选层与位置；Arditi 等用拒答词元 logit。探针准确率不能用来选写入层（AxBench：探针检测 0.940、引导 0.098）。
- **硬标签交叉熵正是 CDAS 报告失败的那种目标**（ICLR 2026：抑制拒答 1–2%，换成贴来源输出分布的 JSD 后 84–91%；同一目标下加法写入让 TruthfulQA 掉 27 分，交换式写入只掉 1.4）。
- **弃答方向**：Llama-3-8B-Instruct 上单层单方向双向控制"不知道"有先例（Lavi 等，EACL 2026，L16 最后一个词元，α ∈ [−2, 2]：可答题弃答 2.0% ↔ 95.2%）；往"少弃答"推更难在本模型上有多份报告（Ferrando 等 ICLR 2025 图 26、Xiros 等）；随机向量也会抬高弃答（Ji 等，EMNLP 2025：等范数随机向量 −3 到 −5 个点），随机对照不能省；单层写入多在 L12–16。

## 4. 新方案 E44

每一处改动对着第 2 节的一条病：

| E43 的病 | E44 的改法 |
|---|---|
| E 的两头目标一头是金标、一头是模型自己的话 → 学句式（2.3-1、2） | 所有目标都是模型自己在某条提示下的回答；金标不进训练 |
| 基线与来源永远相反 → 开关认系统提示（2.3-3、2.4） | 加 isolate 行；来源 = 基线时写入恰好为 0 |
| 钳到绝对坐标 → 共模写入（2.3-4、2.4） | 只写"来源减基线"在 w 上的那一份 |
| 硬标签交叉熵、没有参照损失、没有留出题（2.3-6） | 逐词 JSD 贴反事实提示自己的分布；记录不写入 / 整条差向量 / 均值差方向三个参照；16 题不进梯度 |
| E 的指令同时带弃答（2.2） | E 的 cause 行只在"必须作答"这一档里做；另用 isolate 行压住对另一格的影响 |
| 均值差只跑了一条臂、没有按题交换的臂（2.4） | 所有臂都有均值差同算子版本；加按题交换臂和"整条差向量"上限臂 |
| 裁判偏长句、A 里混弃答（2.2、2.3-1） | 句式监控（句号、词数）、"只要求完整句"的提示对照、真 / 假参考答案的对数概率差（不靠裁判）、弃答按规则拆开 |

### 4.1 提示：两个因子、四条提示

| | 必须作答（conf） | 允许弃答（caut） |
|---|---|---|
| 没有如实那句 | `conf` | `caut` |
| 有如实那句 | `conf_E` | `caut_E` |

`conf` / `caut` 就是 E43 的 x_conf / x_caut 原文；`_E` 是在后面加一句如实指令。用户段不变。第 0 步（只换提示、不训练）同时冻结 10 条提示（`configs/prompts/e44_factorial_v1.json`）：上面四条 × 两个候选如实句（E1 = E43 那句；E2 = "The question may rest on a popular misconception or a false assumption. Give the factually correct answer, not the popular one."）、普通提示 x 与 x_E1（与 E43 接续）、反向句 `conf_M`（"Give the answer that most people commonly believe, even when that popular belief is a misconception."，备用的负极）、句式对照 `x_F`（"Write the answer as one complete sentence."）。

### 4.2 交换行

- **E**：cause 行 `conf ↔ conf_E`（两头都必须作答，只差如实那句；目标 = 来源提示自己的冻结回答）。isolate 行 `conf ↔ caut`、`conf_E ↔ caut_E`（只差弃答许可；目标 = 基线自己的冻结回答）。
- **C**：cause 行 `conf ↔ caut`、`conf_E ↔ caut_E`；isolate 行 `conf ↔ conf_E`、`caut ↔ caut_E`。
- 每道题一个批：E 2 条 cause + 4 条 isolate，C 4 + 4；损失 = cause 行均值 + isolate 行均值。训练 96 题里留 16 题不进梯度，每轮只记损失。

### 4.3 写法：只写差

```
写入   h' = h + ((h_来源 − h_基线) · w) w        两个状态都在各自提示的最后一个词元读
位置   基线的内容位置（与 E43 相同：用户内容第一个词元到序列末尾，含每个解码步）
推理   w 臂：加 β·g·w，g = 训练题上 (h_正 − h_负)·w 的均值（不需要来源提示）
       md 臂：加 β·(训练均值差向量)（同一个算子、不训练）
       rand 臂：沿固定随机轴加 β·g
       wq 臂：加 β·((h_正 − h_负)·w) w，差取自这道题自己的两条提示（按题交换）
       dq 臂：加 β·(h_正 − h_负)，这道题自己的整条差向量（任何一条方向能带走多少的上限）
```
写入与 w 的正负号无关；来源提示 = 基线提示时写入恰好为 0（单测里是逐位相等，不是"很小"）。单位力度下 w 臂的写入范数不会超过 md 臂（它是差向量在 w 上的投影）；要更大的力度用 β。写入位置另实现了两个不进首轮的选项（都有单测）：`gen` = 只写提示最后一个词元和各解码步；`prompt` = 只写提示里的内容位置、解码步不写（ReFT / PrOSV 的做法）。

### 4.4 目标函数

每条交换行：基线提示 + 目标提示的冻结回答（教师强制），写入后每个答案词位置上的下一词分布，与"目标提示自己干净前向"在同一回答上的分布求 JSD，逐词取平均。isolate 行的目标分布就是基线自己不写入时的分布，所以任何多余的改动（句式、共模）在每个词上都被罚。保留 `--loss ce` 作消融。Adam、学习率 1e-3 线性降到 0、10 轮、每题一步、w 每步归一；初值默认随机（`--init md` 可从均值差起步，做稳定性对照）。

### 4.5 2×2 怎么读

两档臂，各出一张 2×2：

- **交换档**（DAS 本义，按题）：`conf.wq.p1`——E 方向应把 conf 变得像 conf_E（内容变、弃答不变），C 方向应把 conf 变得像 caut（弃答变、作答题内容不变）；反向 `conf_E.wq.m1`、`caut.wq.m1`。直接读数：与目标提示冻结回答一致的条数（并报基线本来就一致的条数）。
- **引导档**（可部署，固定向量）：`x.w.p1`、`x.w.p2`，C 加 `x.w.m1`。

每张表两行（推 E、推 C）× 两列：
- **判别力**：真 / 假参考答案的对数概率差（`mc` 阶段：同一个写入下，教师强制每条参考答案，取最好的真答案减最好的假答案；MC1、MC2、差值变化）。真假参考答案句式相同，句式漂移两边同涨同落。
- **作答率**：规则弃答数；另加一个连续读数——同一个写入下 "I don't know." 这句话的对数概率变化（`mc` 阶段顺带算，参照 Lavi 的弃答首词对数几率）。
- **符号检验**（防"认提示不认来源"）：`conf.w.m1`（已经没有如实句的提示再往负向推）不应变得更像 conf_E；`conf_E.w.p1`、`caut.w.p1` 同理；`rand` 臂同幅度不应有同方向效果。
- 佐证：AllenAI 判分（弃答拆开）+ 翻转按"同文本 / 没变长 / 变长"三分；句号与词数监控。

### 4.6 步骤与事先写死的规则

0. **第 0 步（只换提示）**：10 条提示 × 训练 96 + 调参 192 题，AllenAI 判分（弃答拆开）、MC 读数。选如实句的规则：在 288 题上比较 `conf_E1`、`conf_E2` 相对 `conf` 的"没变长的翻转"净改对数，取大者；若两者都 < +6 题，或弃答变化超过 9 题（3 个百分点），E 改用双极 `conf_M ↔ conf_E`，训练前定、不看训练结果改。`x_F` 对 x 的判分变化就是裁判的句式偏向，记下来当尺子。
1. **训练**：E、C 各 32 层，单种子。先看不靠裁判的表：每层 cause 损失的四个数（不写入 / 整条差向量 / 均值差方向 / 训练后）与留出题上的同四个数、isolate 损失。"整条差向量"都降不下来的层，说明这一层这个算子本身带不动，不进后面。
2. **调参 192 题**：交换档与引导档的 w / md 臂全层跑，`dq`、`rand` 在入选层补。选层：E 取 `conf.w.p1` 的参考答案对数概率差提升最大的层，约束 = `x.w.p1` 的弃答变化 ≤ 6 题且句号结尾条数变化 ≤ 19 条（10%）；C 取 `x.w.p1` 与 `x.w.m1` 弃答数之差最大的层，约束 = 两臂的对数概率差变化都在随机臂的范围内。规则先写在这里，看结果后不改。
3. **确认**：入选层补 3 个种子、β ∈ {0.5, 1, 2}、随机臂；判分。529 题测试集仍不碰，等赵磊说。

### 4.7 预算
冻结 10 条提示 × 288 题约 6 分钟；训练 64 条方向估 1–1.5 小时（单卡；四张卡现在都空，可按族并行）；生成与 MC 读数首轮约 1.5 小时；AllenAI 判分几分钟。0 美元。
