## 1. 为什么还要试一次

E41（`09`）按正确口径（验证过的 C 固定、E 扫全层、模型自己决定答不答）得到 0 / 4 项为正，结论"C 的作用是门槛"。但 E41 用的 C 力度是 2×2 选中的 α = 2，在那个力度上 **C 已经饱和**：Llama 推弃答后 1058 条测试陈述里只剩 100 条自答，Qwen 和 Gemma 推弃答后自答 0 条——"同样多题"的比较在饱和处退化。所以把 C 的力度降下来，在 0.25 / 0.5 / 0.75 / 1 / 1.5 / 2 六个力度、两个方向上各做一遍，E 固定在 2×2 选中的那一层（Llama L11、Qwen L35、Gemma L12，力度 3），其余全部沿用 E41 的协议与预声明分析（`e41_analysis.py`）。

事先标准（记事本 N7，跑之前写死）：至少两个模型、至少一个力度上，**E+C 自答的答对数**显著多于 **E 按自己的置信度卡到同样多题**（P2，Holm 校正），博士原句才算成立。GPT 第 24 轮审核后两处收紧：Holm 改为每个模型 24 项（6 力度 × 2 方向 × P1 / P2）统一校正；并指出只比单 E 不够，"胜过任一单方向"还要比**单 C 卡到同样多题**（P5b，补充对照，事后加的，单独标出）。

## 3. 读法（人话）

- 在六个力度、两个方向、三个模型上，只要 C 没把作答推到 0 或推到全答，**E+C 让模型自己选出来的那批题，答对的都明显少于"同样多题、按 E 的置信度挑"**，差 34–107 题（占 1058 条测试陈述的 3–10 个百分点），全部显著；**也明显少于"同样多题、按 C 单独的置信度挑"**（P5b），差 14–85 题。
- P1 ≈ 0 说明机制：C 挪的是门控分的门槛，不是挑题的依据；门控分挑题比置信度差得多（`13` 的发现），所以靠 C 自选的 E+C 一定输给按置信度卡阈值的 E 或 C。
- 结论：**博士原句"相同作答率下组合优于任何单一方向"，在正确口径下、从 α = 0.25 到 2、三个模型都不成立**；E41 的"C 的作用是门槛"在中间力度上同样成立。这不是"E+C 没用"：两个旋钮可叠加（`09`），E 抬曲线、C 沿曲线走（`12`）仍是我们建议的主句。
