# E26 同作答率主实验与 E27 发布版重跑：结果（2026-11-06）

赵磊的要求："保证全面审核后，就要开始全面跑实验了。"审核见 `13`；本文是 18:23 开跑的四条链与之后一条探索链的结果。

**纪律**：分析计划在任何结果出来之前写进 `13` 第 4 节（提交 66868ab，18:30），分析代码 `review_checks/e26_primary_analysis.py` 在测试判分完成前提交（ca67e33，19:17）；E26 用默认配置、代码取自 GitHub 7987310 的独立服务器副本；层与强度一律在 192 道调参题上按事先规则选，529 道测试题上报告（问答主表 523 道实质金标题）。**测试集在前几轮已看过，不是新数据**（`13` 第 3 节 E）。原始产物：`results/03_E26同作答率_E27生成适配/`。

术语：E（证据方向）、C（承诺方向）；"承诺分"= 另一提示里模型对"你知道 / 能答这题吗"首词 Yes 减 No 的分数；"简单置信"= 真假判断里真 − 假对数概率差的绝对值、问答里不加干预时答案的平均对数概率；同作答率 = 只交付固定比例的实质回答（其余交付"I don't know."），比交付集里答对多少；Holm（多重比较校正 · 一组检验里把显著门槛逐个调严）。

## 1. 结论

1. **老师的主张"相同作答率下，组合比任何一个单独方向都好"——未成立。** 事先声明的主对比（DAS 的 E+C 对 E）12 格里差值在 −3 到 +9 题之间，Holm 校正后 0 格显著。**对老师原句：消极。**
2. **C 在相同作答率下没有作用。** 只推 C 对不加干预的原模型，12 格全部约等于 0；剂量探测（`13` 第 2 节）显示 C 把承诺分整体平移 0.6–1.0 个标准差、却几乎不改题目排序（秩相关 0.96–0.998）。**"C 就是门槛旋钮"有了直接证据：对我们的解释，积极。**
3. **E 在真假判断上，相同作答率下仍提高答对数；自由问答上没有任何方向有用。** 真假判断：推 E 对原模型（都按承诺分排序）在 50% / 75% 两档两模型都显著（+26 到 +40）；推 E + 简单置信对原模型 + 简单置信，Llama 50% / 75% 显著（+40 / +44），Qwen 未过 Holm（+17 / +22）——这两组是事后探索。自由问答：所有对比都不显著。**真假判断：积极；自由问答：消极。**
4. **"你知道吗"的自报承诺分作为挑题依据很差。** 真假判断上，E+C 在 5 个格子（Llama 50% / 75%，Qwen 三档）里显著输给至少一种简单置信对照（共 8 个 Holm 显著的负对比）；原模型按承诺分挑题，75% 档反而不如随机（Qwen −49，Holm 0.026；Llama −42，Holm 0.074）。**新发现，中性偏积极**（与 Kumaran 等"口头置信跟踪承诺而非对错"一致）。
5. **E27 生成适配：发布版代码复现了 GPT 的数字，但这个提升很脆弱、而且与 DAS 无关。** Qwen 上各起步各种子按裁判原判都多答对 21–50 题，但回答变长、未正常结束变多；DAS 起步独有大量 U+FFFD 乱码，扣掉后不胜随机；最严规则下只剩均值差起步（+21）与随机种子 42（+27）显著。Llama 上五个适配器都是零效果。**对 DAS 作为方法：消极。**
