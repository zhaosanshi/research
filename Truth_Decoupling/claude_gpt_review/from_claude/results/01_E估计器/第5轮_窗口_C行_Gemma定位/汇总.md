### 3.1 做了什么

按 GPT 的设计，用现成的 Gemma 方向（第 20、25 层的 DAS-tf 方向，另加同层均值差方向作对照；中点 cB 与扫描完全相同），在固定顺序取的样本上（第 1 个 DAS 训练对 `tqa:765`，调参集里按测试顺序的前 2 对 `tqa:685`、`tqa:270`）比三种处理：**原样**（零改动走同一个钩子，必须逐位相同）、**交换**（把配对句在该方向上的坐标写进来，α = 1，即 DAS 训练时的操作）、**放大**（扫描用的算子与中点，α = 3）。每次前向记录：实际被改的位置及其 token、|h|、|Δ|、|Δ|/|h|、写回 bfloat16 后保留的比例（kept/Δ）、方向上的投影"改前 → 预期 → 实际"、首词的 P(True)/P(False)/p_true/argmax/top-5、KL(p_参考 ‖ p_干预)（DAS 损失的 t = 0 项）与 KL(p_原 ‖ p_干预)。再把交换与放大在**全部 96 对训练对与全部 192 对调参对**上重复一遍做统计，并与扫描 JSON 里同一调参半的数字对表。

保真检查两项都过：原样处理逐位相同；统计出的调参半基线 J 0.630 / AUROC 0.890 / B 0.518 对扫描的 0.620 / 0.891 / 0.518，`E_L25_a3` 放大后 0.594 / 0.881 / 0.531 对扫描的 0.599 / 0.880 / 0.534（批大小 1 对 8 的 bfloat16 数值差，384 句里差 4 句的判定）。**诊断走的就是生产代码的路。**

环境事实（GPT §3 要求随诊断记录）：torch 2.13.0a0（NVIDIA 26.06 容器）、transformers 4.57.1、CUDA 13.3、模型 bfloat16、`Gemma3ForConditionalGeneration`、隐藏维 3840、48 层、滑动窗口 1024、层类型 40 层局部注意力 + 8 层全局、注意力实现 sdpa。强制真假提示下的 token 长度：估计集 68–117、测试集 65–121，**没有一条超过 1024**，局部注意力与本问题无关。

### 3.4 读法：断点在哪

1. **写入本身没问题。** 位置就是提示末 token（Gemma 聊天模板的换行符），零改动逐位复现，DAS 的改动 98% 到 100% 保留。GPT 的分叉 ①（位置或数值）对 DAS 排除。
2. **第 20 层：根本没有一条能交换首词的方向。** DAS 训练损失 4.70 已经说明没拟合上；训练对上只有 1.4% 交换成功。扫描选它只是调参集上的噪声（调参 ΔJ +0.047，测试 +0.009）。
3. **第 25 层：交换能泛化，放大却无益——GPT 的分叉 ③。** DAS 方向在没见过的 192 对上 80% 交换成功、关掉 87% 的 KL，把每句换成配对句的坐标后 J 从 +0.63 变成 −0.40——这条坐标**就是模型输出的决定变量**。但它读出的真假 AUROC（0.859）**不高于**模型嘴上的 0.889，放大它只是把模型已有的判断（包括错的）推得更极端：调参集上 6 句错→对、13 句对→错，ΔJ −0.036。
4. 合起来：**放大式要起效，坐标必须比模型的输出更懂真假**（Llama 第 11 层就是这种：方向能读出的比嘴上多，放大让下游"听"它）。Gemma 上我们找到的因果方向（晚层 DAS）不比输出多知道什么；更懂真假的读出（第 22 层探针 AUROC 0.95，第 4 轮）又不是一条能交换的单方向（中层 DAS 损失 3.6 到 5.0）。**Gemma 的失败不是估计器选错、不是强度、不是位置精度，是单条方向在 Gemma 上同时满足"因果"与"比输出更懂"两条的层不存在。** 对论文：消极；但它是一个可写的发现，且与 CDAS 的"可读 ≠ 可推"一致。

529 道测试对的**原始问题**，模型自由作答；共用系统提示允许说 "I don't know"（`prompts.qa.system_idk_ok`）；贪心 48 token；三条件同一提示、同一批次：原样 / 仅 E / 仅 C 向弃答。配置固定为已报的那组（Llama：DAS 窗口 10-11-12 α2，提示对比 C 第 28 层 α2；Qwen：DAS 第 18 层 α3，自评分组 C 第 30 层 α2），方向按 `e23_knob_sweep.py` 同一代码路径从同一 96 估计对重建（试点数字与 e23 到四位小数一致），E 的中点改为 96 估计题在问答提示下末 token 激活的均值；**只在预填充那一次前向的提示末位置写入**（审计三项——每方向每批 1 次、首次前向长度 = 提示长、前向次数 = 新 token 数——67 批全部通过）。裁判 deepseek-chat（A 对 / B 错 / C 未作答）叠规则弃答短语；金标剔除 "I have no comment" 一类（72 题含，8 题只有这类→另列）；521 题入主表；截断率 < 1%；未判定 0。

### 9.3 事实

1. **E 在真实回答上没有效果**（两模型）：Llama 结果变化 18 题且对称（5 对→错、5 错→对、3 错→弃答、3 弃答→错、2 弃答→对），Qwen 14 题同样对称；答对率 +0.004 / +0.000，区间含 0。同一方向、同一层、同一强度在强制真假上 ΔJ +0.149 / +0.051，放到预填充末位置后生成的答案基本不变（Llama 16%、Qwen 7% 的回答文本有改动，对错不变）。
2. **Llama 的提示对比 C 向弃答确实把真实作答推向弃答**（+0.25），且有选择性：新增弃答的 136 题里 102 题原本答错（75%；基线已作答题里答错占 68%），已作答中答对比例 0.320 → 0.369。**但机制是插词**：136 题里 133 题的回答含 "Unknown" 这个词（"Unknown, varies."、"Unknown Cape Cod."、"Unknown method."），"I don't know" 类说法反而从 11% 降到 6%；裁判按内容判"未作答"的 105 题，其余 31 题是规则按 "Unknown" 判的。提示对比 C 是用"说 Unknown"的谨慎系统提示估出来的，它学到的首先是这个词。金标全为弃答型的 8 题在 C 下全部弃答（基线 4 弃答 4 答错）。
3. **Qwen 的自评分组 C 向弃答在真实回答上反向**：弃答 −0.044、作答率 +0.044；新增弃答只有 25 题（全是 "I don't know."），同时 48 题从弃答改为作答（32 题答对、16 题答错），另有 31 题对→错、26 题错→对的改写（"Yes, there is gravity." → "No, there is no gravity."）。自报知道率上 −0.48 的杠杆没有接到真实弃答上；它改变的是"答什么"。
4. 基线本身：同一允许弃答的提示下，Llama 弃答 15%、答错 58%；Qwen 弃答 37%、答错 37%。

### 9.4 读法（不是定论；对论文：E 行消极，C 行 Llama 中性偏积极、Qwen 消极）

- 两上下文协议里的 E 效果（强制真假判别）没有迁移到自由作答。**赵磊的判断（2026-11-02）：方向本身不对——E、C 都是在"判断这句话真假"的提示下估的，放进自由问答的提示里用，上下文不同。** 翻出 10 月 25–26 日 E4b 的记录（`03_请审_真实问答验证代码与方向上下文.md` §2）：真假句估出来的均值差 E，在 717 道 TruthfulQA 原题的自由作答上，**连续写**（α2 / α3）和**只写一次**（α5）都是零或负（Llama 0.336 → 0.326 / 0.266；Qwen 0.385 → 0.407 / 0.298；Mistral 0.513 → 0.488 / 0.509）。所以此前把"只在预填充写一次"列为首要候选原因的说法**撤回**：写几次不是主因，方向的来历才是。下一步 E25 = 在问答上下文里估 E_QA（问答提示 + 真 / 假答案，答案末 token 均值差）与 C_QA（问答提示上的自信 / 谨慎对比，多措辞平均），方案已交 GPT 审（`03` §4），审完再实现。
- C 的两条估法在真实回答上分道：提示对比 = "说 Unknown" 杠杆（有效果，靠插词）；自评分组 = 改答案不改弃答。与第 6 轮 §1 的担心一致：自报标签可控 ≠ 控制了实际弃答。
- 这些数字应作为论文主张的边界写进去，不替换两上下文协议的表。

## 10. 估计集扩样：96 → 288 对，DAS 与均值差同数据（赵磊："DAS 一定比均值好，可能是 1:2:7 比例不对"；文件 `../估计集扩样_96vs288对/`，完整表格与读法见 `01` 末尾"估计集扩样结果"与问题 32）

设计：旧 192 调参对并入估计集（288 对），从旧 529 测试对重抽 192 调参、余 337 测试；DAS 与均值差都用 288 对；旧 96 对扫描按同一批题重切，四组在相同调参 / 测试题上配对自举。辅助线：种子 43 / 44（|cos| 1.000）、96 对 × 30 轮（= 10 轮）都已排除随机性与步数。

读法（对"1:2:7 饿着 DAS"的假设：消极；对协议：中性，96 对够用；对估计器之争：Qwen 积极、Llama 中性）：三倍数据没救 DAS（方向在有效层余弦 0.96–0.99，几乎不动）；均值差更吃数据；Qwen 两个数据量 DAS 都显著胜，Llama 288 对下均值差 J 高 0.015（不显著）、AUROC 高 0.007（擦边）但 DAS 偏置偏移少 0.034；层段现象不变（Llama L9–12 DAS 独赢、L13–16 均值差独赢）。按"均值差 ≥ DAS 就查 DAS"的原则，下一个候选变量是 DAS 训练目标（交换翻 True / False）与评测方式（放大）不一致：深层交换损失 0.02 却放大无效。

**赵磊的读法（2026-11-03）：积极。**"现在的结果反而是积极的，说明以后我们用 96 对数据就可以了，没必要扩大数据，而且真正方法找到的时候，反而说明用于训练的数据可以足够小，也不会影响什么。"据此：估方向固定 96 对、切分不再动、扩样线关闭；数据效率（96 对 ≈ 288 对、换种子不变、加轮数不变）作为论文卖点；精力转到方法（E25、DAS 目标与评测一致）。
