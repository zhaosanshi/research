- 容器里的 transformers 是 4.57.1，不认识这个架构。所以在容器里另建了独立环境 `envs/tf519`：

  - torch 用容器自带的 2.13.0a0；
  - 老实验的环境一个字节没动。
- 模型从 `/data1` 复制到容器能看到的 `/data/sanshizhao/Truth_Decoupling/models/`（容器只挂了 `/data`），两边大小逐字节一致。
- 线性注意力的加速库（fla、causal_conv1d）没装，走 transformers 自带的参考实现：结果正确，只是慢一些。其中递推的核心部分在 float32 里算，卷积和投影仍是半精度。

一批一起算和一条一条算的差异：
- 半精度下，最后一个词的残差流（residual stream · 每层输出的那条主干向量）最大相对差 2.8%（9B）、3.7%（27B）。
- 为分清原因，在 9B 上又做了两个对照：
  - 全精度（float32）下，有补位的批次只差 0.16%；
  - 半精度下，完全等长、没有补位的批次也差 2.5%。
- 所以这是半精度计算噪声（批大小不同，矩阵乘法的舍入顺序不同），不是补位泄漏进了线性注意力的"记忆"。
- 下面所有条件都用同一种分批（每批 8 条、同样的顺序），对三种方法一视同仁，比较是公平的。
- 但这种噪声会让小差异更难判断：在调参集上从 64–128 个候选里挑最好的，会挑进一点噪声；测试集上的估计仍然不偏，只是更晃。所以 DAS 和均值差差得很小时，不要过度解读。

## 3. 协议：与老模型的正式 2×2 完全相同

**题目与划分**

- 估计集 96 对：calib + dev，用来估方向。
- 调参集 192 对：用种子 42 从测试池里抽，和老模型是同一批，只用来选层、选力度。
- 测试集：剩下的 529 对。
- **博士的 100 对**：
  - 用种子 20261110 从这 529 对里抽 100 对，名单在 [`code/configs/splits/dr_100pairs_20261110.json`](code/configs/splits/dr_100pairs_20261110.json)，随本文件一起推送；
  - 两个模型用同一批；
  - 抽题脚本 `scripts/review_checks/make_dr_100pairs.py` 会重算调参集的抽法，并和老 Qwen3-8B 扫描里存的调参标记逐条核对；
  - 已核验：和估计集、调参集都不重叠；和老 Llama、Gemma 的调参集重叠数为 0。

**两遍问法**（和以前一样）
- A 遍："你知道这题的答案吗？Yes / No"。得到的是**自报** Yes 比例，不是实际作答率。
- B 遍：强制回答 True / False。由此算：
  - J（Youden's J · 约登指数 · 真陈述判真率减假陈述判真率）；
  - AUROC（area under ROC curve · ROC 曲线下面积 · 把真陈述排在假陈述前面的概率）；
  - B（判 True 的比例，0.5 表示不偏向任何一边）。

**E（证据方向）**
- DAS：
  - 每一层各训一个秩 1 方向；
  - 目标是金标签双向交叉熵，读、写都在提示末位；
  - 用估计集 96 对，训练 10 轮，学习率 0.001，种子 42；
  - 参数取实验配置 `E1_directions_tqa`，和老模型相同。
- 均值差：同样的 96 对、同样的提示。
- 写入方式：amplify（沿方向放大模型自己的信号，中心点取估计集在该遍提示下的均值），每层，力度 α ∈ {2, 3}。
- 选择规则（只看调参集）：自报 Yes 比例变化 ≤ 0.03 的条件里，取 J 提升最大的；并列时取扫描顺序里的第一个。

**C（承诺方向）**
- 两种估法：
  - Cp：自信 / 谨慎两种系统提示的对比；
  - Cs：模型自报 Yes / No 的对比。
- 两种都与同层的 DAS-E 正交，加法写入，α ∈ {1, 2}，朝弃答、朝作答两个方向。
- 选择规则：|ΔJ| ≤ 0.02 且 |ΔB| ≤ 0.05 的条件里，取 Yes 比例变化最大的。

**三方比较的公平性**
- 同提示、同评分、同预算：同 96 对估计、同 α 网格、同样每层都试、同一条规则。
- 不另外扫参数，不看测试结果后换题或改设置。

**2×2 的读法**（和以前一样）
- E 行应当动 J / AUROC，不动 Yes 比例；
- C 行应当动 Yes 比例，不动 J / B。

## 5. 事先写死的读法

- **"提升成立"**（对一个模型、一个报告集）：DAS − 原模型、DAS − 均值差两项的 AUROC（按 p_true 算，和以前所有报告一样）区间都在 0 以上。按对数几率差算的 AUROC 和 J 一并列出，不作为门槛。
- **博士的标准**："两个新模型相比原模型和均值差都有提升，差值区间也支持这个差异"，即两个模型在 100 对上都"提升成立"。
  - 529 对一并报告。
  - 两个报告集结论不一致时照实写。100 对是 529 对的一部分，两者不独立。
  - 区间跨 0 就写"还不能确定"。
- **均值差 ≥ DAS 时**：按赵磊以前的规矩（"均值差 ≥ DAS = DAS 方向 / 方式没找对"），先查 DAS 训没训对，再写结论：损失曲线、和均值差的夹角、选中的层，列出待查项。数字照实报，不删。
- **自报 Yes 不等于实际作答**：B 遍每题都必须答 True / False，A 遍只是自报。分开做的 E、C 不拼成"组合效果"。
- **旧题交代**：
  - 529 对测试集在老模型上被反复看过：从 10-25 起，所有真假判断实验都在上面报过结果；
  - 方法本身是在老模型上看着结果定下来的：DAS 的训练目标（11-05 改为金标签双向交叉熵）、α 网格、选择规则；
  - 新模型在这份方案推送之前产生过的东西，全部列在这里：
    - 加载探针：6 条估计集陈述，以及两个常识问题的生成；
    - A / B 遍读数检查：只用估计集 192 条；
    - 单层 DAS 试训，只用估计集：9B 第 0、1、16 层，27B 第 32 层；
    - **为验证分块合并，9B 用均值差在第 0–3 层跑过一个小扫描。**它用的是测试文件的前 48 对：其中 8 对属于博士的 100 对，34 对属于 529 对，其余 14 对是调参集。这 96 条上的基线数字我看到过（J 0.604、AUROC 0.858），没有据此选任何东西。

  - 各块的基线逐位相等、题目和划分相等；
  - 层不重叠，合起来正好是全部层；
  - 条件按"层从小到大"的扫描顺序拼接，保证并列时的取舍和一次跑完相同。
