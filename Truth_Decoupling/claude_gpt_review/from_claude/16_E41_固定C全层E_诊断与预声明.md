# E41：按赵磊的口径重做 C+E——验证过的 C 固定，E 扫全部层（2026-11-07，开跑前写定）

赵磊（11-07 20:52）："C+E 的方法，我理解应该是找到某层 C 的正结果，然后做所有层的 E，然后看 C+E。其他的问题都不理想，你赶紧找出问题，然后你来修改和推进。"

对象：GPT 第 20 轮（`9e02c77`）、第 21 轮（`6d609b6`）的 C+E 实验；对照物是正式 2×2（报告 `11` 第 8 节，`report_2x2_das_tfce.md`）。

术语：E（证据方向 · 放大后提高真假判别力）；C（承诺方向 · 推动后改变"答不答"）；2×2（E 只动判别、C 只动作答率的四格表）；同作答率（固定作答的数量再比答对多少）；配额（按某个分数排序、只交付前 K 个）；门控分（模型回答"你知道吗"时 Yes 减 No 的分数）。

**结论先行：GPT 第 18–21 轮从来没有做过"验证过的 C + 全部层的 E"这个实验。它用的 C 是另一条方向，E 只试了 3 个候选层。** 具体差在五处（第 1 节）。我已按赵磊的口径写好实验（E41）并开跑（第 3 节）；分析计划在任何结果出来之前写定（第 4 节）。但有一点必须先说：**在"按分数排序取前 K"的配额口径下，一个只平移门槛的 C 天然不会改变结果**，这不是代码错，是口径决定的（第 2 节）；所以 E41 的主检验用的是另一种同作答率口径——模型自己决定答不答，再和"用门槛卡到同样多"比。

## 1. GPT 的 C+E 和"验证过的 C + 全层 E"差在哪

| | 正式 2×2 里验证过的 C（报告 11 第 8 节） | GPT 第 18–21 轮 C+E 用的 C |
|---|---|---|
| 估计方法 | 提示对比（自信 / 谨慎系统提示下的均值差，Cp）或自报（模型说 Yes / No 两组的均值差，Cs） | 隐藏态与"Yes 减 No 连续分数"的协方差方向 |
| 估计用的提示 | "Do you know the answer to this question? Yes / No" | 第 18 轮：同上；第 20 轮改成新的"能力"提示（"你能判断真假吗 / 能给出实质准确回答吗"），C 随之重估 |
| 层怎么选 | 全层扫描，调参集上按规则选（\|ΔJ\| ≤ 0.02、\|ΔB\| ≤ 0.05 下作答率动得最多） | 每个模型只保留 1 层，按估计集上的读出相关性选（`c_top_k = 1`） |
| 力度 | α = 2，乘以两组均值的间距（gap） | ±1 倍投影标准差；第 21 轮再降到"实际写入量"的中位数 1–2%（Llama 1.84%、Qwen 1.06%） |

| 与 E 的关系 | 每层对同层新 DAS-E 正交 | 同层正交 |

| | 正式 2×2 的 E | GPT C+E 里的 E |
|---|---|---|
| 层 | 全部层（Llama 32、Qwen 36、Gemma 34），α ∈ {2, 3} | 第 18 / 20 轮：每个估计器最多 3 个候选层（旧扫描的前三名）；第 21 轮：固定 1 层（且 Qwen 的最佳 E35 被排除，因为"后面没有层放 C"） |

所以：**第 20 轮主表里的 C（Llama L26 / L24，Qwen L29 / L35）、第 21 轮的 C（L7 / L23，L8 / L26）都不是 2×2 验证过的那条 C；E 也没有扫全层。** 赵磊说的那个实验确实没做过。

另外三处要指出：
- **第 20 轮换了门控提示**，等于换了 C 的定义。之后所有"C 的作用"都是针对新提示的，和 2×2 不可比。
- **第 21 轮把 C 的力度降到每步只改 1–2%**，比 2×2 用的 α = 2 小一个量级，然后得出"行为增量 0–4 句"。这是把 C 调到几乎不动再测它有没有用。
- **GPT 自己的"原生门控"诊断（第 20 轮 `native/`）已经给出了关键事实：** 让 C 的 Yes / No 真的决定交付，交付量能从 0 拉到 164 / 192，但同样数量下答对数低于"固定 E + 置信度门槛"（Llama 真假判断 K = 192：145 对 152；自由问答 K = 155：52 对 64）。这说明问题不在 C 推不动，而在**门控分本身挑题挑得差**。

## 2. 为什么配额口径下 C+E ≈ E 是设计决定的

- 配额评估 = 按一个分数排序、交付前 K 个。C 的作用是把门控分整体平移（第 18 轮剂量探测：秩相关 0.96–0.998；第 20 轮 GPT 复核：各格实际交付题目换了 2–16 道，排序"接近不变"但不是完全不变）。整体平移不改排序，前 K 个几乎不变 → E+C 的交付集 ≈ E 的交付集。
- 这一点我在开跑前的审核（报告 `13` 第 3 节 D）已写明并预期；第 20 轮 GPT 把它收窄为"C 不是完全不换排序"，数字上成立，但不影响结论。
- 要让 C 有机会，必须让 C **自己**决定答不答（模型的 Yes / No），然后和"不推 C、用门槛卡到同样多"比。这正是老师"相同作答率"的另一种实现：C 是旋钮，门槛是对照。GPT 第 20 轮的 native 诊断做的就是这个，但用的是它自己那条 C、一个层、E 只有一个。

## 4. 预声明分析（`e41_analysis.py`，提交于任何结果之前）

全部在测试半（529 对）上报告；区间用按题对重抽样 2000 次；每个模型内部 Holm 校正。

**V1 可加性：** E+C 相对 E 的 Δ作答率 / ΔJ / ΔAUROC / ΔB，以及 E+C 相对 C。看两点：C 的作答率位移是否在 E 之上保留；E 的 J 增益是否在 C 之上保留。这是 2×2 的自然延伸（"两个旋钮能不能一起转"）。

**V2 同样多的自答题（主检验）：** "自答"= 第一遍模型说 Yes；K = 自答数；答对 = 自答题里第二遍判对的数量。
- P1：E+C 自答答对数 − E 按**自己的门控分**卡到同样 K 的答对数；
- P2：E+C 自答答对数 − E 按**真假置信度**（|True − False|）卡到同样 K 的答对数；
- P3：C 自答 − 原模型按门控分卡到同样 K；P4：E 自答 − 原模型卡到同样 K。
- **主族 = P1、P2 在 2×2 所选 E 层（Llama L11 α3、Qwen L35 α3、Gemma L12 α3）× C 两个符号，共 4 项，Holm 校正。** 正值 = C 挑出来的题比门槛挑出来的更准。其余所有层都是探索，按层给表；调参集上选出的最好层，在测试集上报并标明"探索、已看过的数据"。

**V3 配额口径（与 E26 / 第 20 轮可比）：** 按真假置信度排序，测试集 25 / 50 / 75% 配额下各臂的答对数，E+C − E 带区间。

**决策规则（先写死）：**
- 主族 4 项中有任何一项 Holm 后显著为正 → "验证过的 C 在同作答率下有额外收益"成立，进入 QA 版本。
- 全部不显著、且探索表里 P2 > 0 的层不多于一半 → 结论为：C 的作用就是门槛，在同作答率下没有额外收益；论文主张改写为"E 抬曲线、C 沿曲线走"（E 提高判别，C 以接近零判别代价设定作答率，这是 2×2 已证明的）。
- V1 若在多数层成立，是独立的积极结果（两个方向可叠加），单独报。
