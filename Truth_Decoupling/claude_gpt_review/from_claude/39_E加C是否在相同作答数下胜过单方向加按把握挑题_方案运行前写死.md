## 1. 要回答的问题

博士的主句：**相同作答率下，E + C 组合胜过任何单一方向。**

- 真假判断上没成立：N7（三个模型 × 六档力度 × 两个方向）里，E + C 自己选答哪些题，和"只用 E、再按模型自己的置信度挑出同样多的题"比，全部更差（少答对 34–107 题）。结论是 C 挑题不如模型自己的置信度，C 只是门槛。
- 自由回答上，E + C 已有描述性的好结果（`37`）：普通问法上作答数回到基线，答对 64 → 93（Pro）。但还没和"单一方向 + 按把握挑题"比过。这一次就比这个。

## 2. 方案（写死）

- **答还是不答，不看对错**：回答被规则判为"不知道"（`refusal_rule`，与裁判无关）就算弃答。
- **比较点**：E + C −0.25（`36` 里事先按规则选中的那档）的非弃答数 N0 = 192 − 24 = **168**，是主比较点。次要比较点：E + C −0.5（N = 186）、E + C −1（N = 188）。
- **组合**：普通问法 x 上的 E + C k，已生成、已判分。
- **对照**（都在同一个 N 上；"挑题"= 在自己的非弃答回答里，按把握分只留最高的 N 个作答，其余算弃答）：
  1. **E + 挑题（必须作答问法）**：`conf` 加 E 第 10 层力度 2 的回答（192 个都作答），留把握最高的 N 个。这是**决定性对照**，对应真假判断 N7 里的"E 置信同 K"。
  2. E + 挑题（普通问法）：`x` 加 E 的回答（非弃答 151 个）。N 大于 151 时够不着，如实报"够不着"。
  3. C + 挑题：`x` 加 C 第 31 层 −0.25 / −0.5 / −1 的回答，候选不够 N 就报够不着。
  4. 不写入 + 挑题：`conf`、`x` 的冻结回答。
- **把握分**：模型在同一问法、同一写入下，对自己原样生成的那串词元的**平均每词对数概率**（主）；结束符补上但不计分。决定性对照另报两种：总对数概率、第一个词的对数概率。并列时按题目顺序。
- **判分**：沿用磁盘上已有的两家裁判标签，不重新判。决定性对照用的回答，就是第 3.2 节判过的 `conf.w.p2`（本脚本重生成，逐词元相同）。
- **统计**：按题配对自举 10 000 次（种子 20261112），算"E + C 的答对数 − 对照的答对数"，取 95% 百分位区间。挑题在全部 192 题上一次定好，不随自举重挑。另报"从候选里随机挑 N 个"的期望答对数，作参照。
- **判读（写死）**：主比较点上，
  - E + C 比"E + 挑题（必须作答）"多答对，且两家裁判的区间都在 0 以上 → 记"组合胜过单用 E 加挑题"；
  - 两家区间都在 0 以下 → 记"单用 E 加挑题胜"；
  - 其余 → 记"分不出"。
  - C + 挑题、不写入 + 挑题按同样的规则判。
  - 这只是调参题上的探索，要在没参与选择的题上再确认。

## 4. 红队与修改（02:09 审完；02:17 改完，跑之前）

独立红队子代理只读审查：没找到会把数算错的代码错误，也没有偷看对错标签；它还在两个判分目录、两家裁判上复算了规则弃答标记（0 处不一致），并核过 teacher forcing 与生成逐位置对应。提出的问题和处理：

1. **（阻断判读）192 题上，原来写死的"两家区间都不含 0"几乎只能判出"分不出"。** Pro 下，从必须作答 + E 的回答里随机留 168 个，期望答对 92.75，和 E + C 的 93 几乎一样；AllenAI 下，就算"最理想地挑"（偷看答案只留对的）也只比 E + C 多 9，区间 [−21, +3] 还碰到 0。**处理**：判读改成下面的第 2.1 节——主读数是"对照落在随机挑和最理想挑之间的哪里、E + C 在它的上面还是下面"；区间规则保留，但写明只能判出约 13 题以上的差。
2. **（应修）98% 的复现检查拦不住"漏了写入"**：C −0.25 只改了 24 个回答，打分时完全不加写入也能复现约 98.3%。**处理**：加"第一个不同的词"检查。在带写入的回答和去掉写入的系统自己生成的回答第一次分叉的那个词上，比较两边的差距"log p(目标词) − log p(原来的词)"：带写入时必须比去掉写入时更偏向目标词，至少 90% 的题如此，且平均偏移大于 0。写入漏了，差距就不变；写错方向，就是一半对一半，两种都过不了。小样本验收（前 2 批 16 题）：所有带写入的目标都是 100% 偏向目标词，平均偏移 +0.16 到 +3.3。最初试的"分叉词上取最大值必须复现 90%"在两层写入上只有 75%，因为分叉点本来就是写入刚好把贪心解码推过去的地方，常常两个词几乎一样大，bf16 的一点误差就会翻过来，所以改用差距偏移。取最大值的复现率仍然报告。
3. **（应修，判读）决定性对照换了问法**：E + C 用普通问法，"E + 挑题"用必须作答问法。这一项比的是两套能直接用的系统，不是"C 和把握分谁挑得好"。**处理**：加两个**同一问法、同一 E** 的对照——"E + C −0.5 的回答（186 个）或 E + C −1 的回答（188 个），再按把握分留 168 个"。它们和 E + C −0.25 的区别只在"由 C 定哪些题不答"还是"由把握分定"，正对应真假判断 N7。三个都算决定性对照。
4. **（建议）C 单用、不写入这几个对照，候选里答对的总数就低于 E + C，怎么挑都赢不了。** **处理**：每行加"最多能答对"（最理想挑）一列，这几行的输赢由量决定，判读时不当成"挑题本事"的证据。
5. **（建议）一致性核对补全。** **处理**：打分时逐项核对写入的方向文件哈希、记录哈希、种类、力度、写入量与生成文件一致；比较程序核对每个目标的问法和写入是预期的、自检都通过，并逐题核对"打分的回答 = 判分的回答"。
6. **（建议）输出里自动给出判读，并报答错数之差和被选回答的平均词数**（平均对数概率可能偏爱长句）。**处理**：都加了。

### 2.1 改后的判读（替代第 2 节最后一条；写在运行之前）

- **主读数（描述）**：主比较点 N = 168 上，每家裁判分别报：E + C 的答对数；每个对照按把握挑出的答对数；同一候选里随机挑 N 个的期望答对数；最理想挑的上限；答对差和答错差的 95% 区间；被选回答的平均词数。
- **自动判读**：对三个决定性对照（E + C −0.5 再挑、E + C −1 再挑、E + 挑题·必须作答），
  - 两家裁判的区间都在 0 以上 → "组合胜"；都在 0 以下 → "对照胜"；
  - 区间含 0 但两家点估计同号 → "倾向组合"或"倾向对照"；
  - 其余 → "分不出"。
- **192 题能分辨的大小**：区间半宽约 13 题，只能判出比这更大的差；更细的结论要更多题（529 题上约 ±4 个百分点）。

- 带写入的 8 个目标，"第一个不同的词"检查全是 100% 偏向目标词，涉及 24–146 题，平均偏移 +0.32 到 +3.74。

**按第 2.1 节写死的规则自动判读**（两家裁判合起来）：
- 对"同一问法、按把握挑"（E + C −0.5 再挑、E + C −1 再挑）：**倾向对照**。两家点估计都是负的，区间都含 0。
- 对"必须作答 + E 再挑"：**分不出**（Pro −5，AllenAI +3）。
- 次要比较点（N = 186、188）：都是分不出。

**读法**：

1. **对"只用 C / 不写入 + 挑题"，组合大胜，但这是由量决定的。** 这些对照的候选里，答对总数本来就低于 E + C，怎么挑都赢不了。所以这一条说明的是"E 带来的内容增益在 C 把作答量补回来之后还在"，不是"C 挑题更好"。**积极（弱形式成立）**
2. **在有 E 的前提下，C 挑"哪些不答"不比模型自己的把握分更好。**
   - 同一问法、同一个 E 下，把"由 C 定哪些不答"换成"由把握分定"，答对略多（Pro +2 到 +4，AllenAI +2 到 +6），但都在区间内。
   - 换成"必须作答 + E 再按把握挑"，和 E + C 打平。
   - 这和真假判断 N7 的结论同向（C 是门槛，挑题不比置信度强），只是这里差得小，分不出。
   - 博士主句的强形式"相同作答率下组合胜过**任何**单一方向"，在这里**不成立**。**消极**
3. **"挑题本事"的位置**（Pro）：
   - 把握分能拿到"随机挑 → 最理想挑"之间 30%–40% 的空间（必须作答 + E：92.8 → 98，上限 106）；
   - E + C 自己定哪些不答，大约在随机水平（93）。
   - AllenAI 下，E + C 略好于随机（118 对 111.1–116.5），把握分挑也在同一带（115–124）。
4. **回答长度没有偏向 E + C**：被选回答的平均词数，E + C 是 9.1，"必须作答 + E 再挑"是 5.6。更短的那组 Pro 反而多判对 5 题。

**结论（调参题，探索）**：在自由回答的普通问法上，E + C 是一个好用的组合。E 管内容，C 把作答量调到想要的水平，作答数回到基线时答对多 29 题（Pro）。但"由 C 决定哪些题不答"并不比"按模型自己的把握分卡门槛"更好。所以博士主句只能写成弱形式："相同作答率下，E + C 胜过只用 C（因为有 E），并且和单用 E 再按把握卡门槛相当"，不能写成"胜过任何单一方向"。和真假判断的结论是一致的。
