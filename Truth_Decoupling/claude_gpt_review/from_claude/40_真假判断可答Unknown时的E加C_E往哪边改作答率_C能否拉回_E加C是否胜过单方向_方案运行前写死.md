## 1. 要回答的三个问题

1. **最终的 DAS E 在"同一遍可以答 Unknown"的真假判断里，作答率往哪边变？** 早期均值差 E 在 13 个模型上是让模型更敢答（Qwen3-8B 作答 +4.6 到 +11 个百分点），最终的 DAS E 在这种问法下从没测过。
2. **C 能不能把作答率拉回基线，同时保住 E 的判别提升？**
3. **作答数相同时，E + C 是否胜过"只用 E + 按置信度卡门槛"和"只用 C + 卡门槛"？** 之前在"强制判 True / False + 另一遍自报"的协议下（N7），E + C 比"E + 置信度门槛"少答对 34–107 题。

## 2. 方案（写死）

- **数据**：TruthfulQA 真假陈述 1442 条（721 对）。调参集与 E41 / N7 用同一个种子抽的 192 对，测试集是其余 529 对。和以往所有真假判断实验一样，只在调参集上做选择，测试集只报数。
- **方向**：主结果 2×2 的那一套，按 E41 的代码路径原样估计。

  | 模型 | E（DAS tf-ce-bidir，放大写入） | C（2×2 选中的） |
  |---|---|---|
  | Llama-3.1-8B | 第 11 层 | Cp：往弃答第 25 层 / 往作答第 26 层 |
  | Qwen3-8B | 第 35 层 | Cs：第 33 层 / 第 24 层 |
  | Gemma-3-4B | 第 12 层 | Cp：第 25 层 / 第 23 层 |
  | Mistral-7B | 第 13 层 | Cs：第 18 层 / 第 20 层 |

  C 的方向哈希和 gap 必须和 E41 记录的一致（Mistral 没跑过 E41，没有可核对的记录），不一致就停。
- **问法与读法**：只许在 True / False / Unknown 里选一个、同一遍读出（`user_tf_idk`），三类各自的变体词概率相加后取最大；选 Unknown 就算弃答。
- **E 的中心点**：在可以答 Unknown 的问法下重算，取估计句里真陈述均值与假陈述均值的中点。另留一个诊断条件，用原来强制问法下的中心点，量一下以前那个 bug 有多大。
- **C 两种**：
  - 主用：2×2 的 C（在"你知道答案吗"那一遍上估的）；
  - 备用：CpI，在可以答 Unknown 的问法下，用"自信"减"谨慎"两种系统提示估出来，同样和同层的 E 正交，层和方向与 2×2 的 C 相同；
  - 两种都报。主用的 C 搬到新问法上可能不起作用，所以事先就把备用的放进来。
- **条件**（共 61 个）：
  - 不写入；
  - E 力度 1 / 2 / 3；
  - E 力度 3 用旧中心点（诊断）；
  - 两种 C 各在往弃答、往作答两个方向，力度 0.1 / 0.25 / 0.5 / 0.75 / 1 / 1.5 / 2，单用；
  - E 力度 3 + 上面每一种 C。
- **选档（只在调参集上、只看作答数）**：
  - 方向：E 单用让调参集作答数变多，C 就往弃答推；变少就往作答推。
  - 力度：E + C 的调参集作答数与不写入最接近的那一档；并列时取小的。
- **比较（测试集，沿用 N7 的定义）**：E + C 自己作答的那些题里答对几题，和以下对照在同样作答数 K 下比：
  - P1 / P2：只用 E，按它自己的"作答对 Unknown"差距 / 按 |log P(True) − log P(False)| 取前 K；
  - P5 / P5b：只用同一个 C、同一力度，按同样的分数取前 K。
  - 按整对重抽自举 2000 次，种子 0，每次重抽都重算 K 和前 K。每个模型、每种 C，对这 4 个比较做 Holm 校正。
- **判读（写死）**：
  - 某个模型上"强形式成立"= P2、P5b 都显著为正（Holm p < 0.05）；"弱形式成立"= P5b 显著为正，且 P2 不显著为负。
  - **天花板标记**：调参集上不写入时选 Unknown 的比例低于 5% 的模型，照常报，但不计入总判读（Llama、Gemma 预计如此，作答数接近全答时，同作答数比较会退化）。
  - 总判读：没有天花板的模型里，至少 2 个"强形式成立"，才写"真假判断上强形式成立"；弱形式同理。
  - 另报：E 单用的作答率、J、AUROC 变化（第 1 问）；C 单用在新问法下能不能动作答率，方向对不对（第 2 问）；全部力度的曲线。

冒烟里，旧中心点沿 E 偏了 −1.99 个标准差。力度 3 时这相当于额外往 False 推了约 6 个标准差，所以重算中心点是必须的。

问题和处理如下。

1. **（阻断判读）C 什么都没做，原判读也可能判成立。** 例如 Llama 几乎不选 Unknown，E 不改作答率，匹配会落到最小力度，E + C 约等于 E，P5b 就等于 E 自己的增益，也会显著。**处理**：判读前加"适用条件"，有一条不满足就记"不适用（原因）"，不判强弱形式。
   - 不是天花板模型；
   - 调参集上 E 单用改变的作答数 ≥ 调参句数的 3%；
   - 匹配到的 E + C 把 E 的作答数变化至少收回一半；
   - C 单用确实把调参集作答数往预定方向推；
   - E、C、E + C 三个条件上，三类标签词的概率总量中位数都 ≥ 0.5（见第 3 条）。
2. **（应修）两种 C 各算一遍，没写哪种算数。** **处理**：事先写死，主用 2×2 的 C；只有它在最大力度 2 下仍收不回 E 作答数变化的一半时，才改用 CpI。两种都报，判读只看被指定的那种。
3. **（应修，事后补不回来）没存 True / False / Unknown 三类各自的对数概率。** Gemma、Qwen 的 C gap 很大，强力度下模型可能已经不输出这三类词了，三选一就成了噪声。**处理**：每条陈述存三列；分析里算三类概率总量的中位数，低于 0.5 的条件做标记，并计入适用条件。
4. **（建议）**
   - 改成数值稳定的 P(True) 算法；
   - 汇总里加"判 True 的比例"；
   - 运行脚本改用固定的代码副本，四个模型并行时用的是同一份代码；
   - 冒烟改用新标签重跑；
   - Mistral 没有 E41 参照，跑完后用 E 层与两个 C 层的对齐余弦，和 E23 扫描记录（0.758140787652528 / 0.695660704178688 / 0.671304113854369）逐位比对。

   以上都已照办。另外记一条消极的事实：天花板会挡掉 Llama（选 Unknown 约 1%）和 Gemma（约 2%），能计入总判读的实际上只有 Qwen 和 Mistral，模型覆盖面会窄。

### 5.2 第 2 问：C 能不能把作答率拉回

- **主用的 C（2×2 那条，在"你知道答案吗"那一遍上估的）搬到这种问法上，在 Qwen、Mistral 上推不太动**。Qwen 力度 2 只少答 1.7 个百分点，只收回 E 带来变化的 20%；Gemma 上力度 2 能少答 20 个百分点。

- Qwen 上 E + CpI 力度 1，调参集作答数 242，基线 246，把 E 带来的变化收回 105%。**积极**
- **新的事实**：自报那一遍估的 C，和"同一遍里选不选 Unknown"那个决定不完全是一回事。在同一种问法下估的 C 才推得动。这和 11-07 的阻碍 1（作答率是自报）直接相关。

### 5.4 读法

1. **故事的前两步，在真假判断上也成立**：
   - 允许答 Unknown 时，E 照样提高判别（四个模型）；
   - 有余地的模型上，E 会顺带改变作答率（Qwen +19 个百分点，方向是更敢答）；
   - 在同一种问法下估的 C 能把作答率拉回基线，E 的判别提升保住。**积极**
2. **第三步"E + C 最好"，在真假判断上同样不成立**：在同样的作答量下，E + C 和"E + 模型自己的置信度门槛"打平，Mistral 上还更差。这和自由回答（`39`）、和以前的 N7 都一致——C 的作用是门槛，把作答量调到想要的位置，但"挑哪些不答"不比模型自己的置信度强。**消极（对博士主句的强形式）**
3. **两种任务的同一条主线**：
   - E 管答什么，强制作答和允许弃答时都提高判别或答对；
   - 允许弃答时，E 会顺带改作答率，方向随任务——真假判断里更敢答，自由回答里更谨慎；
   - C 是作答量的旋钮，能双向把作答率调回目标，同时保住 E 的收益；
   - 在相同作答量下，E + C 与"E + 置信度门槛"相当，不更好。
