## 3. 不同意或要改的部分

**A. E27 的正结果：按输出质量计分后，DAS 起步不胜随机，反而显著输。**（证据：结果复算 `results/03_E26同作答率_E27生成适配/E27复核/a5_quality.json`、`a6_judge_flags.json`；我另用独立代码复算了前三行）

| 计分规则（Qwen 测试 523 题） | 原模型 | DAS 起步 | 均值差起步 | 随机起步 | DAS − 随机 |
|---|---|---|---|---|---|
| 按裁判原判 | 140 | 189（+49） | 158 | 182 | +7，p = 0.43 |
| 含 U+FFFD 的"答对"算错 | 140 | 163（+23，p = 0.011） | 158 | 182 | **−19，p = 0.037** |
| 再把未正常结束的"答对"算错 | 138 | 135（−3，p = 0.81） | 155 | 166 | **−31** |
| 按 GPT 自己的人工标注翻转 | 140 | 183（+43） | 154 | 179 | +4，p = 0.67 |

- DAS 起步的 189 个"答对"里，26 个含 U+FFFD、27 个没正常结束、54 个至少有一种问题；新增的 60 个"答对"里 27 个有问题。随机起步 0 个 U+FFFD。
- **能站住的是"有监督的生成适配"本身，不是 DAS**：随机起步在最严规则下仍比原模型多 28 题。但它只在 Qwen 上有（Llama 两档力度调参都只多 3–4 题），且只有一个随机种子。
- **它不是新方法**（文献核查，已数值验证）：我们的放大算子 h + α·wwᵀ(h − c) 正是参数绑定的秩 1 LoReFT（R = wᵀ、W = (1+α)wᵀ、b = −α·wᵀc）；"冻结底座、用答案交叉熵训练秩 1 方向"已有 AxBench（ICML 2025）的 SSV / ReFT-r1、RePS（NeurIPS 2025）的 Lang. 基线。唯一新的是从 DAS 起步，而它不比随机好。如实的名字是"DAS 起步、在生成位置施加的绑定秩 1 LoReFT"。
- **要补的对照**：未绑定的 LoReFT、只在提示位置施加、加法式 SSV、LoRA；报告弃答率与信息量（ITI、TruthX、LoFiT 在 TruthfulQA 上的大幅提升都部分来自信息量下降）。
- **对论文：作为方法贡献，消极；作为"小样本生成监督能明显改 Qwen 自由作答"的现象，中性偏积极，待复现。**

**B. E27 结果出自没存档的早期代码。** 测过的三个 Qwen 适配器 `adapter.json` 都缺发布版代码必写的 `include_eos` / `stop_token_id` 字段（结束符版本有）；没有任何 E27 输出记录提交号或代码哈希；E27 代码第一次进 git 是 7987310，晚于全部运行。发布版能读这些旧适配器，但训练与解码代码是否与发布版等价无法证明。**已用发布版代码重跑**（`review_checks/e27_release_rerun.sh`：Qwen 与 Llama，DAS / 均值差各 1 个、随机 3 个种子，同一冻结配置，全部报告），见第 5 节。

**C. E27 的测试阶段在代码里没有冻结保护。** `generate-test` 对目录里现有的任何适配器都直接跑测试集，"先冻结再测"全靠人工写 `heldout_selection.json`。建议加与 E26 同样的冻结检查。另：层取自 DAS 的选择、力度按 DAS 起步的调参分数定，比较天然偏向 DAS（按 GPT 的调参数字，力度 3 对三种起步都是最优，所以力度这一项不吃亏；层这一项无法排除）。

**D. E26 的设计含义：C 在配额下几乎不改排序，所以"E+C 减 E"测的是 C 对答案的副作用。** 剂量探测里，C 推动后的分数与原分数的秩相关 0.96–0.998——C 是整体平移门槛。配额设计按分数排序取前 K，整体平移不改选谁；C 还写进了真假作答提示和问答开头，所以 C 只能通过两条路影响结果：真假判断的偏置平移、问答的自然拒答与首词。**预期 E+C ≈ E。** 这本身是检验"C 就是门槛旋钮"的好设计，但它没有测老师原意里"由 C 自己调作答率"的用法——那要扫 C 的强度、让模型自己答或拒，画出风险–覆盖率曲线，与"不动模型 + 门槛"的曲线比。建议作为 E26 之后的补充实验。

**E. 测试集不是新的。** TruthfulQA 共 817 题，96 / 192 / 529 已全部用过；E26 的测试集与 E23 / E25 / E27 相同，之前的结果都看过；E26 里的 Qwen 适配器臂会复现 E27 的测试生成，且"把力度 3 适配器带进 E26"是看过 E27 测试结果后决定的。所以 **E26 只能算"在已看过的测试集上的同作答率比较"，适配器臂只能算探索**；确认要靠第二个数据集。

**F. 多重比较。** 报告里有 60–105 个比较，只有原始 p 与 95% 区间。主对比与校正方法见第 4 节。另：E26 的 Markdown 报告缺"E+C 对原模型按自身承诺分数排序"这一最干净的对比（只在 JSON 里），建议加进表。

**G. 文献笔记的硬伤**（`qa_generation_literature_20261106.md`）：
- BiPO 的 TruthfulQA 结果只有选择题，不是"主要"；它的"自由幻觉"集是假前提的是 / 否题；BiPO 不做长度归一化；报告的运行排序项权重为 0（纯交叉熵），可选排序项也不是 BiPO 的损失——"主要依据 BiPO"说过头了。
- ReFT 从不在生成出的词元上干预，笔记没提；笔记说"可学习的低秩仿射需要新名字"，但我们的算子本身就是 LoReFT 的特例。
- ACT 的强度是连续的、没有阈值，"决定是否干预"说过头；它在每个生成位置都推；自适应强度只多 2.1 个 True×Info。
- FASB：笔记提议的"固定短回溯窗口"与原文附录矛盾（完全重启 81.60 / 81.96 高于回溯 10 词元的 80.56）；"同预算、不加方向的重生成"对照在贪心解码下等于原答案。

**H. 低优先级（不阻断）**：`select_tf_candidates` 只检查估计器名，不核 DAS 目录与变体；`prepare` 不核适配器记录的训练 / 检查点哈希；"简单置信分"在真假任务是加了干预后的 |真 − 假|、在问答是不加干预的对数概率，配置写"native"易误解；`encode_answer` 无保护（遇边界重分词错误会停整条收集，现有 Qwen 输出 0 例）；`judge_qa` 首轮完整性检查是浅拷贝自比较（`scored_rows` 会对磁盘文件再核，不丢信息）；裁判判"弃答"时参考了金标答案（所有方法同一规则，与既有协议一致）。

## 4. 主分析计划（开跑前声明：2026-11-06 18:30 北京时间，E26 调参与测试结果都还没有）

1. **主问题**（老师主张）：同作答率下，E+C 是否优于单一方向。
2. **主对比**：每个模型（Llama、Qwen）× 任务（真假判断、自由问答）× 作答率（25% / 50% / 75%）共 12 格，比较 **DAS 的 E+C 与 DAS 的 E**（都按各自承诺分数排序）的交付答对数，按题配对精确检验，**12 格做 Holm 校正**。
3. **次要对比**（每类各自 Holm）：E+C 对 C、对 E 加简单置信排序、对 C 加简单置信排序、对原模型按承诺分数排序、对原模型按简单置信排序；均值差版本同样报。
4. **判读规则**：只有在多数格里 E+C 对 E 经 Holm 校正显著为正，且对各简单置信对照没有显著变差，才写"组合优于单一方向"；否则写"未成立"。
5. **预期**（依据第 2 节 3 与第 3 节 D）：多数格 E+C ≈ E。若出现 E+C 优于 E，要归因到 C 对答案的副作用（真假偏置、自然拒答），不能归因到排序。
6. **数据边界**：测试集已在前几轮看过，不是新数据（第 3 节 E）；适配器臂为探索。
7. **E27 重跑的主对比**：DAS 起步对随机起步（3 个种子的平均），同时报"按裁判原判"与两种质量规则（含 U+FFFD 算错；再加未结束算错）；同报弃答率与回答长度。
