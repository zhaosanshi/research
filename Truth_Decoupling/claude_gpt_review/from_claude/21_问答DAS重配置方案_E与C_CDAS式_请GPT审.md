## 0. 逐题比原文查出来的事实（11-09）

E25（问答 DAS v1，11-05）有两个版本：v1（同轮自检读出，选中 Llama L9 α1）和 v1u（新用户轮读出，选中 **L29 α3**，最终线，见 `11` §6）。测试集 529 题，基线回答与干预后回答逐题比（去大小写、空白）：

| 条件 | 性质 | 一字不改 | 改了 | 改了的题里对错怎么变 |
|---|---|---|---|---|
| v1 DAS L9 α1 | 层内写入（放大） | 508 / 529 | 21 | 错→错 15，对→错 4，错→对 0 |
| v1u DAS **L29 α3**（最终线） | 层内写入（放大） | 428 / 529 | 101 | 错→错 48，对→对 19，错→对 10，对→错 9，弃答来回 15 |

| v1u 金标坐标诊断，L29（192 题） | 层内写入（交换金标答案的坐标） | 164 / 192 | 28 | 错→错 20，对→对 5，错→对 0 |
| E42 秩 1 单层来源交换 8 臂（192 题） | 层内写入（交换） | 176–188 / 192 | 4–16 | 几乎全是同类改写，B→A 各臂 0–1 |
| E42 `truthful_source_only`（192 题） | **提示对照**：换成如实指令的提示直接作答，对普通提示**零写入** | 70 / 192 | 122 | 错→弃答 30，错→对 16，对→弃答 11 |
| E42 `gold_source_only`（192 题） | **提示对照**：把金标写进提示直接作答，**零写入** | 8 / 192 | 184 | 错→对 83 |

能说的：
1. 现有的秩 1 层内写入，浅层几乎不改文本（96% 一字不差），深层（最终线）改 19% 的文本但净效应为零（错→对 10、对→错 9）；把正确答案自己的坐标钉进去也没有错→对。"从没试过深层"这个解释不成立。
2. 最后两行是提示层面的对照：提示里换指令或直接给答案，输出会变。它们**不是整层写入的上界，也不能证明一条方向装不下一个答案**（ReFT 附录 F.1 里秩 1 干预能背长序列）。
3. 不能说的：根因已经定位。目标（判决词）、读写位置（答案末位训练、提示末位与生成步使用）、写法（放大）三个因素没有逐一排除；10 对 9 不证明"随机"，只是净效应为零。

## 1. 为什么换这三处（探索动机，不是已证明的必要修复）

**第一处：训练目标从"判决词"换成"答案文本"。** 旧问答 DAS 的目标是答案后面一个自检词 True / False 的交叉熵；真假判断任务的输出就是那个词，TF 上 DAS 显著赢均值差（`11` §5），自由问答的输出是多词答案。相关工作里改生成的方法都对输出文本本身做监督：ReFT 对整段输出做教师强制交叉熵；RePS 把整段交叉熵（Lang.）当对照，调好后有竞争力；CDAS 匹配来源的输出分布，在安全拒答抑制任务上（不是知识问答）报告原 DAS 目标 1% / 2%、CDAS 91% / 84%（各目标各自训练方向，不是同一条方向）。这些支持"检查训练目标与生成行为是否匹配"，不保证对我们的问答有效。

**第二处：来源用另一条提示（指令对比）。** 推理时模型只看到问题，写进去的值必须能在没有答案的情况下取得。旧 E25 在**答案末位**读写（那里正误答案已进入状态，训练中的交换并非空操作），使用时却写在提示末位和生成步——训练与使用的上下文不一致，这是最可疑的一点。改成：同一问题配两条只差一句指令的提示，来源坐标在提示末位读，训练和推理都能取得。

**第三处：写法从放大换成钳制到来源均值。** 放大是把坐标离中心的偏差乘 (1+α)：离中心近就几乎不动，偏哪边就更偏哪边。钳制是不管原值多少直接钉到固定值 a（训练题来源提示的平均坐标），不用调 α；CDAS 的推理即分别取两类来源各自的平均坐标。

```
放大：z' = 中心 + (1+α)·(z − 中心)
钳制：z' = a          （力度恒为 1，只换目标值；不把负号传进力度）
```

## 3. 配置

### 3.1 训练对（Llama，92 题）

每题三条提示，只差系统指令里的一句：x（现有问答提示）；x_E = x + "Answer truthfully and directly. Correct common misconceptions."；x_C = x + "If you are not completely certain, answer exactly 'I don't know.'"。事先生成并冻结 y_plain = 模型在 x 下的贪心回答。
- E 的一对：来源 x_E，正向目标 y_true（金标 best_answer，选法同 E25）；基线 x，反向目标 y_plain。
- C 的一对：来源 x_C，正向目标 "I don't know."；基线 x，反向目标 y_plain（不用金标，免得把"促作答"和教知识混在一起）。

### 3.2 目标

w 为单位向量，层固定；来源坐标在来源提示的最后一个词读一次。
- D⁺：把来源坐标钉进基线 x 的内容位置，教师强制正向目标，对目标每个词算交叉熵取平均。
- D⁻：把 x 末词的坐标钉进来源提示的内容位置，教师强制 y_plain，交叉熵。意思：去掉那句指令带来的坐标，模型应回到它自己本来的回答。
- 两项各 0.5；Adam，学习率 1e-3，10 轮，梯度裁剪 1，每对一步；目标长度上限 24 词元，截断条数记录在案。
- 这是受监督的交换干预（正向用金标），不称复现 CDAS。

### 3.3 写入与端点

- E：普通提示钉到 a_E = 训练题 x_E 末词坐标的平均。
- C 两侧都用训练过的端点、换基线来测：(i) 基线 x 钉到 a_C（x_C 坐标平均）→ 看拒答率上升；(ii) 基线 x_C 钉到 a_plain（x 坐标平均）→ 看拒答率回落。不做镜像外推。
- 诊断臂：每题用自己的来源坐标（先跑来源提示前缀读出）。它与均值臂接近只说明这批题上均值近似没有明显损失，不证明方向与题目无关。
- 描述性记录（不设闸）：每题配对坐标差 z_E − z、实际写入量（‖Δh‖ / ‖h‖）、组间 AUROC。AUROC 不能当闸：192 题若各题坐标相差 100、指令只加 1，每题都同向变化而组间 AUROC 只有 193 / 384 = 0.5026；w 与目标一起反号时干预完全相同而 AUROC 由 1 变 0。

### 3.4 层与顺序

L12、L16、L20、L24、L28，单种子。先做一层一对样本的读位 / 目标位 / 写位核对和 1–3 题输出冒烟，再估全量耗时。T = 8 只作执行冒烟，不作整答案方法的结论。

### 3.5 选择（E、C 分开）

- E：调参 192 题，看 A（真且有信息）的变化，同时报完整三类（真 / 假、有信息 / 含糊、拒答）和"相同实质作答数"下的比较；拒答差在 ±3 个百分点内只是事先定的质量等价界，不等于相同作答率。
- C：按拒答控制幅度与共同作答题上的答案保持（纠正数 / 损伤数都列）选。现提示下基线拒答 23 / 192 = 11.98%，侧 (ii) 的可达范围由 x_C 下的基线拒答率决定，先测再定指标，不对两侧硬套同一个门槛。

### 3.6 对照

1. 提示对照：直接用 x_E / x_C 生成。E42 已有同类数字：如实指令提示 A 72 对 67（+5 [−7, +16]，拒答 23 → 63），提示里给金标 A 162。
2. 实际写入量匹配的随机方向（沿用 `core/qa_norm_matched_random.py` 的匹配机制，报告实际剂量；不用"钉到同一个名义值"）。
3. 均值差同算子：x_E 与 x 末词状态的均值差方向，同样钳制。

### 3.7 报告口径（不设硬闸）

改动率、纠正 / 损伤数、ΔA 与配对自举区间、拒答变化、完整三类；完全相同的回答复用已绑定的判决。措辞：区间含 0 写"未证实正收益"；未落进等价界写"未证实等价"，不写"证实有害"。E 与 C 的同层夹角只报告，不自动派生正交化分支。529 题多轮反复看过，本方案的设计也用了它的逐题表现，只称"历史测试集"，正式泛化结论要用未参与设计的数据。

### 3.8 判分

现有 `judge_two_axis_run.py` 的链是 cells → AllenAI → Pro → disputes → GPT 判争议格 → adjudicate → 人工。**赵磊 11-10 01:05 定（原话）："各报各的，后面先看 DAS 能不能改动，再看哪个口径更对发表有利。"** 所以本轮不调用 GPT、不合票：DeepSeek Pro 两轴与 AllenAI 各作为一个单裁判口径分别报告，两家不一致的格只列条数、不当终判。看结果的顺序：先看不依赖裁判的东西——改动率、拒答变化、改动回答的原文——确认写入确实改动了输出；再看两家口径下的对错。

### 3.9 预算

先用小样本实测训练耗时再估全量；判分 AllenAI 免费、Pro 约 1 美元。
