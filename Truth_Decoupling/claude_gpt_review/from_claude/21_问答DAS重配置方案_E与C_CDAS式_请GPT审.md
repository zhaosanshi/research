# 21 问答 DAS 重配置方案：E 与 C 都改成"整段回复目标 + 全位置钳制"（Llama 先行）——请 GPT 审（2026-11-09 23:30 北京时间）

赵磊 11-09 23:10 的要求原话："我们应该怎么配置 DAS 呢，给出你的建议……我让 GPT 来审核你的方案。记住，是 E 和 C 都要考虑的，可以先用 llama 模型试。"他对现状的判断：选中的层太浅（"一般都是 1/2 或者 2/3 之后才会有效果"），并给了四篇参考（ReFT / LoReFT、AxBench ReFT-r1、RePS、CDAS）。本文是方案，**没有跑任何新实验**；GPT 审完、赵磊拍板后再动代码。

术语：DAS（Distributed Alignment Search · 分布式对齐搜索 · 学一条方向，把这条方向上的坐标从 A 输入换进 B 输入，模型就按 A 的意思输出）；DII（distributed interchange intervention · 分布式交换干预 · 只换子空间上的坐标，其余不动）；钳制（clamp · 把坐标钉到一个常数）；JSD（Jensen–Shannon 散度 · 对称的分布距离，两边都不许塌）；教师强制（teacher forcing · 训练时喂正确前文，预测下一个词）；on-policy（在策略 · 用模型自己的输出当训练材料）；β（因子 · 钳制值相对来源均值的倍数，1 = 来源均值）。

## 0. 为什么要重配：今天逐题比原文查出来的事实

E25（问答 DAS v1，11-05）有两个版本：v1（同轮自检读出，选中 Llama L9 α1）和 v1u（新用户轮读出，选中 **L29 α3**，这是最终线，`11` §6）。两版的测试集 529 题，把基线回答和干预后回答逐题比（去大小写、空白后比较）：

| 条件 | 一字不改 | 改了 | 改写（词重合 ≥ 60%） | 换答案 | 改了的题里对错怎么变 |
|---|---|---|---|---|---|
| v1 DAS L9 α1（浅层） | 508 / 529 | 21 | 7 | 14 | 错→错 15，**对→错 4，错→对 0** |
| v1u DAS **L29 α3**（深层，最终线） | 428 / 529 | 101 | 23 | 78 | 错→错 48，对→对 19，**错→对 10，对→错 9**，弃答来回 15 |
| v1u 均值差 L10 α3 | 439 / 529 | 90 | 33 | 57 | 错→错 52，对→对 22，错→对 6，对→错 4 |
| v1u 写入**金标坐标**诊断，L29（192 题） | 164 / 192 | 28 | 5 | 23 | 错→错 20，对→对 5，**错→对 0** |
| E42 秩 1 单层来源交换 8 臂（192 题） | 176–188 / 192 | 4–16 | 多数 | 少数 | 几乎全是同类改写，B→A 各臂 0–1 |
| E42 整层状态换成真实来源（不是秩 1） | 70 / 192 | 122 | — | — | 错→弃答 30，错→对 16，对→弃答 11 |
| E42 金标状态写入（正对照） | 8 / 192 | 184 | — | — | 错→对 83 |

读法：
1. **浅层（L9）是"没改动"**：96% 一字不差。**深层（L29，α3）能改 19% 的文本，但改得随机**：错→对 10、对→错 9。把正确答案自己的坐标钳进去（金标坐标诊断）改了 28 题，错→对 0。所以不是"层太浅"一个原因——深层也试了、而且是最终线；是**这条方向装的变量不对**。
2. 我们问答 DAS 学的变量是"模型对一个答案的真假判决"（训练目标 = 答案后面一个自检词 True / False 的交叉熵，写在答案末位），然后拿它去改"答案本身的生成"。真假判断任务的输出就是那个判决，所以 TF 上 DAS 显著赢均值差（`11` §5）；自由问答的输出是多词答案，判决方向不管它——读得出（认错 AUROC 0.67–0.78，读的正是判决信号）、改不动。
3. 领域里的对照实验替我们做过：CDAS（ICLR 2026）Table 10 / Table 2——**原版 DAS 目标（最大化反事实标签概率）直接当 steering 用几乎无效**（拒答抑制 1%–2%），同一个交换原语换成"整条回复的分布匹配"就到 84%–91%。我们的目标正是标签那一类。
4. 层带：赵磊说"1/2 或 2/3 之后才有效果"。我们自己的数据：TF-DAS 的交叉熵从 L13 起才真正下降（`11` §5）；认错读出前三分之一读不出、末段最准（页 15）；TF 的 C 选在 L25 / L26。文献：CDAS 给 Llama-3.1-8B 选 L12 / 32、70B 选 L32 / 80（0.4 深度）；RePS 的层在 0.38–0.77 深度；ReFT 指令跟随用 3 / 9 / 18 / 24 层。所以候选层带定在 **L12–L28**（0.375–0.875），另放一个 L8 当浅层对照，用数据回答"浅层为什么不行"。

## 1. 从四篇里综合出的设计原则

| 原则 | 取自 | 我们现在的做法 | 改成 |
|---|---|---|---|
| 监督信号 = 整段回复 | ReFT（教师强制交叉熵）、RePS（整段偏好）、CDAS（逐词分布匹配） | 答案后一个自检词 | **整条回复逐词 JSD 分布匹配，双向**（主）；教师强制交叉熵（消融） |
| 来源 = 提示对比，不是答案对比 | CDAS（同一指令 ± 概念要求） | 同一提示下金标正误答案 | **同一问题、不同系统指令**（真实性指令 / 弃答指令 / 作答指令），回答用模型自己的 |
| 写法 = 钳制到来源均值 | CDAS（β = 1 单位因子） | 居中放大 (1+α) | **全位置钳制 Φ(h) = h + (β·ᾱ − wᵀh)·w**，主结果 β = 1 |
| 写的位置 = 所有位置 | CDAS（指令 + 回复）、RePS（所有提示词 + 每个生成步） | 训练只写答案末位，推理写提示末位 + 生成词 | **训练与推理都写全部位置** |
| 力度以数据差距为单位 | RePS（因子 × 范数 ≈ 激活范数）、CDAS（来源均值） | 裸的 α 1–3 | β ∈ {0.5, 1, 1.5, 2} 只画曲线，主结果 β = 1 |
| 选层、选因子用真实生成 | AxBench（一半测试指令选因子） | 自检标签代理分 | **调参 192 题真实生成的 ΔA + 拒答率约束** |
| 对照 | AxBench（prompt 打败所有表征方法） | 无 prompt-only | **prompt-only、范数匹配随机方向、均值差同算子、整层来源交换上界、金标正对照** |

秩：主结果秩 1 单层（保住"两条方向、各管一事"的论文叙事）；秩 4 的 LoReFT 式做一格上界消融（Wh + b 可学来源投影，ReFT 式 2）。

## 2. E 方向（真实性）配置

**数据与配对。** 用现有切分：训练 e_train 92 题，调参 e_tune 192 题，测试 529 题（和 E25 同一划分、同一种子）。每题三条提示：
- x：现有问答提示（允许说 I don't know）；
- x_E：同一问题 + 真实性系统指令，例如 "Answer truthfully and directly. Correct common misconceptions. Do not say you don't know."（措辞最终版请 GPT 一起定，训练与推理不能用这句提示生成，它只用来造来源状态）；
- y、y_E：模型自己在 x、x_E 下的贪心回答（on-policy，弱监督，和 CDAS 一样不用外部偏好）。

过滤：只保留 y_E 判真、y 判假的题（AllenAI 两裁判免费初筛，Pro 复核），预计 92 题留 30–50 对；少于 30 对就启用变体 B（y_E 用金标 best_answer），两版都报。

**目标（CDAS 式，双向）。** w 为单位向量；对一对 (x, y) 与 (x_E, y_E)：
- D⁺：把 x_E 在第 L 层各位置的坐标 wᵀh(x_E) 钳进 x 的同层同位置，教师强制 y_E，逐词让干预后的下一词分布逼近 x_E 自己的下一词分布（JSD）；
- D⁻：对称，把 x 的坐标钳进 x_E，教师强制 y，逼近 x 自己的分布；
- 两项各 0.5，每对一步 Adam，学习率 1e-3，10 轮，梯度裁剪 1；T = 回复全长（上限 24 词元）。

**写入。** 训练和推理都在**所有位置**（提示 + 已生成词）钳制：Φ(h) = h + (β·ᾱ_E − wᵀh)·w，ᾱ_E = 训练集 x_E 在该层的平均坐标；主结果 β = 1，曲线 β ∈ {0.5, 1, 1.5, 2}。不用放大。

**层与种子。** L8（浅层对照）、L12、L16、L20、L24、L28；每层 3 个种子，余弦 ≥ 0.5 对齐后平均（现有 `load_das_direction` 规则）。

**选择。** 调参 192 题真实生成：选 ΔA（两轴口径 A = 真且有信息）最高且拒答率 |Δ| ≤ 3 个百分点的层；进测试 529。选层不再用自检标签代理。

**前置检查。** 改动率（干预后文本与基线不同的比例）≥ 30% 才算"写得动"，才进判分；低于 30% 直接记"写不动"，不浪费判分。

**对照（同一批题、同一算子）。** ① 均值差：x_E 与 x 的提示末位均值差方向，同样钳制；② 范数匹配随机方向；③ prompt-only：直接用 x_E 生成（若 E 不比它好，说明方向只是把指令效果搬了一半，要如实写）；④ E42 的整层来源交换当上界；⑤ 金标状态写入当正对照。

**成功标准（预注册）。** 积极：测试 ΔA 的 95% 区间 > 0，拒答率 |Δ| ≤ 3 pp，且 ΔA 显著高于随机方向；改动率 ≥ 30%。消极：改动率 ≥ 30% 但 ΔA 区间含 0（"改了没改对"），或改动率 < 30%（"写不动"）。配对自举 2000 次，种子 0；层与 β 的多重比较 Holm 校正。

## 3. C 方向（作答率）配置

**数据与配对。** 同 92 题，三条提示：x_abs（弃答倾向："If you are not completely certain, answer exactly 'I don't know.'"）、x_ans（作答倾向："Always give your best substantive answer. Never say you don't know."）、x（现有）。训练对 = (x_abs, y_abs) 与 (x_ans, y_ans)，y 用模型自己的贪心回答；过滤：y_abs 是拒答、y_ans 是实质回答。预计留 40–70 对。

**目标。** 同 §2 的双向 JSD。**位置** 全部。**层带** L16–L28 步 4（TF 的 C 在 L25 / L26），加 L8 对照。秩 1，3 种子。

**与 E 的关系。** 训练完报告 cos(w_C, w_E)。若 |cos| > 0.3，再出一版"对 w_E 正交后归一"的 w_C，两版都报（TF 协议里 C 对 E 正交就是这么做的）。

**写入与曲线。** 钳到 β·ᾱ_abs（推弃答）或 β·ᾱ_ans（推作答），β ∈ {0.5, 1, 1.5, 2}，得到作答率曲线。

**指标。** ① 拒答率随 β 单调变化，幅度 ≥ 20 pp；② "不动判别"：两种条件下都作答的题上，对→错与错→对翻转数对称，ΔA|answered 的区间落在 ±3 pp 等价界内；③ MC2 不变（C 对选择题概率不应有影响）；④ 补充：同交付量 K 下对置信度门槛的 P1 / P2 类比较（N7 的口径），只报不作成功标准。乱码率 < 2%。

**成功标准。** ① 与 ② 同时满足为积极；① 满足 ② 不满足记"C 碰了判别"；① 不满足记"写不动"。

## 4. 自由问答 2×2（Llama）怎么报

| | ΔA（真且有信息） | Δ拒答率 | ΔA\|两边都作答 |
|---|---|---|---|
| 推 E（β = 1） | 主指标，区间 > 0 为积极 | 等价界 ±3 pp | — |
| 推 C（β = ±1） | — | 主指标，≥ 20 pp | 等价界 ±3 pp |

口径：先报我们两轴的 A/N 与 AllenAI 相乘版（领域可比），SimpleQA 式三类从同一批票折算；哪一个做主口径等老师定（`docs` 本地草稿，未进仓库）。每格配对自举 2000 次，Holm。极性先写：E 行区间含 0 = 消极；C 行作答率动但判别也动 = 消极。

## 6. 预算

## 7. 风险与对策

1. **方向学到的是"指令风格"不是真实**（AxBench：prompt 打败所有表征方法）→ prompt-only 对照必报；E 不比 prompt-only 好就如实写。
2. on-policy 过滤后对数太少 → 变体 B 用金标 y_E；两版都报。
3. 全位置钳制伤流畅 → 乱码率、对自然分布的 KL（CDAS 的做法）、必要时 GPT 流畅分。
4. 秩 1 容量不够 → 秩 4 LoReFT 式上界一格；若秩 4 行秩 1 不行，论文叙事要改。
5. **新颖性**：CDAS 已发表，我们能主张的只是"E / C 两条方向在同一框架下的分工 + 作答率可控 + 同作答率下的真实性比较"，不是方法本身；写作必须引用并写清差别。
6. TruthfulQA 自由回答判分本身不稳（Illusion of Progress，EMNLP 2025 主会）→ 改动率、拒答率这些不依赖裁判的指标先行。
