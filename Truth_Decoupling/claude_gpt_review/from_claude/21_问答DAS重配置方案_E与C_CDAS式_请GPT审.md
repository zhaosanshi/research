## 1. 问答为什么不能照抄 TF：三句人话

**第一句：方向学的是"判决词"，拿去改"整段回答"，不管用。** 我们问答 DAS 的训练目标是答案后面一个自检词 True / False 的交叉熵。真假判断任务的输出就是那个词，所以 TF 上 DAS 显著赢均值差（`11` §5）；自由问答的输出是多词的答案，判决方向不管它——读得出（认错 AUROC 0.67–0.78，读的正是判决信号）、改不动。CDAS（ICLR 2026）替我们做过对照：同一条方向、同一个"换坐标"动作，训练时只盯一个固定目标词，拿去压模型不拒绝只能压掉 1%–2%；训练时让整段回答变得像来源那一版，能压掉 84%–91%（它的 Table 2、10、31）。

**第二句：差别要造在问题那一段，不能造在答案那一段。** 推理时模型只看到问题，还没写答案，我们要写进去的信号必须在问题这一段就存在。TF 天然满足：真句和假句本身不同，读完句子内部状态就不同。问答不满足：训练对"同一问题 + 对答案"和"同一问题 + 错答案"在问题那一段一字不差、内部状态一模一样，换坐标等于没换，方向只能去学"答案写的是什么"；到了推理答案还没写出来，方向就哑了。E42 里换一条坐标只改 2%–8%、把金标答案的整个内部状态搬过去却改 96%，就是这个现象——一条方向装不下一个答案。唯一办法是用**指令**让问题那一段不同：同一个问题，一版前面加"如实回答、纠正常见误解"，一版不加；方向学的是"这句指令带来的内部变化"，推理时把这个变化写进普通提示。C 同理：一版加"不确定就说不知道"，一版不加。

**第三句：写的时候把坐标钉到"如实那一版"的刻度，不是把原有偏差放大。** 原写法是放大：看坐标 z 离中心差多少，放大 (1+α) 倍——z 在中心附近就等于没动，z 偏在"假"那边就偏得更厉害，α 1–3 没动静、再大写散（`10`）。新写法是钳制：不管 z 原来多少，直接钉到固定值 a，a 取训练题"如实指令那一版"的平均坐标，不用调 α。

```
放大：z' = 中心 + (1+α)·(z − 中心)      离中心近 → 几乎不动；偏哪边 → 更偏哪边
钳制：z' = a                             a = 如实指令那一版的平均坐标；β 倍 = β·a
```

这三处是必要的改动。其余的（on-policy 回答、三条提示、多种子、β 网格、秩 4、五个对照、JSD）都降为第二轮可选，见附录 A。

## 3. 最小版配置

### 3.1 训练对（Llama，92 题，E25 的 e_train 划分不动）

每题两条提示，只差系统指令里的一句：
- x：现有问答提示（允许说 I don't know）。
- x_E：x + "Answer truthfully and directly. Correct common misconceptions."（措辞请 GPT 一起定；这句只用来造来源坐标，不参与生成）。
- x_C：x + "If you are not completely certain, answer exactly 'I don't know.'"

E 的一对 = (x_E, y_true = 金标 best_answer) 与 (x, y_false = 第一条可用的金标错答案)。C 的一对 = (x_C, "I don't know.") 与 (x, y_true)。金标来源与 E25 相同（`core/qa_context.py` 的选法：best_answer 为正，incorrect 列表第一条可用的为负）。

### 3.2 目标：整条答案的交叉熵，双向

w 为单位向量，层 L 固定。读坐标的位置 = 来源提示的最后一个词（和 TF 的提示末位锚点一致，不做网格搜）。
- D⁺（E）：把 x_E 末词的坐标 z_E 钉进 x 的**全部位置**（提示 + 教师强制的答案词），教师强制 y_true，对 y_true 的每个词算交叉熵取平均。意思：普通提示带上"如实"的坐标，就该写出对的答案。
- D⁻（E）：把 x 末词的坐标 z 钉进 x_E 的全部位置，教师强制 y_false，交叉熵。意思：去掉"如实"的坐标，就该写出那个常见的错答案。
- C 对称：D⁺ 把 x_C 的坐标钉进 x，教师强制 "I don't know."；D⁻ 把 x 的坐标钉进 x_C，教师强制 y_true。
- 两项各 0.5；Adam，学习率 1e-3，10 轮，梯度裁剪 1，每对一步；答案长度上限 24 词元。和 TF 的 `loss="ce", bidirectional=True` 同一套训练循环，只是目标词从 1 个变成答案的全部词、写的位置从末位变成全部位置。

### 3.3 写法：钳制到均值，加一个不用均值的诊断臂

- 主结果：推理时把普通提示的全部位置（提示 + 每个新生成的词）钉到 a = 训练 92 题 x_E 末词坐标的平均值（β = 1）。C 推弃答钉到 a_C = x_C 坐标的平均；推作答钉到 ā_x − (a_C − ā_x)，即往另一边推同样一段。
- "用均值吗"的说明：这里的均值只是定**刻度**的一个数，和放大写法里的中心、C 加法写法里的"一个真假差"是同一类东西；方向 w 仍是 DAS 学出来的，与"均值差估计器"无关。
- 诊断臂（便宜）：每道题推理时先把 x_E 版跑一遍前缀，读出它自己的 z_E，把普通版钉到这个值。它和均值臂差不多 → 旋钮是题目无关的，均值够用；它明显更好 → 方向里装着题目相关信息，均值太粗。
- 生成前预检：在调参 192 题上算 x 与 x_E 两组末词坐标 z 的 AUROC。低于 0.7 说明方向没学到指令带来的变化，不进生成、不花判分。

### 3.4 层

L12、L16、L20、L24、L28（Llama 32 层的 0.375–0.875）。依据：TF-DAS 的交叉熵从 L13 起才真正下降（`11` §5）；认错读出前三分之一读不出、末段最准（博士包页 15）；TF 的 C 在 L25 / L26；CDAS 给 Llama-3.1-8B 选 L12、70B 选 L32（0.4 深度）；RePS 的层在 0.38–0.77 深度。每层每方向 1 个种子。

### 3.5 选择

调参 192 题真实生成（β = 1），选 ΔA（两轴口径 A = 真且有信息）最高且拒答率 |Δ| ≤ 3 个百分点的层，进测试 529 题。不再用自检标签的代理分选层。

### 3.6 对照（同一批题、同一钳制算子）

1. prompt-only：直接用 x_E（或 x_C）生成。E 若不比它好，说明方向只是搬了指令效果的一部分，如实写（AxBench 的教训）。
2. 范数匹配随机方向：同样钉到同样幅度。
3. 均值差同算子：x_E 与 x 末词状态的均值差方向，同样钳制。
整层来源交换上界（改 64%）与金标正对照（改 96%）引用 E42 现成数字，不重跑。

### 3.7 判定（预注册，配对自举 2000 次、种子 0；层间 Holm）

- 前置：改动率（干预后文本与基线不同的比例）≥ 30% 才算"写得动"；低于 30% 记"写不动"，不判分。
- E 行：测试 ΔA 的 95% 区间 > 0，拒答率 |Δ| ≤ 3 pp，且 ΔA 显著高于随机方向 → 积极；改动率够但 ΔA 区间含 0 → "改了没改对"，消极。
- C 行：β = ±1 下拒答率变化 ≥ 20 pp 且方向正确；两种条件下都作答的题上 ΔA 的区间落在 ±3 pp 内 → 积极；拒答动但共同作答题 ΔA 出界 → "C 碰了判别"，消极。
- 训完报告 cos(w_C, w_E)；|cos| > 0.3 再出一版对 w_E 正交后归一的 w_C（TF 协议的做法）。
- 口径：先报我们两轴的 A/N 与 AllenAI 相乘版，SimpleQA 式三类从同一批票折算；主口径等博士定。

### 3.8 预算

训练：5 层 × 2 方向 × 1 种子，每个约 10 分钟（92 对、10 轮、≤ 24 词元）→ 约 2 小时单卡。生成：192 题 ×（10 个方向层 + 3 对照 + 诊断臂）约 30 分钟；测试 529 题只跑选中配置。判分：AllenAI 初筛免费，Pro 终判约 1 美元；不用 GPT 裁判。Llama 一轮约半天到一天。

## 4. 不行再换，一次只换一个变量（顺序）

1. 交叉熵目标 → 整条回复 JSD 分布匹配（CDAS 主目标；它的消融里 JSD 优于交叉熵式目标，RePS 则显示调好的交叉熵是强基线）。
