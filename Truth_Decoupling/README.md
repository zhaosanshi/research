# Truth_Decoupling

研究大语言模型残差流（residual stream）里两条低秩方向的解耦：

- **E 方向（证据方向）**：推它，模型对陈述真假的判别力上升，作答率不变。
- **C 方向（承诺方向）**：推它，模型的作答率上升或下降，判别力和真/假偏置不变。

核心主张是一个 2×2 的因果矩阵：E 只动判别力，C 只动作答率。实验在 Llama-3.1-8B、Qwen3-8B、Gemma-3-4B 上进行（Gemma-3-12B、Mistral-7B 作失败分析），主数据集为 TruthfulQA 的真/假陈述对与原题自由问答。截至 2026-11-06，真假判断任务上三模型都显示"任务内的近似选择性"，自由问答上 E 没有稳定收益；详见 `老师审核/`。
