## 2. 做法：与 11-12 那次相同，只换模型

- **题**：TruthfulQA 真假陈述 721 对。调参集 192 对，与以往同一个种子；测试集为其余 529 对。只在调参集上做选择，测试集只报数。
- **问法**：同一遍里只能在 True、False、Unknown 中选一个；选 Unknown 算不答。
- **E**：两个新模型真假判断 2×2 选中的 DAS 方向与力度，即 Qwen3.5-9B 第 31 层、Qwen3.8-27B 第 63 层，力度都是 3。中心点在允许 Unknown 的问法下重算。
- **C 有两种，都报**：
  - 主用：2×2 选中的 C，在"你知道答案吗"那一遍上估的；
  - 备用 CpI：在允许 Unknown 的问法下，用自信与谨慎两种系统提示估出，层与主用的 C 相同，与同层的 E 正交。11-12 的判读用的就是它。
- **两个新模型的 2×2 两种 C 都选了层**，要事先定用哪一组：
  - **主跑提示对比 Cp 那一组层**：Qwen3.5-9B 往弃答第 16 层、往作答第 17 层；Qwen3.8-27B 第 62、63 层。理由：判读用的 CpI 也是提示对比方向，与 Cp 的估法一致。
  - 自报对比 Cs 那一组层（Qwen3.5-9B 第 28、31 层；Qwen3.8-27B 第 57、60 层）另跑一遍，作为补充照报，不进总判读。
- **条件、选档、比较、判读**全部沿用方案 `40` 第 2 节：
  - 61 个条件：不写入；E 力度 1、2、3；E 力度 3 用原问法的中心点（诊断）；两种 C 各在两个方向、7 个力度上单用；E 力度 3 加上每一种 C。
  - 选档只在调参集上、只看作答数。E 单用使作答数变多，C 就往弃答推，否则往作答推；力度取 E+C 作答数最接近不写入的那一档。
  - 比较：E+C 自己作答的 K 题里答对几题，与"只用 E，按两种分数各取最有把握的 K 题"（P1、P2）和"只用同一个 C、同一力度，取前 K 题"（P5、P5b）相比。整对重抽 2,000 次，每个模型、每种 C 的四个比较做 Holm 校正。
  - **强形式成立** = P2、P5b 都显著为正；**弱形式成立** = P5b 显著为正，且 P2 不显著为负。
  - **天花板**：调参集上不写入时选 Unknown 的比例低于 5% 的模型照报，不计入总判读。
- **代码**：`e45_tf_idk_ec.py` 与 `e45_analysis.py` 与 11-12 那次逐字节相同。这次从放有两个新模型配置的代码副本 `code_newmodels_20261112` 运行，两个新模型的真假判断当初就是用它跑的；它的核心文件比 11-12 那次所用的副本新。新写的只有启动脚本 `Iteration_01/code/launchers/e45_newmodels_20261119.sh`。

## 3. 事先写下的预测

依据是四个较早模型的结果。

1. **E 单用**（力度 3）在两个模型上都提高 AUROC，测试集区间在 0 以上。
2. **天花板**：两个模型在调参集上不写入时选 Unknown 的比例都不低于 5%（Qwen 系列较常答 Unknown）。
3. **E 改变作答数的方向**：两个模型上，E 单用都使调参集的作答数变多（与 Qwen3-8B 相同：E 让证据更清楚，模型更敢下判断）。
4. **C 能否拉回**：主用的 C 收回的变化不到 E 带来变化的一半；CpI 能把调参集作答数拉回到不写入的 ±3% 以内。
5. **作答数相同时**：两个模型上强形式都不成立（P2 不显著为正），弱形式至少在一个模型上成立。
