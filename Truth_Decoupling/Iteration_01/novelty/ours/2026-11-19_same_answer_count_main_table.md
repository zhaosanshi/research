# 相同作答数下的主表：自由问答，组合用冻结的方案 N1

撰写：赵磊（Fable 5.2 代笔）。起始日期：2026-11-19（北京时间）。

下文路径均相对于仓库的 `Truth_Decoupling/`。评分只按答对得 1 分、不答 0 分、答错扣 1 分（净分），裁判为 DeepSeek Pro。方案 N1 见 `Iteration_01/novelty/ours/2026-11-17_silence_and_release.md` 第 4.10 节。

## 1. 起因

- 博士 2026-11-05："在相同作答率下，组合是不是比任何一个单独方向都好。这一句就是我们这篇文章的主要 contribution，别的都是支撑"。
- 博士 2026-11-15："另一组用必须作答时只推 E 的回答，按置信度挑出同样多的来比。两个分开算，把实际答了多少、答对多少、差多少和区间列出来。"
- 2026-11-14 做过一版（`for_Dr_review/2026-11-11/进度和结果.md` 第二节 B 第 4 部分）：组合用当时的 E+C，按答对题数比。对"只推 C 再挑题"成立；对"只推 E 再挑题"三个模型都没有成立。
- GPT 2026-11-18 23:43 建议先把这张表补完，组合换成冻结的 N1（`Iteration_01/discussion/novelty_review/2026-11-18_n1_decision_for_claude.md`）。

## 2. 做法

- **没有新的生成，也没有新的判分**。用的是已有的回答、已有的 Pro 判分、已有的把握分。程序 `Iteration_01/code/diag/main_table_same_n.py`，输出 `main_table_same_n_20261119.txt`。
- **题**：测试集。Llama-3.1-8B、Qwen3.5-9B 为 523 题，Qwen3.8-27B 为 522 题，Gemma-3-12B 为 522 题，Gemma-3-27B 为 523 题（去掉金标只有"无可奉告"的 6 题与个别被 Pro 拒判的题）。
- **设置**：全部沿用调参集 192 题上选定的，没有在测试集上重选。
- **作答数**：规则检测器没有认作"不知道"、而且不是空白的回答数。不用裁判的标签，因为裁判的标签和对错相关。
- **把握**：模型对自己这条回答的把握，取回答各词元的平均对数概率（同一种问法、同样的写入下计算）。程序逐条核对过，把握分对应的正是被判分的那条回答。
- **挑题的对照系统**：只回答自己最有把握的 N 条，其余说"不知道"。N 取 N1 的作答数。
  - **强形式**：必须作答问法上只推 E（力度与 N1 相同），留最有把握的 N 条。这是单用 E 时最强的对照。
  - **原模型**：必须作答问法、不写入，留最有把握的 N 条。
  - **弱形式**：普通问法上只推 C，留最有把握的 N 条。
- **区间**：按题配对重抽 4,000 次。五个模型合计时按题号重抽，同一道题的五个模型一起抽。
- **事先没有写预测**。Llama 与两个 Qwen 的测试题在设计 N1 时已经看过。两个 Gemma-3 模型在博士 100 题以外的 424、425 题，Pro 判分是在 N1 冻结之后才做的，单列在第 3.5 节。

## 4. 读法

1. **对原模型、对单 C**：作答数相同时，N1 在五个模型上都更高（对原模型 +109 至 +264，对单 C +96 至 +304），区间都在 0 以上。
2. **对单 E，各自的作答数**：N1 在五个模型上都更高，区间都在 0 以上（+18 至 +50）。
3. **对单 E 加挑题，作答数相同（博士要的那组对照）**：五个模型合计 +145 [+78, +210]。分模型看，Qwen3.8-27B 与 Gemma-3-27B 的区间在 0 以上；Llama-3.1-8B 与 Qwen3.5-9B 的点估计为正，区间包含 0；Gemma-3-12B 为 −6，区间包含 0。
4. **与 11 月 14 日那一版的不同**：组合由当时的 E+C 换成 N1，评分由答对题数换成净分。那一版三个模型都没有成立。
5. **Gemma-3-12B 是反例**。在这个模型上，必须作答问法加 E、全部作答就有 168 分，高于 N1 的 157 分；在 N1 冻结之后才判分的 424 题上，N1 减强形式为 −16 [−39, +6]。
6. 博士 11 月 15 日点名的 Qwen3.5-9B：两边都答 446 题时，N1 答对 312 题、答错 123 题，对照答对 305 题、答错 129 题，没有拉开。

## 5. 限制

- 事先没有写预测；Llama 与两个 Qwen 的测试题在设计 N1 时看过。未参与设计的题只有第 3.5 节的两个 Gemma-3 模型，一正一负。
- 区间只描述选定设置下逐题的差异，不含在调参集上选设置这一步的波动。
- 作答数按规则检测器计，含裁判判为含糊的回答；表中同时给了对错数。
- 挑题只试了回答自身的对数概率这一类把握分，没有试让模型自报把握、多次采样的一致性等做法。
- 结论只在 TruthfulQA 的测试题上。
