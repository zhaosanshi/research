## 3. 请重点看的地方

1. **`per_model_table.py` 的选力度规则有没有偷看**。力度只由 MMLU 的“选力度”那一半决定；N1 的两个上限在该力度的 TruthfulQA 调参集上选；TruthfulQA 测试集与 MMLU 的另一半只用来读数。请核对半分用的种子与 1,000 道诊断题的归属（全部在“选力度”的一半里）。
2. **`ns_stable_table.py` 与 `ns_probe_table.py` 的保留规则**。两者都只会给出模型不写入时的回答或者留空；“回答相同”用的是 N1 规则里现成的比较函数（`release_origin.norm`）。请核：留空的回答会不会被记成对或错；各遍回答之间题目顺序是否对齐；第二批测试题用的是另一个题库文件（`*_bank_test2_20261120.jsonl`）；族内成员在调参集上选、并列取靠前（较弱）的一个。
3. **`ns_probe_table.py` 里两处对照的口径**。“换问法”对照用的是必须作答问法那一遍回答与不写入回答是否相同；“按把握挑题”对照用必须作答那一遍、按回答词元的平均对数概率保留同样多的题。两者与“用 E 复核”比的是同一批题、同样的记分。
4. **`ns_caut_confirm.py` 的选择集**。它把调参集与第一批测试题合在一起选设置，这是有意的：第一批测试题在探索各种变体时已经看过，结论只读第二批。请核它有没有任何地方用到第二批题的数字来选。
5. **别名匹配的已知偏差**。否定句里出现标准答案字样也会被判对（例如“某某并没有写这部剧本”）。这会抬高“只推 E 直接作答”的分数。本批所有新题集数字都是别名匹配判的，没有新的 Pro 判分。
