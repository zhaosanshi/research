# 排期 L：叠法只补空——如实句已答的题不动，只在它留空的题上用 E + C

撰写：赵磊（Fable 5.2 代笔）。北京时间 2026-11-23 08:37。路径相对于仓库的 `Truth_Decoupling/Iteration_01/`。探索。

**先说明顺序**：这份规则写在看过 TruthfulQA 测试集上"如实句 → 叠法"的逐题转移表之后（排期壬 11-22 23:09 的记录）。所以测试集上的读数是事后的，调参集并列列出，结果要在没用过的题上再确认一次才算数。

名词：S0 = 普通问法 + 如实句，不写入；SE = 如实句 + E；SN1 = 如实句 + E，仍留空的题再加 C（排期壬的叠法）；SC = 如实句 + 只加 C；`conf_E2` = 必须作答 + 如实句，不写入；N1 = 不带如实句的主表方法；净分 = 答对 +1、不答 0、答错 −1。

## 0. 为什么

- GPT 晨间复核（[2026-11-23_morning_review.md](../validation_dataset/2026-11-23_morning_review.md)）：整套叠法在 MMLU、GSM8K 上有代价，正常题上一口否定；相同作答数下，C 在叠法里的单独收益没有确认（+14 [−25, 55]）。这两点属实。
- 已有的转移表（五个模型，TruthfulQA 测试集 520 道共同题，S0 → SN1）：S0 已答的题上，叠法把错的改对 178、把对的改错 134、错的改成不答 81、对的改成不答 60；S0 没答的题上，叠法补对 206、补错 74。前一部分净 +109，改对与改错接近对半；后一部分净 +132，七成多是对的。
- E 的训练对比用的正是这一句话（加与不加）。这句话已经给过一次"如实"的量，叠法在它已答的题上又给了一次。排期 K（训练侧加保持项）的读数是：否定开头压掉了，加分也一起没了。
- 做法：S0 答了的题原样交；只有 S0 留空的题才用 E + C 再问。已答的题一个都不改，所以相对于只加这句话，正常题上的一口否定与 MMLU、GSM8K 上的代价按构造为零。

## 1. 定义（每个模型、每道题；只用现成的回答与判决，不生成、不调裁判）

- 留空 = 现成的"是否作答"规则判为不作答（与 N1 用的同一条规则；不看裁判的判决）。B = S0 留空的题。
- 每个系统在 B 之外一律交 S0 的回答；在 B 之内交下面某一遍的回答，那一遍也不答就仍留空：

| 记号 | B 内交谁的回答 | 现成来源 |
|---|---|---|
| 补 EC | SN1（如实句 + E，仍留空再加 C；两个上限用排期壬已经选定的） | 排期壬第一步与 7.1 |
| 补 E | SE（如实句 + E，不加 C） | 同上 |
| 补 C | SC（如实句 + 只加 C；上限用 7.2 选定的） | 排期壬 7.2，只有 TruthfulQA |
| 补 提示 | `conf_E2`（必须作答 + 如实句，不写入） | 现成的 T2 |
| 补 N1 | 不带如实句的 N1 | 现成的 F1 |

- 题：TruthfulQA 测试集（五个模型共同的 520 题）与调参集 192 题；(QA)² 留出 470 题（分题型）与 100 道调参题（没有补 C；补 提示 若没有现成回答就写"没有"）；事实题四批只有 SE，没有加 C 的那一遍，只读补 E。

## 2. 读数（分模型与五个模型合计；差值给按题配对的区间）

1. 每个系统的净分与作答数；B 的大小；补答条数，其中判对、判错、判为无信息各多少。
2. 各系统减 S0。
3. 补答方式之间：补 EC − 补 C、补 EC − 补 E、补 EC − 补 提示、补 EC − 补 N1。先列自然作答数。再列相同补答数：每个模型里补得多的一方，按它自己这些补答的自判分从低到高去掉，去到两边一样多。自判分用现成的批大小 1 分数；缺的照排期癸第 5 节的规矩补算，只补缺的那几条。
4. 补 EC 的补答按"用了多大的 C 才答出来"分开：只靠 E 就答了（C = 0）、0.25、0.5、1、2，各档的条数、对、错。不带如实句的 N1 在原模型留空的题上也照这样列一遍，作并列。
5. 整套叠法 SN1 减 补 EC（即叠法改动 S0 已答题的那一部分），拆成四个数：错变对、对变错、错变不答、对变不答；对变错里以否定开头的有多少条。
6. 调参集上同样的 1–5。

## 3. 开读前的核对（对不上就停下报告）

- 五个模型合计的净分与作答数先对上现成的数。TruthfulQA 测试集：S0 +706 (2,269)、SN1 +947 (2,438)、SE +894 (2,126)、SC +759 (2,552)、T2 +689 (2,598)、F1 +781 (2,518)。(QA)² 留出 470 题：S0 +40 (2,013)、SN1 +294 (2,139)、SE +287 (1,886)。
- 转移表的六个数 178 / 81 / 134 / 60 / 206 / 74 先复现（那张表的"不答"含判为无信息的回答；第 1 节的"留空"只按规则，两者不同，各算各的并注明）。
- 用这一程序按第 1 节的定义重算补 提示 与 补 N1，要与现成的 T2 +689、F1 +781 逐模型相同。
