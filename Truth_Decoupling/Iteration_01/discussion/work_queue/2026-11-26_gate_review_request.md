# 请 GPT 评估：给 E 加一个开关（逐题判断像不像陷阱题）——第一步的结果，第二步做不做

撰写：赵磊（Fable 5.2 代笔）。日期：2026-11-26（北京时间）。

赵磊 2026-11-26 21:28："关于开关做不做，等GPT的回复吧。"这份文件是给你的材料与问题。

## 一、为什么想到开关

论文主句不变：两个方向一起用（N1）比只用 E、只用 C 都好。N1 之后 TruthfulQA 测试集上各模型还剩 191、124、150、154、169 道错答（顺序 Llama-3.1-8B、Qwen3.5-9B、Qwen3.8-27B、Gemma-3-12B、Gemma-3-27B，下同），其中"原来就错、拧 E 也没改过来"的 96、101、80、69、134 道。今天查清的事实（排期 [2026-11-26_queue_o.md](2026-11-26_queue_o.md) 进度各条）：

- 这批回答 C 够不着（往敢答拧 C 不变；必须作答也不变；往谨慎的手段不优先压住它们）。
- 能动它们的是更大的 E（例如 Llama-3.1-8B 力度 3.5 → 5，只拧 E 的测试集净分 +40 → +69），但更大的 E 过不了能力线（MMLU 掉 2.8 至 4.3 点）。
- 三个口子：让 C 给 E 的 MMLU 损伤兜底（排除：E 加 C 一起写时 MMLU 的掉分与只写 E 基本相同）；E 分两档（排除：调参集上十个格子的区间都含 0）；给 E 加开关（下面）。
- 另一个已知短板：FalseQA 上前提没错的题，拧 E 丢分。

## 二、开关是什么、第一步做了什么

排期：[2026-11-26_queue_p.md](2026-11-26_queue_p.md)（做法与读数的标准在跑之前写定并入库）。

- 开关 = 普通问法、不写入时，提示最后一个词元处某一层输出上的逻辑回归（L2，C = 1，先标准化）；输出"是陷阱题"的概率，大于 0.5 记为打开，门槛不调；层由训练题内部按题对分组的 5 折交叉验证选。
- 用法（这一步只是模拟）：开关开 → 交 N1 的回答；开关关 → 交原模型（不写入）的回答。
- 两种训练题：甲 = FalseQA 官方训练集 1,187 对（一对里一道前提错、一道前提对，此前没用过）；乙 = 甲，加 TruthfulQA 训练与调参部分（陷阱）、(QA)² 100 道试验题、PopQA 与 TriviaQA 的训练与调参部分、MMLU 样本外 500 道、GSM8K 训练集 300 道（普通）。共 4,546 道（陷阱 1,525、普通 3,021）。
- 只读数、不训练的题：FalseQA 留出 600（官方测试集里抽的）、(QA)² 留出 470、TruthfulQA 测试、PopQA 与 TriviaQA 测试、MMLU 1,000 道样本、GSM8K 前 304 道。程序按题号与题目文字断言它们不在训练题里。
- 这一步不生成回答、不判分：读内部状态、训练、用现成回答与判定模拟。

程序（未经你审，探索）：[gate_capture_1126.py](../../code/diag/gate_capture_1126.py)、[gate_fit_1126.py](../../code/diag/gate_fit_1126.py)、[gate_sim_1126.py](../../code/diag/gate_sim_1126.py)、[run_gate_1126.sh](../../code/launchers/explore_20261120/run_gate_1126.sh)。输出：`results/write_positions/gate_1126_fit_20261126.txt`、`results/write_positions/gate_1126_sim_20261126.txt`。

## 四、我们自己看到的问题

1. 乙的普通题一侧有 PopQA、TriviaQA、MMLU、GSM8K 各自的训练题。开关在这些题集上几乎全关，有一部分是认出了题的样式；只有 FalseQA 成对题上的 82% 至 90% 是"前提对错"本身的读数。(QA)² 上只有 64% 至 67%。
2. 力度不变时，TruthfulQA 上带开关比不带低 3 至 29 分（两个模型区间在 0 以下）；PopQA 上只拧 E 原有的加分没有了。
3. 留出题的判定在别的比较里读过；标准是今天定的；达到标准的模型正好 3 个。
4. 开关这个做法别人提过（ICLR 2025，CAST：用条件方向决定是否施加干预）。它在本文里只能当部件。
5. 执行人中途因网络中断，结果由主会话核对；计划没写到、执行人自己定的几处（提示词元的核对换成三项替代核对；GSM8K 训练集是从 Hugging Face 取的）记在排期 P 的进度里。

## 五、想请你判断的

1. **第二步值不值得做？** 第二步 = 在开关打开的题上把 E 拧到更大的力度并配 C（N1 的后两步），调参集上选力度，再到测试集上读；能力线改为量"带开关的整条流程"。如果值得，评测怎么设计才站得住（哪些题集、和谁比、作答数怎么拉平）？如果不值得，理由是什么？
2. **开关关着的题交什么？** 现在模拟的是交原模型的回答（PopQA 上 E 的加分没了，FalseQA 上前提没错的题不再丢分）。另一种是关着的题仍只拧 E（PopQA 的加分留着，FalseQA 上前提没错的题继续丢分）。哪一种更合理，或者应当两种都报？
3. **怎么证明开关读的是"题目有没有陷阱"而不是"题集样式"？** 我们想到的对照：训练题里去掉某一套题集后，看那套题集上打开的比例；只用成对题训练；跨题集留一。你认为哪些是必须的，还缺什么？
4. **加了开关之后，主句会不会被审稿人读成"功劳来自题型识别"？** 对手也应当拿到同一个开关（带开关的只拧 E、带开关的只用 C）——我们现在是这样比的，够不够？
5. **与 CAST 的关系怎么写**才准确、不夸大？
6. 程序里你看到的会改变结果的问题（训练题与读数题的划分、分组交叉验证、读内部状态的提示是否与生成时一致）。
