## 1. 这一步要回答的问题

1. 用没有用过的训练题训练一个开关，它在留出题上能把"陷阱题"和"普通题"分多准？
2. 在各套题上它打开的比例是多少（TruthfulQA 应当大多打开；事实题、MMLU、GSM8K 应当大多关着）？
3. 用现成的回答与判定模拟"带开关的 N1"（开关开 → 交 N1 的回答；开关关 → 交原模型的回答），各套题上比现在的 N1、只拧 E、只用 C 高多少或低多少？
4. 只在开关打开的题上写 E 时，MMLU 掉多少（用排期 O 第 5 节存下的逐题记录算，主表力度与大一档力度各一遍）？

这一步不生成新的回答，不判分，不花钱；只上卡读取模型内部状态。

## 2. 开关是什么

- **读什么**：普通问法、不写入时，提示最后一个词元处每一层的输出（残差）。每道题单独前向一次（批大小 1，不补齐），提示的写法与各题集生成回答时相同（TruthfulQA、FalseQA、(QA)²、PopQA、TriviaQA 用自由回答的提示；MMLU、GSM8K 用能力评测的提示）。
- **怎么判**：线性分类器（逻辑回归，L2，C = 1，特征先标准化，标准化只用训练题的均值与方差），输出"是陷阱题"的概率；概率大于 0.5 记为打开。门槛不调。
- **用哪一层**：在训练题内部做 5 折交叉验证（按题对分组：同一对的两道题不分到两折），取平均 AUROC 最高的一层，平手取靠前的层。E 层、C 层的读数另外并排报。
- **两种训练数据（都报）**：
  - 甲：只用 FalseQA 官方训练集（1,187 对，一对里一道前提错、一道前提对；本项目从未用过）。这是最干净的对比：同一种出题方式，只差前提对错。
  - 乙：甲，再加别的没用过的训练题。陷阱题：TruthfulQA 的训练与调参部分（96 + 192 道）、(QA)² 那 100 道试验题里前提有问题的 50 道。普通题：(QA)² 试验题里前提没问题的 50 道、PopQA 与 TriviaQA 的训练与调参部分（各 300 + 192 道）、MMLU 那 1,000 道样本之外随机取的 500 道、GSM8K 训练集随机取的 300 道（随机种子 20261126）。
- **只在这些题上读数，训练一概不用**：FalseQA 留出 600 题（官方测试集里抽的 300 对）、(QA)² 留出 470 题、TruthfulQA 测试 523 题、PopQA 与 TriviaQA 的测试题（各 500，两批都读）、MMLU 1,000 道样本、GSM8K 测试题（前 304 道）。程序里要有断言：任何读数用的题不在训练题里。

## 3. 读数（事先写下；都按模型分开，五个模型各一行）

1. **分得准不准**：FalseQA 留出题（前提错 300 / 对 300）与 (QA)² 留出题（有问题 235 / 没问题 235）上的 AUROC、门槛 0.5 时的正确率、两类各被判为陷阱的道数。甲、乙两种训练各报；所选层、E 层、C 层各报。
2. **打开的比例**：TruthfulQA 测试、PopQA、TriviaQA、MMLU、GSM8K 上被判为陷阱的比例。
3. **模拟带开关的 N1**（现成回答与判定；作答数不拉平；区间按题或按题对重抽）：
   - FalseQA 留出 600 题（并分前提错 / 对）：带开关的 N1 减 N1；带开关的 N1 减 只用 C；带开关的 N1 减 带同一开关的只拧 E。系统与上限取 `diag/falseqa_read.py` 的原样。
   - TruthfulQA 测试 523 题：带开关的 N1 减 N1；减 只拧 E；减 原模型。
   - (QA)² 留出 470 题：带开关的 N1 减 N1；减 只拧 E。
   - PopQA、TriviaQA：带开关的只拧 E 减 只拧 E；减 原模型（这两套题上 N1 的上限等于只拧 E）。
   - 先做两项核对：开关全开时净分等于 N1 的净分，全关时等于原模型的净分，逐题相同。
4. **MMLU**：只在开关打开的题上取 E 选的字母、其余取不写入的字母，正确率相对不写入的变化；主表力度与大一档力度各一遍，和"每题都写 E"并排。
5. **有利的标准**（决定要不要做第二步，即在开关打开的题上用更大的 E 重新生成并判分）：甲、乙里至少一种训练，在五个模型里至少三个同时满足——
   - FalseQA 留出题上"带开关的 N1 减 N1"的区间在 0 以上；
   - TruthfulQA 测试题上"带开关的 N1 减 N1"的区间不整个在 0 以下；
   - 大一档力度下"只在开关打开的题上写 E"的 MMLU 变化不低于 −1 点。
   达到 → 报赵磊，请他与博士定是否做第二步；达不到 → 照实报是哪一条没达到、差多少。
6. 这一步的读数有一处要照实写明：TruthfulQA、FalseQA、(QA)² 的留出题都在别的比较里读过，现成判定是看过的；开关本身的训练没有用它们。
