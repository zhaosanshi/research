## 1. 做什么

对每个模型、每道题的两条候选回答各算一个自判分，按自判分挑一条。没有任何阈值、力度或上限要选。

- **自判分**：用现成的 `selfjudge_probe.py`（E45 的代码路径）。把（题目，回答）写成陈述句（`selfjudge_probe.statement`），问模型真 / 假 / 不知道，自判分 = logp(真) − logp(假)。两种条件：
  - 不写入（`baseline`）：五个模型。
  - 写入真假方向（`E_a3`，真假判断那条线上的 DAS 方向，力度 3）：只有 Llama-3.1-8B、Qwen3.5-9B、Qwen3.8-27B 有这个方向。
- **候选**：a_S = S0 的回答；a_N = N1 的回答；a_T = "必须作答 + 如实句"（`conf_E2`，不写入）的回答，只用于纯提示词的对照。
- **系统**（"不同" = 陈述句不同；"作答" = 现成判分口径下算作答）：
  - A1：只有一边作答就用那一条；两边作答且陈述句相同就用它；两边作答且不同，取自判分高的一条，相同时留 S0 的。
  - A1z：A1 之后对交上去的回答用规则 Z（自判分 < 0 就不答；以否定前提开头的回答豁免，沿用现成的 NEG_RE）。
  - 参照：S0；N1；F1；以及各自加规则 Z 的 S0z、N1z（N1 交上去的每条回答都查，即现成的 S3）、F1z。
  - 纯提示词的对照（同样的规则，第二条候选只来自提示词）：TA1 = 把 A1 里的 a_N 换成 a_T；TA1z = TA1 加规则 Z。
- **题**：TruthfulQA 测试集（主表题单）；调参集并列给出（这里不调任何东西，只是第二份样本）。

## 2. 读数

分模型；五个模型合计（不写入）；三个模型合计（写入，并列它们的不写入）。净分与作答数都列；差值带按题配对的 95% 区间。

1. **挑得准不准**：两条候选恰好一对一错的题上，自判分挑中对的那条的比例——不写入、写入各一；"全挑 S0""全挑 N1"并列。
2. A1 − S0；A1 − F1；A1 − N1；A1 − TA1。
3. 两边都查：A1z − S0z；A1z − F1z；A1z − N1z；A1z − TA1z。
4. 写入减不写入：A1、A1z 各一（三个模型）。
5. 相同作答数：两个系统作答数不同时，作答多的一方按它交上去回答的自判分从低到高去掉，直到与另一方相同（分模型做，同一条件的自判分），再比一遍。自然作答数与相同作答数两种都列。

预期（一句）：自判分挑中对的那条高于一半；A1 高于 F1。若 A1 不高于 F1，就照实写"挑"不加分、加分只来自补空题。
