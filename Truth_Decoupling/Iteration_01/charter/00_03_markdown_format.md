# Markdown 格式规则

撰写：赵磊（Opus 5.5 代笔）。起始日期：2026-11-15（北京时间）。

本规则适用于 Iteration_01 内全部 Markdown 文件。

1. **加粗的句末标点放在加粗之外**。中文标点紧接在加粗结束符之前、其后又紧接正文时，GitHub 采用的 CommonMark 规则无法识别加粗，星号会原样显示。
   - 正确：`**顶会论文可视为可信**。顶会指……`
   - 错误：`**顶会论文可视为可信。**顶会指……`
2. 文件提交前，须用 CommonMark 渲染器检查，确认没有原样显示的星号。
