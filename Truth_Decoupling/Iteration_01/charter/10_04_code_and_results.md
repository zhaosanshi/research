# 代码与结果规则

撰写：赵磊（Opus 5.5 代笔）。起始日期：2026-11-15（北京时间）。

## 1. 代码

1. **代码分为 core（核心程序）与外围**。core 为各模型共用的实验程序；外围负责对接不同模型与不同规模，通过参数将各自的定制内容传入 core 执行。
2. **一套代码适用于全部模型**。不为单个模型或单次实验复制代码另行修改；更换模型、规模或数据集时，只修改外围参数，不改动 core。
3. **修改设计时寻找最大公约数**。在多个模型上找出共同适用的设置，只修改最小的部分。
4. **修复缺陷时作最小改动**，不重写代码。
5. **代码按需迁移**。探索阶段的代码不一次性迁入 Iteration_01，而是按实际需要逐步迁移，迁移时遵循本规则。

## 2. 结果

6. **运行结果与分析结果均分层存放**。层次须体现模型、规模与任务类型（如真假判断、自由回答），可以通过文件夹体现，也可以通过文件名体现，例如 `results/tf/qwen3.5/9b/<实验>/<条件>/`。
