# 文献阅读规则

撰写：赵磊（Opus 5.5 代笔）。起始日期：2026-11-15（北京时间）。

## 1. 阅读

1. 文献必须下载全文阅读，不得仅凭检索结果中的题目和摘要推断论文内容。

## 2. 可信度

2. **顶会论文可视为可信**。顶会指 10_01 所列会议。下载时，第一优先级为会议官方网站的正式版本。
3. **arXiv 论文须核查作者或机构是否权威、论文是否严谨**。部分论文仅为抢先占据选题而发布，缺乏实质内容，不应因其存在而放弃或改变研究判断。此类论文仅供参考。
4. **发表年份**：除会议等级外，还须考虑发表年份。同一等级内，近两年（当年与上一年）发表的论文优先，具体体现为：
   - 检索与阅读按年份由近及远进行，例如依次为 2026、2025、2024 年；
   - 判断本研究的新意、确定实验方法与评测方式时，以近两年的顶会论文为主要依据，较早的论文作为背景参考。

## 3. 命名

5. 论文下载后按可信等级命名，格式为"等级标签__arXiv 编号或年份_简称_会议与年份.pdf"，例如 `A1_TOP_FULL_TRUSTED__2510.01782_refusal_index_ICLR2026.pdf`。等级标签如下：

| 等级标签 | 含义 |
|---|---|
| A0_TOP_SPOTLIGHT_FULL_TRUSTED | 顶会口头报告或亮点论文 |
| A1_TOP_FULL_TRUSTED | 顶会主会论文 |
| A2_PEER_FULL_TRUSTED | 其他经同行评审的会议或期刊论文 |
| B_AUTH_PREPRINT_FULL_STRONG | 作者或机构权威、论证严谨的预印本 |
| C_PREPRINT_FULL_LIMITED | 一般预印本，参考价值有限 |
| D_PREPRINT_FULL_OCCUPANCY | 抢先占据选题、缺乏实质内容的预印本，仅供参考 |
| U_FULL_UNVERIFIED | 等级尚未核实 |
