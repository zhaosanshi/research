## 1. 我们的建议

1. **接受老师的结构**：主表 Llama + Qwen；Gemma、Mistral 进附录；2×2 降为验证（用全扫描散点图）；主实验是两任务上的方法对比表。
2. **历史备选主句（尚未批准）**，保留老师“相同作答率”的口径。第 20 轮已纠正“组合优势只是 2×2 推论”的说法，下面这句同样只能当待验证假设：

   > 在相同作答率下比较，现有真实性 steering 的提升大部分来自多拒答；拆出来的 E 是唯一在相同作答率下仍保留提升的方向，而 C 就是那个"门槛"旋钮。

   这句话是假设，必须先用实验验证（见下面方案 A、B）；如果不成立，就回到老师原句或 GPT 建议的主线（"DAS 目标组合改善真假判别，并显示与自报承诺的近似选择性"）。
3. **方向估计保留新 DAS**，均值差作完整对照；补三种稳健性对照。
4. **真实问答的历史备选做法**：“推 C 控制作答率 + 用 E 核验自己的答案再决定答不答”。这不替代用户要求继续寻找自由生成 DAS 的任务；旧实现未显示稳定收益应如实保留，新实现需单独验证。

## 2. 可选实验（按推荐顺序）

耗时为估计：真假判断扫描每个条件约 20–40 秒 / 模型 / 卡；v1 问答全链（代理、真实生成、裁判、冻结、测试）三个模型各占一卡并行，墙钟约 1.7 小时。服务器共 4 卡。

| 方案 | 做什么 | 代价 | 回答的问题 | 风险 |
|---|---|---|---|---|
| **A**（先做） | 真假判断任务上做"相同作答率"比较：E + C 联合扫描，对照只推 C、只推 E + 门槛（第一遍 Yes / No 边际与第二遍真假边际两种门槛）、不动模型只设门槛、提示词（自信 / 谨慎系统提示）、均值差方向 + C；画风险–覆盖率曲线，报曲线下面积、50 / 70 / 90% 作答率处的准确率、拒答指数，配对自举区间 | 约半天代码 + 3 GPU 小时 | 组合是否只是"E + 门槛"；提示词是否就够 | 低；预期组合约等于 E + 门槛，这本身就是"C 是门槛旋钮"的证据 |

| **B**（关键） | 真实问答 + 真实弃答，相同作答率比较：只推 C、C + E 核验、只设门槛（模型自评 P(True)、答案词元概率、给弃答词元加 logit 偏置）、提示词、ITI（官方协议）、CAA、TruthX、KAPPA、LITO / CASAL 式组合（即入口页的统一清单）；DeepSeek 语义裁判 | 2–4 天（基线实现占大头）；生成约 1–1.5 万条 + 裁判费用 | 老师主句能否在真实问答上成立；ITI 等的提升是否主要来自多拒答 | 中：E 在自由作答上为零，组合可能只等于只推 C；基线复现可能偏离原论文 |
