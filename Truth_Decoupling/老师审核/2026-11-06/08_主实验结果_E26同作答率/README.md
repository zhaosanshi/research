# 08 老师建议的主实验：结果（2026-11-06 晚补）

老师 11-05 提出的主实验（"在相同作答率下，组合是不是比任何一个单独方向都好"）已由 GPT 实现（第 18 轮，E26），Claude 审核后于 11-06 18:23 正式运行，Llama-3.1-8B 与 Qwen3-8B 两个模型、真假判断与自由问答两个任务都已跑完。完整报告：[`claude_gpt_review/from_claude/14_E26同作答率主实验_E27发布版重跑_结果.md`](../../../claude_gpt_review/from_claude/14_E26同作答率主实验_E27发布版重跑_结果.md)；审核与开跑前声明的分析计划：[`13`](../../../claude_gpt_review/from_claude/13_审核GPT第18轮_E26同作答率_E27生成适配.md)；原始产物：[`results/03_E26同作答率_E27生成适配/`](../../../claude_gpt_review/from_claude/results/03_E26同作答率_E27生成适配/)。

## 实验怎么做的

- 固定题集上，每种方法先生成候选答案，再按分数只交付 25% / 50% / 75% 的实质回答，其余一律交付"I don't know."；模型自己的拒答不能填额，回答不够就标"不可行"。比较的是交付集里答对多少。
- 方法：不加干预的原模型（按承诺分、简单置信、随机三种挑题方式）；只推 E、只推 C、E+C（DAS 与均值差两种方向）；以及 E、C 配简单置信挑题。"承诺分"是模型对"你知道 / 能答这题吗"首词 Yes 减 No 的分数（即老师建议的 C 定义）；"简单置信"是真假判断里真假对数概率差的绝对值、问答里答案的平均对数概率。
- 每档作答率下的配置在 192 道调参题上独立选，529 道测试题上报告；分析计划（主对比 = DAS 的 E+C 对 E，12 格 Holm 校正）在任何结果出来之前写定。
- 限制：TruthfulQA 共 817 题已全部用过，测试集在前几轮看过，这是"已看过的测试集上的比较"，确认需要第二个数据集。

## 结果

| 问题 | 结果 | 对论文 |
|---|---|---|
| 相同作答率下，E+C 是否胜过只推 E（主对比） | **否。** 12 格差值 −3 到 +9 题，Holm 校正后 0 格显著 | 对老师原句：消极 |
| 只推 C 是否有用 | **没有。** 对原模型 12 格全部约等于 0。C 把承诺分整体平移 0.6–1.0 个标准差，但几乎不改题目排序（秩相关 0.96–0.998）——C 就是门槛旋钮 | 对"C 是门槛"的解释：积极 |
| 推 E 是否有用 | **真假判断上有用**：推 E 对原模型（都按承诺分挑题）50% / 75% 两模型都显著（+26 到 +40 题）；推 E + 简单置信对原模型 + 简单置信，Llama 显著（+40 / +44），Qwen 未过校正。**自由问答上没用** | 真假判断：积极；问答：消极 |
| 承诺分适不适合挑题 | **很差。** E+C 在真假判断 5 个格子里显著输给简单置信挑题；原模型按承诺分挑题，75% 档比随机还差（Qwen −49，校正后显著） | 新发现 |
| C 能否调动实际作答 | **很弱。** 同一 C 把"能答"的自报比例从 0.33 推到 0.73，实际实质回答只变 ±4–6 个百分点 | 自报与行为脱钩 |
| GPT 第 18 轮的生成适配（E27）正结果 | 发布版代码复现了数字，但扣除乱码与未结束回答后脆弱、与 DAS 无关；Llama 上零效果；算子即已发表的秩 1 LoReFT | 对 DAS 作为方法：消极 |

## 对下一步的含义（请老师判断）

1. 老师的主句按原样不成立。数据支持的说法是：**在相同作答率下，只有判别方向 E 保留提升（真假判断任务），承诺方向 C 只是门槛，挑题应该用置信度而不是自报的"知道 / 不知道"。**
2. 改写主张中"现有真实性 steering（ITI、CAA、TruthX）的提升多来自多拒答"那一半还没测——这需要在 TruthfulQA 自由生成上做同作答率重评。
3. 自由问答上 E、C、E+C 都没用；若论文需要真实问答的正结果，要么换方法，要么换数据集。
4. 需要第二个数据集（建议 BBQ）做确认。
