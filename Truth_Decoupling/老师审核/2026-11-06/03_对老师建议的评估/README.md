## 2. 正对角与反对角

2×2 的行是"推哪个方向"，列是"看哪个指标"：

| | 判别力（J、AUROC） | 作答率 |
|---|---|---|
| 推 E | **应该大**（正对角） | 应该接近 0（反对角） |
| 推 C | 应该接近 0（反对角） | **应该大**（正对角） |

两半缺一不可：只有正对角，说明两个方向什么都动、没分开；只有反对角，两个方向什么都不动也能满足。两半都成立才叫解耦。

- **正对角：成立，而且不是挑出来的。** 不经任何规则的全扫描里，E 在 204 个条件里 200 个提高 J、202 个提高 AUROC；C 在规则所选的格子里把自报作答率移动 24–75 个百分点。
- **反对角：近似成立。** E 不碰自报作答率在 Qwen、Gemma 上有统计支持（95% 区间落在 ±0.03 内），Llama 区间上界超出一题；C 不碰判别只有点估计支持，三格有显著的小幅判别损伤；C 还会系统地挪真假判断的偏置（协议所用六格区间都不含 0，四格越过 ±0.05）。C 推得狠时常见"J 动、AUROC 不动"，符合"挪门槛"的解释（推断）。

## 3. “组合胜过单一方向”需要怎样验证

**第 20 轮更正**：下面 1–2 条是基于“C 只有单调门槛作用”的条件性预测，不能当成已经证明的事实。只有 C 不改候选、且对分数施加同一严格递增变换时，固定配额集合才必然不变。当前秩相关接近 1 不等于这些前提成立。E 与 C 各自选参还可能选择不同的 E，因此额外需要固定 E 的消融。也不能仅由旧 2×2 推出组合必然胜过 C。

全扫描显示 C 推动作答率时 AUROC 几乎不动、偏置会动，这符合 **"C 主要在挪'答不答'的门槛"** 的解释（推断，没有直接测过）。如果是这样，老师那句话在审稿人眼里会变成：

1. **组合对只推 C：需要实测。** E 单独提高判别力，不保证叠加 C 后仍保留该收益；两种写入还可能相互影响。
2. **组合对“只推 E，再设门槛”：必须保留的强对照。** 当前结果符合门槛解释，但尚未证明严格等效。Dr. No 的部分视觉问答结果显示简单偏置或概率门槛很强，支持加入对照；不能用另一个任务的结果证明本项目任何 C 都等价于门槛。
3. **除了单方向，必须与强基线比**：提示词、不动模型只按模型自己的把握设门槛，以及直接相关的已有方法。先完成老师明确要求的原模型、E、C、E+C 与简单筛题，不把整张文献清单当成本轮开始有效验证的前置条件。
4. **"任何一个单独方向"范围太宽。** 审稿人会拿自己熟悉的方法来打，必须明确列出比哪几个。
5. **真实问答那一半大概率不成立。** E 在自由作答上为零，组合约等于只推 C；能救的只有"不推 E、改用 E 核验自己的答案再决定答不答"，那已经是另一种方法，要在论文里讲清楚。目前这种用法的 DAS 版只有 Llama 显著（Gemma 上均值差版显著，+0.050）。
6. **"作答率"要换成真实弃答。** 真假判断任务里的作答率是单独问一遍"你知道吗"的自报，审稿人会质疑它不是真正的弃答；真实问答的那一半正好能回答这个质疑，所以它必须成立。

**我们建议的改写**（保留老师"相同作答率"的口径，把弱点变成要证明的东西）：

> 在相同作答率下比较，现有真实性 steering 的提升大部分来自多拒答；拆出来的 E 是唯一在相同作答率下仍保留提升的方向，而 C 就是那个"门槛"旋钮，这解释了原因。

已有迹象支持：ITI 原文附录里，很多"翻成真话"的例子其实是改口说"我不评论"，Vicuna 上真实率 88.6 而"真且有信息量"只有 74.0；TruthfulQA 本身把"我不评论"算作真话；TruthX 的提示里自带"不完全确定就说我不评论"。**但这是假设，尚未实测**，实验计划见 `07`。

## 4. 两条主线都成立的话，够不够顶会

我们自己和一个独立子代理（只给它主张和证据、不给我们的看法）分别判断，结论一致：

| 情形 | 现实目标 |
|---|---|
| 两个任务都成立，且赢过统一基线清单（门槛、提示词、ITI、CAA、TruthX、KAPPA、LITO / CASAL 等） | ACL / EMNLP 主会；NeurIPS / ICLR 还需更大模型（≥ 27B）、更多模型家族和有"知道却说错"差距的数据集，以及带置信区间的风险–覆盖率曲线 |
| 只有真假判断成立，真实问答不成立（按现有数据可能性最大） | Findings 或 workshop |

审稿人最可能的反对意见：

1. C 若只挪门槛，"组合在相同作答率下更好"就是 2×2 的推论，除非赢过门槛与 logit 偏置。
2. DAS 用金标签训练，会不会只是把一个分类器写进了模型？需要补打乱标签训练的 DAS、同样大小的随机方向、跨数据集测试三种对照。
3. 相对已有的"信念 / 行为分离"工作（拒答指数 ICLR 2026、承诺-弃答电路 NeurIPS 2026（作者自述接收）、KAPPA ICML 2026、Kumaran 的决策 / 正确性正交方向、LITO、YOPO、CASAL）显得增量。
4. 真假判断的作答率是自报，不是真弃答。
5. 数据集只有 TruthfulQA（真假陈述也由它改写），主表只有 8B 模型。
