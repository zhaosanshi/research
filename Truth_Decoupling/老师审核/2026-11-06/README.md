## 一、一页纸现状

论文主张：模型残差流里有两个低秩方向——**E（证据方向）**放大后只提高真假判别力、不改作答率；**C（承诺方向）**推动后只改作答率、不改判别力（"2×2"）。

| 问题 | 现状 | 对论文 |
|---|---|---|
| 真假判断任务里，放大 E 能否只提判别、不动作答率 | **基本能。** 三个模型的判别力都显著上升，自报作答率变化很小（Qwen、Gemma 的区间落在 ±0.03 内，Llama 上界超出一题）。新目标训练的 DAS 在 Llama、Qwen 上 J 与 AUROC 都显著胜过均值差；Gemma 与均值差打平 | 积极 |
| 推 C 能否只改作答率、不动判别 | **近似能。** 作答率大幅移动（24–75 个百分点），判别点估计变化很小；但这里的作答率是单独一遍"你知道答案吗"的自报；C 有三格伴随小幅判别损伤，J 的区间没有一格完全落在 ±0.02 内；C 还会挪真假判断的偏置（六格区间都不含 0，四格越过 ±0.05：推向作答更爱判"真"，推向弃答更少判"真"） | 积极，但只能写"近似选择性" |
| 两个方向是否"各管各"（2×2） | **任务内近似选择性。** 不经任何挑选的全扫描：E 在 204 个条件里 200 个提 J、202 个提 AUROC；C 明显改作答率时 94–100% 的条件 AUROC 不动 | 积极 |
| 自由问答里 E 能否提高答对率 | **不能。** 两版问答 DAS × 三模型，测试集答对数净变化在 −4 到 +3 题之间（共 523 题），没有稳定收益 | 消极 |
| DAS 方向的读出用法（认错题、选择题、核验后弃答） | 有正结果，但多数只胜模型自评，不胜均值差或有监督探针 | 小幅积极 |
| 老师 11-05 的新主张：相同作答率下，E+C 组合胜过任何单一方向 | **还没有任何数据**；文献里这个位置基本空着：LITO（ACL 2024 Findings）做过不对齐作答率的组合，YOPO（预印本）在固定 25% 弃答比例下做过近似等覆盖率的组合（只在域内胜） | 未知 |

**主结果数字**（测试集 529 对）：

| 模型 | 放大 E：ΔJ / ΔAUROC / Δ自报作答率 | C 推向弃答：Δ作答率 / ΔJ | C 推向作答：Δ作答率 / ΔJ | 新 DAS − 均值差：J / AUROC |
|---|---|---|---|---|
| Llama-3.1-8B | **+0.091 / +0.048** / +0.006 | −0.597 / −0.017 | +0.248 / +0.013 | **+0.036 / +0.030** |
| Qwen3-8B | **+0.070 / +0.031** / +0.006 | −0.482 / −0.013 | +0.444 / −0.017 | **+0.038 / +0.022** |
| Gemma-3-4B | **+0.034 / +0.032** / −0.008 | −0.747 / +0.004 | +0.253 / +0.004 | −0.021 / +0.003（打平） |

（加粗 = 主效应的配对自举 95% 区间不含 0。C 列的作答率变化区间全部不含 0；C 列的 ΔJ 中只有 Llama 推向弃答那格（−0.017 [−0.030, −0.004]）区间不含 0，是小幅损伤；区间见 `02` 第 3 节。C 列为各模型按预定协议所用的 C：Llama、Gemma 用提示对比 C，Qwen 用自报 C。）

## 二、请老师判断的问题

每一项都给了选项和我们的推荐，理由在对应目录。

1. **论文主线选哪一句。**
   - (a) 老师 11-05：在相同作答率下，组合是否比任何单独方向都好。
   - (b) GPT 第 17 轮：DAS 目标组合改善真假判别，并显示与自报承诺的近似选择性。
   - (c) **我们推荐**：在相同作答率下比较，现有真实性 steering 的提升大部分来自多拒答；拆出来的 E 是唯一在相同作答率下还保留提升的方向，C 就是那个门槛旋钮。它保留了老师"相同作答率"的口径，又避开"组合胜单方向只是 2×2 的推论"这个审稿硬伤（见 `03` 第 3 节）。这是假设，需实测。
2. **方向估计**：保留新 DAS（推荐，主表两个模型显著胜均值差），还是按老师建议换成均值差 + 层间正交。均值差无论如何保留为完整对照。
3. **真实问答那一半怎么做**：(a) 继续找让 E 改变自由生成的方法；(b) **推荐**改为"C 控制作答率 + E 核验自己的答案后弃答"，与基线比风险–覆盖率曲线；(c) 写成适用边界。
4. **第二个数据集**：推荐 BBQ（题里自带"无法确定"选项；KAPPA 报告 Llama 在 BBQ-Age 上内部知道的比说出来的多 29.3 个点，BBQ-Religion 上 10.6 个点）。早先一次旧协议检查显示，知识类数据集（FEVER、CounterFact、GoT）上探针并不比模型输出更准，E 没有可提的空间。
5. **基线清单与对齐口径**（全材料统一用这一版）：只推 C；只推 E + 门槛；均值差方向（+ C）；不动模型只设门槛（模型自评 P(True)、答案词元概率、给弃答词元加 logit 偏置）；提示词（自信 / 谨慎系统提示）；ITI；CAA；TruthX；KAPPA；LITO / CASAL 式组合。按风险–覆盖率曲线与固定作答率下的准确率比较。请老师增删。
6. **模型**：主表 Llama + Qwen，Gemma、Mistral 进附录（同意老师）。

## 四、术语

| 术语 | 含义 |
|---|---|
| E（证据方向） | 放大后应只提高真假判别力的方向 |
| C（承诺方向） | 推动后应只改变"答不答"的方向 |
| TF 协议 | 真假判断任务：两遍前向——第一遍问"你知道这题的答案吗"读 Yes / No 得自报作答率；第二遍强制判断陈述真假得 J、AUROC、偏置 B。E、C 两遍都施加 |
| J | 判别指数：真陈述的判真率减假陈述的判真率 |
| AUROC | 排序判别面积：真陈述的"真"分数排在假陈述前面的概率，不依赖门槛 |
| B（偏置） | 判"真"的比例 |
| 作答率（自报） | TF 协议第一遍里模型说"知道"的比例；**不是**自由回答里的真实弃答率 |
| DAS | 分布式对齐搜索：交换模型内部表示的一小部分，训练能改变判断的方向。"新 DAS"指 11-05 改用的目标：源陈述的金标签、双向交叉熵、提示末位一步 |
| 均值差 | 真陈述激活均值减假陈述激活均值（96 对配对数据，等于配对差的均值） |
| 2×2 | 行 = 推 E / 推 C，列 = 判别力 / 作答率。**正对角**（E 动判别、C 动作答率）应大，**反对角**（E 动作答率、C 动判别）应接近 0；两半都成立才叫解耦 |
| 近似选择性 | 正对角显著、反对角点估计很小，但没有统计上证明反对角为 0 |
| 调参 / 测试 | 层、强度一律在 192 对调参数据上按事先规则选，529 对测试数据上报告 |
| 配对自举 | 同一批题重采样 2000 次比较两种条件的差值 |
| 风险–覆盖率曲线 | 作答率从低到高变化时，已作答题里答错的比例怎么变；比较"相同作答率"的标准做法 |
