## 一句话核心主张
用逻辑回归探针（logistic regression probe · 一个线性分类器从激活里读出标签）在提示最后一个 token 处读出模型的"solvability belief"（可解性信念 · 模型开口之前对"这题我能不能做出来"的内部判断）方向：70–75% 准确、非线性探针不更好、CKA 显示"能解/不能解"两态几何上截然分开；但沿这条方向在探针最佳层做 steering，能把探针判定从 0.04 翻到 0.97（反向亦然），却对 Math-Hard / Knights&Knaves / OpenR1 代码 / QwQ 规划四个任务的最终正确率零影响（p=0.91–0.99）；作者用"评估流形高维（参与率 PR≈34–44）vs 执行流形低维（PR≈16–18）、在 CoT 首 token 处发生坍缩"解释这一"信心 ≠ 能力"的因果惰性。

## 方法细节
- **数据**：3000 道数学推理题按模型零样本是否做对标为 solved/unsolved；三道过滤——剔除 true/false、选择题等格式提示；按推理域/子主题分层抽样；长度匹配（均值 83.22 vs 83.06 token）→ 846 题。评测扩展到 GSM8K/Math-Hard/Open-R1 Math、Knights and Knaves、Open R1 Verifiable Coding、qwq-32b-planning。
- **探针位置**：残差流在**最后输入 token** 处（Table 1：LR 74.4%，优于 10% 处 54.2%、50% 处 65.1%、EOS 67.9%）；逐层扫描：峰在中后层 70–75%（Fig 1，三模型）。
- **线性性论证**：SVC/XGBoost/MLP 均不显著优于 LR → "信号线性但嵌在高维噪声里"。
- **几何**：CKA（Centered Kernel Alignment · 两组表示相似度的核方法）solved-vs-solved、unsolved-vs-unsolved 对角线高，交叉近零；t-SNE/UMAP 两簇分开。
- **干预**：d_solv = LR 探针权重向量；h' = h + α·d_solv，施加于**探针准确率最高层**（附录 A.3.2 明确以此为准则）、最后输入 token；α 的取值与是否扫描未报告。度量：① 同一探针的预测概率（"belief flip"）；② 任务准确率；p 值为与基线比较。
- **几何解释**：四组激活（solved/unsolved 信念态；成功/失败 CoT 执行态）做 PCA：信念需 >120 个主成分解释 90% 方差，执行只需几十个；PR=(Σλ)²/Σλ²：信念 33.6±2.9 / 44.4±2.5，执行 16.0±0.6 / 17.9±0.9（100 次 bootstrap）。
- **轨迹投影**：定义评估基与执行基，逐 token 算 ‖proj_B(h)‖²/‖h‖²，提示阶段贴评估基、CoT 首 token 处瞬间切到执行基（Fig 4 右）。
- **附录 B.1**：提示处理到 20–40% 时中层激活就已偏向最终信念质心（"belief crystallization point"）。

## 与 老师方案的关系
- 重叠点：
  1. "评估者 / 执行者两系统"与我们 "证据 E / 承诺 C 两方向"同构：他们的 solvability belief 近似我们的承诺/信心侧，competence 近似证据/正确性侧；他们证明推信念不改正确率，与我们"C 方向应改弃答行为而不改知识"的预期一致。
  2. 都用线性探针、都用 LR 权重当方向、都做正反两向干预。
- 冲突点（他们的结论会不会打我们的某条主张）：
  1. 摘要级结论"沿信念轴的线性推动是因果惰性的"会被审稿人泛化为"信心/承诺方向 steering 没用"，直接压 C3。但他们**只量了任务准确率，从未量弃答率、口头置信度或回答意愿**——而那才是 C 方向的目标变量。我们必须把弃答率作为主指标并引用此文说明口径差异。
  2. 他们的"在探针最佳层干预"是 ReadBest≠SteerBest（2609.22135）和 LAP（2604.15557）都证明会失效的做法；其零效果很可能部分是选层错误 + 单 token 位置 + 未扫 α 的伴生物。这反过来是 **C2 的现成反面教材**：按读层选写层 → 干预惰性。
  3. 若他们是对的（信念真的不影响执行），则我们门控里"未知时推 C 让模型弃答"仍成立，但"已知时推 C 让模型敢答"是否提升正确率就不该被承诺——C 只该改承诺，不该改对错。有利于把 C1/C3 的主张收窄到行为层。
- 可借用点（方法、数据、指标、对照）：
  1. **校准集长度匹配 + 主题分层**协议：我们 32 对校准样本应做同样控制并报告 t 检验，否则 dact/sep 可能学到长度。
  2. **线性 vs 非线性探针对比**作为 E/C 线性假设的论证模板。
  3. **参与率 PR** 作为 E、C 子空间维度诊断——若 C（承诺）子空间低维而 E 高维，可解释为何 rank-1 对 C 够用、对 E 不够。
  4. **反向干预对照**与"探针翻转"作操纵检查，但要用**留出探针**而非定义方向的那个。
  5. 附录 B.1 的"提示处理过程中信念结晶点"分析可移植到"承诺何时形成"。
- 明确差别（我们还能声称什么是新的）：
  1. 他们没测弃答/承诺行为；我们 C3 正是以弃答率、三分评测为目标。
  2. 他们无任何选层方法、读写同层；我们 LA-Score + Δ=|R*−W*|。
  3. 推理题（数学/代码/逻辑）vs 事实真实性；单一信念方向 vs E/C 两方向正交分解。
  4. 若我们能展示"在 W* 推 C 改变弃答率而正确率≈不变"，就把他们的"惰性"重新解释为"干净解耦"——同一现象、相反叙事，且我们的更可控。

## 对四条主张的威胁等级
| 主张 | 威胁 | 理由 |
|---|---|---|
| C1 解耦 | 低 | 概念上支持"信心与能力可分"，但其单方向框架可被用来说"只需一条信念轴"。 |
| C2 选层 | 低 | 无选层方法；其"在探针最佳层干预→零效果"反而是我们 R*≠W* 的例证，可引用。 |
| C3 门控 | 中 | "推信念方向改变不了结果"会被拿来质疑 C 方向干预的价值；我们必须以弃答率而非准确率作为 C 的成功指标并正面回应。 |
| C4 泛化 | 低 | 4B–24B 推理任务，与我们域不同。 |
