# 2609.32964 · The Commit-Abstain Circuit: Why Language Models Hallucinate Instead of Abstaining

- 权威度与严谨度判断：[顶会已发表（作者自述接收，待 proceedings 核实）] 理由：10 个指令模型（3B–14B，5 家族）+ 27B/35B 两个外推；3 个 in-distribution 数据集各 1000 条（50/50 切分）+ 2 个 OOD 数据集；10 seeds；20 组尺寸匹配随机消融对照；7 个基线（HaMI、HaloScope、Semantic Entropy、INSIDE、MERA、Multi-LLM、Non-CAC Random MLP）；弃答 token 集经 AMT 双标注验证（κ=0.96）；30 配置 Wilcoxon 符号秩检验；对 A 集 4 种构造做敏感性分析。缺点：∆(x) 是 logit 级代理量；干预标签靠正则匹配；无人工评估生成质量。

## 一句话核心主张
把幻觉重新定义为 unsupported commitment（无依据的承诺 · 模型内部已有"这题答不了"的信号却还是硬答），用 causal head gating（因果头门控 · 给每个注意力头/MLP 装一个可学的开关，看谁关了会改变决策）在十个模型里都找到一个稀疏的 Commit-Abstain Circuit（CAC，承诺-弃答电路，中位数仅占 5.2% 组件），发现"早层累积承诺、晚层弃答修正不足"（accumulate-yet-undercorrect）的统一模式，并用 CAC 组件级特征训练一个轻量 MLP 把弃答决策准确率提高 12.2 点、false abstention（错误弃答 · 本来能答却说不知道）降 2.5×。

## 方法细节
- **决策量（是行为读数，不是残差流方向）**：commit-abstain margin（承诺-弃答边际）∆(x) = z_{c*}(x) − z_{a*}(x)：在最后一个输入 token 位置、生成任何 token 之前，词表里"承诺集 C"的最高 logit 减去"弃答集 A"的最高 logit。A 为 17 个开启弃答语的首 token（I / Unfortunately / Insufficient / Unanswerable / Unknown / Cannot / Unable / Ambiguous …），由 10 模型在 1000 条独立 unanswerable 题上的首 token 汇集、去重、AMT 两人验证得到；C = 词表其余全部。∆≥0 判为 commit。与贪心完整生成的行为标签一致率 97.6%（95.8–98.7%），2.4% 分歧主要是"先给答案再转折"的 pivot 句。
- **方向**：d(x) = u_{c*} − u_{a*}（两个 token 的 unembedding（反嵌入 · 把残差流映射成词表 logit 的矩阵行）向量之差，逐输入变化）。∆ 按 direct logit attribution（直接 logit 归因 · 利用残差流可加性，把 ∆ 拆成每个头/MLP 贡献 v_k(x) = d(x)ᵀc_k(x) 之和）分解。**全文没有估计任何残差流里的"承诺方向"或"证据方向"，也没有 system prompt 对比。**
- **电路定位（扩展 Nam et al., NeurIPS 2025 的 CHG）**：对每个注意力头（缩放拼接后的 value）和 MLP 子层（缩放输出）装 sigmoid 门 G=σ(g)；任务损失 L_task = −(1/B)Σ(2y−1)·∆(x|G)，即可答题推高 ∆、不可答题压低 ∆；c*、a* 用无门控模型预计算并固定。三阶段：λ=0 任务优化得 Ĝ → 保留压力（λ>0，门→1）得 G+ → 移除压力（λ<0，门→0）得 G−。C-component（承诺促进）：G− > 0.5（顶住移除压力仍开）；A-component（弃答促进）：G+ < 0.5（顶住保留压力仍关）。门梯度 ∝ −(E_{y=1}[v_k] − E_{y=0}[v_k])，故分类反映的是"在可答 vs 不可答上的贡献差"而不是 v_k 的绝对符号（App. D.1 给出反例：一个在两类上都为正的组件可被判为 A）。预筛 top-K 候选（72–87 个），Adam，100 步，B=16，λ 自适应 = E|∆|/(BK)，10 seeds，入选需 ≥8/10 seed 角色一致。
- **功能干预**：(a) 按门控分数渐进消融 top-k 组件，对照 20 组尺寸匹配的随机非 CAC 消融；(b) 放大：组件输出 h → αh（残差相加前），α∈{1,1.5,2,2.5,3,10,100,1000}；用 RMSNorm 在大 α 下的极限解释"极端放大=只看该组件方向的内在下游效应"。
- **CAC-Informed 策略**：每个 CAC 组件的 v_k(x) + 统计量（mean/std/min/max、A 组件和、C 组件和）→ 16–64 维 → MLP(32→128→64→32→1)，BN+ReLU+dropout 0.15，BCE，AdamW lr 1e-3，早停；P(answerable) 低于验证集校准阈值则弃答。另有逻辑回归变体。
- **模型**：Qwen-3.5 4B/9B，Gemma-3 4B/12B，Llama-3.2 3B / Llama-3.1 8B，Ministral-3 3B/14B，Phi-4-mini 4B / Phi-4 14B；OOD 外推 Gemma-3 27B、Qwen-3.5 35B。贪心解码 max 256 token，单卡 H100。
- **数据**：KUQ（参数化、世界上没有确定答案）、SQuAD 2.0（上下文不支持）、MuSiQue（多跳去掉一篇支撑文档），各 1000，50/50 train/test；OOD：HotpotQA（支撑段落换成干扰段落）、SelfAware。

## 与 老师方案的关系
- 重叠点：(1) 叙事内核相同——"知识失败 vs 控制失败"（原话 "framing hallucination as a control failure rather than a knowledge failure"），与我们"证据方向 E vs 承诺方向 C"的二分在概念层正面撞车，而且他们已经占住 commit/abstain 这组术语；(2) ∆(x) 的 2×2 读数（TC/TA/FC/FA）≈ 我们问答级"按已知/未知拆分报纠正/损伤/转弃答"的口径；(3) 都在最后输入 token、生成前读信号；(4) 最终也落到一个"按输入判断是否弃答"的学习型策略，功能上就是门控器。
- 冲突点（会不会打我们的主张）：(a) **叙事首创性被抢**：审稿人会问"commit-abstain 的内部机制不是 Nguyen 等已经做了吗"。(b) Finding D：弃答促进组件是"修正信号、独立不足以保证弃答"，放大到 1000× 也压不掉 FC 平台——说明单靠推一条"弃答/承诺方向"在部分样本上注定失效，对我们 C3"未知题打 C 方向促弃答"是直接的实证警告。(c) 但他们**不**区分"承诺"与"证据"两条方向，也不测对错——Limitations 明说不处理"可答题答错"，所以并未证伪 C1。(d) ∆ 是 logit 级行为读数不是残差流方向；没有 2×2 因果矣阵（E→J 不动作答率；C→作答率不动 J）；无 prompt 维度。
- 可借用点：① KUQ / SQuAD 2.0 / MuSiQue / HotpotQA / SelfAware 五个 unanswerable 数据集与 50/50 协议；② 17-token 弃答集 A 及"与完整生成一致率 97.6%"的验证法，可直接拿来做我们问答级"转弃答"检测器；③ 20 组尺寸匹配随机消融 + 30 配置 Wilcoxon 的对照规格；④ "放大 α 平台"分析（RMSNorm 下大 α 等价于只看该方向的内在效应），可用于 C 方向的剂量-响应上限诊断；⑤ Zero-Threshold / CAC-LR / HaMI / HaloScope 作为门控器基线。
- 明确差别（我们还能声称什么是新的）：(1) 两条**残差流方向**（E、C）而非组件电路；(2) 用 system prompt 对比（"不确定就说不知道" vs "必须给确定答案"）估 C 方向——他们完全没碰 prompt 维度；(3) 2×2 因果解耦矩阵——他们只有可答性一轴；(4) 陈述级 Youden's J + 偏置 B 的 SDT 口径；(5) 三分门控（不干预 / 打 E / 打 C）——他们的策略只决定"弃不弃"，不会"纠正"答案；(6) 免训练选层——他们不涉及选层（电路定位本身要优化门）。

## 对四条主张的威胁等级
| 主张 | 威胁 | 理由 |
|---|---|---|
| C1 解耦 | 中 | 叙事（control vs knowledge failure）被抢先占位；但他们没有两条方向、没有对错轴、没有 2×2。相关工作里须把 CAC 定位为"logit 级行为读数 + 组件电路"而非方向解耦 |
| C2 选层 | 低 | 不做选层；唯一相关的是"C 组件早、A 组件晚（80% 深度后）"的深度结构，可作我们 C 方向写层偏后的旁证或反例 |
| C3 门控 | 中 | 已有"内部特征→是否弃答"的学习型门控（MLP/LR），在 30+24 配置上打败 7 个基线；我们的三分门控须与 Zero-Threshold/CAC-LR 式门控直接比较，并回应"A 组件放大无法消除 FC 平台"的警告 |
| C4 泛化 | 低 | 10+2 模型、5 家族、5 数据集，比我们 3 家族 0.6B–8B 覆盖更宽；不打主张但抬高了审稿人期望 |
