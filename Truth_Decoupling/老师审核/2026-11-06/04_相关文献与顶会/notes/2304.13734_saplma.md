# 2304.13734 · The Internal State of an LLM Knows When It's Lying
- 作者 / 机构 / 发表处与年份：Amos Azaria（Ariel University, Israel）、Tom Mitchell（CMU）。**Findings of EMNLP 2023**（pp. 967–976；多篇后续论文引用一致）。arXiv v2 2023-10-17。
- 权威度与严谨度判断：**[顶会已发表（Findings）]**，但按今天的标准严谨度偏低。理由：2 个模型（OPT-6.7b、LLaMA2-7b）；自建 true-false 数据集 6084 句 6 主题；leave-one-topic-out（留一主题 · 训练时不见测试主题）协议是亮点；基线有 BERT 嵌入分类器、3/5-shot 提示、"It is true that X" 句概率；245 条模型自生成句由 3 位人工判定（Kappa 0.957）；探针是**非线性 MLP**（不是方向）；每层只报均值无标准差（说"很小"）；数据集与代码公开。后被 Levinstein & Herrmann（2024）指出探针对否定句不泛化。

## 一句话核心主张
把 LLM 读/生成一句话时某个隐层的激活喂给一个小前馈网络，就能以 71%（OPT-6.7b）–83%（LLaMA2-7b）的平均准确率判断这句话真假，且训练时完全不见测试主题；这比 few-shot 提示（≤56%）和句子概率都强得多——LLM 内部"知道"自己说的是不是真话，而这个信号与句子概率是两回事。

## 方法细节
- **数据（§3）**：true-false dataset 6084 句：Cities 1458、Inventions 876、Chemical Elements 930、Animals 1008、Companies 1200、Scientific Facts 612。前 5 个主题从结构化表（simplemaps、Wikipedia 发明家、PubChem、National Geographic、Forbes 2000）按模板造真句，随机换另一行的属性值造假句；Scientific Facts 由 ChatGPT 生成正反句、两位标注员核对、去掉 48 条有争议的。
- **模型与位置（§4）**：OPT-6.7b 与 LLaMA2-7b，各 32 层、4096 维。取**句末 token** 的隐状态；候选层：最后一层、第 28、24、20、16（中间）层。
- **分类器**：三隐层 MLP（256-128-64，ReLU）+ sigmoid，Adam，5 epoch，不调超参；每个主题训 3 次取均值。**不是线性探针**，没有方向可言。
- **协议**：留一主题——用其他 5 个主题的激活训练，在当前主题上测。
- **基线**：BERT 句嵌入 + 同结构 MLP；OPT-6.7b 3-shot / 5-shot（同主题示例，取 P(true)/P(false) 比值再按均值阈值化——因为模型偏爱输出 "true"）；"It is true that X" vs "It is false that X" 句概率比较。
- **自生成句实验**：给 OPT-6.7b 一条真句让其续写，贪心解码，过滤非事实句，得 245 条；3 人人工判真假（48.6% 真）。分类器在全部 6 主题上训 14 次、在生成句上测。另用 30% 生成句做验证集调阈值。
- **随机标签对照**：打乱标签后训练准确率仅 62.5%（真标签 86.4%）→ 分类器容量不足以死记，必须利用结构。

## 与 老师方案的关系
- 重叠点：
  - 6 主题 true-false 数据集后来成为 Marks & Tegmark、Bürger 等人的标准素材（companies_true_false、element_symb、animal_class、inventors、facts），我们若用这些集就间接用了它。
  - 留一主题协议是检验"方向泛化"的最低标准。
  - "模型偏爱输出 true、要用比值+阈值校正"（§5 基线描述）和"生成句 70% 被判真、要抬阈值"（§5）都是**偏置**现象的早期观察——与我们"C 方向改作答倾向、不改判别"的拆分思想同源。
- 冲突点（他们的结论会不会打我们的某条主张）：无实质冲突。非线性探针、无方向、无干预、无承诺维度。唯一要小心的是：他们证明 MLP 探针在自生成句上 AUC 只有 .66–.76，说明"知识探针 p(x)"在模型自己生成的开放文本上会比在模板句上差很多——C3 门控里的 p(x) 若在模板真假句上训、在开放 QA 上用，要预期掉点。
- 可借用点（方法、数据、指标、对照）：
  - true-false 数据集（开源）作为 E 方向估计/测试的补充主题。
  - 留一主题协议。
  - "随机标签训练准确率"对照：证明探针不是死记——我们的知识探针也应报这个。
  - 自生成句 + 人工标注的评估设定，是检验 E/C 干预在**生成**而非**判别**任务上效果的模板。
  - §8 的"检测确定 vs 不确定比检测真假更有用"可以直接引为门控的动机原句。
- 明确差别（我们还能声称什么是新的）：
  - 他们是非线性检测器，我们是线性方向 + 因果干预。
  - 他们只有真假一维；我们有承诺维度、门控、选层、下游副作用。
  - 他们的"commits（承诺 · 逐 token 生成时一旦说出就回不了头）"是 token 级的路径依赖解释，与我们"愿不愿意下结论"的承诺方向是不同概念——写 related work 时要防止术语混淆。

## 对四条主张的威胁等级
| 主张 | 威胁 | 理由 |
|---|---|---|
| C1 解耦 | 无 | 非线性探针、无方向、无干预。 |
| C2 选层 | 低 | 他们逐层试了 5 个层发现中间层（20/16）最好、且最佳层随模型和数据（模板句 vs 生成句）而变——这是"选层非平凡"的早期证据，支持而非威胁 C2。 |
| C3 门控 | 低 | §8 提出"检测确定 vs 不确定更有用"但没做；自生成句上探针 AUC 仅 .66–.76 提示 p(x) 在开放生成上的天花板。 |
| C4 泛化 | 无 | 2 个 7B 模型、6 主题；与我们的泛化主张无重叠。 |
