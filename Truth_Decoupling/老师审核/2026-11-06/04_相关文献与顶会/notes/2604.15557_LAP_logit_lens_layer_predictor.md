- 权威度与严谨度判断：**[普通预印本]**。优点：5 个 transformer 模型（Gemma-2-2B 主、Llama-3.1-8B、Mistral-7B-v0.3、Qwen2.5-7B、Qwen2.5-1.5B）+ Pythia 160M–6.9B 尺度链 + 2 个非 transformer（Mamba-1.4B、RWKV-1.6B，只做 logit lens）；25 个受控二元概念族（每族 176–294 条提示，类别平衡、模板一致）专门用来消掉任务结构混杂；做了层深混杂控制（偏相关、族内置换检验）；与 oracle（全层暴力扫描 · 每层都真做一遍干预取最好）直接对比；有"训练探针选层"对照；报告附带损伤（KL）与效率；开源代码；算力极小（单卡 3090 Ti，约 4 GPU 小时）。短板：**只做单 token 下一词补全任务**（steering 效果 = 目标 token 概率变化 ΔP，不是行为）；层内相关性 ρ 的 26 个点里 A_lin 与 ΔP 都随深度单调涨，混杂只部分消掉（geography 族偏相关 r=0.372，p=0.067 不显著）；"4/5 命中 oracle"依赖一条**临时规则"排除末层"**（Table 5 不排除时 geography 选 L25、差 3 层、只拿到 oracle 的 0.1%；Table 11 排除后变成 ✓100%，两表互相不一致）；摘要里"选层 ρ=+0.63~+0.92"是把不同实验的数混在一起报的；**完全没碰真实性/诚实性概念**（引言引了 ITI 一句就没了）；refusal 演示用的是"方向可分性"而非 A_lin（Fig 4），其实换了信号；无人工评估。另：检索到一篇 ICML 2026 论文《Steerable but Not Decodable: Function Vectors Operate Beyond the Logit Lens》（arXiv 2604.02608，**未读全文，仅据检索摘要**）报告相反的解离——logit lens 读不出来的任务也能 steer，提示 A_lin 的预测力有边界。

## 一句话核心主张
把 logit lens（logit 透镜 · 把中间层残差直接乘 unembedding 矩阵看它想输出哪个词）的逐层 argmax 准确率 A_lin(ℓ) 当成**免训练、一次前向**的 steering 成功预测器：跨 24 个受控二元概念族、5 个模型，峰值 A_lin 与最大 steering 效果 ΔP 的 Spearman ρ（斯皮尔曼秩相关 · 只看排名是否一致，不看数值线性）为 +0.86~+0.91；族内逐层 ρ 为 +0.63~+0.92；在 Gemma-2-2B 上"取 A_lin 最高层"命中 oracle 层 4/5（拿到 ≥99.6% 的 oracle ΔP）；而一个 5 折逻辑回归探针在 L0–L25 每层都 >93% 准确，按它选层做 steering 却几乎零效果——**"能读出来"与"能写进去"不是一回事**。

## 方法细节
- **对象**：残差流（residual stream · 每层读写的那条共享主干向量）h_ℓ；输出头 logits = W_U · LayerNorm(h_L)，W_U 为 unembedding（反嵌入矩阵 · 把隐状态映射回词表 logit 的矩阵）。因为每层 h_ℓ 都在同一空间，可对任意中间层套这个输出头。
- **A_lin(ℓ)**（式 1）：对概念族 C={(x_i,t_i)}（提示 + 唯一正确的单 token 答案），A_lin(ℓ) = 用 logit lens 在第 ℓ 层 argmax 恰好等于 t_i 的样本比例。**无需训练**。沿用最终层 LayerNorm，继承 Belrose 等人指出的层范数失配问题（§5 用 tuned lens 对比过：raw lens 反而是更好的选层预测器，因为 diff-of-means steering 读出用的就是 W_U∘LayerNorm）。
- **探针间隙 Δ(ℓ)=A_mlp(ℓ)−A_lin(ℓ)**：A_mlp 来自残差 MLP 探针 ĥ=h+f_θ(h)（d→512→d，GELU，dropout 0.1，80% 样本训练，约 30 s/层），再过同一 unembedding；Δ 大 = 信息在但非线性编码。
- **扰动敏感度 λ(ℓ)**（式 3）：往 h_ℓ 加 α=0.01‖h_ℓ‖ 的随机单位向量，看后续前向把扰动放大多少（K=10）；λ 高 = 表示不稳定、steering 后果不可预期。
- **LAP(ℓ) = (A_lin, Δ, λ)**，A_lin 是主预测量，另两项解释失败原因。
- **steering 协议**：d_ℓ = h̄_target − h̄_non-target（difference-of-means · 两组激活均值相减得方向），注入 non-target 提示，量目标 token 概率变化 ΔP；附带损伤 KL_collateral 在 50 条无关提示上算，效率 = ΔP/KL。
- **选层策略（附录 A/J）**：取 A_lin 最高层（**排除末层**，因末层有范数失配异常）；go/no-go：峰值 A_lin<0.05 判不可 steer，>0.1 判可 steer。阈值在 Gemma-2-2B、Qwen-1.5B、Pythia-2.8B 上标定，在 Qwen-7B、Llama-8B 上验证。
- **三体制框架**：① A_mlp 低 → 概念不在残差流里，任何方法都没戏；② A_mlp 高但 A_lin 低（"结晶间隙"）→ 概念在但非线性编码，diff-of-means 失效，SAE 类方法或可；③ A_lin 高 → 与输出投影对齐，diff-of-means 有效。中层启发式（Turner/Templeton）在事实类概念上落在体制 ②：Gemma-2-2B L15 五族 A_mlp>0.7 但 A_lin=0，steering 零效。
- **机制解释（output-alignment principle）**：C(h+d)≈C(h)+C(d)，C=W_U∘LayerNorm；steering 效果由 C(d) 在目标 token 上的权重决定；C(d) 目标 token 排名与 ΔP 相关 ρ=+0.73~+0.84，A_lin 更强（+0.86~+0.90）。
- **数据**：5 个核心族（arithmetic 831、geography 564、sequence 433、word transform 506、analogy 348）做族内逐层分析；25 个受控二元族（he/she、Europe/Asia、even/odd、…；~22 项/类 × 4 模板）做跨概念可 steer 性预测。核心族直接跨族比较只有 ρ=+0.18（p=0.54），受控族才显出 +0.86~+0.91——作者据此主张"比较可解释性工具必须控住任务结构"。
- **模型用途表（Table 6）**：Gemma-2-2B（26 层，主实验）；Llama-3.1-8B/Mistral-7B/Qwen2.5-7B（复现）；Mamba-1.4B/RWKV-1.6B（只做 logit lens）；Llama-3.2-1B-Instruct（refusal 演示，40 有害+40 无害）；Gemma-2-2B 与 OLMo-2-1B-Instruct（London→Paris 实体 steering 演示，20+20 提示）。

## 与 老师方案的关系
- 重叠点：
  1. **目标完全一致**——免训练、前验地预测 steering 最有效层，并以"与 oracle 全层扫描的相关性 / 命中率 / 成本节省"作证伪口径；他们报 ρ、oracle 百分比、≈10% 开销、30× 加速，与我们"ρ>0.7、误差≤1 层、成本≤扫描 10%"几乎同一套指标。
  2. **"训练探针准确率对选写层无用"**（Table 11）——这正是我们 R*≠W* 子主张的前置事实，他们已用对照实验钉死。
  3. 同用 difference-of-means 方向、同报 KL 附带损伤。
- 冲突点（他们的结论会不会打我们的某条主张）：
  1. **LA-Score 的 sep 项（5 折逻辑回归 AUC）被他们证明对预测写层基本无信息**（每层 >93%、选出来的层 ΔP≈0）。若 S(ℓ) 里 sep 不做消融，审稿人会直接引 Table 11 质疑；sep 只应用来定义读层 R*，进 S(ℓ) 必须给出边际贡献证据。
  2. 他们用**一个量、零训练**就拿到 ρ 0.86–0.91；我们四量 z 分数求和显得过度工程化，必须证明 S(ℓ) 在真实性/弃答任务上**优于 A_lin（或其首 token 代理）**，否则"更简单的已存在"。
  3. 选层精度标杆已立：0–1 层误差、≥99.6% oracle ΔP（4/5 族）。我们"≤1 层"不再是新口径，只能靠**换域**（多 token 行为）与**换方向估计器**（DAS）立新。
  4. 他们发现事实类概念只在**最后四分之一层** A_lin>0 且 steering 只在那里有效，否定"中层最好"的行规。若我们的 W* 落在中段，需解释为何 A_lin 预测不了（可答：我们的目标是分布级/多 token 的弃答行为，A_lin 在那里没定义——他们自己在附录 C 把这列为未来工作）。
- 可借用点（方法、数据、指标、对照）：
  1. **A_lin 当基线预测器**（成本几乎为零）；对 C 方向可用其附录 C 的"首 token 代理 / token 集概率质量"变体（例如 "I"/"un"/"不" 等弃答首 token 的 logit-lens 质量）。
  2. **oracle 百分比指标**：所选层 ΔP ÷ oracle 层 ΔP，比"层误差"更能体现平台效应。
  3. **层深混杂三件套**：控制层索引的偏相关、族内置换检验、受限子集分析——我们报 ρ(LA-Score, 实测增益) 时必须同样控住"越深越好"的平凡趋势。
  4. **效率指标 ΔP/KL** 与**基线概率检查**（天花板效应）。
  5. **C(d) 目标 token 排名**：把我们的 E/C 方向过 unembedding，看 "I don't know / unanswerable" 类 token 排名——既是机制解释也是 C 方向是否"输出对齐"的诊断。
  6. 三体制叙事可用来解释为何某些层/模型上 E 或 C 不可 steer。
- 明确差别（我们还能声称什么是新的）：
  1. **域**：他们是单 token 事实补全；我们是多 token 真实性与弃答行为。A_lin 需要唯一目标 token，对"承诺 vs 弃答"这种分布级行为没有定义；LA-Score 的 dact/dattn/mass 全在激活空间，不需要目标 token——这是真空位。
  2. **方向估计器**：他们只验证 diff-of-means；CDAS（2602.05234，附录 J）显示 DII/DAS 训练出的方向**没有一阶（unembedding）效应**、靠下游组件起作用——意味着 A_lin 类预测器对 DAS 方向可能失效，而激活空间分数可能恰好适用。值得做成一个实验。
  3. **读写分离的量化**：他们只给"探针选层很差"的对照，没有把 R* 与 W* 的层距当成一个被报告、被跨模型比较的量；我们报 Δ=|R*−W*|。
  4. **两方向解耦 + 门控**：他们完全没有。
  5. **真实性域零覆盖**：他们没做任何真实/诚实概念。
  - 建议论文措辞：在 related work 把 LAP 列为"最接近的免训练选层预测器"，把 LA-Score 定位为"把免训练选层扩展到 logit lens 无定义的多 token 行为目标（弃答/承诺）"，C2 实验里必须把 A_lin（首 token 代理版）与 LayerNavigator 的 S_l 一起列为基线；sep 项要么退出 S(ℓ)，要么给消融。
