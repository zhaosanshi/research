## 一句话核心主张
把 steering（激活引导 · 往残差流加一个向量改行为）写成带约束的最小改动问题：训练线性探针预测"模型这题会错多少"，只在预测误差高于阈值 α 时沿探针方向推、推到刚好压到 α 为止（闭式解，强度与预测误差成正比）；α 在校准集上按"提升显著大于 0"的统计检验挑选，若没有任何 α 能显著提升就**整体不 steer**——论文里的 abstention（弃权）指的是**放弃干预**，不是让模型拒答，模型始终输出一个标签。

## 方法细节
- 误差定义：E = 1 − prob_y（在合法标签集合内归一化的金标概率）；读位置两种：last（提示末 token）与 exact（生成中第一个匹配合法标签的 token，取自 Orgad et al.）。
- 探针：每层一个线性回归（Lasso 多档正则 + 无正则，选验证 RMSE 最低），目标是连续误差 E；另比较 SAE（sparse autoencoder · 稀疏自编码器 · 把激活拆成稀疏可解释特征）特征，结论是 SAE 不更好、还更贵。
- 闭式 steering：v* = max(0, (α − wᵀh)/‖w‖²)·w（线性探针）；sigmoid 探针时把 α 换成 logit(α)。逐 token、逐层自动给强度；**所有层所有 token 一起推**（附录消融显示全层全 token 优于只推最佳层或只推生成 token）。
- 校准：α ∈ [0,1] 十等分网格；α_valid = {α : Δ_cal(α) > ε + b(δ,K,N)}，b 来自 Hoeffding + 联合界；论文设 δ=0.01、ε=0，Δ 用准确率差；α_valid 为空 → 不 steer（"global abstention"）。
- 基线：BASE-x（提示后缀 "Think before you answer."）；BASE-µk（误差最高 / 最低各 k 条的均值差，k=50/100/200，提示末 token、探针最佳层）；BASE-p̂ / BASE-p̂log（回归 / 逻辑回归探针权重直接当方向、不校准）；MERA-µ100、MERA-p̂log = 把 MERA 校准套在别人的方向上。
- 数据：Yes/No（金融新闻问答，No 占 67.5%）、SMS Spam（多数类 86.4%）、Sentiment（Neg 55.3%）、MMLU-HS、MMLU-PROF；训练约 3000（MMLU-PROF 2601）、校准 / 测试各 250（MMLU 210）。模型：Llama-3.2-1B、Gemma-2-2B、Qwen-2.5-3B 的 base 与 IT。
- 指标：SPI（Steering Performance Impact · 引导性能影响分 · 提升按"剩余可提升空间"归一、下降按"原准确率"归一，压到 [−1,1]）。

**我们自己的复算（不是作者的结论，引用时要注明）**：MERA 的大增益几乎都落在"多数类比例"上——Yes/No 五个大增益格 steer 后准确率 0.656–0.688，而多数类（No）占 67.5%；SMS Spam 三个大增益格都是 0.886–0.888，多数类 86.4%；Sentiment 的 Gemma base 0.124 → 0.554，多数类（Neg）55.3%。这与"把输出偏置推向多数类标签"（判别准则 / 偏置移动，不是判别力提升）在数值上一致。论文只报准确率，分不清这两种情况。

## 与本方案（E/C 双重分离 + 等覆盖率组合）的关系
- 重叠点：
  1. 同样是"用探针读出的误差 / 置信信号决定推不推、推多强"，与 C 方向按输入门控的思路同构；标题里的 abstention 容易被审稿人联想成我们的"弃答"。
  2. 同样涉及"方向估计器之争"：回归探针方向（MERA）vs 均值差（BASE-µ / MERA-µ100）vs 逻辑回归探针。
- 冲突点：
  1. 无直接冲突。它**不让模型拒答**、没有覆盖率维度、没有两条方向，因此不占 N2。
  2. 若审稿人只看标题把它当成 "steering + abstention" 的先例，需要在相关工作里一句话澄清："MERA 的 abstention = 放弃干预，模型照常作答"。
- 可借用点：
  1. **它正好是 N1 测量设计的反面教材**：只报准确率的 steering 评测分不清"判别力提升"与"偏置推向多数类"。上面的复算（steer 后准确率 ≈ 多数类比例）可以放进引言 / 相关工作，作为"必须把 J/AUROC 与作答率 / 准则分开报"的动机（措辞标明是我们的复算）。
  2. 校准阈值的有限样本保证（Hoeffding + Bonferroni，δ=0.01）可借来给我们 E/C 强度选择、等覆盖率工作点加"显著才算"的门槛。
  3. "exact token"读位置、"全层全 token 推"的消融，可作为 E 估计位置的对照项。
- 明确差别（我们还能声称什么是新的）：
  1. 我们分开报 J/AUROC（判别力）与作答率（准则），并做 2×2；MERA 只有准确率。
  2. 我们的"弃答"是模型真实的回答 / 拒答行为；MERA 的"弃权"是工程开关。
  3. 我们的 E 用 DAS（Distributed Alignment Search · 分布式对齐搜索 · 用互换干预训练出因果子空间）；MERA 用回归探针，未比 DAS。

## 对三条主张的威胁等级
| 主张 | 威胁 | 理由 |
|---|---|---|
| N1 双重分离 | 低 | 不区分判别力与准则，只报准确率；反而提供了"准确率增益可能只是偏置移动"的例子，支持 N1 的测量设计。 |
| N2 等覆盖率组合 | 低 | 没有作答 / 弃答、没有覆盖率、没有两方向组合；"abstention"指不干预。 |
| N3 DAS 胜均值差 | 低 | 显示"回归探针方向 + 校准"优于均值差，但不是 DAS，且增益可能来自偏置移动；不构成先例冲突。 |
