# 2608.14465 · You Only Pass Once: Answering and Abstaining Together in a Single Forward Pass of a Frozen Language Model (YOPO)

## 一句话核心主张
提高答对率的"写入器"（在中层按输入加向量的小 MLP）和决定弃答的"读出器"（可答减不可答的均值差方向，打分后取阈值）可以放进同一次前向——但写入会**破坏**读出方向的判别力（1.5B 上 HellaSwag AUROC 0.919→0.836）；用一个无标签的小映射把"写后状态"还原成"写前状态"就能修回 63%。组合系统在域内胜过任一单件；并且"是否作答的判断应放在读侧"，训练进写入器或 LoRA 的弃答跨域会崩。

## 方法细节
- 写入器（probe）：三层（深度约 0.4 / 0.55 / 0.7）读 5 个提示位置，写回 r + a‖r‖u(r)（方向与长度都依赖输入），只训练这个 MLP（答案交叉熵），以可插拔 hook 实现，不改骨干权重。
- 读出器（direction）：d = mean(h | 充分) − mean(h | 不充分)，在读层（1.5B/7B 第 18 层）；得分 s = dᵀh，低于阈值就弃答；域内阈值在选择集上定，跨域取目标集无标签得分的中位数。
- 修复映射 M：M(h) = h + Uσ(Vh)（秩 64，U 初始化为 0，即从恒等映射起步），只用 MSE 把写后状态 h_on 还原成写前状态 h_off，不用任何标签。
- 评测：αNLI / HellaSwag 四条件（完整 / 删一个观测 ×2 / 两观测都替换）上的三分类准确率（答 1、答 2、弃答），阈值取评测集自身得分的第 25 百分位（≈ 把弃答比例固定在 25%）；SQuAD2、RepLiQA、MuSiQue-C/F 四个问答集（各 2,000 题、半数不可答）上自由生成的 answer-or-abstain 准确率，并报金标签弃答的 oracle 上界。
- 读出 vs 训练判断（§4）：同样的可答性判断，均值差方向跨域只掉 2.3 点；训练进 probe 掉 16.4 点、训练进 LoRA（Low-Rank Adaptation · 低秩适配 · 只训少量低秩权重）掉 22.2 点，后两者跨域甚至低于直接提问模型。

## 与本方案（E/C 双重分离 + 等覆盖率组合）的关系
- 重叠点：
  1. **结构上就是"提升答对的干预 + 决定作答的机制"组合胜过各自单独**——N2 的同构命题，而且在自由生成问答上有正结果（只是不可答来自上下文缺失）。
  2. 它的"写入器 / 读出器"二分 ≈ 我们的"E（改答对质量）/ C（改是否作答）"二分；它用百分位固定弃答比例，接近等覆盖率比较。
- 冲突点：
  1. **对 N1 的直接警告**：写入（提准确率的编辑）会改变弃答方向读到的东西——小模型上两件事并不干净可分。我们的 2×2 必须显式检验"推 E 之后，C 的读数 / 作答排序有没有变"，而不只是看作答率均值不变。
  2. **对"steer C"设计的挑战**：作者的结论是"弃答应留在读侧，别写进模型"——训练进写入器 / LoRA 的弃答跨域崩溃。审稿人会问：为什么 C 要推出来，而不是读一个方向再取阈值？N2 需要证明"推 C"胜过"读 C + 阈值"。
  3. 对 N3 的旁证：带标签训练的判断（probe、LoRA、监督判别器）域内强、跨域崩，均值差方向跨域稳——我们用金标签训练的 DAS（Distributed Alignment Search · 分布式对齐搜索）方向也要做跨数据集检验，否则"DAS 胜均值差"可能只是域内过拟合。
- 可借用点：
  1. "写入是否破坏读出"的量化方式（写前 / 写后 / 修复后三列 AUROC），可直接用于 E 与 C 之间的干扰诊断。
  2. 三分类准确率 + 固定弃答百分位 + "两遍参照" + oracle 上界的评测协议。
  3. 无标签还原映射，可作为 E、C 同时施加时出现干扰的补救手段。
- 明确差别（我们还能声称什么是新的）：
  1. 它的弃答是"读出 + 阈值"，不是一条被推动的方向；它没有"判别力 vs 准则"的 2×2。
  2. 任务是上下文可答性与常识推理选择题，不是参数知识的真假判断；不涉及 DAS。

## 对三条主张的威胁等级
| 主张 | 威胁 | 理由 |
|---|---|---|
| N1 双重分离 | 低-中 | 不占"双重分离"，但给出"提准确率的写入会损害弃答读出"的反向证据（小模型尤甚），审稿人会要求我们证明 E 与 C 之间没有这种干扰。 |
| N2 等覆盖率组合 | 中 | "提准确率干预 + 弃答机制在同一次前向组合胜各单件"已有严谨预印本（含自由生成问答），且主张弃答放读侧；我们的新意收窄为"C 是被推动的方向 + 等覆盖率 + 参数知识"。 |
| N3 DAS 胜均值差 | 低 | 不涉 DAS；但"标签训练的判断跨域崩、均值差方向跨域稳"是对金标签 DAS 的跨域质疑。 |
