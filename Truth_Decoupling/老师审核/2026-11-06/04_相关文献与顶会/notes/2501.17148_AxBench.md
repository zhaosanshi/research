# 2501.17148 · AxBench: Steering LLMs? Even Simple Baselines Outperform Sparse Autoencoders

- 作者 / 机构 / 发表处与年份：Zhengxuan Wu*、Aryaman Arora*（共同一作，Stanford）、Atticus Geiger（Pr(AI)²R）、Zheng Wang、Jing Huang、Dan Jurafsky、Christopher D. Manning、Christopher Potts（Stanford）。**ICML 2025 主会**（arXiv v3 2025-03-03 仍标 Preprint）。代码 github.com/stanfordnlp/axbench，数据与字典开源于 huggingface.co/pyvene。
- 权威度与严谨度判断：**[顶会已发表]**。理由：500 个概念（Concept500）× 4 个表征位点（Gemma-2-2B L10/L20、Gemma-2-9B L20/L31）；每概念 144 训练样本、≈72 检测评估样本、10 条 Alpaca-Eval 指令 × 14 个强度；强度选择与评估**分半**（防过拟合）；逐方法独立调超参；配对 t 检验；三维 LLM 裁判（概念/指令/流畅，调和平均）。短板：**只有 Gemma-2 一族**；裁判是 gpt-4o-mini、无人工评估；任务是"把概念塞进开放生成"而非行为/真实性控制；每方法只允许**一个全局常数强度**（作者自述可能低估 steering）；字典类方法的超参按**检测 AUC**而非 steering 效果选（作者自述算力所限）；概念列表来自 SAE 自动解释，偏 token 级、浅层。

## 一句话核心主张
在 500 个开放词汇概念、长文本生成的大规模基准上，**prompting（提示 · 直接在提示里写"请把 X 融进回答"）打败所有表征干预方法（含 DiffMean、探针、SAE、LAT、PCA）**，finetuning 其次；表征方法中只有作者新提的 ReFT-r1 接近 prompting；而在"概念检测"上 DiffMean/探针/ReFT-r1 最好、SAE 不行——**检测得好 ≠ steer 得好**。

## 方法细节
- **数据（§3.1）**：从 GemmaScope SAE 的 Neuronpedia 概念描述抽 500 个概念；gpt-4o-mini 生成：正例 = 融入概念的回答；负例 = 目标模型自己的原始回答（跨概念共享）；评估集另加"硬负例"（多义词的另一义）。文本/代码/数学三类，70/15/15。n=144 训练。
- **检测 C（§3.2）**：token 级分数 max-pool 为序列分数（结果中按均值），min-max 归一化；指标 AUROC；另报 balanced/imbalanced（≈1% 正例）F1。
- **Steering S（§3.3）**：ŷ_steer = LM(x, h ← Φ_steer(h))，pyvene 实现；在 Alpaca-Eval 指令上生成 ≤128 token；gpt-4o-mini 分别给 concept / instruct / fluency 0–2 分，取**调和平均**（任一项差整体就差）；先解释再打分；温度 1.0、无重复惩罚。
- **方法（§4）**：DiffMean（正均值 − 负均值，单位化；steer 为 h + α w）；PCA（正例第一主成分）；LAT（随机配对差分的 PCA，Zou et al.）；Probe（logistic 回归方向，steer 同 DiffMean）；SSV（直接用 LM 损失学一个加法向量）；**ReFT-r1**（新方法：Φ(h_i) = h_i + (1/k) TopK(ReLU(h·w)) · w，联合优化 LM 损失 + 非 top-k 的 L1，同时学检测与 steer）；SAE（GemmaScope 解码方向加法）；SAE-A（用训练集 AUROC 选 SAE 特征）；基线：Prompt（**非零样本**：先让 LLM 为概念生成一段增强提示再前置，Appendix J.1）、SFT、LoRA、LoReFT；检测另有 BoW、IG、I×G。实际干预量 α = 强度 × 检测集上的最大激活。
- **干预层**：固定 2B 的 L10/L20、9B 的 L20/L31（有 SAE 的层），**不做选层**。

- **关键观察**：① Prompt 在 9B 上比 2B 高 50%（0.70→1.07），prompting 的优势随模型变大而变大；② **Probe 方向检测第二（0.940）、steering 倒数第二（0.098）**——"better classification does not directly lead to better steering"（§5.2）；③ 强度↑ instruct 分单调↓；早层 concept 分先升后降，晚层单调升（Fig 4）；④ DiffMean/ReFT-r1 在**更早层**胜率更高（2B L10 > L20；9B L20 > L31）；⑤ ReFT-r1 在 Pareto 前沿。
- **作者自述局限（§K）**：单一常数强度可能低估 steering；默认解码无重复惩罚（与多数 steering 文献不同）；字典类方法超参按检测 AUC 选。

## 与 老师方案的关系
- 重叠点：我们三种估计器（rank-1 DAS / 均值差 / 逻辑回归探针）正对应 AxBench 的 ReFT-r1 类（学出来的 rank-1 干预）/ DiffMean / Probe；我们的 prompt-only 对照正是其 Prompt 基线；"检测好≠steer 好"是我们 C2"读层≠写层"的**估计器层面**版本。
- 冲突点：
  1. **AxBench 明确结论：prompting 大幅优于所有 steering（0.894 vs DiffMean 0.239）**。若我们的 prompt-only（"不确定就说不知道"）在选择性弃答/J 上与门控 steering 打平或更好，C3 整条就塌。这也是审稿人最可能的第一刀。注意 CAST 声称相反结论（steering 优于 prompting），两边口径不同（AxBench 是概念注入+LLM 裁判，CAST 是拒答率），论文必须正面调和。
  2. **逻辑回归探针方向几乎不能 steer**（0.098，比 SAE 还差）。我们若用 LR 探针方向做 E/C 干预，C1 的 2×2 矩阵在该估计器上大概率出不来；要么只把 LR 探针当"读"工具（sep），不当"写"方向，要么预期并报告其失败。
  3. 他们的 prompting 优势随尺度放大——我们 C4 里 8B 模型上 prompt-only 最可能赢。
- 可借用点：① 调和平均三维评分（目标效果 / 任务相关 / 流畅）可改造成我们的"J / 作答率 / 流畅"联合口径，防止靠乱码刷分；② 强度选择与评估分半；③ 配对 t 检验 + 胜率表；④ "非零样本 prompting 基线"（让 LLM 先写增强提示）——我们的 prompt-only 若只是一句 system prompt，审稿人会说没调优（CAA 也承认这点），应参照 AxBench 做强 prompting 基线；⑤ 其 Prompt 对小模型弱的现象 = 我们的切入点：0.6B–1.7B 模型指令遵循差，steering 可能真有价值。
- 明确差别（我们还能声称什么是新的）：
  1. AxBench 的任务是"往回答里塞概念"（风格/话题注入），不是**校准/真实性/弃答**这类与模型知识状态相关的行为；prompting 能轻松注入话题，但"知道自己不知道"是否能靠提示解决，AxBench 没测。
  2. AxBench 不做层选择、不做门控、不做方向解耦、不测通用能力损伤（无 MMLU）。
  3. 我们可以把 C3 重写成一个**有条件的主张**："在指令遵循弱的小模型（≤1.7B）上门控 steering 优于 prompt-only；在 8B 上两者相当但可叠加"——这与 AxBench/CAA 都兼容，且 CAA Table 3 已显示 steering 可叠加在 system prompt 之上。
  4. 必须报告 steering+prompt 叠加组，否则"prompting 就够了"无法反驳。

## 对四条主张的威胁等级
| 主张 | 威胁 | 理由 |
|---|---|---|
| C1 解耦 | 中 | 不做解耦；但 LR 探针方向几乎零 steering 效果，意味着三估计器中至少一个难以产出"E 改 J"的因果效应，2×2 矩阵可能只在 DAS/均值差上成立。 |
| C2 选层 | 低 | 不选层、仅 2 层/模型；但"检测第二、steering 倒数第二"的 Probe 结果与"DiffMean 早层更好"是读≠写的旁证，可引用。 |
| C3 门控 | **高** | 顶会级证据：prompting 在 Gemma-2 上大幅优于一切 steering，且随尺度放大；我们的 prompt-only 对照若认真调优，很可能在 8B 上追平门控。需把 C3 改为条件化主张并加 steering+prompt 叠加组。 |
| C4 泛化 | 中 | 只 Gemma-2 一族，不直接覆盖我们三族；但其"prompting 优势随尺度增大"趋势对我们 0.6B→8B 跨尺度结论是直接风险（大模型上 steering 增益可能消失）。 |
