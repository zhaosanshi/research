# 2503.14477 · Calibrating Verbal Uncertainty as a Linear Feature to Reduce Hallucinations

- 作者 / 机构 / 发表处与年份：Ziwei Ji*, Lei Yu*, Yeskendir Koishekenov, Yejin Bang, Anthony Hartshorn, Alan Schelten, Cheng Zhang, Pascale Fung, Nicola Cancedda。Meta FAIR + Meta GenAI + 港科大 + 多伦多大学。arXiv v2 2025-04-22；任务说明标注为 EMNLP 2025 主会（PDF 本身是 arXiv 版，未印会议名，按主会对待）。代码开源：github.com/facebookresearch/verbal_uncertainty_feature_calibration。
- 权威度与严谨度判断：**[顶会已发表 + 大机构]**。理由：4 个模型（3 家 7–8B + 一个 70B）、3 个数据集各 1k 测试样本、有随机方向对照、有跨数据集迁移、有"换一种 VU 打分器重新抽方向"的反循环论证（App. E.5）、开源代码。弱点：没有人工评估（VU 全靠 LLM-as-a-Judge（大模型当裁判 · 让另一个大模型给输出打分）），没有做 MMLU 之类的通用能力副作用检测，层选择是启发式的。

## 一句话核心主张
LLM 残差流里存在一个单一线性方向 VUF（Verbal Uncertainty Feature · 口头不确定性特征 · 控制模型"说话口气有多犹豫"的那根轴），它与模型真正的 SU（Semantic Uncertainty · 语义不确定性 · 模型采样多次答案互相矛盾的程度）只有中等相关（r≈0.3–0.6）；沿这个方向按"SU−VU 差距"做逐样本门控干预，能把"自信地说错"的比例平均相对降低 29.6%，正确率只掉 1–2 个点。

## 方法细节
**两个量的定义**
- VU（口头不确定性）：`VU(U|C) = 1 − Pr(P|U,C)`，即听者听了回答 U 后会给命题 P 多低的可信度。实际操作：Llama-3.1-70B-Instruct 当裁判，对每个采样答案输出 decisiveness（果断度）∈[0,1]，拒答记 0；一个问题的 VU = 多个采样答案 VU 的平均（App. A.2）。备选验证：用 NV-Embed-v2 算答案与一组"我不确定"原型句的余弦相似度（ESU/EUU 分数），与裁判分高度相关。
- SU（语义不确定性）：Semantic Entropy（语义熵 · 采 10 个答案按意思聚类后算熵），T=1、top-p 0.9、top-k 50 采 10 个，另用 T=0.1 采 1 个作"最可能答案"。

**方向估计（§3.1，式 2–3）**
- 用"鼓励表达不确定性"的 prompt 让模型自己作答，按 VU 分排序：顶部 N 个为 D_uncertain，底部 N 个为 D_certain（做干预时用三数据集合并，VU ≥ 0.9 vs ≤ 0.05，App. G.1）。
- difference-in-means（均值差 · 两组激活各取平均再相减）：取**问题最后一个 token** 的残差流激活 h^(l)(x)，`r̂ = mean_uncertain − mean_certain`，再 L2 归一化。每层各算一个。
- 注意：对比的是**模型自己自然生成的犹豫 vs 自信的回答对应的输入**，不是 system prompt 对比。

**干预层与位置（§3.2 + App. E.1）**
- 层选择纯启发式：PCA 看两簇是否线性可分 + 不同数据集抽出的 VUF 两两余弦相似度在哪些层高 → 结论"中间层到末层可靠"。
- 实际用**多层同时加**：Llama-3.1-8B 第 15–31 层、Mistral-7B 第 15–31 层、Qwen2.5-7B 第 16–27 层。
- 干预施加于**生成过程中的所有 token**（all tokens），不只是最后一个。

**干预公式**
- 因果验证（式 4）：`h^(l)(x) ← h^(l)(x) + α · r_VU^(l)`，α>0 增加犹豫，α<0 减少犹豫，单调。
- MUC（Mechanistic Uncertainty Calibration · 机制式不确定性校准 · 按每道题"该多犹豫却没犹豫"的差额来定推力大小）（式 5–6）：`α_su(x) = clip(su_norm(x) − vu(x), 0, max_α)`，su_norm = SE/ln N。max_α：Llama-8B 1.0、Mistral 0.4、Qwen 3.0、Llama-70B 4.0。**只在幻觉检测器触发的样本上干预**——这是一个按输入门控的干预。
- Qwen 对同样 α 不敏感，作者归因于 Qwen 激活范数大（归一化后的方向相对太短）。

**检测（§4.1）**
- 逻辑回归把 VU 与 SU 合起来预测幻觉；另训练两个线性回归 probe（探针 · 从隐藏状态里读出一个数的小线性模型）从问题最后 token 隐藏状态预测 VU 与 SU（VU 用第 5–20 层，SU 用第 10–20 层），实现"prefill 结束就能判"。注意：读 probe 用第 5–20 层，写干预用第 15–31 层——**读层与写层事实上不同**，但作者没有把这当主张。

**数据**：TriviaQA、NQ-Open、PopQA，各抽 10k 训练 / 1k 验证 / 1k 测试。闭卷短答 QA。

## 评价口径与关键数字
指标定义（§4.2）：Overall Hallucination Rate = 不拒答且答案不被金标蕴含；Confident Hallucination Rate = 答错且 VU 低于阈值；Correctness Rate；Refusal Rate；VU/SU Disagreement Rate（一高一低的比例）；VU–SU 相关系数；错题/对题的平均 VU。

| Mistral-7B | 46.9 → 29.1 | 45.3 → 43.4 | 7.8 → 21.2 | 0.28 → 0.60 | 0.20 → 0.50 | 0.06 → 0.10 |
| Qwen2.5-7B | 48.1 → 34.6 | 35.7 → 34.9 | 16.2 → 22.1 | 0.32 → 0.39 | 0.51 → 0.57 | 0.17 → 0.18 |
| Llama-3.1-70B | 29.7 → 23.5 | 64.1 → 62.9 | 6.1 → 10.1 | 0.60 → 0.76 | 0.35 → 0.44 | 0.10 → 0.11 |

| 数据集 | before | 随机向量（同 α 同幅度） | TriviaQA 抽的 VUF 迁移 | 本数据集 VUF |
|---|---|---|---|---|
| TriviaQA | 23.3 | 20.1 | — | 19.0 |

Table 1 检测 AUROC（Llama-8B）：SU 单独 79.2 / 65.3 / 71.2 → SU+VU 79.7 / 66.0 / 75.7（TriviaQA / NQ / PopQA）。Probe 预测的 SU/VU 做干预（Table 4）效果略差但可用（TriviaQA Conf. Halluc. 19.0 vs 22.3）。

作者自述局限（Limitations）：只做短答 QA；依赖预定义 probe 与打分；**方法只改变"表达"，不纠正错误答案本身**。

## 与 老师方案的关系
- 重叠点：
  1. 他们的 VUF 本质上就是我们的 **C（承诺/commitment）方向**——都是"模型愿不愿意下结论"这根轴，都用均值差估计，都证明沿它推能单调改变犹豫/拒答率且几乎不动正确率（Table 3：Correctness 只掉 1–2 点、Refusal 上升）。我们 2×2 矩阵里"C 改作答率不改 J"这一格，他们已经给了 4 模型 × 3 数据集的证据。
  2. **MUC 就是一个按输入门控的单方向干预**：逐样本 α 由 SU−VU 差额决定、只对检测为幻觉的样本开火——与我们 C3 的"已知题不干预、未知题打 C 方向"思路同构。
  3. 前提一致：他们明确量化了"表达 ≠ 知识"（VU 与 SU 相关仅 0.3–0.6），这是我们 E/C 分离的经验基础，可直接引用。
- 冲突点：
  1. 他们没有做 E 方向，没有做"E 推了不改作答率"的另一半矩阵，所以**不会直接推翻 C1**，但会让审稿人说"C 这半边不是新发现"。
  2. **随机方向对照显示随机扰动也能降幻觉 3–5 点**。我们如果只报"干预后未知题多弃答"而没有同幅度随机方向对照，会被这篇反杀。
  3. 他们的 Qwen 不敏感现象（归一化方向在大范数模型上太弱）提示：我们跨模型族用统一 α 会出问题，C4 要按模型校 α。
- 可借用点：
  1. VU 的 LLM-judge 打分 prompt（App. A.2）和 ESU/EUU 原型句——可直接拿来当我们"作答率/承诺度"的连续版指标。
  2. 评价口径：Confident Hallucination Rate、VU/SU Disagreement Rate、VU(错题) vs VU(对题)——后两个正好是"C 只动表达不动知识"的证据格式。
  3. 对照组设计：随机向量同 α 同幅度；跨数据集方向迁移。
  4. 数据：TriviaQA / NQ-Open / PopQA 各 1k 测试子集的协议（10 采样 SE + 1 低温答案）。
- 明确差别（我们还能声称什么是新的）：
  1. **E 方向**及其与 C 的正交性/交叉效应检验（他们完全没有）。
  2. C 方向用 **system prompt 对比**估计（他们用模型自己自然产生的犹豫 vs 自信回答的输入做对比，需要先跑 70B 裁判打分，成本高且有循环风险）。我们的估计器更便宜、无需裁判。
  3. **DAS（Distributed Alignment Search · 分布式对齐搜索 · 用梯度学出一个最能解释因果行为的旋转子空间）rank-1 估计器**与均值差/逻辑回归三者对比——他们只有均值差。
  4. **LA-Score 免训练选层 + 读层≠写层的显式主张**——他们是启发式多层叠加（15–31 层），且读 probe 层（5–20）与写层（15–31）不同这一事实被他们忽略了，我们可以指出来并系统化。
  5. 门控用**知识探针 p(x)** 三分（已知/部分已知/未知）而非 SU−VU 差额，不需要采样 10 次；且部分已知题打 E 方向（他们只会增加犹豫，不会纠正答案——他们自己在 Limitations 承认）。
  6. 小模型（0.6B）与通用能力副作用（MMLU/GSM8K）——他们没做。

## 对四条主张的威胁等级
| 主张 | 威胁 | 理由 |
|---|---|---|
| C1 解耦 | 中 | "C 方向改作答率不改正确率"这半边他们已做实（4 模型 3 数据集）；E 半边与交叉效应仍是真空。必须把 VUF 当作 C 的直接前作引用并对比。 |
| C2 选层 | 低 | 他们层选择是启发式（PCA 可分性 + 跨数据集余弦），多层叠加，无自动打分、无读写层区分主张。 |
| C3 门控 | 中-高 | MUC 已是"按输入 SU−VU 差额门控 + 只对检测到的幻觉开火"的单方向干预，且展示已知题正确率基本不掉、未知题多弃答。我们必须展示：三分门控 + E/C 双方向优于"仅 C 方向门控"（即优于 MUC 式基线），否则 C3 新意不足。 |
| C4 泛化 | 低 | 他们 3 族 7–8B + 70B，3 数据集，无 MMLU/GSM8K。我们 0.6B 起 + 副作用检测是增量；但 Qwen 不敏感现象提醒跨族 α 校准。 |
