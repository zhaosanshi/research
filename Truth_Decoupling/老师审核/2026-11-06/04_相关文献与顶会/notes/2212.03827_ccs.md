# 2212.03827 · Discovering Latent Knowledge in Language Models Without Supervision
- 作者 / 机构 / 发表处与年份：Collin Burns*、Haotian Ye*（PKU）、Dan Klein、Jacob Steinhardt（UC Berkeley）。**ICLR 2023 主会**（OpenReview id ETKGuby0hcs，被本组其余各篇一致引用为 ICLR 2023）。arXiv v2 2024-03-02。
- 权威度与严谨度判断：**[顶会已发表]**，领域奠基作（CCS 成为后续所有真值探针论文的标准基线）。理由：6 个模型跨三种架构（T5 / UnifiedQA / T0 编码-解码；GPT-J 自回归；RoBERTa / DeBERTa 纯编码）；10 个数据集 × 每集 1000 条 × 平均 9 个提示 ≈ 18 万样本；有监督 LR 作上界、校准 0-shot 作基线；App. H 给出显著性（Wald 检验 p<1e-5）；代码开源（github.com/collin-burns/discovering_latent_knowledge）。**无干预实验**；模型最大 GPT-J 6B / T0 11B，没有现代 decoder-only 大模型；后续工作（Farquhar et al. 2023 "Challenges with unsupervised LLM knowledge discovery"——此条为本人补充的领域常识，非本文内容）指出 CCS 可能找到任意显著特征而非真值。

## 一句话核心主张
不用任何标签、也不看模型输出，只靠"一个陈述和它的否定不能同时为真"这一逻辑一致性约束，就能在激活空间里找到一个线性方向，把是/否问题答对——跨 6 模型 10 数据集平均比 0-shot 高 4%，对提示扰动的敏感度减半，且在用误导性前缀把模型"说"的准确率打掉 9.5% 时，它"知道"的准确率不掉——**模型知道什么和模型说什么是两回事**。

## 方法细节
- **问题设定（§2.1）**：给定是/否问题 q₁…qₙ 和冻结模型的表示 φ(·)，不用标签、不用输出答对问题。
- **对比对（contrast pairs · 同一个问题分别接 "Yes" 和 "No" 两个答案）**：x⁺_i = q_i + "Yes"，x⁻_i = q_i + "No"。两者差异有两处：(1) 末尾 token 不同；(2) 一真一假。要找的是 (2)。
- **归一化（§2.2，App. G.1）**：φ̃(x⁺) = φ(x⁺) − μ⁺，φ̃(x⁻) = φ(x⁻) − μ⁻，**各自减各自的均值**，消掉 (1) 的"Yes/No 簇"差异；再按平均范数 × √d 缩放。这是整个方法最关键的工程细节。
- **探针**：p_θ,b(φ̃) = σ(θᵀφ̃ + b)，线性。
- **损失（CCS）**：L_consistency = [p(x⁺) − (1 − p(x⁻))]²（一致性 · 两边概率加起来该是 1）；L_confidence = min{p(x⁺), p(x⁻)}²（排中律 · 不许两边都 0.5 糊弄）；L_CCS = 平均和。两项缺一个都有退化解。
- **推理**：p̃(q) = ½[p(x⁺) + 1 − p(x⁻)]，>0.5 判 Yes；哪一簇是"真"由 CCS 决定不了——评测时取两种标法的最大准确率；App. A 说原则上可用合取/析取无监督定簇。
- **训练**：AdamW lr 0.01，1000 epoch，随机初始化 10 次取无监督损失最低的一次。
- **位置/层**：末 token、**最后一层**（T5/UQA 用编码器、T0 用解码器——按无监督损失谁低选谁）；App. F 每 2 层扫一遍。
- **基线**：0-shot（标签 token 平均 log-prob）；校准 0-shot（加阈值 γ 使预测 50/50，+≈5%）；LR（用标签，视为上界）；CRC-TPC（对比差向量的第一主成分阈值 0）；CRC-BSS（双峰显著性搜索 · 找一个方向使两侧簇内方差/总方差最小，类似无监督 LDA）。
- **误导前缀实验（§3.2.2，App. B）**：在提示前加一段"答错的问答"前缀。

## 与 老师方案的关系
- 重叠点：
  - **"知道 vs 说"的二分是我们 E vs C 的概念祖先**：误导前缀改变了模型"说"的（0-shot 掉 9.5）但没改变 CCS 读出的"知道"的——这就是"提示改变承诺、不改变证据"的最早实验证据。我们的 C 方向用 system prompt 对比估计，逻辑上是把他们的"前缀效应"做成了一个可控方向。
  - CCS 是 Marks & Tegmark、Bürger、Liu 等人的标准基线；我们三估计器里没有 CCS，审稿人可能问为什么。
  - 对比对各自归一化的技巧，与我们用 system prompt 对估 C 方向时必须剔除"提示 token 本身"的差异是同一问题。
- 冲突点（他们的结论会不会打我们的某条主张）：
  - 无直接冲突：零干预、无承诺方向、无门控、无选层。
  - 间接：CCS 找到的方向后来被 Marks & Tegmark 证明因果上弱于均值差（13B 上 .31/.73 vs .85/.97），被 Farquhar 等指出会抓任意显著特征——所以**无监督找方向 ≠ 找到因果方向**，这反而支持我们"探针方向与因果方向要分开验证"的立场。
- 可借用点（方法、数据、指标、对照）：
  - **分侧归一化**：估 C 方向时，"不确定就说不知道"提示下的激活和"必须给确定答案"提示下的激活应各减各的均值后再比较，否则 C 方向会混入提示词的词面差异。CCS 的做法可直接搬。
  - **一致性约束作为 E 方向的正则**：E 方向上真句与其否定句的投影应互为相反数——可作为 E 方向估计质量的无监督检验（接上 Bürger 的 t_G/t_P 分析）。
  - 误导前缀实验设计：把"模型说的"和"探针读的"分开报，是 2×2 矿阵（E 改 J 不改作答率）的原型。
  - 校准 0-shot 的阈值 γ 平衡法：我们报作答率时应说明有没有做类似校准。
  - 提示敏感度（跨提示标准差）作为稳健性指标。
- 明确差别（我们还能声称什么是新的）：
  - 他们只读不写；我们干预。
  - 他们没有把"说"的那部分做成方向，只是展示它存在；我们把承诺做成可控方向并检验它不动判别力。
  - 他们是 2022 年的编码器/编码-解码模型；我们是现代 decoder-only 指令模型。
