# 2405.16908 · Can Large Language Models Faithfully Express Their Intrinsic Uncertainty in Words?

- 作者 / 机构 / 发表处与年份：Gal Yona, Roee Aharoni（Google Research）, Mor Geva（Tel Aviv University + Google Research）。**EMNLP 2024 主会**（Proceedings pp. 7752–7764，短文形式：6 页正文 + 附录）；arXiv v2 2024-09-26。无代码链接。
- 权威度与严谨度判断：**[顶会已发表 + 大机构]**。理由：5 个前沿闭源模型（GPT-3.5/4-turbo、Gemini Nano/Pro/Ultra）、2 个数据集各 932 题、LLM 裁判做了人工校验（果断度打分与人类概率词调查一致；置信度与作者标注 r=0.97，n=100）。弱点：**纯行为学，无可解释性、无干预**；闭源模型不可复现内部；只测短答、非歧义题、显式 hedging（措辞上的保留，如"我不太确定但……"）；无代码。

## 一句话核心主张
提出"忠实的回答不确定性"（faithful response uncertainty）指标：模型每句断言的**果断度**（decisiveness · 听者光看回答措辞会给这句话多高的可信度）应与模型对该断言的**内在置信度**（intrinsic confidence · 重采样 20 次有多少比例不自相矛盾）相匹配。实测 GPT-3.5/4 与 Gemini 三档全部不及格：默认解码时无论多不确定都斩钉截铁地答；提示它"不确定就加保留语"后虽然会出现 hedging，但 **hedging 的位置与内在置信度几乎不相关**——该犹豫的不犹豫，不该犹豫的乱犹豫。

## 方法细节
**定义（§2，Def. 1）**：`faithfulness_M(R;Q) = 1 − (1/|A(R)|) Σ_A |dec(A;R,Q) − conf_M(A)|`，∈[0,1]。
- `dec(A;R,Q) = Pr[A is True | R, Q]`：感知果断度，由 Gemini Ultra 用 few-shot prompt（Tab. 5）从回答里抽断言并打 0–1 分；拒答（punt）记断言为空、分 1.0。
- `conf_M(A) = 1 − (1/k) Σ 1[A contradicts A_i]`：k=20 次重采样，用**矛盾**而非双向蕴含（Kuhn et al. 2023 的 semantic entropy 用双向蕴含；作者认为"Honolulu"vs"Hawaii"不该算不一致）判定，裁判 prompt 见 Tab. 6。
- 这是 2503.14477（VUF 论文）VU 裁判 prompt 的直接来源。

**评价指标（§4）**：MFG = 平均 faithfulness；**cMFG** = 把置信度分 10 个等宽桶，每桶内取平均再平均（模拟置信度均匀分布，便于跨模型比较）；**0.5 是基线**——"永远果断"或"随机果断"两种与置信度无关的策略都得 0.5。只在未拒答样本上算（selective prediction 设定）。

**数据**：PopQA（只留 director/screenwriter/producer/author/place of birth/occupation 六类关系，去掉短实体，抽到 932 题）；NQ 用 AmbigNQ 标出的非歧义子集（932 题）。排除歧义题以隔离"模型不确定性"而非"数据不确定性"。

**模型与推理协议**：gpt-3.5-turbo、gpt-4-turbo、Gemini Nano/Pro/Ultra；贪心解码。四种 prompt（Tab. 2）：
- Vanilla：一句话完整作答。
- Granularity：不确定就答粗粒度。
- **Uncertainty**："If you are uncertain about your answer to the question, convey this uncertainty linguistically by precisely hedging this answer."
- Uncertainty+：Uncertainty + 每模型手工构造的 few-shot 示例（m=2 对，r=3 次随机取平均；示例来自 TriviaQA，置信度=1 的配果断答案、<1 的手工加 hedging）。

**人工校验（§3）**：100 条答案改写加 9 种概率词后打分，与 Fagen-Ulmschneider (2023) 人类概率词感知调查的 IQR 一致（Fig. 2）；置信度分与作者人工标注相关 0.97。

## 与 老师方案的关系
- 重叠点：
  1. **这是我们整个前提的行为学奠基文献**：表达的果断度（≈承诺 C）与内在置信度（≈证据 E）在前沿模型上几乎脱钩。我们的"E 与 C 是两个方向"是对这一现象的机制解释。
  2. 他们的 Uncertainty prompt（"不确定就用保留语精确表达"）与我们估 C 方向用的 system prompt（"不确定就说不知道" vs "必须给确定答案"）几乎是同一句话。他们已证明这条 prompt 能单独移动果断度而几乎不动置信度（Fig. 4/5）——这恰好是我们 C 估计器"只动承诺不动证据"的行为学前验。
- 冲突点：
  1. 没有直接冲突。但有一个隐含警告：prompt 诱导的 hedging 与置信度不相关，意味着**沿 C 方向推只会让模型"均匀地更犹豫"，不会自动校准**——所以单独推 C 不能改善 faithfulness，必须按输入（E/知识探针）门控。这正是 C3 存在的理由，也说明若我们的 C3 只报弃答率不报 faithfulness/校准，审稿人可问"你只是让模型更怯，没让它更诚实"。
  2. 他们用 k=20 重采样矛盾率定义置信度，我们用真/假对估 E——两者不是一回事：他们的是自一致性，我们的是对陈述真伪的证据。审稿人可能要求我们证明 E probe 分数与重采样置信度相关（或解释为何不相关更好）。
- 可借用点：
  1. **faithfulness / cMFG 指标**：门控干预后的 cMFG 应显著高于 0.5 且高于全局 C 推——这是比"弃答率上升"更有说服力的 C3 成功判据，且有顶会先例。
  2. 果断度裁判 prompt（Tab. 5）与矛盾判定 prompt（Tab. 6），已有人类校验，可直接复用作我们"作答率/承诺度"的连续版度量。
  3. 数据协议：PopQA 六类关系子集 + AmbigNQ 非歧义子集各 932 题，排除歧义题以隔离模型不确定性。
  4. Uncertainty+ 的 few-shot 构造法（置信度=1 配果断示例、<1 配手工 hedging 示例）可用于构造更干净的 C 对比对。
- 明确差别（我们还能声称什么是新的）：
  1. 他们是黑盒行为评测，没有任何内部表示分析、方向估计或干预；我们给出机制和干预。
  2. 他们明确说"依赖内部表示的方法"是未来方向——我们正是在填这个空。
  3. 他们只有闭源模型；我们是开源 0.6B–8B 三族，可复现。

## 对四条主张的威胁等级
| 主张 | 威胁 | 理由 |
|---|---|---|
| C1 解耦 | 低 | 只有行为学证据"表达与置信度脱钩"，无方向、无干预；是我们的前提而非竞争者。 |
| C2 选层 | 无 | 与层选择无关。 |
| C3 门控 | 低 | 无干预；但其"prompt 诱导的 hedging 与置信度不相关"结论要求我们证明门控后 faithfulness 真的提升，不能只报弃答率。 |
| C4 泛化 | 无 | 闭源模型行为评测，与我们的泛化主张不重叠。 |
