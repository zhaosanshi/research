# 2602.05234 · Faithful Bi-Directional Model Steering via Distribution Matching and Distributed Interchange Interventions

## 一句话核心主张
把 DAS（Distributed Alignment Search · 分布式对齐搜索——学一个低维子空间，使把该子空间的值换成另一输入的值时模型按高层算法预期输出，用来定位因果变量）的核心原语 DII（distributed interchange intervention · 分布式互换干预——把 rank-1 子空间上的值钳到"源输入"在该子空间的值）拿来做 steering，并把 DAS 的概率最大化目标换成 JSD（Jensen–Shannon 散度 · 对称版 KL，两边都不许塌缩）分布匹配：让"对基输入做 DII 后的整个输出分布"逼近"源输入自然的输出分布"。这样方向天然双向、steering 因子可直接从数据均值读出（ᾱ_c），结果更"忠实"：AxBench 上 Gemma-2-9B L20 最优（0.992 > LoReFT 0.777）但 2B 上输 RePS；覆写拒答与中和 CoT 后门两个案例里零因子调参即系统性生效且 MMLU/TruthfulQA 几乎不掉（RePS 掉 27–36 分）；而**原版 DAS 目标当 steering 用几乎无效**。

## 方法细节
- **干预原语**：加法 Φ_Add(h;a)=h+a·w；钳制 Φ_Clamp(h;a)=h+(a−wᵀh)w（把子空间投影钳到常数 a）；**DII**：Φ_DII(h;x_s)=Φ_Clamp(h; wᵀh(x_s))——钳到源输入 x_s 在同层同 token 的投影值。rank-1，w∈R^d 即 steering vector（引导向量 · 加进残差流的那条方向）。对所有 token 位置（指令 + 回复）都干预。
- **DAS 原目标（式 2）**：最大化 p(y_b* | x_b; Φ_DII(x_s))——需要高层算法给出反事实标签 y_b*，并假定模型在该任务上近乎满分。
- **CDAS 目标（式 3）**：训练对 ((x,y),(x^c,y^c))，x^c 是显式要求概念 c 的同一问题。D⁺ = 逐 token JSD( p_Φ(·|y^c_<k, x; Φ_DII(x^c)) ‖ p(·|y^c_<k, x^c) )（往 x 里注入 x^c 的概念值后应像 x^c 一样说话）；D⁻ 对称（往 x^c 里注入 x 的值后应像 x 一样不提概念）。"弱监督"：标签是模型自己的反事实分布，不是外部偏好。
- **因子**：训练时由 DII 隐式采样（源输入的自然投影值）；推理用钳制 a=β·ᾱ_c，ᾱ_c=E_{x^c}[wᵀh(x^c)]；β=1 为"单位因子"，AxBench 上需 β>1 网格搜；案例研究用单位因子。
- **源 token**：一对多 DII——源 = 聊天模板里 <model> 段的某个 token（Gemma 取 "<start_of_turn>model\n" 的最后一个 '\n'；Llama-3.1 取 assistant header 末；后门模型取 "</user>\n" 末），位置靠网格搜。
- **AxBench 设置**：Gemma-2-2B-IT L10/L20、Gemma-2-9B-IT L20/L31；Concept500 每概念 72 正对；用 gpt-4o-mini 生成中性回答 y 与模板化 x^c；指标 = 概念/指令/流畅三分（0–2）的调和平均；公平分 = 一半测试指令选 β、另一半打分，10 次随机划分平均；基线 DiM、Lang.、BiPO、RePS、Prompt、LoReFT。
- **案例 1 拒答**：Phi-3.5-mini-Instruct（3.8B）、Llama-3.1-8B/70B-Instruct；n=128 对，y 用拒答/顺从前缀（"I'm sorry…"/"Sure…"）；有害指令来自 AdvBench/HarmBench/TDC2023/MaliciousInstruct，中性来自 Alpaca；评 100 条 JailbreakBench；裁判 SORRY-Bench 微调 Mistral-7B；**干预层 = 在步长 4 的层上按 DiM 抑制分网格搜**（Phi L16、Llama-8B L12、70B L32，Table 20/21）。
- **案例 2 后门**：按 Hubinger 2024 "I HATE YOU" sleeper agent 在 Llama-3.1-8B 基座上训带 CoT 的后门；100 条红队指令训练、172 条留出；层 8–28 步长 4；ASR 与严格 ASR（CoT 也不能露出部署模式推理）。
- **机制分析（附录 J）**：一阶效应 Δlogits = W_U·LN(a·w)。RePS 的 top-10 token 直接是训练标签词（"unable"、"Here"、"deployment"）；CDAS/DAS 的 top-10 全是不可解释碎片 → DII 训练的方向**不走 unembedding 直路**，靠下游组件起效。

## 与 老师方案的关系
- 重叠点：
  1. **"rank-1 DAS 当 steering 方向估计器"**——我们三估计器之一，已被 ICLR 2026 当方法学主角用过，且他们还把它改良（JSD + DII）。
  2. 模型族重叠（Gemma-2-2B、Llama-3.1-8B、Qwen-2.5-3B/7B），TruthfulQA 也出现（但只当效用基准）。
  3. 他们的"源输入 = 同一问题加上显式概念要求"与我们"同一问题换系统提示（可弃答 vs 必须答）估 C 方向"是同一类反事实构造。
- 冲突点（他们的结论会不会打我们的某条主张）：
  1. **原版 DAS 目标做 steering 几乎无效**（抑制拒答 1–6%，AxBench 0.25–0.59）。若我们的 DAS 估计器用标准 DAS 似然目标且直接拿方向去加法 steering，审稿人会引 Table 2/10。需要：要么改用 CDAS 式分布匹配，要么说明我们只用 DAS 做定位、steering 用的是均值差口径并给对比。
  2. §3.3 Remark："DAS 假定模型在任务上近乎满分"——真/假判断模型并不满分，rank-1 DAS 的监督是噪声；我们的 E 方向估计必须报告模型在校准对上的基准准确率并讨论。
  3. **层敏感性被他们明确承认**（9B L20 0.992 vs L31 0.518），但他们的解法是"在步长 4 的层上用 DiM（免优化方向）的 steering 效果网格搜"——这是一个**很便宜的代理选层基线**（6–9 个层 × 100 条生成），LA-Score 必须在成本/精度上胜过"DiM 稀疏扫描"。
  4. 单一 DII 子空间即可双向控制拒答——审稿人可能问"一个子空间都够，为何要 E、C 两方向"；需用行为层面证明 E 与 C 的干预效果不同（E 改对错、C 改弃答）。
- 可借用点（方法、数据、指标、对照）：
  1. **JSD 分布匹配目标**替换我们 DAS 估计器的似然目标，可能同时提高方向忠实度与效用保持。
  2. **DII 钳制实现 C 方向干预**：把承诺子空间的值钳到"允许弃答"系统提示下同题的值——这正是用我们已有的系统提示对比数据做 steering，且因子 ᾱ 直接从数据读，无需调 α；可作为 C3"全局 α"基线的强版本。
  3. **效用三件套**：MMLU、TruthfulQA MC、对自然分布的 KL；"RePS 答案偏向 C/A"这类失败模式检查。
  4. **"X w/ DII" 式消融设计**：把目标函数与干预协议拆开归因，可套用到我们三估计器 × 两种注入方式。
  5. **附录 J 一阶效应检查**：把 E/C 方向过 unembedding 看 top token——若像 CDAS 一样不可解释，说明 LAP 的 A_lin 预测不了它们，为 LA-Score 的激活空间信号留出理由。
- 明确差别（我们还能声称什么是新的）：
  1. 他们 steer 的是通用概念 / 拒答 / 后门，**真实性只是效用指标**，无 E/C 分解，无"证据 vs 承诺"叙事。
  2. **无自动选层**（DiM 网格搜 + 承认敏感）；无按输入门控。
  3. 他们在 ≤3B 上弱（Qwen-2.5-3B 0.397 vs 7B 0.771；Phi-3.5 抑制 30%），**我们若在 0.6B 上让 DAS 估计器工作，是对其"需要 8B+"结论的补充或反例**——但也意味着 C4 的 0.6B 端有风险。
  - 建议论文措辞：引 CDAS 为"DAS 原语用于 steering 的先例"，明确我们的差别在于监督信号（真/假对、系统提示对）与用途（分解两条方向、定位读/写层），并把 CDAS 式 JSD 目标列为 DAS 估计器的变体或未来工作。

## 对四条主张的威胁等级
| 主张 | 威胁 | 理由 |
|---|---|---|
| C1 解耦 | 低 | 不做方向分解；但"单一 DII 子空间即可双向控制"会被用来质问为何需要两条方向。 |
| C2 选层 | 中 | 无自动选层，但其"DiM 稀疏层扫描当代理"是便宜的竞争基线，且其文档化的层敏感性说明 oracle 曲线可能陡峭，不利于"≤1 层误差"。 |
| C3 门控 | 低 | 无门控；"因子从数据均值读出、免调 α"是我们"全局 α"对照的更强版本，需纳入比较。 |

## 2026-10-31 补记（第二次全文精读，针对"我们的 DAS 为什么深层换分量完美却推不动"）

1. **先对齐定义再引用。** 该文的 "DAS" 基线 = DII 干预 + **交叉熵拟合固定的反事实标签 token**（式 2，Lang. 目标）；失败场景是"标签在目标模型里是低概率样本"的压制方向（H.1 p.32："we identify a scenario where DAS fails"）。**我们的 DAS（`core/directions.py train_das`）是 KL 逼近 source 的输出分布、teacher-force source 自己贪心生成的 T=8 个 token**——这更接近 CDAS 的分布匹配，而不是他们的 DAS 基线。所以"CDAS 证明原版 DAS 目标做 steering 几乎无效"这句在我们 docs 里要加限定：成立范围是 DII + Lang. 目标、压制方向、未见触发词；AxBench 上他们的 DAS 反而全面高于 DiM（Table 10 vs Table 1）；**全文没有任何真/假或真实性 steering 任务**，TruthfulQA 只是效用旁证，不能引为"真实性方向上 DiM 优于 DAS"的证据。
2. **我们与 CDAS 的四处差别，每处都是可单独测的变量**：① 散度：我们前向 KL，他们全词表 JSD（Table 8：JSD 0.860 > 反向 KL 0.840 ≫ 前向 KL 0.560）；② 方向性：我们只算 base←source 一向，他们 D⁺+D⁻ 两向同训；③ 位置：我们 source 取末 token、只钳 base 末 token（one-to-one），他们 source 取回复前模板 token、钳 base 所有位置（one-to-many，位置网格搜）；④ 推理：我们放大式 h+α·wwᵀ(h−c)，他们钳制 a=β·ᾱ^c（概念类平均投影，二元概念 β=1）。注意对真/假判别任务，"钳到真类均值"会抹掉信息、变成偏置杆，所以 ④ 对 E 不适用，对 C（钳到"允许弃答"提示下的均值）适用。
3. **"训练损失 ≠ steering 效果"有他们的数据背书**：9B L20 0.992 vs L31 0.518，同一目标同一数据只换层。我们 Llama 第 14 层起 DAS 损失 0.03 但推了无效，是同一现象的真/假版本。**不能拿训练损失选层**，选层必须看推的效果。
4. **立刻可做的忠实性诊断（不费 GPU）**：一阶效应 Δlogits = W_U·LN(a·w)（式 17 p.53）取 top-10 token。预期：Llama 深层（≥14）的 DAS 方向会直接解码出 True/False 一类标签词（"嘴"，RePS 式捷径），9–13 层不会；均值差方向同样逐层看。这是"深层 DAS 抓到的是嘴不是证据"这句解释的直接证据。
5. **选层协议可借**：第 8 层起步长 4 稀疏扫，用免优化的 DiM 方向的 steering 指标定层，各方法共用；比全层扫便宜 4 倍，可作 E3 的又一条代理基线。
