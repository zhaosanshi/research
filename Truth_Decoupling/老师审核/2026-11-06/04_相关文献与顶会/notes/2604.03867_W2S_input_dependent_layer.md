# 2604.03867 · Where to Steer: Input-Dependent Layer Selection for Steering Improves LLM Alignment

- 作者 / 机构 / 发表处与年份：Soham Gadgil*、Chris Lin*（共同一作）、Su-In Lee——University of Washington, CSE（Lee lab）。**EMNLP 2026 主会**（arXiv 2604.03867v2，2026-10-15，元数据注记 "EMNLP 2026 (Main Conference) Camera Ready"；v1 2026-04-04）。代码：github.com/suinleelab/where-to-steer（基于 steering-bench）。NIH R01 EB035934 / RF1 AG088824 资助。
- 权威度与严谨度判断：**[顶会已发表]**。优点：两个主模型（Llama-2-7B-Chat 32 层、Qwen-1.5-14B-Chat 40 层）+ Qwen3-32B（64 层）复现；13 个 MWE 多选行为 × 1000 + TruthfulQA（817）+ PKU-SafeRLHF（1000）开放生成；5 次运行报 95% CI；系统/用户提示扰动的 OOD 评测；GPT-5.5 判流畅/重复/连贯；玩具模型存在性证明；编码器、Top-k、标签平滑消融；成本表。短板：**层预测器准确率只有 ~40–45%**（TruthfulQA ~45%、Safety ~40%），增益来自"任何次优层都比固定层好"而不是预测准；**训练标签需要对每个训练样本做全层扫描**（每行为 7–13 GPU 小时，与固定层基线同成本），完全不是免训练；默认依赖 OpenAI text-embedding-3-large（BERT 版增益缩水）；steerability 是多选 log-odds 对 α 的斜率，属代理指标；Table 3 里 Llama 与 Qwen 的 CAA 行数字完全相同（0.715 (0.092) / 0.830），疑排版错误；单目标 steering；无人工评估。

## 一句话核心主张
最优 steering 层随输入而变——Llama-2-7B-Chat 上逐输入最优层与全局固定层平均相差 3.8 层、Qwen-1.5-14B-Chat 相差 6.5 层，改用逐输入最优层可把 steerability（可引导性 · 加不同强度向量时模型偏好随强度变化的斜率）平均提升 55%/86%；于是提出 W2S：用冻结的提示编码器 + 小 MLP 学"输入嵌入 → 最优层"的映射，推理时逐输入选层，在 13 个 MWE 行为和 TruthfulQA/PKU-SafeRLHF 开放生成上对 CAA 与 L2S 两种向量提取法都稳定优于固定层，且在 OOD 提示扰动下保持优势。

## 方法细节
- **记号**：固定层 CAA（Contrastive Activation Addition · 用多对正负回答激活均值差做方向）h̃ = h + α v^(ℓ)；CAST（条件激活引导 · 只对满足条件的输入加向量）是"是否干预"；L2S（Learn to Steer · 学一个输入→向量的网络 g^(ℓ)）是"加什么向量"；W2S 是"在哪层加"：ℓ_i = f(x_i)，f = f_pred ∘ f_enc。
- **理论（Example 1，附录 A）**：构造一个 4-token、3 层玩具模型 + 非线性目标函数 u，证明 CAA 下 x=t1,t2,t3,t4 的最优层分别为 1,2,1,2；注记：若 u 对 logits 线性则第 2 层永远最优，所以输入依赖性来自目标行为对 logits 的非线性。
- **实证（§4，Fig 1）**：对每个输入扫全层取 steerability 最高层 vs 固定层：Δsteerability 全部为正；最优层分布横跨早/中/晚层。
- **W2S 训练**：40-10-50 划分；标签 L* = 对每个训练样本全层扫描取 per-sample steerability 最大层；剪掉从未成为最优的"非活跃层"（Llama 32→~24，Qwen 40→~35）；f_pred 为浅 MLP，交叉熵 + L2，AdamW，5 折 CV 调 lr/隐藏维/层数/权重衰减；编码器候选：LLM 第一层 last/mean token、bert-base-uncased（CLS）、text-embedding-3-large（轮廓系数 0.64，最优）。
- **评价**：Tan et al. 2024 的 steerability = mLD = log p(y⁺) − log p(y⁻) 对 α∈{−1.5,…,1.5} 的最小二乘斜率；"可 steer 样本比例" = 斜率>0 的比例；开放生成版用生成 token log-prob 之和的差。
- **固定层基线**：CAA 全层扫描取平均 steerability 最高层（Llama L11/13，Qwen L21/31）；L2S 先扫 steering 层再扫 context 层。
- **OOD**：只在 BASE（system "You are a helpful, honest and concise assistant."）上训练，测 SYS.POS / SYS.NEG / USER.POS / USER.NEG（把行为描述加进系统或用户消息）。
- **多层扩展（§6.5）**：按预测器 top-2/top-3 层顺序注入。**频率感知标签平滑（附录 K）**：在每样本 top-k 层中选全局最常见者作标签，预测器准确率与下游都提升。
- **成本（Supp Table 15）**：数据收集 7 h（Llama）/11 h（Qwen）每行为，**与固定层基线相同**（都要全层扫描）；训练 0.8 s（CAA）/27–34 s（L2S）；推理每样本多 0.2–0.5 s。

## 与 老师方案的关系
- 重叠点：
  1. 都主张"选在哪层干预"是独立于"方向怎么估"的设计维度；都把 TruthfulQA 当测试域；都把 LayerNavigator 列为固定层先行工作。
  2. 都承认"按输入调干预"有价值——他们调层，我们按知识探针门控 α/方向。
- 冲突点（他们的结论会不会打我们的某条主张）：
  1. **§4 的事实结论直接动摇"一个全局最优层 W*"的前提**：逐输入最优层偏离固定层 3.8–6.5 层、横跨早中晚。若真实性方向也如此，我们"选层误差 ≤1 层"是在跟一个本身只是"数据集平均"的 oracle 比，意义被削弱。必须自己画出 E/C 方向逐输入最优层分布：若集中（如 ±1 层），全局 W* 成立且是对 W2S 的反例；若分散，LA-Score 需退为"选全局折中层"并坦白。
  2. **他们在 TruthfulQA 上已用"按输入选层"提升了 CAA 的真实性 steering**（0.715→0.830，L2S 0.886→3.175）——审稿人会问 C3："为何门控 α 而不是门控层？两者比过没有？"
  3. 预测器 40–45% 准确率仍带来增益 → 最优层附近是平台（第 2、第 3 优都胜固定层）。这说明"≤1 层误差"可能是低门槛，真正该报的是下游增益百分比。
- 可借用点（方法、数据、指标、对照）：
  1. **steerability 斜率 + 可 steer 样本比例**作 C2/C3 的统一口径（比单一 α 下的准确率更稳）。
  2. **OOD 提示扰动协议（SYS/USER × POS/NEG）**——对我们尤其关键：C 方向本来就是用系统提示对比估出来的，必须展示换系统提示后 C 方向 steering 仍有效、不只是"记住了那两句提示"。
  3. **逐输入最优层分布图（Fig 1）**作为我们 E/C 两方向的必备诊断图。
  4. 频率感知标签平滑、"第 k 优层"分析可用于论证平台效应。
  5. Qwen3-32B 作为向上尺度外推点；GPT 裁判三维质量检查。
- 明确差别（我们还能声称什么是新的）：
  1. **成本结构相反**：W2S 需要对每个训练样本做全层扫描当标签（7–13 GPU 小时/行为）+ 训练预测器 + 外部嵌入 API；LA-Score 是 32 对校准样本、一次前向缓存、零训练的前验分数。两者是"昂贵逐输入"与"廉价全局"两端，可组合。
  2. **门控轴不同**：他们按输入换层、方向与 α 固定；我们层固定、按知识状态（已知/部分/未知）换 α 和方向——正交，且我们的门控有可解释的知识语义。
  3. **无读写分析、无方向分解**：TruthfulQA 只是 15 个行为之一，用 CAA 单方向。
  4. 他们的"最优层"是 per-sample 斜率的 argmax；我们的是 dev 集行为增益。
  - 建议论文措辞：引为"层选择重要性的最新证据与昂贵的学习式替代"，LA-Score 定位为免训练全局选层；增加实验：E/C 方向的逐输入最优层离散度，若小则直接作为"全局层足够"的证据。

## 对四条主张的威胁等级
| 主张 | 威胁 | 理由 |
|---|---|---|
| C1 解耦 | 无 | 单方向、不做分解。 |
| C2 选层 | **中** | 不做免训练预测，不直接抢 LA-Score；但其"最优层随输入变 3.8–6.5 层"削弱"单一最优层 + ≤1 层误差"的意义，并提供一个强的学习式基线；若其准确率 40% 的预测器都能赢固定层，我们必须报下游增益而不只是层误差。 |
| C3 门控 | **中** | 已在 TruthfulQA 上用逐输入选层提升真实性 steering；我们的门控需与"逐输入选层"比较或至少论证互补。 |
| C4 泛化 | 低 | 7B–32B 聊天模型、15 个数据集；我们 0.6B–8B 三族四数据集的真实性覆盖仍独立。 |
