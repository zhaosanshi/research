# 2406.01563 · LoFiT: Localized Fine-tuning on LLM Representations

- 作者 / 机构 / 发表处与年份：Fangcong Yin、Greg Durrett（UT Austin）；Xi Ye（Princeton）。**NeurIPS 2024 主会**：proceedings.neurips.cc 摘要页标 "Advances in Neural Information Processing Systems 37 (NeurIPS 2024) Main Conference Track"，pp. 9474–9506，DOI 10.52202/079017-0301；neurips.cc/virtual/2024/poster/94329 为 poster，链 OpenReview dfiXFbECSZ；arXiv v2（2024-10-31）注 "NeurIPS 2024 Camera Ready"（均已核实）。正式版 PDF 与 arXiv v2 逐句比对：只多一条参考文献（注意力输出上的 logit lens 做法）和投稿自查清单，正文与数字一致；下文页码按 arXiv v2。代码 github.com/fc2869/lo-fit。
- 权威度与严谨度判断：**[顶会已发表]**。优点：3 个模型（Gemma-7B、Llama 2-7B / 13B）× 7 个任务；2 个随机种子取平均；选头有 4 种对照（随机头、探针选层、偏置范数选头、ITI 选头）；与 LoRA / RED / ReFT 三种 PEFT 同表比较；跨任务换头的差异用配对 bootstrap 检验；有 OOD（分布外）能力保持测试。弱点：**TruthfulQA 用 DPO 而不是交叉熵**；TruthfulQA 是同分布训练后测（326 题训练、两折交叉验证）；开放生成只有 GPT-4 一个裁判、表 4 无误差条、只测 Llama 2 基座两档；RED 是作者自己复现的（当时无官方代码）；ReFT 在 TruthfulQA 上只干预首 1 + 末 1 个 token；最大 13B。

## 一句话核心主张
冻结整个模型，先给每个注意力头学一个缩放向量、按范数挑出最重要的 3%–10% 头，再只在这些头的输出上学一个随机初始化的加性偏移向量——这种"学出来的局部偏移"在 TruthfulQA、MQuAKE、CLUTRR 上大幅胜过 ITI / RepE 这类"从激活里提取的向量"，可训参数比 LoRA / RED 少 20–200 倍却与之相当；TruthfulQA 开放生成的 True×Info 也明显高于 ITI。

## 方法细节
- 术语：attention head（注意力头 · 每层里并行的几十个小注意力单元）；offset / bias vector（偏移 / 偏置向量 · 固定加到某处激活上的向量）；ITI（Inference-Time Intervention · 推理时干预 · 用探针挑头、把"真−假"激活均值差加到头输出上）；RepE（Representation Engineering · 表征工程 · 用对比提示取方向再加回去）；PEFT（parameter-efficient fine-tuning · 参数高效微调 · 只训极少量参数）；DPO（Direct Preference Optimization · 直接偏好优化 · 用"好答案 vs 坏答案"成对数据直接调参，不另训奖励模型）；MC1 / MC2（TruthfulQA 多选题两种计分 · 按对数概率挑答案）；True×Info（真实率 × 信息量 · TruthfulQA 开放生成的综合分，防止"一律无可奉告"刷真实率）。
- 第 1 步·选头（§3 Step 1）：每个头输出 z^(l,i) ∈ R^{d_head} 乘 (1 + A_l^i)，A 为可学缩放向量；冻结全部预训练权重，端到端训练 A，加 L1 稀疏正则；按 ‖A_l^i‖ 取 top-K 头。脚注 2：改用偏移向量范数选头效果更差。
- 第 2 步·偏置调优（§3 Step 2）：只在被选头上加可学偏移 z ← z + v_l^i，冻结其余参数，用同一训练数据训练 v；推理时同样加。最终模型只保留 v（A 丢弃）。
- 等价改写（我们的推导，非原文）：v 加在输出投影 W_O 之前 → 对残差流（residual stream · 各层累加的主干表征）的作用 = 每层一个**与位置、与输入都无关的常数向量** Σ_i v_l^i W_O^(i)。所以 LoFiT ≈ "多层、每层被限制在所选头输出子空间里的加性 steering vector（引导向量 · 加进残差流的一条固定方向）"，与 BitFit（只调偏置项的微调）同类。
- 位置（§4）：训练时"对输入序列每个 token 位置学同一组缩放和偏置"；推理"每个解码步都加"。
- 目标（§4、附录 D）：CLUTRR、MQuAKE 用金标答案交叉熵；**TruthfulQA 用 DPO**（金标真答 vs 错答成对），理由是"SFT 在 ITI 论文里被证明无效"；DPO β = 0.5。§4 原文只说 TruthfulQA 的 fine-tuning 用 DPO，未区分两步。
- 初始化（§3、附录 D.1）：A、v 都从 N(0, σ) 随机初始化，σ_A = σ_v = 0.001，"对随机种子稳健"——**不从 ITI 方向或任何提取方向初始化**。
- 数据量与训练：每任务 ≤500 条；TruthfulQA 按 ITI 划分 326 / 82 / 407 题、两折交叉验证；5 epoch、batch 8、AdamW。
- 头数：§5 用 3%（Gemma-7B 16 / Llama 2-7B 32 / 13B 48 个头）；§6 与 PEFT 比用 10%（48 / 96 / 160 个头）。
- 模型：默认基座（非 chat）；OOD 实验用 Llama 2-7B-Chat。
- 评测：MC1 / MC2 按对数概率；开放生成用 gpt-4-0314 判真（提示里给该题金标对 / 错答作参考）和判信息量（few-shot 打分，≥0.5 记为有信息），报 True、Info、True×Info。

## 与本方案（E/C 双重分离 + 等覆盖率组合）的关系
- 重叠点：
  1. **"学出来的表征偏移 > 从激活里提取的方向（ITI）"在 TruthfulQA 上已于 NeurIPS 2024 发表**：随机初始化、冻结底座、几百条数据，多选与开放生成都大幅胜 ITI（表 1、表 4）。我们的生成适配（Qwen3-8B 第 34 层，h' = h + α·w·wᵀ(h − c)，只训 d 维单位向量 w，金标答案长度归一化交叉熵，~92–192 对）在任务、数据规模、"冻结底座 + 只学极少表征参数"三点上与它同构。
  2. 位置口径同类：它是"训练时所有输入位置、推理时每个解码步"；我们是"提示末位 + 每个预测答案 token 的位置"，覆盖面略窄。
  3. 开放生成同样是"LLM 裁判 + 金标参照"，只是它拆成 True 与 Info 两维。
- 冲突点：
  1. **审稿人会说"生成适配 = 把 LoFiT 搬到残差流上的单方向版"，或直接归为 AxBench 的 SSV（supervised steering vector · 监督引导向量 · 冻结模型、用语言建模损失直接训一条向量）**。LoFiT 本身就是每层常数加性向量（见上文等价改写）；我们只是把"常数加法"换成"沿 w 的投影放大"（= 秩 1、权重绑定的 LoReFT）。作为方法无新意可言。
  2. **随机初始化在 LoFiT 里就够用**（σ = 0.001）。我们自己的数据也是随机初始化（182）≈ DAS 初始化（189），不显著，均值差初始化（158）反而更差——"DAS 初始化带来增益"无法主张；N3 若拿这组数当证据，会被 LoFiT"随机初始化即可"直接削弱。
  3. LoFiT 弃用交叉熵、改用 DPO，理由是"SFT 在 TruthfulQA 上无效"（ITI 论文表 1 里全参 SFT 的 True*Info 低于 ITI，见 2306.03341_ITI.md）；我们用交叉熵也涨分，审稿人会追问口径：单一裁判、只看"答对"、不看信息量 / 作答率。
- 可借用点：
  1. **True / Info 两维拆分 = 粗粒度的 E / C 拆分**：表 4 里 ITI 把 True 推高的同时 Info 明显下降——"真实性干预"有一部分是靠少答 / 答得空换来的（ITI 原文附录也承认很多"翻成真"是改口 "I have no comment"）。我们的生成适配必须同时报作答率 / 信息量，否则 140→189 可能混入 C 的效应；这正是 N1 双重分离要排除的混淆，可作为论文里"为何必须做 2×2"的现成例子。
  2. 对照设计可平移：随机头 vs 选定头（表 2）≈ 我们的随机初始化 vs DAS 初始化。LoFiT 的结论是"位置（哪些头）要紧"，我们的结论是"初始方向不要紧"，两句可并列写成"训练配方决定增益，方向来源不决定"。
  3. 现成同口径基线：ITI、RepE、LoRA、RED、LoReFT 在 TruthfulQA 上都有数（表 1、3、4），生成适配一节可直接引作对照。
  4. OOD 能力保持检查（表 5）：适配训完后测 TriviaQA / NQ / MMLU 是否掉分，我们可照做。
- 明确差别（我们还能声称什么是新的）：
  1. 无 E / C 两方向，无判别力（J / AUROC）与作答率的分离测量，无等覆盖率选择性作答。
  2. 不讨论方向估计器（DAS vs 均值差），只比"学出来的 vs ITI / RepE 提取的"。
  3. 生成适配本身不能当方法贡献写，只能写成"沿用 LoFiT / SSV / 秩 1 ReFT 的标准做法，把它用在 E 方向上"；能主张的新东西只能来自测量：E 适配提高正确率而作答率不变（前提是真测了作答率）。

## 对三条主张的威胁等级
| 主张 | 威胁 | 理由 |
|---|---|---|
| N1 双重分离 | 低 | 只有一个"真实性"干预，无作答方向，未测判别力与作答率；其 True↑ Info↓ 现象反而说明 N1 的分离检验有必要。 |
| N2 等覆盖率组合 | 低 | 无选择性作答、无覆盖率控制；True×Info 把"无可奉告"交给信息量裁判处理，不是等覆盖率口径。 |
| N3 DAS 胜均值差 | 低-中 | 已发表"随机初始化学出的偏移远胜 ITI 均值差方向"，"学出来的 > 均值差"不新；若 N3 的证据来自生成适配的初始化对比（DAS vs 随机不显著），会被它直接削弱。 |

## 值得引用的原句（≤3 句，标注 section/页）
1. "When training with LoFiT, we learn the same scalars and biases for every token position of the input sequence. When performing inference with LoFiT, we use greedy decoding and we add the bias terms at the targeted attention heads to every decoding step." （§4, p.5）
2. "For TruthfulQA, we use direct preference optimization [37] by pairing the gold truthful responses and untruthful responses as preference data for fine-tuning, as SFT has been shown ineffective in [21]." （§4, p.5）
3. "During training, we learn V with the cross-entropy loss on the same training data. v_l^i is initialized from N(0, σ_v) and σ_v is an adjustable hyperparameter." （§3 Step 2, p.4）
