- 权威度与严谨度判断：**大机构预印本**。理由：主模型 1 个（Llama-3.1-8B-Instruct）+ 复现 1 个（Qwen2.5-7B-Instruct，附录 B.3）；因果干预实验每点平均 200 条、头级实验 50 条；steering 向量用 200 对（短答）/600 场景（谎言子类）；有 MMLU 能力保持检查；评分用 LLM judge（10 分 liar score），无人工评估；对照组较弱（没有随机方向/随机头对照，层选择没有和其它准则比较）；附录 C.3 的文字甚至留有"if observed consistently"这类未定稿语句，说明稿子还在打磨。

## 一句话核心主张
把 lying（说谎 · 知道真相却为了别的目标故意说假话）和 hallucination（幻觉 · 不知道所以说错）在定义上分开——P(hallucination) := 1 − P(truth)，P(lying) := 1 − P(truth | lying intent)——然后用 logit lens（对数几率透镜 · 把中间层残差直接投到词表看它"此刻想说什么"）、零消融和 contrastive activation steering（对比激活引导 · 用"叫它说谎 vs 叫它说真话"两组 prompt 的激活差作为方向向量加到残差流上）证明：Llama-3.1-8B 在 chat 模板的 dummy token（占位 token · `<|eot_id|><start_header_id>assistant<|end_header_id|>` 这些不带内容的模板符号）上"预演"谎言，谎言在第 10–15 层成形，只需零掉 1024 个头中的 12 个就能把说谎率压到幻觉率水平；steering 系数 +1.0 把被要求说谎时的诚实率从 20% 提到 60%，MMLU 只从 0.613 掉到 0.597。

## 方法细节
- **三种设定**：短答（单词/单 token）、长答（多句）、多轮对话（销售员 vs 买家，3 轮）。system prompt 给显式说谎意图（"Tell a lie"）或隐式意图（"不惜一切卖出产品"）。
- **量化**：P(truth) = 模型在所有正确答案上的概率质量；短答下 P(hallucination)=1−P(truth)（诚实意图），P(lying)=1−P(truth|lying intent)。长答改为采样一条回复，用 LLM judge 打 10 分 liar score：1–3 真话、4–6 "bad lie"（一眼假）、7–10 "good lie"（有说服力）；具体 lie_i(a)=9 为欺骗性谎言、6 为较弱谎言、3 为胡言乱语。
- **机制分析（§4.1，Llama-3.1-8B-Instruct）**：
  - Logit lens：被要求说谎时，中晚层在 dummy token 位置就预测出候选谎言（"Sydney"、"Melbourne"），最后一层才切回模板 token；说真话时也有"预演"，但说谎的预演从 dummy token 开始发散。
  - 零消融（200 例平均，5 层窗口）：零掉 dummy token 上第 1–15 层的 MLP → liar score 大幅下降并回到说真话（Fig.8 最大跌幅在第 2 层窗口）；说真话时同样消融影响很小 → dummy token 作为"草稿纸"是说谎专用的。注意力路径：dummy token 在 ~第 10 层读取问题主语（"Australia"），~第 11–12 层读取意图词（"lie"/"deceive"）；最后一个 token 在 ~第 13 层从 dummy token 读取汇总信息。**关键层 10–15。**
  - 头级稀疏性（50 例）：第 13、15 层里只有极少数头（L13H23、L15H8 等）起作用。贪心选 top-k 头零掉：在"幻觉率 <0.1 且说谎率 >0.9"的题上，零掉 12/1024 个头即把 P(lying) 压到 P(hallucination) 水平（Fig.4）；零掉 20 个头可修复长答谎言（Jeff Bezos 例，Table 1）。
- **Steering（§4.2）**：200 对对比 prompt（"Describe the capital of France, but intentionally state that it is Berlin" vs "...factually"），对每层差向量做 PCA 取第一主成分 v1^(l) 为说谎方向。**层选择 L={10,…,15}**：依据 (a) §4.1 因果定位，(b) "perfect classification criterion"（完美分类准则 · 该层上 200 对差向量在 v1 上的投影全部为正）。干预：h ← h + λ·v。定义 lying signal（说谎信号 · 当前 token 激活在说谎方向上的投影）：0–10 层接近 0，10–15 层方差大（谎言成形），15–31 层稳定偏高（谎言润色）。
- **PCA 可视化（§4.2 / 附录 C.4）**：Truth（诚实意图+答对）、Hallucination（诚实意图+答错）、Lie（说谎意图+答错）、Honesty-control（说谎意图+诚实 steering）四组。幻觉比谎言更靠近真话；三者在深层更分开；steering 在 10–14 层把 Lie 簇推向 Truth，之后未干预的层继续把它拉过去。作者承认 steering 方向并不直指 Truth 簇中心，系数过大会掉质量。
- **谎言子类（§4.3 / 附录 C.5）**：white vs malicious、commission（作为之谎 · 明说假话）vs omission（不作为之谎 · 隐瞒关键信息）。600 场景（20 话题 × 30 模板对）得向量，评测各 100 条。
- **销售员（§4.4 / C.6）**：Honesty Score（judge 对照产品真相打 1–10）与 Sales Score（judge 不看真相只看话术打 1–10）；20 种人格 prompt 描出基线 Pareto 前沿；正向诚实 steering 把前沿推向左上。
- **Qwen2.5-7B-Instruct（附录 B.3）**：结构相同但层更晚（13–23 层），关键头 L11H21、L13H1、L15H23。

## 与 老师方案的关系
- 重叠点：
  - **概念骨架高度重叠**：他们的 hallucination（不知道→错）vs lying（知道→故意错）区分，就是我们"证据 E"与"意图/承诺 C"两轴的说谎版；他们 PCA 图里 Truth / Hallucination / Lie 三簇可分、幻觉更靠近真话，等价于说"模型内部能区分'没证据'和'有证据但不照说'"。
  - **估计器重叠**：prompt 对比均值差 + PCA 第一主成分，就是我们 C 方向的 mean-diff 估计器（他们多做一步 PCA）。
  - **免训练选层已有雏形**：他们的 perfect classification criterion（200 对投影全正）是一个零训练、纯数据驱动的层筛选准则，和 LA-Score 的定位重叠；而且他们**选层结果 10–15 与因果定位一致**，并明确区分"谎言成形层 10–15（干预处）"与"说谎信号最强层 15–30（读出处）"——这就是"读层≠写层"的另一处实证（同样未命名）。
  - **能力保持**用 MMLU，与我们一致。
  - **Pareto 前沿**（诚实 vs 任务得分）与我们"纠正/损伤/转弃答"三分法想回答的问题同构：干预的收益与代价怎么权衡。
- 冲突点（他们的结论会不会打我们的某条主张）：
  - 他们的 steering 在 MMLU 上有可测的 −1.6～−1.9 点代价；若我们的全局 α 对照也掉分，正好支持"要门控"（C3）；但若我们声称"能力无损"，审稿人会拿这张表要求我们给出同口径数字与显著性。
  - 他们的"intent"是**说假话的意图**，不是**作答意愿**；如果我们把 C 叫作"承诺方向"，必须明确与"lying intent 方向"不是一回事——否则会被问"你的 C 和 Huan et al. 的 lying direction 余弦多少"。
  - 他们在 Llama-3.1-8B 和 Qwen2.5-7B 上找到的关键层不同（10–15 vs 13–23），说明层位置模型相关——这**支持**C2 需要自动选层，但也意味着如果我们跨模型报固定层，会被这篇反驳。
- 可借用点（方法、数据、指标、对照）：
  - P(lying)/P(hallucination) 的形式化定义，可直接改写为我们"已知题/未知题"的概率版定义（P(truth|honest) 高 = 已知）。
  - perfect classification criterion 作为 LA-Score 的**对照基线**（必须比它好或说明差别）。
  - dummy token / chat 模板 token 位置分析：我们的 C 方向（system prompt 诱导）很可能也在模板 token 上成形，应做位置消融。
  - Truth / Hallucination / Lie / Steered 四簇 PCA 图作为直观图示。
  - Honesty-vs-utility Pareto 前沿作为补充图。
- 明确差别（我们还能声称什么是新的）：
  - 他们没有弃答/IDK 行为，没有"已知题不受损、未知题多弃答"的拆分评测，没有门控。
  - 他们没有比较估计器（无 DAS、无探针 vs 均值差对比），没有陈述级 J/B 口径，没有把"方向"和"行为可分性"做成可证伪的双重分离实验（E 改 J 不改作答率 / C 改作答率不改 J）。
  - 他们层选择只给结果不给评分、不与其它准则比；模型只有 7–8B 两个，无小模型。

## 对四条主张的威胁等级
| 主张 | 威胁 | 理由 |
|---|---|---|
| C1 解耦 | 低 | 概念上支持（幻觉/谎言/真话三簇可分），但他们的 intent 轴是"说假话"不是"作答意愿"，没有正交性或双重分离证据，不与我们冲突；需在相关工作里明确区分两种 intent |
| C2 选层 | 中 | 已有免训练数据驱动选层准则（perfect classification）并给出"成形层 10–15 ≠ 信号最强层 15–30"的实证；LA-Score 必须与之对照并证明更优或更通用 |
| C3 门控 | 低 | 无门控；但 MMLU 掉 1.6–1.9 点的全局 steering 数据可作为"全局 α 有代价"的旁证，同时提醒我们能力保持要给显著性 |
| C4 泛化 | 低 | 两个 7–8B 模型、机制一致但层不同；对我们 0.6B–8B 三族无直接冲突，反而支持按模型选层 |

## 值得引用的原句（≤3 句，标注 section/页）
1. "We define P(lying) := 1 − P(truth | lying intent). Most LLMs are tuned to follow instructions, therefore P(lying) > P(hallucination)." （§4 Quantifying Lying，p.4）
2. "(i) layers 0-10 with minimal lying signals are involved in fundamental and truth-oriented processing; (ii) layers 10-15 with a high variance in lying signals are busy with ensuring the request to generate a lie; (iii) layers 15-31 with steady lying signals further improve the lying quality." （§4.2，p.7）
3. "Hallucinations are generally closer to Truths than Lies are, and these distinctions become more pronounced in deeper layers. This suggests an inherent, albeit imperfect, awareness within the model regarding the veracity of its potential outputs." （§4.2 Visualizing the Impact of Steering，p.7）
