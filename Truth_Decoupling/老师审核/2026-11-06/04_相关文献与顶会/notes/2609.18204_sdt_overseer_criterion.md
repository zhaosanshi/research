# 2609.18204 · Beyond Accuracy: How Procedural Traces Shift the Decision Criterion of LLM Overseers
- 作者 / 机构 / 发表处与年份：Zihan Chen、Di Zhu（Stevens Institute of Technology）、Lei Zheng（UMass Boston）、Weiling Li（Stony Brook）。arXiv 2026-09（v1）。脚注自述 **"Accepted at the 60th Hawaii International Conference on System Sciences (HICSS)"**——HICSS 是信息系统（IS）领域会议，不是 ML/NLP 顶会。
- 权威度与严谨度判断：**普通预印本（IS 会议已接收，统计做得很规矩，但规模小、领域窄）**。理由：5 个模型（含 2 个闭源 Claude）、仅 19 个任务项、一个领域（Yelp 餐厅合规推荐）；设计是完全交叉（fully crossed · 每个因子每个水平都两两组合）4,560 次判断，推断按 item 聚类、做了 leave-one-item-out、item 固定效应、1,000 次 bootstrap；原因编码有 2 个 LLM 裁判 + 2 名人工标注者（103 条子样本，κ 0.71–0.87）；承诺公开刺激材料与脚本。弱点：hit rate 在天花板（≈100%），所以 d′ 的估计几乎全由 false alarm 驱动；无人类 overseer 对照臂。

## 一句话核心主张
用信号检测论（Signal Detection Theory, SDT · 把"分得清不清"和"下手狠不狠"拆成两个数）审计 LLM-as-a-judge（LLM 当裁判 · 让一个模型审另一个模型的输出）：更详细的"我已经核查过了"流程叙述**不会**降低裁判的判别力 d′（敏感度 · 真错误和真正确在裁判眼里拉开多远），而是把决策准则 c（criterion · 裁判在哪里画线决定拒绝）往"拒绝"方向推，让裁判把正确的工作也错杀——只看 accuracy 完全看不见这件事。

## 方法细节
- **被试（overseer）**：claude-opus-4-6、claude-opus-4-7（闭源）、minimax-m2.5、gemma-3-27b-it、qwen3-next-80b-a3b（开源权重）。温度 0.7（opus-4-7 不接受温度参数，用默认）。
- **刺激**：19 个合规式推荐任务（Yelp Open Dataset 真实评论，三个美国城市），每题有一个满足全部标准的正确选项和一个**恰好违反一条**客观标准的错误选项；揭示违规的那条评论**永远在屏幕上**（所以漏检不能怪信息缺失）。
- **操纵（只改展示，不改答案和证据）**：
  - Trace（流程叙述）4 级：none / concise（4 步）/ detailed（逐标准 7 步 + 自我核查语）/ flawed-verification（8 步，对错误项额外加一句假的"我已专门核实过 budget"）。模板生成，5 个模型看到的一样。
  - Attribution（证据归属）2 级：unattributed（每条评论只标 feature 和 sentiment，不标说的是哪家店）/ attributed（加 "about: Chateau West" 标签）。
- **设计**：5 模型 × 19 题 × 2 正误 × 4 trace × 2 attribution × 3 次运行 = 4,560，解析成功 4,551（99.8%）。
- **SDT 量**：REJECT 为"阳性"。hit = 错误项被拒；false alarm = 正确项被拒。d′ 与 c 用 Hautus (1995) 的 log-linear 极端比率修正（防 hit=100% 时 z 值无穷）。另记 right-reason hit（拒绝时是否点名了真正违反的那条标准）。
- **推断**：false rejection 的 logistic 回归，自变量 trace dose（0–3）、attribution、交互，SE 按 item 聚类。
- **原因编码**：934 条错杀理由分 4 类（attribution gap / over-skepticism / substantive / other），2 个 LLM 裁判（一个面板内，一个 claude-opus-4-8 面板外）独立标注，κ=0.89；2 人工标 103 条，与裁判 κ 0.71–0.76，互相 κ 0.87。

## 与 老师方案的关系
- 重叠点：**这是目前我见到的最直接的"把 SDT 的 d′ / c 拆解用到 LLM 评测"的先例**。我们的陈述级口径 J = TPR+TNR−1（Youden's J · 非参数版判别力）与 B = P(判 True)（标签偏置 · 相当于准则 c 的非参数替身），和他们的 d′ / c 是同一个思想。他们的发现"一个纯展示层/prompt 层操纵只动 c 不动 d′"，在行为层面就是我们 C（承诺）方向要做的事：改作答意愿，不改判别力。
- 冲突点：对我们四条主张没有直接打击；但**降低我们"首次把判别力与决策准则分开评 LLM 真实性"这一叙事的新颖度**。他们在 §1 自称 "To our knowledge it has not been used to isolate how procedural traces affect an LLM overseer"，说明 SDT 在 LLM 评测里到 2026 年仍少见，但已不是零。我们必须引用并明说差别。
- 可借用点：
  1. **Hautus (1995) log-linear 修正**：若我们除 J 之外还报 d′，极端率（TPR=1 或 FPR=0）必须修正，否则 z 无穷大。
  2. **"accuracy 掩盖准则漂移"的表格样式**（Table 2 一行 accuracy / hit / FA / d′ / c）直接可搬到我们的 E vs C 干预结果表。
  3. **right-reason hit** 思路：我们问答级的"纠正"要不要再查一下是不是"因为对的理由改对"（如 TruthfulQA 的答案有没有真的引用正确事实），否则纠正可能是碰巧。
  4. **置信度不能当门控信号**（§5.6）：我们的按输入门控若用模型自身置信度/logit 作为门控变量，要先验证它在"该弃答"和"不该弃答"两类上真的分开。
  5. 统计做法：按 item 聚类的 logistic 回归 + leave-one-item-out + bootstrap，比只报均值±std 更能过审稿。
- 明确差别（我们还能声称什么是新的）：他们是行为层（prompt 操纵裁判），我们是机制层（残差流方向干预）；他们只有一个被操纵量（c），我们声称找到两个**正交可分别控制**的内部方向，E 动 d′/J、C 动 c/B；他们的任务是裁判别人的输出，我们是模型自己陈述真假与问答。可以说："Chen et al. 在行为层观察到 prompt 只移准则不移敏感度，我们在表征层给出了它对应的方向，并证明可以独立操控另一个（E）方向。"

## 对四条主张的威胁等级
| 主张 | 威胁 | 理由 |
|---|---|---|
| C1 解耦 | 低 | 不构成反例，反而是行为层的旁证（prompt 只动 c 不动 d′）；唯一代价是"d′ vs c 拆分"叙事不能自称首创。 |
| C2 选层 | 无 | 不涉及内部表征与层选择。 |
| C3 门控 | 低 | §5.6 警告：模型置信度与对错几乎不相关（qwen 差 0.5 分），若门控依赖置信度需另行验证。 |
| C4 泛化 | 无 | 不涉及。但他们 5 模型异质性极大（opus 不动、qwen 全动），提醒我们跨模型族结论要逐模型报，不能只报合并均值。 |

## 值得引用的原句（≤3 句，标注 section/页）
1. "A single accuracy score, however, conflates two quantities long separated in signal detection theory: sensitivity (can the overseer tell correct work from flawed work?) and response bias (how much doubt does it require before it rejects?)." （§1，p.2）
2. "As the trace grows more detailed, pooled accuracy falls from 0.80 to 0.70 while d′ stays near 2.4 to 2.7, so the entire accuracy drop is the criterion sliding." （§5.2，p.6）
3. "a sensitivity deficit calls for a more capable model, a criterion problem for recalibrating how much the overseer demands before it rejects." （§6.1，p.9）
