## 一句话核心主张
"答得准"（accuracy）和"该拒的时候拒"（knowledge-aware refusal · 不知道就说不知道）是两种**独立**的能力：提出 Refusal Index（RI · 拒答概率与答错概率的 Spearman 秩相关），用"两遍评测"（第一遍允许拒答，第二遍强制作答被拒的题）从二值观测里经高斯 copula 极大似然估出来。RI 在改提示词让拒答率大幅变化时**基本不动**（比启发式指标稳 70%），和准确率只有 R²=0.24 的弱相关，模型家族比规模和准确率更能预测它；现有 SimpleQA 的 F 分等启发式指标随拒答率乱飘（最多 70%），测的根本不是一个稳定的能力。

## 方法细节
- **定义**（§3）：错误指示 W_i=1{f(x_i)≠y_i}（含拒答），拒答指示 R_i=1{f(x_i)=⊥}；潜变量错误概率 w_i、拒答概率 r_i；RI = ρ_S = Corr(Rank(r_i), Rank(w_i))。完美知识型拒答 ⇔ 拒答概率随错误概率单调递增。强调这是**判别型**（rank）指标，不是 ECE 那种绝对误差型，所以对总拒答率不敏感。
- **两遍评测**（§3.1，图 2）：第一遍 system prompt 允许拒答（输出 `<answer>UNANSWERED</answer>`），记 R_i；第二遍只对被拒的题换 prompt "always give an answer, never return UNANSWERED"，记 W'_i。合成正确性 Ŵ_i = R_i·W'_i + (1−R_i)·W_i。把 (R, Ŵ) 看成二元标准正态按阈值 τ_R=Φ⁻¹(1−r)、τ_W=Φ⁻¹(1−μ) 截断（tetrachoric 相关），四格计数 n_ab 极大似然估 ρ，再 ρ_S = (6/π)·arcsin(ρ/2)。附录 J 给了 Python 代码。
- **改拒答率的四档提示**（表 5）：Low（"只有有信心才答"，示例 0/10 拒）、Normal（1/10）、High（4/10）、Highest（"非常谨慎，宁拒不错"，6/10）。附录 I：不同提示下**共同作答题目的正确性一致率 >90%**，说明提示只改拒答倾向、不改答题质量。
- **判分**：与 SimpleQA 相同，GPT-4o-mini 判 CORRECT / INCORRECT / NOT_ATTEMPTED；第二遍里 NOT_ATTEMPTED 记为错。温度 0.7、top-p 0.95。

## 与 老师方案 / 我们论文的关系
- **这是我们 H2 的行为学版本，已经发在 ICLR 2026**：他们用来改拒答率的四档 system prompt（"只有有信心才答" ↔ "非常谨慎宁拒不错"）正是我们估承诺方向 C 的那一对对比提示；他们的结论——"提示引起的拒答率变化只是移动了拒答概率分布，没有改变拒答概率与错误概率之间的相关"（§4.2 末句）、共同作答题正确性一致 >90%（附录 I）——就是"承诺是准则移动，不是判别力变化"。**我们在陈述级、三模型、α 扫描上看到的"C 推了作答率、同题 J/B 不变、弃答有选择性"与此完全同构。** 所以论文里不能说"没人发现过"，要说：他们在黑盒行为层发现了这个现象，我们找到残差流里实现它的那根 rank-1 方向，并证明现有真实性 steering 推的就是它。
- **RI 是我们该用的弃答质量指标**：我们现在报的"新增弃答里基线答错 vs 答对的比例"（2–2.5×）是 RI 的粗糙版。改用 RI（或其连续版：弃答概率与错误的 AUROC）有三个好处：有出处、对作答率不敏感、能直接和他们 16 个模型的数字比。承诺方向 steering 的"干净"应定义为 **ΔRI≈0**（纯准则）；门控（C3）的目标应定义为 **ΔRI>0**，而他们已证明提示词做不到这一点——这是门控必须跨过的门槛，也是门控若成功的卖点。
- **两遍评测可以直接修老师方案 §4.1 的已知/未知切分**：被拒的题强制作答一遍，就知道它是"知道但不想说"还是"真不知道"，比按 baseline 对错切干净。
- **不占我们的位置**：不做内部方向、不做干预、不碰证据侧（J）、不做 2×2。"知道（答得准）≠ 说出来（该拒才拒）"是他们的 claim，但是在"能力"层面；我们的 claim 在"机制"层面且含证据侧。
- **可借用**：① RI + 两遍评测协议；② 等 RI 曲线（iso-RI）作图；③ 提示间正确性一致率 >90% 的检验（我们可对 C 方向 steering 前后做同样检验）；④ 表 2 的"归一化差 + 变异系数"报法；⑤ 附录 L 的提醒：线性探针 P(IK) 会掩盖过度自信——我们的知识探针门控要用 RI 校验而不是只看探针 AUROC。
