# 2509.22449 · Detecting (Un)answerability in Large Language Models with Linear Directions

- 作者 / 机构 / 发表处与年份：Maor Juliet Lavi、Tova Milo、Mor Geva——Blavatnik School of Computer Science and AI, Tel Aviv University。**EACL 2026 主会长文**（ACL Anthology 2026.eacl-long.29，Volume 1: Long Papers，pp. 682–699，Rabat）；arXiv 2509.22449v1，2025-09-26。代码：github.com/MaorLavi/unanswerability-directions。资助 Alon 奖学金、Intel Rising Star、ISF 1083/24、2707/22。
- 权威度与严谨度判断：**[顶会已发表]**。优点：4 个抽取式 QA 数据集各 4000（1200 训 / 800 验 / 2000 测，类别平衡）× 2 模型 = 16 个同域 + 12×2 个跨域组合；置换检验（10,000 次）+ McNemar 检验；100 例人工错误归类（发现 26% 标签本身错）；GPT-4o-mini 裁判在 50 例人工核验上全对；迁移到 SelfAware/CREPE；α∈[−2,2] 因果干预；开源代码。短板：**只有 2 个模型**（Llama-3-8B-Instruct、Gemma-3-12B-IT），无尺度链；**方向选择是暴力枚举**——L×N_pos 个候选方向每个都要在 K 条验证样本上真跑一次干预前向（成本未报告）；**从未与"探针最佳层"对比**，所以读层≠写层没有被量化；弃答代理只是 "unanswerable" 的首 token "un" 在 abstain-aware 提示下的概率；阈值需按数据集重新校准；单方向。

## 一句话核心主张
在每层 ℓ × 每个聊天模板 token 位置 p 用 difference-in-means（均值差 · 不可答样本激活均值减可答样本均值）造候选方向 v_{ℓ,p}，然后**不按探针准确率、而按"把该方向加进残差流后模型说 unanswerable 的 log 概率提升多少"（steering score ψ_steer）**选唯一方向 (ℓ*,p*)，再把隐状态投影到 v̂* 做二分类：同数据集 F1 75.9–96.4%、略低于逻辑回归分类器，但跨数据集掉幅只有 7.4%（分类器掉 30.2%），校准阈值后在 Llama 11/12、Gemma 10/12 组合上显著胜出；α=+2 把弃答率推到 ~96%（可答题也弃答 95%），α=−2 压到 2%——方向既能读也能因果写。

## 方法细节
- **任务**：抽取式 QA（给上下文 c 与问题 q，判上下文是否含答案），y=1 不可答。
- **候选方向（§3.1）**：v_{ℓ,p} = (1/M)Σ h_{ℓ,p}^{(j)}(unans) − (1/N)Σ h_{ℓ,p}^{(i)}(ans)，p 取**用户指令之后的聊天模板 token**（模型开口前的内部状态）；共 L×N_pos 个候选，用训练集 1200 条算。
- **选择（§3.2）**：对验证集每条样本，h̃_{ℓ,p} = h_{ℓ,p} + v_{ℓ,p}（未归一化加法）前向，取下一 token 分布；ψ_steer = (1/K)Σ_i [log p^{(i)}(t_un) − log Σ_{t≠t_un} p^{(i)}(t)]，t_un = "unanswerable" 的首 token "un"；选 argmax ψ_steer 的 (ℓ*,p*)。附录 C：取 top-2 方向相加做分类，平均只多 0.19–0.63 F1，无益。
- **分类（§3.3）**：φ_unans = ⟨h*, v̂*⟩；阈值 τ 在验证集 ROC 上取离 (FPR=0,TPR=1) 最近点；跨数据集时可只重校准 τ（方向不动）。
- **数据**：SQuAD 2.0、RepLiQA（人写、网上没有、防参数知识）、NQ 与 MuSiQue（Slobodkin 2023 策划版：把金段落换成语义相近但不含答案的段落造不可答）；每集 4000，1200/800/2000。迁移：SelfAware（科学无共识/主观/哲学）、CREPE（错误前提）。
- **模型与位置**：Llama-3-8B-Instruct（32 层）所有数据集都选到 **L16、位置 −1**；Gemma-3-12B-IT（48 层）选 L26–27、位置 −1 或 −4（MuSiQue）——"一致落在模型中部"。
- **基线**：Standard Prompt；Abstain-aware Prompt（加"答不了就回 unanswerable"）；Classifier（Slobodkin 2023 式逻辑回归，在训练+验证集上 CV）。所有输入都用 Abstain-aware 提示格式。
- **评价**：按类的 P/R/F1 与 macro-F1；提示基线输出由 GPT-4o-mini 判是否弃答。
- **因果（§4.3）**：h̃* = h* + α v̂*，α∈[−2,2]，在验证集可答/不可答各算弃答率。

## 与 老师方案的关系
- 重叠点：
  1. **"按写效果而不是按读准确率选方向/层"**——与我们 R*≠W*、以写层 W* 做干预的思想同源，且他们在真实性邻域（可答性/弃答）上做出来了。
  2. 他们的 unanswerability 方向是现有文献里**最接近我们 C（承诺/弃答）方向**的对象：加它→弃答，减它→硬答。
  3. 同用均值差方向、同在模型开口前的模板 token 取激活、同做 α 双向扫描。
- 冲突点（他们的结论会不会打我们的某条主张）：
  1. 审稿人会说"用干预效果选层/方向已有 Lavi 等（EACL 2026）"。差别必须讲清：他们是**对每个候选真做干预的暴力搜索**（L×N_pos×K 次前向），我们是**不做干预、只缓存一次前向的前验预测**；成本是本质差别，但他们没报成本，我们要替他们估（Llama-3-8B：32 层 × ~5 位置 × 800 验证 ≈ 1.3×10⁵ 次前向 vs 我们 32 对 × 1 次）。
  2. "合并两个方向无增益"（附录 C）会被用来反驳 C1"需要两条方向"。但他们合并的是**同一概念的两个候选**，不是正交的两类信号；我们需展示 E、C 余弦≈0 且行为效应不同。
  3. 他们的单方向同时携带"上下文里有没有答案"（证据性）与"该不该弃答"（承诺性）——加方向让**可答题也 95% 弃答**，恰说明这条方向里混着 C；我们的分解可以把它拆开，但也意味着一个单方向账户已经能解释他们的所有现象，我们必须给出"分开后才有的新预测"（例如：只推 E 不改弃答、只推 C 不改对错）。
- 可借用点（方法、数据、指标、对照）：
  1. **ψ_steer（弃答 token 的 log-odds 提升）**作为 C 方向"写效果"的廉价 oracle——比生成式评测便宜几十倍，可用来验证 LA-Score 的 ρ。
  2. **"方向稳定、阈值漂移"**的发现：我们的知识门控阈值跨数据集必须重校准，且应报告校准前后两套数字。
  3. SelfAware、CREPE 作为 C 方向的迁移测试集；Slobodkin 版 NQ/MuSiQue 的"换段落造不可答"构造法可用于造 E 的对照对。
  4. 100 例人工错误归类 + 标签错误率报告；置换/McNemar 跨数据集显著性协议。
  5. **模板 token 位置也搜**（−1 到 −4）：我们固定位置，至少应做位置消融。
- 明确差别（我们还能声称什么是新的）：
  1. 他们是"选"（在候选里实测挑）；我们是"预测"（算分不干预）——并承诺 ρ、层误差、成本三项可证伪。
  2. 他们从未报告探针最佳层，所以 **Δ=|R*−W*| 仍未被任何人量化**；我们填这个空。
  3. 抽取式 QA 的证据在上下文里；我们是参数知识 + 系统提示对比的承诺，E 与 C 分开估。
  4. 无门控、无尺度（8B/12B 两点）、无 DAS。
  - 建议论文措辞：引为"以干预效果选方向的先行工作，证明写效果选出的方向跨域泛化更好"，并把 LA-Score 定位为"把这一选择从暴力枚举变成免干预预测"。

## 对四条主张的威胁等级
| 主张 | 威胁 | 理由 |
|---|---|---|
| C1 解耦 | 中 | 单一 unanswerability 方向已能同时检测与控制弃答，且"两方向合并无益"；我们必须证明 E/C 正交且行为效应可分，并说明其方向是 E+C 的混合。 |
| C2 选层 | 中 | "按写效果选方向/层"已有顶会先例，但是暴力枚举、未与读层对比、未报成本；"免干预预测 + R*/W* 量化"仍空。 |
| C3 门控 | 低 | 无门控；其 α 扫描是"全局 α"基线的现成形态。 |
| C4 泛化 | 低 | 2 模型、4 抽取式 QA；我们的数据集与尺度链独立。 |
