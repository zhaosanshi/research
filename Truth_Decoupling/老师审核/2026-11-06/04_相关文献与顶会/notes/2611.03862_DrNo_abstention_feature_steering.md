# 2611.03862 · Dr. No: Feature Steering for Abstention in Vision-Language Models

- 作者 / 机构 / 发表处与年份：Farid Hasanov, Bahram Zonooz, Mykola Pechenizkiy（Eindhoven University of Technology）, Riccardo Renzulli（University of Turin）, Decebal Constantin Mocanu（University of Luxembourg）。**仅 arXiv**（v1 2026-11-02，无 Comments，未见接收信息）。
- 权威度与严谨度判断：**[普通预印本，严谨度中上]**。优点：基线齐全（6 种事后不确定性阈值法 + 弃答提示 + logit bias + dense steering + 随机 SAE 特征对照）；阈值与 steering 超参都在验证集上选；配对 bootstrap 95% CI；挖掘种子稳定性检验。弱点：领域是"图文不匹配 / 选项缺失 / 假前提"这类**输入不完整的可答性**，不是参数知识的真假；超参按基准各选一套；增益小且混合（MM-UPD 平均 dual 输给 log-prob 阈值；MuSiQue 比不 steer 还差）；没有覆盖率对齐，只比各方法自选工作点的 HM。

## 一句话核心主张
在 SAE（sparse autoencoder · 稀疏自编码器 · 把激活拆成稀疏可解释特征）特征里挖出"弃答相关"与"承诺作答相关"的少数特征，prefill 阶段沿"加弃答、减承诺"方向推（可按模型自身弃答特征的强度门控），在 UNK-VQA 和数学类 AbstentionBench 上比事后置信度阈值法得到更好的"可答题答对 / 不可答题弃答"折中——但优势依赖不可答的来源，"缺正确选项"和多跳检索题上不如阈值法。

## 方法细节
- 挖掘语料：GQA 平衡训练集 5k 可答 + 20k 不可答（语义漂移 / 物体缺失 / 假前提 / 删正确选项各 5k），四选一含 "Unanswerable"，选项位置随机；文本侧用 SUM（合成不可答数学题，20k / 20k）。只用"模型本来就答对 / 本来就弃答"的样本挖特征（行为过滤）。
- 特征打分：均值激活差 Δ_j 与单特征 AUROC（ROC 曲线下面积 · 0.5=瞎猜、1=完全分开）；top-k=3 进 A（弃答集）与 C（承诺集）。
- 干预：v = α(s_A·v_A − s_C·v_C)，v_A、v_C = 单位化 SAE 解码列之和；三种模式（只加弃答 / 只减承诺 / 双向）；门控 g(x)=σ((u−τ)/T)，u = 决策 token 上弃答特征平均激活，τ 取两类均值中点、T 取两类间距的 1/4；只在 prefill 的全部提示位置加，生成 token 不动。
- 最终配置：LLaVA-1.6-Mistral-7B 在 UNK-VQA 用第 24 层 α=5、MM-UPD 用第 16 层 α=2；Qwen3.5-2B 第 15 层 α=1；均为双向 + 门控。
- 基线：不 steer；弃答提示；MSP / 预测熵 / log-prob / P(True) / 语义熵 / 口头置信度阈值（阈值在验证集上最大化 HM 或 dual）；logit bias（直接给弃答选项 logit 加常数）；dense steering（同一公式，但方向用残差流均值差，不经 SAE）。
- 指标：HM = 可答准确率与不可答弃答率的调和平均；MM-UPD 用 dual accuracy（成对的可解 / 不可解题都对才算对）。

## 与本方案（E/C 双重分离 + 等覆盖率组合）的关系
- 重叠点：
  1. 它就是"C 类方向 steering vs 置信度阈值"的直接比较，正好对应 N2 后半句"胜过置信度阈值 / 提示"。命名也撞："abstention（弃答）与 commitment（承诺）特征"。
  2. 门控用模型自己的弃答读数——与"读 C、写 C"的设计同构。
- 冲突点：
  1. **它的数据是审稿人可用的反证工具**：最佳 logit bias（只改输出端弃答 token 的偏置）在 UNK-VQA 上 HM 38.0，Dr. No 38.7，dense steering 38.2——"推弃答方向"与"在输出端调准则"几乎等价。审稿人会据此说：既然 N1 自己说 C 只动准则，那等覆盖率下 E+C ≈ E + 阈值 / logit bias，N2 的"胜过阈值"可能只是噪声。
  2. 在 MM-UPD 和 MuSiQue 上 steering 输给阈值法——"steering 胜阈值"并不普适，N2 需要在多数据集上给 CI。
- 可借用点：
  1. **logit bias 基线**：给"不知道 / No"token 加常数，是最纯的"只动准则"对照；我们的 C 方向必须与它在同一条风险–覆盖率曲线上比较。
  2. 阈值法全家桶 + 验证集选阈值 + 配对 bootstrap CI，是 N2 评测可直接照抄的协议。
  3. Pareto 图（标准准确率 vs 弃答准确率）的呈现方式。
- 明确差别（我们还能声称什么是新的）：
  1. 只有承诺 / 弃答一侧，没有能提升判别力的 E 方向，也不测判别力。
  2. 可答性来自输入不完整（视觉 / 选项不匹配），不是参数知识真假；未做等覆盖率比较。

## 对三条主张的威胁等级
| 主张 | 威胁 | 理由 |
|---|---|---|
| N1 双重分离 | 低 | 只有 C 类方向；其"logit bias ≈ steering"的结果反而支持"弃答方向主要动准则"。 |
| N2 等覆盖率组合 | 低-中 | 已有"弃答 steering 胜事后阈值"的先例（新，2026-11），但结果混合、非等覆盖率、无 E；同时给审稿人"C ≈ 阈值"的弹药。 |
| N3 DAS 胜均值差 | 无 | SAE 特征 vs dense 均值差，未涉及 DAS。 |
