## 一句话核心主张
DAS 把 causal abstraction（因果抽象 · 判断"一个简单算法能不能忠实概括一个复杂网络"的数学框架）里的暴力枚举换成可微优化：学一个正交旋转，在旋转后的坐标里把"基础输入"的指定几维换成"来源输入"的对应值，再转回去，用"换完后网络输出是否等于高层算法的反事实答案"的交叉熵训练旋转，底座冻结；在层级相等和单调性推理两个任务上都找到近乎完美的对齐，暴力搜索和局部对齐都远不如它（数字见下表）。

## 方法细节
- **交换干预**（Def 2）：interchange intervention（交换干预 · 让网络跑基础输入，但把某些内部值强行换成它跑来源输入时的值），也叫 activation patching（激活修补 · 同一操作的另一个名字）。
- **分布式交换干预**（Def 3）：DII（distributed interchange intervention · 分布式交换干预 · 先把一组神经元旋转到新坐标，只换其中几个坐标，再转回原坐标）。公式 F*_N(v) = R⁻¹( Proj_Y0(R(F_N(v))) + Σ_j Proj_Yj(R(F_N(M(s_j)))) )：基础输入保留在 Y0 子空间（作者称"软干预"），Y_j 子空间取来源输入 s_j 的值。**这一步必须先把来源输入跑一遍拿到来源表示**。
- **训练目标**（Def 4）：对所有（基础，来源）组合，最小化"高层模型做交换后的输出分布"与"网络做 DII 后的输出分布"之间的交叉熵。网络与高层模型都冻结，只学旋转（§3.5）。
- **由实验者指定的离散超参**（§3.5）：干预目标 N（哪一层、哪个位置；BERT 只看 [CLS]（分类位 · BERT 句首专门用来做分类的那个位置），§5.1）与各子空间维数。反事实金标签由高层因果模型算出（§3.7 第 2 步、附录 A.1）。
- **旋转实现**（附录 D）：PyTorch（深度学习框架）的 `torch.nn.utils.parametrizations.orthogonal` 满秩正交矩阵，默认随机初始化，多种子取最好；作者在附录 D 提出大模型上"只表示对齐子空间那几列"即可（如 512×2 个参数）——这就是后来 pyvene 低秩 DAS 与 ReFT 的出发点。
- **指标**（Def 5）：IIA（interchange intervention accuracy · 交换干预准确率 · 换完以后网络输出恰好等于高层算法预测答案的比例），作者把它对应到"平均意义下的近似因果抽象"。
- **基线**：暴力搜索（brute-force search · 把神经元按滑动窗口分组挨个试，附录 A.3）；"最近局部对齐"（localist alignment · 局部对齐 · 假定变量就存在某几个原始神经元上；做法是把学到的旋转四舍五入成置换 + 符号矩阵，附录 A.4 算法 1）。
- **子空间再分解**（附录 A.5）：固定第一层旋转，再学第二层旋转，检验已找到的变量能否拆成输入身份。
- **任务**：层级相等（输入四个随机向量 w、x、y、z，标签为 (w=x)=(y=z)，用 3 层 ReLU（线性整流激活 · 负数变 0 的非线性）的 feed-forward network（前馈网络 · 最简单的多层全连接网络））；MoNLI（Monotonicity NLI · 单调性自然语言推理 · 前提与假设只差一个上下位词、可能带否定，NLI 即判断前一句能否推出后一句），用在 MultiNLI 上微调过的 BERT-base。两个网络在任务上都是满分。
- **规模与算力**：层级相等用 64 万对训练旋转，MoNLI 1 万–2.4 万对；单张 2080 Ti 十分钟内收敛；每个实验 3 个种子。

## 与本方案（E/C 双重分离 + 等覆盖率组合）的关系
- 重叠点：
  1. 我们的 DAS 估计器（rank-1（秩 1 · 只动一个方向）子空间、交换后监督输出）直接继承这里的 DII 原语和"交换后要等于反事实标签"的训练范式；N3 比较的就是这一类估计器与均值差。
  2. "两个相等关系分别对齐到同一表示里的两个正交子空间"是"同一残差流里可以并存 E、C 两个因果上可分的变量"的概念先例，对 N1 是支持而非威胁。
- 冲突点：
  1. **满分前提**：原文要求网络在任务上满分、且有已知高层算法给反事实标签（§3.7 第 1 步、附录 D）。我们的真假判断和问答任务模型远非满分，DAS 的反事实监督带噪声——审稿人会问"这还算 DAS 吗"。论文里应写清：只借用 DII 原语与训练范式，不声称做了因果抽象验证。
  2. **高维下能拟合随机结构**：随机网络隐层越大，DAS 越能把 IIA 推离瞎猜水平（§4.4）。4096 维的大模型里，rank-1 DAS 也可能拟合出"能改输出、但不是模型自己用的那条路"的方向，即 interpretability illusion（可解释性错觉 · 找到的子空间能改输出，但不代表模型真靠它计算）。N3 若靠"DAS 训练损失低 / 交换准确率高"立论，会被这一条打。
  3. **原文只定义有来源的交换**：我们部署时用无来源放大 h + α·w·wᵀ(h − c)（CDAS 笔记的补记已指出），这一步原文既无支持也无反对证据。
- 可借用点：
  1. IIA 可作为"E 方向是否因果"的验收指标，与 steering 效果分开报告。
  2. 子空间再分解（附录 A.5）可用来检验 E 方向是不是"答案词身份"的拼装——正对应我们"深层 DAS 抓到的是嘴不是证据"的疑问。
  3. 随机网络对照可直接移植：在同规模、权重打乱的模型上跑同一 DAS 流程，给 N3 一个"DAS 凭空能拟合多少"的下限。
  4. 附录 C 作者自己的说法"直接探针可能看不出表示的真实因果作用"，可作为 N3（DAS 优于均值差这类统计方向）的动机引用，但它只是旋转角度分析，不是对比实验。
- 明确差别（我们还能声称什么是新的）：
  1. 原文没有生成式大模型、没有 steering、没有真假 / 弃答任务、没有与均值差的比较——N1、N2、N3 都不在它的覆盖范围内。
  2. **与生成适配的关系**：生成适配（底座冻结；单层只学一个单位方向 w；对正确答案逐词做 CE（cross-entropy · 交叉熵 · 让正确答案每个词概率变高的损失）；在提示末位和每个答案前缀位置做中心放大）与 DAS 只共享"起点方向"。DAS 学的是"换入来源分量后输出等于反事实标签"，生成适配学的是"无来源放大后正确答案概率最大"——目标、算子、位置都已不是 DAS。所以生成适配的任何收益都不能记到 DAS 原文或原始 DAS 训练名下；GPT 第 18 轮报告里随机初始化与 DAS 初始化差异不显著，也说明"DAS 起点有贡献"尚未被证明。生成适配在算子层面真正的前身是 ReFT（见 2404.03592_ReFT.md）。

## 对三条主张的威胁等级
| 主张 | 威胁 | 理由 |
|---|---|---|
| N1 双重分离 | 无 | 没有大模型、没有两条方向的行为分离测量；"两个变量占两个正交子空间"反而是概念支持。 |
| N2 等覆盖率组合 | 无 | 没有选择性作答、弃答或覆盖率。 |
| N3 DAS 胜均值差 | 低 | 不与均值差比较；但"满分前提"和"高维下能拟合随机结构"（§4.4）是审稿人质疑我们 DAS 方向是否真实的现成弹药。 |
