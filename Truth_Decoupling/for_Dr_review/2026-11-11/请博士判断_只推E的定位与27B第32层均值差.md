## 一、普通问法上"只推 E"算积极还是中性？论文主张怎么写？

### 事实

**表头说明**
- **只推 E，普通问法：**问法允许说"不知道"，只在 E 方向上推。
- **只推 E，必须作答问法：**问法要求必须给答案，同样只推 E。
- **E+C：**普通问法上 E 和 C 同时写入。C 的力度按"不知道"的题数事先选定，不看对错。
- **每格的写法：**答对题数变化 [95% 区间] / 作答题数变化。先写 Pro，括号里是 AllenAI 的同一组数。
  - "必须作答问法"那一列只写答对变化：这种问法下作答量几乎不变。
  - E+C 那一列的括号里，只写 AllenAI 的答对变化。

| 模型（E 层） | E 力度 | 只推 E，普通问法 | 只推 E，必须作答问法 | E+C，普通问法 |
|---|---|---|---|---|
| Llama（第 11 层） | 1 | +7 [−4, +18] / −26（+8 / −27） | +29（+29） | C19：+16 [+5, +27] / −8（+12）；C31：+16 [+4, +28] / +1（+23） |
| | 2 | +5 [−10, +20] / −54（+4 / −53） | +39（+44） | C19：+28 [+11, +45] / −12（+36）；C31：+35 [+18, +51] / 0（+48） |
| 9B（第 15 层） | 1 | +3 [−6, +12] / −10（+8 / −11） | +18（+18） | C16：+8 [+1, +16] / −1（+14） |
| | 2 | −1 [−12, +10] / −24（+6 / −24） | +26（+24） | C16：+19 [+9, +30] / +5（+23） |
| 27B（第 28 层） | 1 | +10 [+0, +20] / −7（+5 / −8） | +21（+22） | C33：+34 [+22, +46] / +38（+35） |
| | 2 | **+30 [+17, +43] / +10（+28 / +11）** | +27（+28） | C33：+49 [+35, +63] / +44（+48） |

**人话**
- **Llama、9B：**只推 E 时，模型把一批题改成"不知道"，改口的多是原来答错的题。
  - 例如 Llama 力度 2：少答的 61 题里，45 题原来答错。
  - 所以答对题数几乎不变，但答了的题里正确率明显上升：Pro 下从 39.5% 到 63.9%。
- **27B：**
  - 力度 1 也是这个样子。
  - 力度 2 时，只推 E 在普通问法上就成立：多答对 30 题，作答还多 10 题。
- **E+C：**三个模型都成立。
  - 27B 有一点不同：C 取最小档 0.25 也太强，作答比不写入时多 38–44 题，没能"拉回原来的作答量"。
  - 所以 27B 这两行不是同作答量下的比较。
- **同作答量下的强对照（已在 P5 报过）：**调参题上，Llama、9B 的 E+C 都和"只推 E，再按模型自己的把握挑题作答"打平。

**529 道测试题上的结果（11-14 10:56 出，两家裁判，523 题；详见 [进度和结果](进度和结果.md) 第二节 B）**

| 模型 | 只推 E，普通问法（力度 1 / 2） | E+C（力度 1 / 2） | 同作答量下 E+C 减"只推 E + 按把握挑题"（力度 1 / 2） |
|---|---|---|---|
| Llama（C 第 19 层） | −1 / +9，少答 59 / 153 题 | +22 / +109 | −7 [−25, +11] / +14 [−3, +31] |
| Llama（C 第 31 层） | 同上 | +32 / +99 | −3 [−21, +15] / +8 [−11, +27] |
| 9B（C 第 16 层） | +20 / +19，少答 24 / 60 题 | +33 / +51 | +0 [−15, +15] / +2 [−11, +15] |
| 27B（C 第 33 层） | +19 / **+60 [+39, +80]**，少答 21 / 多答 4 题 | 规则 v1.1：+23 / 不需要 C | v1：+5 [−11, +21] / +17 [+1, +34] |

- Llama、9B 和调参题一样：只推 E 时大量改说"不知道"，答对数涨得少；E+C 把作答量拉回，答对大涨。
- **27B 在 529 题上坐实了反例：**力度 2 只推 E 就多答对 60 题（AllenAI +70），作答量不变，不需要 C。
- 强对照仍没胜出，按事先写下的读法要两家裁判的区间都在 0 以上：
  - 9B 打平；
  - Llama 力度 2 偏向 E+C，AllenAI 下第 19 层是 +24 [+5, +43]，Pro 下含 0；
  - 27B 力度 2 偏向 E+C，Pro 下 +17 [+1, +34]，AllenAI 下 +15 [−3, +33]。

### 赵磊的看法（11-14 原话，称呼按本目录惯例写作"博士"）

> "这个到底是积极还是中性呢，要留给博士判断，你自己也判断下，E本来就不该在自由回答下，回答的更好啊，因为自由回答就是又与答对相关，又与答不答相关的。所以自由回答正是E+C表现好的一个真实应用场景，这应该是本文的观点，而E单独不够好，正是证明E+C好的辅助依据。"

### Claude 的看法

1. **同意大方向。**
   - 自由回答里，"答对"和"答不答"绑在一起。E 只管"答什么"，但推它时模型会顺带改"答不答"：Llama、9B 上是更多说"不知道"。所以只推 E 时答对数不涨，这是"E 管答什么、C 管答多少"这个两因子图景本来就预言的，不算 E 失败。
   - 它和"必须作答问法上只推 E 就成立"放在一起，正好说明为什么要加 C。
   - **我的标法：**单看这一行，**中性**；放进 E+C 的论证里，是**积极的辅助证据**。

2. **但有三处要如实写，否则审稿人会抓：**
   - **事先的预期不是这样。**
     - 首轮冻结的判据里（`30`、`31` 号文档），E 的主检验就放在普通问法上（力度 1），也就是事先以为只推 E 也会成立。Llama、9B 首轮都没过，27B 力度 1 也没过。
     - 现在说"本来就不该成立"，有事后改口的嫌疑。诚实的写法：事先以为会成立；结果 E 同时改了作答量，Llama、9B 都是这样；由此引出 E+C。
     - 有利的一点："相同作答率下组合胜过任何单一方向"是博士的主句。早在我们做自由回答的 E+C 之前就有了，11-07 讲解时已经叫"博士原句"。不是我们看完数据才想出来的。
   - **27B 是反例。**
     - 27B 力度 2 时只推 E 就成立：调参题 +30（作答还多 10 题），529 题 +60（作答量不变）。所以"E 单独不够"不是普遍规律，随模型变。
     - P5 还发现它随任务变：真假判断里，E 让模型更敢答。
     - 论文里应写"E 会改变作答量，方向随模型和任务而变"，不宜写"E 单独不够"。
   - **"E 单独不够"只说明需要一个控制作答量的办法，说明不了 C 是最好的办法。**
     - 决定性的是同作答量下的比较：E+C 对"只推 E + 按模型自己的把握挑题"。调参题上 Llama、9B 都打平（P5）。
     - 529 题上（11-14 出）也没胜出：9B 打平；Llama、27B 力度 2 偏向 E+C，但都只有一家裁判的区间在 0 以上。
     - 所以更稳的写法是 P5 那句："E 管答什么、C 管答多少；同作答量下 E+C 与'E + 模型自己的置信度门槛'相当。"这时 C 的价值在于可解释，并且能把作答量调到任意目标。
     - 赵磊的写法有一层是有硬证据的：E+C 胜过"只推 C + 按把握挑题"，也胜过"E 换成随机方向 + C"，两家裁判都显著。

3. **建议：**
   - 论文主张用 P5 的写法。"自由回答是 E+C 的真实应用场景"可以写，但证据要落在弱形式上，不写"胜过任何单一方向"。
   - "只推 E"这一行在正文里作为 E+C 论证的一环来写，不单独标积极。

### 请博士判断

1. "普通问法上只推 E 不达标"，论文里算积极、中性，还是只作为 E+C 的铺垫？
2. 论文主张用哪种写法？
   - A：赵磊的写法。自由回答是 E+C 的真实应用场景，"E 单独不够"是辅助证据。
   - B：P5 的写法。E 管答什么、C 管答多少；同作答量下，E+C 与模型自己的置信度门槛相当。
   - 529 题的强对照已经出来，没胜出，所以 Claude 建议 B。A 里"E+C 胜过只推 C、胜过随机方向"这一层有硬证据，可以一起写。

## 二、27B 第 32 层的均值差方向：报不报？

### 事实

- **条件：**调参 192 题，必须作答问法。
- **为什么是这三层：**规则 R3 先用 AllenAI 从 9 个候选层里取前三，送 Pro 复判，最后选中第 28 层。
- **均值差方向：**答对、答错两类回答的平均激活之差，是最简单的对照方向。
- **每格：**答对题数变化；第 32 层的均值差附 95% 区间。

| 层 | 裁判 | DAS 方向，力度 1 / 2 / 3 | 均值差方向，力度 1 / 2 / 3 |
|---|---|---|---|
| 26 | Pro | +20 / +25 / +26 | +0 / −2 / −1 |
| | AllenAI | +22 / +29 / +29 | +2 / +3 / +3 |
| 28（规则选中） | Pro | +21 / +27 / +28 | +1 / +3 / +6 |
| | AllenAI | +22 / +28 / +22 | +2 / +2 / +4 |
| 32 | Pro | +19 / +19 / +26 | +11 [+2, +20] / +16 [+4, +28] / +18 [+4, +31] |
| | AllenAI | +22 / +22 / +25 | +16 [+8, +25] / +20 [+8, +32] / **+29 [+16, +42]** |

**人话**
- 第 26、28 层上，均值差方向几乎没用。
- 第 32 层上，均值差方向也能多答对 11–29 题，区间都在 0 以上。AllenAI 力度 3 时，它比同层的 DAS 还高（+29 对 +25），和 DAS 在三层里的最大值（+29）持平。
- **参照：**Llama、9B 上均值差方向多在 0 附近。Llama 是 −3 到 +3；9B 第 15 层力度 1、2 时有 +10、+8。
- **口径上的一个差别：**
  - 均值差方向的写入大小是"力度 × 均值差的长度"，没有和 DAS 的写入大小对齐。
  - 所以同一"力度"下，两个方向推得不一样远。这个差别对哪一方有利，目前没量过。

### 赵磊的看法（11-14 原话）

> "我的理解是可以不报，因为这个数字远远赶不上DAS的最大值，且不稳定。"

### Claude 的看法：建议报（放附录），不删

- **"远远赶不上"只在 Pro 下成立。**Pro 下差得不少：均值差 +18，DAS 三层最大值 +28。AllenAI 下力度 3 时持平：+29 对 +29。
- **它不是忽高忽低的"不稳定"，而是"随层变"。**第 26、28 层约为 0；第 32 层随力度单调上升，区间都在 0 以上。
- **博士 11-10 的要求第 10 条：**"不一致和没提升的结果也留着"。删掉它，如果审稿人复现到第 32 层，会质疑我们挑数。
- **建议写法：**
  - 正文主表报规则选出的第 28 层。那里均值差约为 0，对比干净。
  - 附录全表列三层，加一句："第 32 层上均值差方向也有效，DAS 的优势随层而变。"
