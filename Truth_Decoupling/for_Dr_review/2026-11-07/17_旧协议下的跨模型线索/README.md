# 17 旧协议下的跨模型线索：方向有跨模型、跨数据集的潜力（待重验）（2026-11-08）

对应首页第二节积极结果 9。全部是 10 月 26 日前后**旧协议**下的数字（当时的切分、选层规则、三层窗口），汇总在 `claude_gpt_review/from_claude/06_探索方法总清单_给GPT统一看.md` 第 3.7、3.11、3.12 节；原始文件多数在本地、未经第二方复算。**不能进主表**，但回答了博士一定会问的问题：这套东西是不是只在 Llama-8B 上碰巧成立？当时的答案是不是。

## 1. 门控写入在五个模型上成立（六模型 × 四数据集链）

六个模型：Qwen3 的 0.6B / 1.7B / 4B / 8B、Llama-3.1-8B、Mistral-7B；四类数据集：TruthfulQA、知识类（FEVER / CounterFact / GoT）、HaluEval、BBQ。同一条自动选层规则、同一套代码（`run_model_chain.sh`）：
- "门控写入"（探针说模型内外不一致时才推 E）在**五个 ≥ 1.7B 的模型上，TruthfulQA 全题正确率 +4 到 +12 个百分点，BBQ 也成立**；知识类数据集不伤。
- 0.6B 在 BBQ 上失败：基线判别力就是零，没东西可放大。
- 换提示词措辞、换随机种子，结果稳。
- 教训：在 Llama 上定的"符号可靠性"选层规则换到别的模型就不成立——在一个模型上定的局部规则不能直接搬。这是现在统一协议"每层都试、调参集按事先规则选、测试集报"的来历。

## 2. 转写式写入（KAPPA 式）五模型都涨

不是放大，是把探针层读出的真假坐标转写进写层：**陈述读出口径的选择题准确率**（每个候选答案改写成陈述问 P(True)，取最高者，不是官方按答案对数概率算的 MC1）五模型 **+8.6 到 +13.7 个百分点**（Llama 0.649 → 0.779）。说明"内部知道、嘴上没说"的差距在五个模型上都能兑现成准确率——只是兑现方式是转写、口径是陈述级选择题，不是自由生成。

## 3. 探针当弃答开关

探针说"这答案是假的"的回答里 81% 真的错；按它弃答，答错率从 61% 降到 33%。这是 C 侧（答不答）用读出来做的早期版本，与现在的"核验后弃答"（`15`、首页积极 7）同一条线。路由式 E+C（E17）25 格里 18 格优于单独门控 E，BBQ 的增益几乎全在"信息不足"题——中性。

## 4. 相反方向的线索

同期试过更大的模型（Gemma-3 12B / 27B、Qwen3 14B / 32B、Mistral-Small-24B）：陈述级 20 个配置里 19 个正，但**问答级 12B 以上反而变差**，Qwen3-32B 连"内部知道、嘴上说错"的差距都没有。"越大越好"不成立；限制更像在"数据集上有没有差距"，不在模型大小。这解释了主表定在 8B，也提醒：往大模型推要先看差距（`16` 第 4 节的差距诊断）。
