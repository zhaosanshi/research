# 2411.14257 · Do I Know This Entity? Knowledge Awareness and Hallucinations in Language Models
- 作者 / 机构 / 发表处与年份：Javier Ferrando（UPC / 巴塞罗那超算中心）、Oscar Obeso（ETH Zürich）、Senthooran Rajamanoharan、Neel Nanda（MATS 项目产出，Nanda 为 Google DeepMind 可解释性负责人）。**ICLR 2025 主会**（PDF 页眉 "Published as a conference paper at ICLR 2025"）。代码开源：github.com/javiferran/sae_entities。
- 权威度与严谨度判断：**[顶会已发表]**。理由：3 个模型（Gemma 2 2B / 9B 及 Llama 3.1 8B 复现）；实体数据量大（4 类共约 3.5 万实体，见下表）；对照齐全（10 个随机 SAE 潜变量同层同系数、权重正交化模型、随机单位向量、token 似然混淆检验）；代码开源。弱点：引导（steering）实验每类实体只测 100 个问题；拒答判定靠字符串匹配，无人工评估；"已知/未知"标签靠模糊匹配打分，作者自认有噪声；9B 与 Llama 上效应明显弱于 2B。

## 一句话核心主张
用 SAE（Sparse Autoencoder · 稀疏自编码器 · 把残差流拆成一堆稀疏的可解释方向）在实体最后一个 token 上找到"已知实体"与"未知实体"两个潜变量方向，它们在基座模型上找到、却能因果性地操控聊天模型的知识型拒答：加大"未知"方向→几乎 100% 拒答已知实体；加大"已知"方向→对编造实体不再拒答而是胡编属性。

## 方法细节
- **方向估计**：Gemma Scope 的 JumpReLU SAE（每层一个，默认稀疏度）。对每层每个潜变量算"分离分数" s = f_known − f_unknown（在已知 vs 未知实体 prompt 上激活频率之差），再对 4 类实体取 min（MaxMin 准则）挑最通用的潜变量；剔除在 Pile 随机 token 上激活率 >2% 的潜变量。公式 (6)(7)。
- **读取位置**：实体最后一个 token 的残差流（residual stream · 残差流 · 各层累加的那条主干向量）。
- **层**：最通用的潜变量集中在中间层；Gemma 2 2B（26 层）分离分数在第 9 层附近达峰后平台（Fig.2）；Gemma 2 9B（42 层）与 Llama 3.1 8B（32 层）同样中间层最好（Fig.9、Fig.25）。
- **干预公式**：x_new ← x + α·d_j（d_j 为 SAE 解码器行向量，等价于激活加法 activation steering · 激活引导 · 往残差流里直接加一个向量）。作用于实体最后 token 及其后的"指令结束"token。Gemma 2 2B IT 取 α ∈ [400, 550]（约 2 倍残差流范数），用验证集选。正交化基线：W_out ← W_out − W_out d^T d 对所有写入残差流的矩阵做（Arditi 等拒答方向论文的做法）。
- **训练数据**：Wikidata 实体 + 属性模板 "The movie 12 Angry Men was directed by ___"。已知 = 至少 2 个属性答对；未知 = 全错；中间丢弃。划分 50/10/40。
- **推理协议**：拒答 = 命中一组"I don't have access to real-time information..."类字符串。
- **不确定性方向（第 7 节）**：改在聊天模型上、在 `<start_of_turn>model` 这个"指令结束"token 读 SAE；用 t 统计量挑"答对 vs 答错"差异最大的潜变量（Gemma 2B IT 第 13/18 层；Gemma 2 9B IT 第 10/21/32 层）。排除拒答样本。

## 与 博士方案的关系
- 重叠点：
  1. 他们的"未知实体"方向 **同时是"模型知道自己不知道"的读出信号，又是拒答的因果杠杆**——这正好横跨我们方案里"知识探针门控"（读）和"承诺方向 C 促弃答"（写）两个部件。
  2. 他们的 Fig.1 右图：对编造实体加"已知"方向→模型从拒答变成胡编（作答率↑、正确率不可能↑）。按我们的 2×2 口径，这就是"改作答率不改 J"的行为，即 C 方向那一行的现象，只不过他们用**已知/未知实体对比**而不是 system prompt 对比来估方向，也没算 J。
  3. 读取位置都在中间层；他们也在"找到潜变量的那一层"直接写（读层=写层）。
- 冲突点（他们的结论会不会打我们的某条主张）：
  1. **C1 最大隐患**：审稿人会问"你们的 C 方向是不是就是 Ferrando 的知识自知方向换个名字？"他们证明知识自知与拒答在表征里是绑在一起的一个方向，且微调是"复用"基座已有机制。如果我们声称 E 与 C 是不同方向，必须量化报告 C、E 与实体识别潜变量三者的余弦相似度和交叉因果效应（打 C 是否动了实体识别潜变量读数，反之亦然）。
  2. **C3**："未知→打方向→拒答"这个杠杆他们做了（虽然是全局均匀 steering，不按输入门控）。他们还顺带暴露了副作用：加"未知"方向会让模型连已知实体也拒答（Fig.3 右、Fig.26 右）——这恰是我们门控要解决的问题，但"杠杆"本身不是我们的新东西。
  3. **C2**：他们用一个免训练、免逐层扫描的指标（分离分数的 MaxMin 曲线）就定了"中间层最好"，且读层写层相同就能近 100% 控制拒答。我们声称"读层≠写层"需要有他们这种设置下的对照数据，否则显得是额外复杂度。
  4. **C4**：效应随模型变大而减弱（9B、Llama 8B 弱于 2B；Llama 上"已知"方向不降拒答）。我们 0.6B–8B 的泛化声明要预期同样的衰减并给出解释。
- 可借用点（方法、数据、指标、对照）：
  - Wikidata 实体 + "≥2 属性答对为已知"的廉价知识标签，可直接用来训练/校验我们的知识探针 p(x)，并构造"真未知"（截止日期后的实体）测试集。
  - 对照组模板：10 个随机方向同层同 α；正交化模型；随机单位向量同范数；token 似然混淆检验（我们的 E/C 方向也该做这一项，防止被说成"只是在读困惑度"）。
  - "Are you sure you know X?" 显式自知探针——可当 C 方向的行为侧校验：C 应该动它，E 不该动。
  - 拒答字符串词表、系数扫描表（Table 6：α 从 0 到 1200 的生成样例）作 α 选择的参考。
- 明确差别（我们还能声称什么是新的）：
  - 他们**没有**量化正确率/Youden's J（J = 敏感度 + 特异度 − 1 · 区分真假能力）与作答率的 2×2 分离矩阵；没有用 system prompt 对比估"承诺"；没有对一般陈述（FEVER / CounterFact）而只对实体；没有按输入分档门控；没有层选择的自动指标（LA-Score）；没有 MMLU/GSM8K 副作用评估；没有比较 DAS/均值差/逻辑回归三种估计器。

## 对四条主张的威胁等级
| 主张 | 威胁 | 理由 |
|---|---|---|
| C1 解耦 | 高 | 已有一个"知识自知"方向同时承担读和写、并能让模型"作答率变、正确率不变"；我们需证明 C ≠ 该方向、E ≠ 该方向 |
| C2 选层 | 中 | 免训练的分离分数曲线即可选层；读层=写层已够用，"读层≠写层"需正面对照 |
| C3 门控 | 高 | "未知→steering→拒答"杠杆是他们的；全局 steering 伤已知题的副作用他们已指出，门控是我们的增量但不是全部 |
| C4 泛化 | 中 | 三模型族但效应随规模衰减；未测通用能力掉分 |
