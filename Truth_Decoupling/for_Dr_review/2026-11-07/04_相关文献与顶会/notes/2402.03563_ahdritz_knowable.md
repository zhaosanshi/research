# 2402.03563 · Distinguishing the Knowable from the Unknowable with Language Models

## 一句话核心主张
小模型的嵌入里线性可读出"这个 token 的不确定性是知识性（epistemic · 认知不确定性 · 其实有唯一正确答案、只是模型不知道）还是固有性（aleatoric · 固有随机性 · 本来就有很多合理续写）"：用大模型熵近零当"可知"标签，线性探针 AUC >0.9，训在 Wikipedia 能迁移到代码（AUC ≈0.8）；还有一个免训练方法 ICLT（In-Context Learning Test · 上下文学习测试 · 把候选词塞进上下文看模型是不是跟着抄）能到 AUC ≈0.7。

## 方法细节
- **标签**：对同一文本跑小模型与大模型；取小模型预测熵在窄带 [k, k+1)（默认 [2,3) 比特）内的 token；若大模型熵 <0.2 → "知识性"，若大模型熵在小模型熵 ±0.1 内 → "固有性"（带人工间隔的二分类；无间隔版以 1 比特为阈）。按类别平衡，并对"前一个 token"做计数平衡以防探针学 n-gram 捷径。
- **探针**：线性或单隐层 MLP（隐层 2048），Adam lr 1e-5，交叉熵，早停。输入为小模型某层在当前位置的嵌入。
- **层**：**中间层最好**（LLaMA 7B 第 16/32 层优于最后一层，OOD 差距更大；Pythia 1.4B 第 8/16 层也好）；Pythia 第 1 层已含不少信息（作为"浅层捷径上限"）。
- **数据**：LLaMA 用模型截止日期之后新建的 Wikipedia 文章（71,586 篇，约 1850 万 token，验证/测试各 2900 篇）；Pile 验证/测试集（OOD 子集：GitHub 代码、Stack Exchange、EuroParl 多语）。
- **ICLT（无监督）**：取小模型 top-k 候选 t_i，构造 ⟨prompt⟩⟨t_i⟩⟨BOS⟩⟨prompt⟩ 再前向，取各候选下的最小熵作分数；直觉：知识性不确定时模型更愿意"抄"上下文给的提示。文档分隔符 BOS 至关重要。
- **合成实验**：约 1 亿参数小模型，问题首位比特标注知识性/固有性，验证"选择性上下文学习"可学。

## 与 博士方案的关系
- 重叠点：
  1. "可知 vs 不可知"的内部表征 = 我们门控要读的"模型知不知道"；他们证实它线性可读、在中间层最强、且**跨领域可迁移**（Wikipedia→代码 0.8）。这与 Orgad/Kossen 的"正确性探针不迁移"形成对照：迁移性好的关键是目标量是**模型内部量**（大模型熵），不是外部正确性标签。
  2. 中间层优于最后层（尤其 OOD）——支持我们"在中间读层训知识探针"。
  3. ICLT 的"可暗示性"（愿不愿意抄上下文）其实是一种行为层面的低承诺度指标，可作 C 方向的外部参照。
- 冲突点（他们的结论会不会打我们的某条主张）：
  1. 他们强调不确定性有两种，而我们的门控只有"未知→促弃答"一条路。对固有多答案的问题（aleatoric），用 C 方向压成弃答是错的；我们需要说明数据集里此类题的比例，或承认门控只针对单一正确答案的事实题。
  2. 他们对"探针只是在读输出熵"这一混淆做了极严格的控制（熵带 + BET 基线）。我们的 p(x) 若不与"小模型自身输出熵"基线比较，会被质疑是熵的换皮。
- 可借用点（方法、数据、指标、对照）：
  - 熵带过滤 + 前一 token 平衡 + BET/BET-FT/PIE 三基线的"反捷径"协议——直接套到我们门控探针的评测里。
  - "大模型当真值代理"：用更大同族模型（如 Qwen 72B 对 Qwen 0.6B–8B）的置信度给小模型打"可知"标签，比人工正确性标签更省且更"模型内部"。
  - 中间层 vs 最后层的层消融表格式。
  - ICLT 作为免训练的知识自知基线。
- 明确差别（我们还能声称什么是新的）：
  - 他们是 token 级自由文本的检测，不做问答级干预、没有方向、没有承诺概念、没有门控；他们的"知识性"读数从未被用于控制输出。

## 对四条主张的威胁等级
| 主张 | 威胁 | 理由 |
|---|---|---|
| C1 解耦 | 无 | 无方向、无干预 |
| C2 选层 | 低 | 中间层读得最好，与"读层在中间"一致；无写层讨论 |
| C3 门控 | 中 | 未区分知识性/固有性不确定性；需加 BET 类熵基线证明门控不只是读熵 |
| C4 泛化 | 低 | 其结论反而支持"内部量目标更易迁移" |
