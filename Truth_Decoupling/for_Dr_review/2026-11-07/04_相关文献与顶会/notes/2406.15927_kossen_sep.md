## 一句话核心主张
语义熵（semantic entropy, SE · 语义熵 · 对同一问题采 10 个答案，按意思聚类后算类别熵，熵高=模型其实不知道）本身就编码在单次生成的隐藏状态里，用线性探针（SEP）就能从单个 hidden state 预测它，**连答案还没生成时（输入末 token）就能预测**；用 SE 当监督目标训出的探针，跨任务检测幻觉比直接用"对/错"标签训的准确率探针泛化得更好（+7.7 到 +10.5 AUROC），但仍不及 10 倍成本的采样法。

## 方法细节
- **监督信号**：N=10 个 T=1 采样（top-p 0.9、top-k 50），DeBERTa-Large 双向蕴含聚类（长文用 GPT-3.5），离散版 SE = 聚类频率的熵；再用"回归树式最佳切分"阈值 γ* 把 SE 二值化为高/低（式 5）。
- **探针**：scikit-learn 逻辑回归（默认 L2 + LBFGS），输入为某层某位置的 hidden state；逐层全扫。两处位置：**TBG**（token before generating · 输入最后一个 token · 还没生成任何答案字）与 **SLT**（second last token · 回答倒数第二个 token · 结束符之前那一个）。
- **对照探针**：准确率探针（同结构，标签改为"答案对/错"，正确性短文用 SQuAD F1，长文用 GPT-4 判）。
- **泛化协议**：留一法——在其余数据集上训，在被留出集上测。
- **聚合报告的层**（Table 4）：SEP 用后段层（Llama-2-7B 第 28–32/32；Mistral 28–32），准确率探针用中段层（Llama-2-7B 第 18–22；Mistral 12–16）——**两种目标的最优层不同**。
- **组件消融**（Fig.A.11）：hidden state > 残差流 > MLP 输出（TriviaQA, Llama-2-7B）。
- **反事实验证**：TriviaQA 加入原文上下文后，SEP 预测的 p(high SE) 分布左移，真值 SE 1.84→0.50，准确率 26%→78%，而 SEP 从未在带上下文的数据上训过。

## 与 博士方案的关系
- 重叠点：
  1. TBG 探针 = 我们在读层、生成前训的知识探针 p(x)，他们证明"生成前一个前向就能读出模型会不会不确定"是成立的。
  2. 核心论点"**模型内部量（SE）比外部正确性更易从隐藏状态读出、更易跨任务迁移**"直接指导我们门控探针的训练目标：用 SE 或 P(IK) 式自采样一致性当标签，而不是用 gold 正确性。
  3. 反事实加上下文验证是现成的探针有效性测试。
- 冲突点（他们的结论会不会打我们的某条主张）：
  1. **C4**：准确率探针跨任务不泛化（与 Orgad 一致）。我们的门控若按"答对/答错"训，四数据集泛化会掉；若按 SE 训，又得接受 SE 探针在分布内略逊、且 SE 高 ≠ 答错（见 2602.08159 D.3：TruthfulQA 上 SE 的 AUC 仅 0.58）。
  2. **C2**：SE 探针最优层偏后（28–32/32），准确率探针最优层在中段（18–22/32）——"读层"取决于读什么。LA-Score 声称自动选层，必须说明针对哪个目标量；同一个模型可能有两个不同的"读层"。
  3. 他们的 hidden state > 残差流 结果提醒：探针输入取哪个张量会改变结论，我们需固定并报告。
- 可借用点（方法、数据、指标、对照）：
  - SE 标签生成管线（N=10、T=1、DeBERTa 双向蕴含、离散 SE、最佳切分二值化）；留一法泛化协议；TBG vs SLT 对比；反事实上下文检验。
  - 基线清单：准确率探针、朴素熵、长度归一化对数似然、p(True)（10-shot 带 brainstorm 的模板在 App. B.4）、语义熵真值。
  - 四个问答集（TriviaQA、SQuAD、BioASQ、NQ Open）及其在 Llama-2-7B 上的准确率基准。
- 明确差别（我们还能声称什么是新的）：
  - 他们只检测、不干预，无方向、无承诺概念、无门控、无层选择指标（逐层全扫后挑最好的一段）。

## 对四条主张的威胁等级
| 主张 | 威胁 | 理由 |
|---|---|---|
| C1 解耦 | 无 | 无方向、无干预 |
| C2 选层 | 中 | 最优层随探针目标（SE vs 正确性）而变；LA-Score 须指明目标量 |
| C3 门控 | 中 | 门控探针应改用内部量（SE/P(IK)）作标签；否则跨任务失效 |
| C4 泛化 | 中 | 准确率探针不迁移；SE 探针迁移但有 SE≠错误的天花板 |
