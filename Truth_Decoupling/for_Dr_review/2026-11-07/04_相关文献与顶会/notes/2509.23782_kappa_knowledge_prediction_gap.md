# 2509.23782 · Bridging the Knowledge-Prediction Gap in LLMs on Multiple-Choice Questions
- 作者 / 机构 / 发表处与年份：Yoonah Park*, Haesung Pyun*, Yohan Jo†（首尔国立大学数据科学研究生院）；arXiv v1 2025-09，v4 2026-06-01；页脚 "Proceedings of the 43rd ICML, Seoul, PMLR 306, 2026"，arXiv Comments "Accepted to ICML 2026"，合作者公开主会海报信息（2026-07-07）→ **ICML 2026 主会**（2026-10-24 核）。代码：github.com/holi-lab/KAPPA。
- 权威度与严谨度判断：[顶会已发表] 理由：主模型 Llama-3.1-8B-Instruct、Qwen2.5-7B-Instruct，扩展 Mistral-7B-v0.3、Qwen3-4B/14B/32B；11 个 MCQ 基准（GSM8k-MC、BBH-Algo/NLP、MMLU 三组、ARC、PubMedQA、TruthfulQA、BBQ-Age/Religion），测试集 2k–15k 条；对照 CAA、DoLA；10 种干扰项抽样种子 + 单侧 t 检验；训练数据量敏感性；32 种 prompt 格式选最均衡者消位置偏置。弱点：干预依赖有标签的 k 类知识探针（监督）；**无随机方向/随机子空间干预对照**；自由生成仅 1 模型 3 数据集、GPT-4o-mini 判分。

## 一句话核心主张
MCQ 上普遍存在 knowledge-prediction gap（知识-预测缺口 · 隐状态里线性可读出正确选项，模型却选了别的）：知识探针比模型本身高出最多 +29 点（BBQ-Age Llama）、TruthfulQA +20 点；几何上，knowledge subspace（知识子空间 · 预测真值标签的 k 类探针权重张成）与 prediction subspace（预测子空间 · 预测模型自己输出的探针权重张成）在深层近乎正交（平均主角→90°，CKA 0.4–0.8），正交程度与缺口大小跨基准强相关（Llama ρ=0.976）；KAPPA 用闭式最小 ℓ2 仿射变换把隐状态在预测子空间的坐标替换成知识子空间的坐标（输入自适应、只改预测子空间分量），TruthfulQA 上 Llama 56.7→73.5、Mistral 40.7→58.3，并迁移到自由生成（41.7→44.2）。

## 方法细节
- **双探针**：层 l、答案前缀最后 token 的残差流 h_l(x)；D_know={(h, y 真值)}、D_pred={(h, ỹ 模型贪心输出)}；各训一个 k 类线性分类器（batch 128，lr 2e-4，1000 epoch 选验证最优）。知识探针对即视为"模型线性可及地知道"。
- **缺口度量**：∆ACC = 知识探针准确率 − 模型准确率；AGR = 两分布 argmax 一致率；KLD = KL(p_M ‖ p_K)。
- **几何**：探针权重去均值后 SVD 取正交基（秩 ≤ k−1）；mean principal angle（平均主角 · 两子空间"有多不重合"，随机基线 88.7°）与 orthogonal linear CKA（中心核对齐 · 投影后表示的样本级相似度，随机 ≲0.2）。
- **KAPPA 公式**：min‖h'−h‖² s.t. W̃_predᵀh̃' = W̃_knowᵀh̃ → h' = h + W_pred(W_predᵀW_pred)⁻¹(W̃_knowᵀh̃ − W̃_predᵀh̃)，即只替换预测子空间坐标、正交分量不动。扩展：目标坐标 = α·W̃_knowᵀh̃ + β·sign(·)；默认单层 α=30、β=0，多层 α=10；表 13 另报 α=80。在 prompt 最后 token 及之后每个生成 token 都施加。
- **选层**：验证集上预测探针准确率 >85% 的层中，取知识探针准确率最高的 top-n 连续层（n=1/3/6）——**即"按读得最准的层写"**。
- **基线**：CAA（正确 vs 随机错误选项的 diff-in-means，验证集选单层，乘子 1.0）、DoLA 动态版。
- **分析**：预测子空间 vs 词表 logit 子空间主角（干预层 65–70°，说明不是直接改 logit）；跨数据集迁移；自由生成（去掉选项，用 MCQ 学到的子空间逐 token 施加）。

## 与 博士方案的关系
- 重叠点：(1) 两个线性子空间——"模型知道什么"（知识）vs"模型要输出什么"（预测）——在同一残差流里近正交，并把预测对齐到知识：与我们 E（证据）vs C（承诺/输出倾向）的分法同构，只是他们的第二轴是"模型将选哪个选项"而非"愿不愿意作答"；(2) 输入自适应的闭式干预（按每个 h 的坐标差决定推多少）本质上是**连续版的按输入门控**；(3) TruthfulQA 是我们四数据集之一，他们在上面有强基线（Llama 73.5）与 CAA 对照数字；(4) BBQ 上模型本该选 "undetermined" 却只选 13–27%——这是"知道该弃答却不弃答"的 MCQ 证据，与承诺偏置同构。
- 冲突点：(a) **选层理念相反**：他们按"知识探针最准的层"写（且要求预测探针 >85%），效果显著——若我们声称"读最准的层 ≠ 写最有效的层"，必须用他们的协议作对照基线（按探针准确率选层）并证明 LA-Score 选的层更好；(b) 他们的干预是子空间级（k−1 维）仿射替换，而非 rank-1 方向加法；若审稿人认为 rank-1 不够，KAPPA 就是现成反例；(c) 他们报告 CAA（均值差 steering）在 TruthfulQA 以外几乎无效，对我们"均值差估计器"的 E 方向是不利先验。
- 可借用点：① 知识探针 vs 预测探针双探针协议——可把我们的"知识探针三分门控"定义为 (知识对,预测对)/(知识对,预测错)/(知识错) 三态；② AGR/KLD 作为"干预后预测是否对齐内部知识"的指标，补充 J/B；③ 主角 + CKA + 随机子空间基线，量化 E 与 C 子空间正交性；④ 32 种 prompt 格式选最均衡者消位置偏置；⑤ 多种子干扰项 + 单侧 t 检验的稳健性报告格式；⑥ TruthfulQA/BBQ 上的 KAPPA/CAA 数字作外部基线。
- 明确差别：(1) 我们的第二轴是**作答/弃答倾向**（承诺），他们是选项选择倾向——完全不处理弃答、不改变作答率，也无 system prompt 维度；(2) 我们做 2×2 解耦（E 不动作答率、C 不动 J），他们只有一轴目标（对齐）；(3) 我们免训练选层并声称读≠写，他们按读选写；(4) rank-1 DAS 因果估计 vs 监督 k 类探针；(5) 我们含自由问答与弃答三分评测，他们主体是 MCQ。

## 对四条主张的威胁等级
| 主张 | 威胁 | 理由 |
|---|---|---|
| C1 解耦 | 中 | "知识子空间 ⊥ 预测子空间"已是 ICML 主会结论；但第二轴不是弃答/承诺，没有 prompt 诱导，没有 2×2。需在相关工作中区分"选哪个"与"答不答" |
| C2 选层 | 高 | 用"知识探针最准层"写就取得大幅提升，是"读最准=写有效"的正面案例；我们必须以此为基线证明 LA-Score 选层优于按探针准确率选层，否则 C2 站不住 |
| C3 门控 | 中 | KAPPA 本质是逐输入自适应的干预（坐标差决定幅度），"固定方向 vs 输入自适应"已被他们点名；我们的三分门控需与 KAPPA 式连续自适应比较 |
| C4 泛化 | 低 | 6 模型 4B–32B、11 基准，覆盖更广；TruthfulQA 自由生成仅 +2.5 点，为我们留了空间 |
