# 2402.17811 · TruthX: Alleviating Hallucinations by Editing Large Language Models in Truthful Space
- 作者 / 机构 / 发表处与年份：Shaolei Zhang、Tian Yu、Yang Feng（通讯），中科院计算所 ICT/CAS（智能信息处理重点实验室 + AI 安全重点实验室）。ACL 2024 主会长文（任务给定；arXiv v2 2024-06-05 为 camera-ready 时间）。代码、模型（HF: ICTNLP/Llama-2-7b-chat-TruthX）、全部生成结果开源。
- 权威度与严谨度判断：**[顶会已发表]**。理由：13 个 LLM（Llama-1/2、Alpaca、Vicuna、Mistral ×3、Baichuan2 ×2、Chatglm3 ×2，6B–13B）；主实验 TruthfulQA 817 题（2-fold：408 训练+验证 / 409 测试）+ NQ / TriviaQA / FACTOR(news, expert, wiki) 多选 OOD；对照组齐（SFT、4 种对比解码、CCS / ITI / TrFr 三种表示编辑）；消融（数据构造 / 架构 / 三项损失）与方向对照（随机方向、正交方向、反方向、语义空间内编辑）；跨模型迁移矩阵；逐层探针精度。短板：**无人工评估**（True/Info 全靠 GPT-judge/GPT-info 两个微调 GPT-3）；ITI/TrFr 数字是作者复现；需要训练一个约 2,500 万参数的自编码器；OOD 只报多选不报生成；Fig.7 的"中间层最好"只给图不给数。

## 一句话核心主张
用一个自编码器把 LLM 每层 attention / FFN 模块输出映射到两个潜空间——truthful space（真实性空间 · 只管"这句话真不真"）与 semantic space（语义空间 · 只管"这句话说的是什么"）——用对比学习让两空间各管各的，然后只在真实性空间沿"真心−假心"均值差方向 δ 编辑并解码回残差流，在 TruthfulQA 上把 Llama-2-7B-Chat 的 True*Info 从 31.90 提到 65.45、MC1 从 34.64 提到 54.22，13 个模型平均 True*Info +20%、MC1 +15%，且反向 −δ 能稳定诱发幻觉。

## 方法细节
**1. 取表示（§3.1）**：从 TruthfulQA 构造三元组 (Q, A_pos, A_neg)，分别喂 Q+A_pos 与 Q+A_neg；**只取同时出现在 A_pos 与 A_neg 里的 token** 的表示（保证语义相同、真实性相反）；表示取每层 attention 模块输出与 FFN 模块输出（32 层 ×2 = 64 个模块），x ∈ R^4096。
**2. 自编码器探针（§3.2，附录 A）**
- TruthEnc、SemEnc：各为 2 层 MLP [4096→2048→1024]；Dec：[1024→2048→4096]。重构 x' = Dec(h_sem + Attn(h_sem, h_truth))，Attn 以语义潜表示为 query、真实性潜表示为 key/value。
- 三项损失 L = L_recon(MSE) + L_ctr + L_edit：
  - L_truth：真实性空间内，同真实性为正样本、相反为负样本（InfoNCE 形式，余弦相似度，τ=0.1）。
  - L_sem：语义空间内，**同一 token 相反真实性为正样本**、同真实性不同 token 为负样本——即逼语义空间对真假不敏感。
  - L_edit：把一对 (x_pos, x_neg) 的真实性潜表示互换后重构，要求 x^{pos→neg} ≈ x_neg、x^{neg→pos} ≈ x_pos——保证"改真实性潜表示能真的改出对应的残差流表示"。
- 编辑方向：δ = mean(H_truth^pos) − mean(H_truth^neg)（潜空间里的均值差，Eq.12）。
**3. 推理时编辑（§3.3）**：Δ = Dec(h_sem + Attn(h_sem, h_truth+δ)) − Dec(h_sem + Attn(h_sem, h_truth−δ))；x̂ = x + α·Δ。**只编辑按验证集探针精度排名前 k=10 的模块**（64 选 10）；α=1.0（生成）、α=4.5（多选）。探针判定 Eq.15：cos(h_truth, 真心) ≥ cos(h_truth, 假心) 则判真。
**4. 训练**：2-fold 交叉（沿 ITI / TrFr 设定），408 题按 3:1 分训练/验证；Adam lr 1e-4。附录 B.3：只用 40 题（30 训 10 验）也能把 True*Info 从 31.90 提到 63.77。
**5. 评测口径（附录 C）**：生成任务贪心解码，GPT-judge 判 True%、GPT-info 判 Info%，主指标 True*Info；"I have no comment" 类回答算无信息量。多选 MC1（最佳答案概率最高）/ MC2（所有正确答案归一化概率和 > 错误答案）/ MC3（所有正确答案排在所有错误答案前）。**few-shot 提示本身含 "reply 'I have no comment' unless you are completely certain"**——弃答已内置于 TruthfulQA 标准提示。

## 与 博士方案的关系
- 重叠点：
  1. 同为残差流（attention / FFN 模块输出 = 写入残差流的增量）上的推理期方向编辑；编辑方向 δ 本质是**均值差**（我们三种估计器之一），只是在非线性潜空间里算。
  2. 它也做了"按探针精度选层"（64 选 10）——这是 C2 的直接对照基线；Fig.7 还报了"探针精度与单模块编辑增益在中间层同时偏高"，即**一个弱版本的"读层≈写层"**。
  3. 13 模型、多族验证（C4 的对照），并发现跨族迁移失败、对齐模型更线性可探。
  4. 用 "I have no comment" 条数（ITI 187 / TrFr 144 / TruthX 87）作为非信息量回答的计数——这正是我们"作答率"口径的现成前例。
- 冲突点（他们的结论会不会打我们的某条主张）：
  1. **对 C1 的表面冲突**：TruthX 的标题叙事是"把真实性从其他东西里解耦出来、一个向量控制真假"。审稿人会问"你们和 TruthX 的解耦有什么区别"。答案要点：它解耦的是 truthfulness vs **semantics（语义 · 说什么）**，两空间一个管真假、一个管内容；我们解耦的是 truthfulness 内部的两个成分 **evidence（证据 · 知道真假）vs commitment（承诺 · 敢不敢下结论）**，两者都与语义正交。TruthX 自己的数据反过来**支持**我们：它的单一 δ 在 5/13 模型上把 Info% 砸掉 10–33 点、+δ 回答约 1/3 变成对冲措辞、有的直接改口弃答——说明"真实方向"里混着"少下结论"的成分，这正是我们说的 E/C 纠缠。
  2. **对 C2 的实质冲突**：TruthX 用探针精度选编辑模块，并在 Fig.7 展示探针精度高的中间层编辑增益也高。若我们声称"读层≠写层"，必须拿数据直接对比"按探针精度选层"与 LA-Score 选层，并解释为何 TruthX 看到的相关性在我们设定下不成立（他们是 64 模块取前 10 叠加，单模块增益极弱 Tab.6 k=1 仅 +3.8 点，所以其相关性证据本身很粗）。
  3. 对 C4：它证明跨族迁移方向失败、小/未对齐模型探针精度低——我们在 0.6B 上估的方向可能质量差，需要报每个模型的探针精度做"方向可用性"前置检查。
  4. 它的 OOD 只报多选（概率比较），不报生成；我们若报 SimpleQA / HaluEval 生成级结果，口径不同不构成冲突。
- 可借用点（方法、数据、指标、对照）：
  1. 方向对照三件套：随机方向、正交方向、反方向（Tab.4）——我们每个 E / C 方向都应配上，证明"效果来自方向而不是扰动"。
  2. ±δ 双向控制作为因果证据；k × α 网格（Tab.6）作为强度扫描模板。
  3. TruthfulQA 标准协议：2-fold、GPT-judge/info、True*Info、MC1/2/3 定义；"I have no comment" 计数；PPL（用原模型评生成）检测生成损伤。
  4. 同 token 配对取表示（只取 A_pos 与 A_neg 共有 token）——我们用 FEVER / CounterFact 真假陈述对估 E 方向时，可借此控制语义混淆。
  5. 跨模型迁移矩阵（Fig.6）——若 C4 想加分，可以报 E/C 方向在同族模型间是否可迁移。
  6. 它的 Tab.9 可直接引用为"单一真实方向会伤 Info% 的证据"。
- 明确差别（我们还能声称什么是新的）：
  1. 解耦轴不同：真实性 vs 语义（TruthX）→ 证据 vs 承诺（我们）；后者是 TruthX 没有触及的真实性内部结构。
  2. 免训练 / 低参数：TruthX 要训约 3,100 万参数的自编码器（两个编码器 + 解码器各约 1,050 万，不计 Attn 融合；若按模块独立训练还要 ×64）+ 三项损失；我们是 rank-1 方向（DAS / 均值差 / 逻辑回归）。
  3. 选层：TruthX 按探针精度选 10 个模块叠加；我们 LA-Score 免训练选单层，并显式检验读层≠写层。
  4. 按输入门控：TruthX 对所有输入施加同一全局 α；我们按已知 / 部分已知 / 未知分流（C3），TruthX 完全没有。
  5. 评测口径：TruthX 只报 True*Info / MC；我们报 Youden's J + 标签偏置 B（陈述级）以及纠正 / 损伤 / 转弃答按已知 / 未知拆分（问答级），能把"True% 上升是因为更真还是因为更不说"拆开——这恰是 TruthX 数据里被 True*Info 掩盖的问题。

## 对四条主张的威胁等级
| 主张 | 威胁 | 理由 |
|---|---|---|
| C1 解耦 | 中 | 它已占了"在真实性空间解耦并单向量控制"的叙事高地，必须在相关工作里正面区分轴（语义 vs 承诺）；但其 Info% 崩塌与对冲措辞是我们动机的现成证据，处理得当是加分项。 |
| C2 选层 | 中 | "按探针精度选层"已是其默认做法，且 Fig.7 展示探针精度与编辑增益在中间层同向——我们必须用同模型同数据正面击败该基线，并说明其相关性证据的粗糙之处（无数字、单模块增益微弱）。 |
| C3 门控 | 低 | 全局 α、无门控、无已知/未知拆分；但 TruthfulQA 标准提示自带 "I have no comment"，我们报作答率时要说明提示设定。 |
| C4 泛化 | 中低 | 13 模型 6B–13B 已证明方向编辑可跨族，但其最小 6B、且跨族方向不可迁移、未对齐模型探针弱；我们 0.6B–8B 的小端是新的，但要预防 0.6B 上方向估计不可靠。 |

## 值得引用的原句（≤3 句，标注 section/页）
1. "TruthX decouples the LLM's internal representations into truthful and semantic latent spaces respectively using an auto-encoder." （§1，p.1）
2. "In practice, TruthX edits the LLM's internal representations on the selected top k layers from all attention and FFN layers based on the probing accuracy of each layer on the validation set." （§3.3，p.4）
3. "intervening attention pattern often leads to non-informative responses like 'I have no comment.' (187/817 for ITI, 144/817 for TrFr), thereby reducing the informativeness (Info %) … TruthX does not exhibit this tendency (only 87/817 for TruthX)" （§4.3，p.5）
