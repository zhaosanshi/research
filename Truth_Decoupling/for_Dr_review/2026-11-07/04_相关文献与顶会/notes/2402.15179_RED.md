# 2402.15179 · Advancing Parameter Efficiency in Fine-tuning via Representation Editing (RED)

- 作者 / 机构 / 发表处与年份：Muling Wu、Wenhao Liu、Xiaohua Wang、Tianlong Li、Changze Lv、Zixuan Ling、Jianhao Zhu、Cenyuan Zhang、Xiaoqing Zheng（通讯）、Xuanjing Huang（复旦大学计算机学院）。**ACL 2024 主会长文**：ACL Anthology 2024.acl-long.726，Proceedings of the 62nd Annual Meeting of the ACL (Volume 1: Long Papers)，pp. 13445–13464，DOI 10.18653/v1/2024.acl-long.726，Bangkok，2024-08（已核实）；arXiv v3（2024-06-02）无 Comments。Anthology 版与 arXiv v3 逐句比对：正文一致，只有页眉页码不同（Anthology 摘要措辞略改）；下文页码按 arXiv v3（Anthology 页码 = arXiv 页码 + 13444）。代码 github.com/mlwu22/RED。
- 权威度与严谨度判断：**[顶会已发表]**。优点：RoBERTa / GPT-2 / T5 / LLaMA-2 四种架构；GLUE、E2E 生成、指令微调三类任务；GLUE 5 个种子、E2E 3 个种子并报标准差；严格"验证集选检查点、测试集只测一次"（作者专门纠正了前人在测试集上选点的做法）；消融完整（去缩放 / 去偏置、加 QKV 编辑、与秩 1 的 LoRA / Adapter 比）。弱点：LLaMA-2 部分单次运行；**TruthfulQA 只报 MC2，且用 TruthfulQA 选检查点后再报 TruthfulQA**（同集选点，数字偏乐观）；AlpacaEval / MT-Bench 靠 GPT-4 裁判；与真实性、steering 方向都无关；默认只编辑 FFN 输出（RED+ 才扩到 QKV）。

## 一句话核心主张
冻结模型，只在每层 FFN 子层输出上学两条 d 维向量——逐维缩放 l_scaling 和加性偏置 l_bias（h₂ = l_scaling ⊙ h₁ + l_bias，从恒等开始：缩放全 1、偏置全 0）——用普通微调损失训练；可训参数比 LoRA 少约 32 倍、比全参少约 25,700 倍，效果与 LoRA / 全参相当；消融显示主要功劳在偏置向量。

## 方法细节
- 术语：PEFT（parameter-efficient fine-tuning · 参数高效微调 · 只训极少量参数）；FFN（feed-forward network · 前馈子层 · 每层注意力之后的那段 MLP）；Hadamard product（哈达玛积 · 逐元素相乘）；LoRA（Low-Rank Adaptation · 低秩适配 · 给权重加低秩增量）；Adapter（适配器 · 在层间插小瓶颈网络）；BitFit（只调偏置项的微调）；IA3（只学缩放向量去改 K、V 和 FFN 激活的 PEFT）；SFT（supervised fine-tuning · 监督微调 · 对金标回答做交叉熵）；steer vector（引导向量 · 推理时加进隐层的方向，原文沿用 ActAdd 的叫法）。
- 编辑（§3.2 式 3）：h₂ = l_scaling ⊙ h₁ + l_bias，h₁ 为某层 FFN 子层产生的表征；每层一对向量。动机直接来自 ActAdd："我们假设这样的 steer vector 可以在微调阶段学出来"。
- 初始化（§3.2）：l_scaling 全 1、l_bias 全 0——训练开始时不改动模型。
- 位置：论文没有单独讨论 token 位置；式 3 对该层产生的表征施加，向量本身与位置无关。
- 目标：任务本身的微调损失（GLUE 分类；E2E 生成；LLaMA-2 用 UltraFeedback 每题最高分回答做 SFT）。
- LLaMA-2 7B 设置（附录 B.4、表 10）：RED 学习率 1e-3、10 epoch、序列长 768、batch 128；每个 epoch 在 TruthfulQA 上评测，选最好的检查点再测其他数据集。
- 变体 RED+（§5.2）：再编辑注意力的 Q、K、V 表征，参数从 0.07M 增到 0.37M。

## 与本方案（E/C 双重分离 + 等覆盖率组合）的关系
- 重叠点：
  1. "冻结底座、只学表征上的少量向量、用普通交叉熵 / SFT 训练"——与我们的生成适配同属一类。我们的算子 h + α·w·wᵀ(h − c) 可以拆成"沿 w 一个方向的缩放（增益 1 + α）+ 沿 w 的偏置（−α·wᵀc）"，正是 RED"缩放 + 偏置"在单方向（秩 1）上的对应物；RED 是逐维（对角）、多层、无方向概念。
  2. LoFiT 把 RED 当主要 PEFT 基线，RED 在 TruthfulQA 开放生成上与 LoFiT 相当（见 2406.01563_LoFiT.md 表 4）。
- 冲突点：
  1. 审稿人可能把生成适配称为"单方向版 RED / BitFit"；它的意义在于旁证"表征编辑式 PEFT"早在 ACL 2024 已成熟，适配器本身不新。
  2. 它的 TruthfulQA 数字只是 MC2 且同集选点，不能当"表征编辑提升真实性"的证据引用。
- 可借用点：
  1. 恒等初始化（缩放 1、偏置 0）是"随机 / DAS / 均值差初始化"之外的第三种对照：若把 α 也设成可学、从 0 起步，可检验"方向初始化还重要吗"。注意我们的绑参算子在 α 固定时不可能从恒等起步（w ≠ 0 就有改动），这一点写方法时要交代。
  2. "偏置的贡献远大于缩放"（表 6）提示：值得做一个消融——同位置、同数据，把投影放大式 α·w·wᵀ(h − c) 换成纯加法 α·w，看增益来自哪一项。
  3. 选点协议（验证集选点、测试集只测一次）——我们的生成适配也要写明选点集与 523 题测试集分离。
- 明确差别（我们还能声称什么是新的）：
  1. 与真实性、弃答、E / C、覆盖率、方向估计器全都无关。
  2. 多层、逐维、无方向；我们是单层、单方向、方向有来源（DAS / 均值差 / 随机）。审稿人不会说生成适配"就是 RED"，但会把它放进"RED / LoFiT / ReFT 一类表征 PEFT"。
