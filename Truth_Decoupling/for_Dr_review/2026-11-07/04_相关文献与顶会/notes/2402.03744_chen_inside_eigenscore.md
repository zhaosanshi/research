- 权威度与严谨度判断：**[顶会已发表]**。理由：3 个主模型（LLaMA-7B / 13B、OPT-6.7B）+ 附录 2 个（LLaMA2-7B、Falcon-7B）；4 个问答集（CoQA 7983、SQuAD 5928、TriviaQA 9960、NQ 3610 题）；两种正确性口径（ROUGE-L、句向量相似度）+ 精确匹配附录；有温度/top-k/采样数/层/阈值敏感性消融；代码开源。弱点：只做检测不做缓解；需 K=10 次采样；正确性全靠自动指标无人工评估；TruthfulQA 上靠 50 个分布内 prompt 才接近 ITI。

## 一句话核心主张
把同一问题的 K 个采样答案在**中间层最后 token** 的句向量堆成矩阵，其协方差矩阵特征值的对数均值（EigenScore · 特征分 · 嵌入空间里的"答案多样性熵"）比 logit 熵、词面相似度更能检出幻觉；再在倒数第二层把极端激活截断（feature clipping · 特征截断 · 把特别大的激活值削平），能压制"自信地一致的错答"，让一部分过度自信幻觉现形。

## 方法细节
- **句向量**：第 t 个 token 在第 l 层的隐藏向量 h_t^l；主实验取**回答最后一个 token、中间层 int(L/2)**（LLaMA-7B 图中标为第 17 层）；消融比较了均值池化与各层。
- **EigenScore**：Z∈R^{d×K} 为 K 个句向量，Σ = Zᵀ J_d Z（居中协方差，K×K），E = (1/K) log det(Σ + α I_K) = (1/K) Σ_i log λ_i，α=0.001。Remark 1：对高斯分布 log det Σ 即微分熵，所以 EigenScore ≈ 嵌入空间的语义熵。
- **特征截断**：倒数第二层每个神经元按一个滚动记忆库（N=3000 个 token 向量）的上下 p=0.2 百分位设 h_min/h_max，分段截断（式 8）。
- **采样**：K=10，T=0.5，top-p 0.99，top-k 5。
- **正确性**：ROUGE-L f-measure >0.5 或 nli-roberta-large 句向量余弦 >0.9；附录 E 用精确匹配。
- **指标**：AUROC（AUC_s 用句向量相似度判对错、AUC_r 用 ROUGE-L）、PCC（皮尔逊相关）。
- **基线**：困惑度、长度归一化熵（LN-Entropy）、词面相似度（Lexical Similarity, Rouge-L）、能量分；附录比较语义熵、SentSAR、SelfCheckGPT、ITI。

## 与 博士方案的关系
- 重叠点：
  1. "**中间层最后一个 token 保留最多真实性信息**"——与我们在中间读层、最后 token 训知识探针一致；他们给出了层曲线（浅/深都差）。
  2. 特征截断是一种对内部状态的无方向干预，确实改变了生成行为（让一致的过度自信错答变得分散，Table 2、App. H.3）——可以视为"降低承诺"的粗糙版本，但不是方向、也不分已知/未知。
  3. 他们点出"自信地一致的幻觉"这一类是所有一致性/熵方法的盲区——对应 Orgad 的 C1 型、Confidence Manifold 的 TruthfulQA 场景。
- 冲突点（他们的结论会不会打我们的某条主张）：
  1. 对 C3：我们的门控若把"未知"定义为低一致性/高熵，就继承了同样的盲区——自信地错的题会被判成"已知"而不被干预。需要明确我们的知识探针对这类题的表现（可借 Orgad 的 C1 分型测）。
  2. 对 C4/基线：TriviaQA 这类短答案上输出侧困惑度就是最强基线，内部法无优势；我们声称内部方向优于输出法时要分数据集说。
- 可借用点（方法、数据、指标、对照）：
  - EigenScore 作为采样式"未知"真值的替代（比 SE 不需要 NLI 模型），或作门控探针的第二标签源。
  - 特征截断作一个廉价的"全局降自信"干预基线，与 C 方向促弃答做对比（看谁在已知题上伤害更小）。
  - 正确性口径敏感性表（ROUGE 阈值 0.3/0.5/0.7 下 AUC 变动很大）——我们报告 J 时也要给口径敏感性。
  - 层消融与 token 位置消融的作图方式；CoQA/SQuAD/NQ/TriviaQA 划分与规模。
- 明确差别（我们还能声称什么是新的）：
  - 他们只检测、无方向、无门控、无层选择、无承诺概念，自己在 App. G 承认"尚未用它来缓解幻觉"。

## 对四条主张的威胁等级
| 主张 | 威胁 | 理由 |
|---|---|---|
| C1 解耦 | 无 | 无方向、无因果干预 |
| C2 选层 | 低 | 中间层最好的结论与我们一致，无读写层讨论 |
| C3 门控 | 低 | 特征截断是应纳入的无门控干预基线；"自信地错"盲区需正面处理 |
| C4 泛化 | 低 | 仅提醒短答案集上输出法基线很强 |
