# 2311.15131 · Localizing Lying in Llama: Understanding Instructed Dishonesty on True-False Questions Through Prompting, Probing, and Patching
- 作者 / 机构 / 发表处与年份：James Campbell（Cornell）、Richard Ren（UPenn）、Phillip Guo（UMD），三人同等贡献；项目源自 ARENA 培训项目，算力由 EleutherAI 提供。2023-11 arXiv v1，PDF 自标 "Preprint. Under review"；arXiv 元数据无 journal_ref（我记忆中可能进过 NeurIPS 2023 SoLaR workshop，未核实，按"仅 arXiv"处理）。代码开源：github.com/jamescampbell57/llama-lying。
- 权威度与严谨度判断：**普通预印本**（但是"指令说谎定位"这条线的起点，被 2509.03518、2604.19117 等后续工作反复引用）。理由：只有 1 个模型（LLaMA-2-70b-chat）；数据只有 Azaria & Mitchell 一个来源的 6 个子集；每子集测试 200 条，头搜索只用 50 条；对照做得不错（双向 patching、LEACE 擦除、随机/全层对照），但没有人工评估，没有多模型复现；作者自己承认是 toy 场景。

## 一句话核心主张
LLaMA-2-70b-chat 被 system prompt 指令说谎时，真值表示在中早层（<23 层）与诚实模式**平行**、之后**反平行**（翻转），用 activation patching（激活修补 · 把诚实运行时的中间激活塞进说谎运行里，看输出会不会被扳回来）定位到第 19–23 层共 46 个注意力头（占全网 5120 个头的 0.9%），修补这 46 个头就能把说谎模型（准确率 2%）扳回诚实（83%），且跨 prompt、跨数据子集泛化。

## 方法细节
- **模型**：仅 LLaMA-2-70b-chat（80 层 × 64 头，d_model=8192，每头 128 维；GQA 架构）。作者说 7b/13b-chat 很难被指令说谎，所以没用。
- **数据**：Azaria & Mitchell (2023) 真/假陈述集，6 个子集：Cities、Inventions、Chemical Elements、Animals、Companies、Scientific Facts。做了"**已知题过滤**"：用 LLaMA-2-7b-chat 在诚实 prompt 下回答，只保留它以 >0.85 概率答对的陈述——目的是把"不知道"和"知道但撒谎"分开，只研究后者。
- **prompt 组合**（Table 1）：system prompt 10 种（1、7 诚实；2、3、4、5、6、8、9、0 说谎）× user prompt 6 种（a–f）× assistant 前缀 3 种（i–iii）。编号如 "2fii" = 说谎 prompt 2 + user prompt f + 前缀 ii。
- **读出方式**：比较下一个 token 是 "True" 还是 "False" 的概率。
- **诚实/说谎的操作定义**：准确率显著高于 50% = 诚实；显著低于 50% = 说谎（因为要系统性答错，必须先算出真值再取反）。
- **关键发现（prompt 工程）**：不加前缀时，说谎 prompt 让模型严重偏向输出 "False"（对假陈述准确率高、对真陈述准确率低）——因为说谎时模型倾向在 "True" 前面先吐 filler token（"That's simple! Of course the statement is true..."）。加前缀 "Oh that's an easy one! The statement is definitely" 之后，说谎变得干净：真/假两类召回都接近 0。
- **报告口径**：不报单一准确率，而是分别报 recall_pos（对真陈述的召回）和 recall_neg（对假陈述的召回），专门用来发现 token 偏置——这和我们"Youden's J + 标签偏置 B"的思路同源。
- **Probing**（线性探针 · 在每个注意力头 128 维的 z 激活上训逻辑回归，预测陈述真值）：在最后一个序列位置，分别在诚实 prompt 和说谎 prompt 下训练，然后交叉迁移测试，并算探针系数的余弦相似度。
- **Activation patching**：把诚实模型的 z 激活修补进说谎模型，最后 25 个序列位置，一次 5 个连续层扫描；再在 19–23 层内做"留一头"搜索（修补该层范围全部头但留掉一个，看准确率掉多少）找关键头。
- **附录 B.1 Logit attribution**（对数几率归因 · 把每层注意力输出直接投影到词表，看它对 "True"−"False" 的贡献）：<40 层几乎无贡献，40–45 开始有，45–75 层贡献绝大部分 → 晚层只是"写输出"，真值表示和说谎机制应在 40 层之前。
- **附录 B.2 LEACE**（最小二乘概念擦除 · 用线性变换把"真值"信息从激活里抹掉但尽量少动别的东西）：Oracle-LEACE 作用于最后 15 个位置，一次 5 层；擦掉 19–23 层（以及 25–29 层）的真值信息对任务准确率伤害最大。
- **附录 B.5 序列位置**：修补 [-25,0] 和 [-20,0] 效果相同（83%），[-15,0] 降到 70%，[-10,0] 和 [-5,0] 都是 35%（说明 -10 到 -5 之间这 46 个头没做相关计算），[-1,0] 只有 8.8%。

## 与 博士方案的关系
- 重叠点：
  - 他们的"诚实 vs 说谎 system prompt 对比"在形式上和我们估计 C 方向的"必须答 vs 可以说不知道"对比是同一类操作（固定陈述、只换指令）；他们的"真值探针"就是我们的 E 方向估计器之一（逐头逻辑回归）。
  - 他们用小模型置信度过滤出"已知题"（7b 以 >0.85 答对），和我们按 baseline 答对与否划"已知题/未知题"是同一思路。
  - 他们分开报 recall_pos/recall_neg 以捕捉 token 偏置，和我们报 J 与标签偏置 B 的动机一致。
- 冲突点（他们的结论会不会打我们的某条主张）：
  - **对 C1 的隐患**：他们发现说谎 prompt 下的"真值探针"在 ~23 层之后变成诚实探针的**反平行**向量——即 prompt 对比所诱导的差异方向，在晚层会与真值方向**共线（反号）**而非正交。我们若在晚层用 prompt 对比估 C，拿到的可能是"翻转的 E"而不是独立的"承诺"方向。必须在论文里报 cos(E, C) 随层的变化并证明低相关，否则审稿人会拿这篇说"你的 C 就是 E 的旋转"。
  - **对 C2 的位置**：他们已经用三种工具（探针、patching、logit attribution）展示"真值在中早层可读、19–23 层可干预、45 层后才写 logit"——即"读层≠写层"这个现象在 70B 上已有实证，只是没被命名、没有自动选层方法。C2 不能声称发现了这个现象，只能声称"免训练自动评分选层"。
  - **对 C4 的隐患**：作者明说 7b/13b-chat 很难被指令说谎。我们 0.6B 模型上用 system prompt 对比估 C，面临同样的"小模型不听指令"风险——需要先验证 0.6B 在"必须答 vs 可以说不知道"两种 prompt 下作答率确实有差异。
- 可借用点（方法、数据、指标、对照）：
  - 诚实↔说谎探针**交叉迁移 + 系数余弦**作为检验两方向是否独立/反平行的标准工具（直接可用于 C1 的证据链）。
  - **双向 patching**（把 C 方向激活从"可弃答"塞进"必须答"、反之亦然）作为因果验证。
  - **LEACE 擦除**作为"该层确实被用到"的对照（比 patching 更干净）。
  - 序列位置消融：我们应检查 C 方向作用的 token 位置（尤其 chat 模板 token）。
  - assistant 前缀技巧解决单 token 读出偏置。
  - Azaria & Mitchell 六子集 + 小模型过滤的"已知题"构造。
- 明确差别（我们还能声称什么是新的）：
  - 他们只做"说谎（断言假话）"，完全没碰"弃答/说不知道"；他们的 C 类操作是把真值取反，我们的 C 是改变作答意愿——这是两个不同的行为轴。
  - 他们没有可控的 steering 向量，只有修补和擦除；没有层选择评分；没有 QA 级评测；没有能力保持检查；单模型单数据族。
  - 我们的 rank-1 DAS、三估计器对比、LA-Score 选层、输入门控都不在他们范围内。

## 对四条主张的威胁等级
| 主张 | 威胁 | 理由 |
|---|---|---|
| C1 解耦 | 中 | 晚层 prompt 对比方向与真值方向反平行（Fig.2b），直接提示"prompt 诱导方向 = 翻转的 E"这一替代解释；我们必须报 cos(E,C) 逐层曲线并选在正交的层 |
| C2 选层 | 低 | 已展示探针/patching/logit 三者定位不同层（<23 / 19–23 / 45+），"读层≠写层"现象被预占，但无自动选层方法；C2 需定位为"免训练评分"而非"发现" |
| C3 门控 | 无 | 无弃答、无门控、无已知/未知拆分评测（他们只在已知题上做） |
| C4 泛化 | 中 | 只有 70B 一个模型；明说 7b/13b 不听说谎指令——我们 0.6B 上 prompt 对比估 C 可能失效，需先验证 |
