- 权威度与严谨度判断：**大机构预印本（严谨度高）**。理由：3 个模型（T5-11B、T5-FLAN-XXL、Chinchilla-70B），3 个数据集 + TruthfulQA，5 种方法（CCS / PCA / k-means / 随机探针下界 / 逻辑回归上界），每法 50 个随机种子且**报告全部种子分布**（Burns 原文只报 loss 最低的种子）；有两条形式定理；附录给全量 prompt 模板；无人工评估（不需要）；未开源代码（Chinchilla 闭源）。

## 一句话核心主张
无监督"知识发现"方法（CCS、PCA、k-means）在 LLM 激活上找到的**不是知识，而是激活里最显著的那个二元特征**：理论上任何二元特征都能把 CCS 损失压到最优（定理 1、2）；实验上随便塞一个"Banana/Shed"随机词、或一个叫 Alice 的角色的观点，探针就去追那个，真值准确率掉到 50%。

## 方法细节
- **对比对（contrast pair · 同一个问题接 Yes 和接 No 两个版本）**：x⁺ = "q? Yes"，x⁻ = "q? No"；取某层最后一个 token 的激活 φ(x)，按 +/− 两组分别减均值除标准差做归一化（为了抹掉"结尾是 Yes 还是 No"这个显著特征）。
- **CCS**：线性探针 p(x) = σ(θᵀφ̃(x)+b)，损失 = 一致性项 (p(x⁺) − (1 − p(x⁻)))² + 置信项 min(p(x⁺), p(x⁻))²。作者改用**对称置信项** min(p⁺, p⁻, 1−p⁺, 1−p⁻)²（附录 A.2：原版有向下偏置，常数探针最优解在 0.4 而非 0.5）。AdamW、全批、1000 epoch、Chinchilla lr 0.001 / T5 lr 0.01。推断用 p̃(q) = (p(x⁺) + 1 − p(x⁻))/2 > 0.5；方向用"准确率 >0.5 则翻转"消歧（truth-disambiguation）。
- **PCA（CRC-TPC）**：对 φ̃(x⁺) − φ̃(x⁻) 做 PCA，取第一主成分过零分类。**k-means**：同样输入，2 簇。**随机探针**：CCS 结构但不训练（下界）。**逻辑回归**：拼接 (φ̃(x⁺), φ̃(x⁻)) 有监督训练，报训练准确率（上界）。
- **模型/层**：Chinchilla-70B 取第 30 层（共 80 层），附录 C.2.3 扫层结果"对层不敏感"；T5 系列取 encoder 输出。上下文 512，数据按标签平衡。
- **定理 1**：对任意二元特征 h: Q→{0,1}，令 p(x⁺)=h(q)、p(x⁻)=1−h(q)，CCS 损失为 0（最优），且 p̃(q)=h(q)。**定理 2**：对任意探针 p 与任意目标分类器 g，存在变换 p' = p ⊕ f_p ⊕ g（⊕ 为连续异或）使 L_CCS(p') = L_CCS(p) 且 p' 诱导的分类器恰为 g。结论：CCS 的一致性结构与知识无关，学到什么全看归纳偏置（prompt、优化器、模型）。
- **五个实验（默认 prompt vs 只改 prompt 的修改版）**：
  1. 随机词：prompt 末尾随机追加 "Banana" 或 "Shed"。
  2. 显式观点：插入 "Alice thinks it is {positive|negative}" 随机分配；T5-FLAN-XXL 需重复 5 次才见效（指令微调让激活更"硬"）。
  3. 隐式观点：DBpedia 二选一主题分类，few-shot 里说明 "Alice 是反资本主义者，遇到 Company 故意答错"，最后一例 Alice 未表态。
  4. prompt 敏感性：TruthfulQA 上 default / literal / professor 三种 prompt（后两者即 Lin et al. 的 helpful prompt 文本，含 "reply 'I have no comment' unless you are completely certain"）。
  5. CCS 与 PCA 一致性：比较两法预测重合率是否高于独立假设。

## 评价口径与关键数字
指标：二分类准确率（balanced，chance=0.5），50 种子小提琴图。

| 实验 | 模型/数据 | 关键结果 |
|---|---|---|

## 与 博士方案的关系
- 重叠点：
  1. 我们三种估计器（均值差、逻辑回归、rank-1 DAS）全是**有监督**的，正好落在本文"LR 在所有实验里都好用、当上界"的那一侧——这是我们相对 CCS 路线的防守点。
  2. 但本文的更广义教训——"对比对里最显著的特征未必是你想要的那个"——对均值差估计器完全适用：真/假陈述对的均值差方向，可能主要是"陈述风格/频率/是否常见"而非证据。
  3. **TruthfulQA prompt 实验直接关系到 E 与 C 的独立性**：他们发现加上"不确定就说 I have no comment"这类谨慎指令后，真/假在激活空间里的簇**变得更可分**。我们用的 C 方向估计恰好就是这类 prompt 对比。这说明"承诺"prompt 会改变"证据"的几何——E 和 C 在表征上可能不是正交的。
- 冲突点（他们的结论会不会打我们的某条主张）：
  - **打 C1 的"C 改作答率不改 J"**：如果 C-prompt 让真/假更可分（他们的 Fig. 5），那沿 C 方向干预可能同时改变 E 探针的 J。必须做：在两种 C-prompt 下分别测 E 探针的 J，以及沿 C 方向加减后重测 J。
  - 对 C 方向的语义解读：Alice 实验表明 prompt 诱导出的方向可能编码"模型正在模拟的角色的态度"而不是"模型自身的承诺度"。我们的 system prompt 对比（"说不知道" vs "必须给确定答案"）和他们的 Alice 操纵在结构上同类。
- 可借用点（方法、数据、指标、对照）：
  1. **随机词 sanity check**：在我们估计 E/C 的 prompt 里随机追加无关 token，验证估出的方向与该随机特征投影不相关（他们贡献的"sanity checks"可以直接搬）。
  2. **报告全部种子**而不是最好的那个；DAS 多次随机初始化的方向余弦相似度要报。
  3. 加 **PCA / k-means 无监督基线**和**随机方向下界**，证明我们的 E 方向不是"最显著方向"的别名。
  4. 他们对 CCS 置信项的**对称修正**（附录 A.2）——若我们用 CCS 当对照需用修正版。
  5. 他们引用的 Clymer et al. (2023, GENIES) 是专门测监督探针分布外泛化的 testbed，可用于 C4。
- 明确差别（我们还能声称什么是新的）：他们只做读出（探针），不做干预；只问"是不是知识"，没有拆"证据 vs 承诺"。他们把 prompt 敏感性当缺陷，我们把 prompt 诱导的那个方向当成一个可控对象（C）——前提是我们能证明 C 与 E 在因果效应上可分（J 与 B 分别响应），这正是 C1 要做的事，也是本文给我们设的门槛。

## 值得引用的原句（≤3 句，标注 section/页）
1. "existing unsupervised methods on large language model (LLM) activations do not discover knowledge – instead they seem to discover whatever feature of the activations is most prominent." （Abstract，p.1）
2. "The upshot is that the CCS consistency structure is more than just slightly imprecise in identifying knowledge—it is compatible with arbitrary patterns." （§1，p.1）
3. "if these methods were detecting knowledge/truth, it shouldn't matter whether we give instructions to interpret things literally." （§4.4，p.10）
