# 11 新 DAS 目标为什么胜过均值差，以及它和 CDAS（ICLR 2026）的区别（2026-11-07）

对应首页第二节积极结果 2。数字来自 `02` 第 2 节（测试集 529 对，配对自举 95% 区间，GPT 第 17 轮从逐题数组复算一致）。

## 1. 两种方法各自在干什么

模型每一层的内部状态是一长串数字（一个几千维的向量）。我们要找的 E，是这串数字里的**一个方向**：沿着它推，模型判真假的能力变强。两种找法：

**均值差**：拿 96 对真假陈述，把真句子的内部状态求平均、假句子的求平均，两个平均值相减，就是方向。它回答的是"真句子和假句子**平均起来在哪个方向上长得不一样**"。缺点：只要真假两组平均有差别的东西都会被算进去，包括和判真假无关的差异；而且数值大的维度说话最响（Gemma-3-4B 第 443 维那种巨激活就是这么把均值差方向带歪的）。

**DAS（Distributed Alignment Search，分布式对齐搜索）**：训练时做一个"换零件"的实验。拿一句真的和一句假的，把假句子内部状态里**只沿着方向 w 的那一个分量**换成真句子的，其他全不动，再问模型"这句真还是假"。如果模型因此改口说"真"，说明 w 这个方向上装的就是模型用来判真假的东西。训练就是不断调 w，让"换了这个分量就改口"发生得越彻底越好。它回答的是"模型**实际用哪个方向来下判断**"。

一句话：均值差找的是"看起来不一样"的方向，DAS 找的是"模型真拿来用"的方向。放大一个模型真拿来用的方向，判别力提升得多、杂音少。

## 2. 我们换了什么目标，效果多大

旧版 DAS（第 4 轮）的训练目标是："换了分量之后，让模型接下来 8 个词的**整个输出分布**向被换进来那句的分布靠"（KL 散度）。11-05 换成新目标，三处一起改：
1. 目标从"模仿续写分布"改成"**直接押被换进来那句的金标签**"（True 或 False）。
2. 损失从 KL 改成**首词元标签概率的交叉熵**（把 True 的各种写法概率加起来，和评测读出用的是同一张表）。
3. 从 8 步改成**提示末位一步**，读写在同一个位置；再加**双向**（真换进假、假换进真都训）。

其余不变：同一批 96 对估计陈述、同一提示、同一锚点、10 轮、同一学习率、同一全层扫描与选择规则。

| 模型 | 新 DAS − 均值差（ΔJ 之差 / ΔAUROC 之差） | 新 DAS − 旧 DAS |
|---|---|---|
| Llama-3.1-8B | **+0.036 [+0.004, +0.070] / +0.030 [+0.022, +0.038]** | **+0.030 [+0.008, +0.055] / +0.031 [+0.024, +0.039]** |
| Qwen3-8B | **+0.038 [+0.008, +0.070] / +0.022 [+0.014, +0.030]** | +0.019 [−0.011, +0.049] / **+0.018 [+0.010, +0.027]** |
| Gemma-3-4B | −0.021 [−0.051, +0.008] / +0.003 [−0.003, +0.009]（打平） | +0.017 [−0.002, +0.036] / **+0.025 [+0.019, +0.031]** |

**拆分（Llama）**：从旧目标换成"金标签 + 单步交叉熵"（单向），J +0.017 [+0.004, +0.034]、AUROC +0.013 [+0.010, +0.015]（这一步同时改了目标、损失、步数三处，不可再分）；再加双向，AUROC 再 +0.019 [+0.013, +0.025]，J +0.013（区间含 0），偏置 −0.014。

**AUROC 同时涨是关键**：它说明模型把真假排得更对了，不只是把判定线挪了挪。

**Gemma 打平要如实写**：Gemma 的均值差本来就不弱（L16 α2，ΔJ +0.055），新 DAS 规则选中 L12 只有 +0.034；但 `10` 的逐层表显示 Gemma 末层 L33 的 DAS 有 +0.07，不漏作答率。所以"打平"一部分是 192 对调参集上选层不稳造成的，第二个数据集会说明。

**对论文：积极，是方法贡献，2 胜 1 平。**

## 3. 和 CDAS（2602.05234，ICLR 2026）的区别

CDAS 也是"把 DAS 的换零件干预拿来做 steering"，而且它在 AxBench（500 个概念的 steering 基准）上也报了 DAS 式方法全面高于均值差——这一点**和我们一致，是支撑**。但它有一句结论和我们正好相反：**"原始 DAS 的标签交叉熵目标做 steering 几乎无效"**，它因此改用全词表分布匹配（JSD）。我们的新目标恰恰就是标签交叉熵，而且胜过了我们自己那个"模仿输出分布"的旧目标。

| | CDAS | 我们 |
|---|---|---|
| 训练目标 | 让换零件后的**整个输出分布**向反事实分布靠（JSD） | 让换零件后**首词元的 True / False 标签**押中被换进来那句的金标签（交叉熵） |
| 任务 | AxBench：500 个开放概念的生成式 steering（"让输出更像在谈某个概念"） | 真假陈述判别：一个二分类的判定词 + 自报作答率（2×2） |
| 部署写法 | **夹值**：把方向上的坐标直接设成一个固定值 | **放大**：h + α·wwᵀ(h − c)，把模型自己在这个方向上的信号放大，保留每句话自己的符号 |
| 位置 | 源提示的单个位置换到基础序列的多个位置 | 提示末位一步，训练和评测同一位置 |
| 方向 | 联合训练两条方向 | 每层一条秩 1 方向，多种子按符号对齐后平均 |
| 结论 | 标签交叉熵目标几乎无效；分布匹配有效 | 标签交叉熵 + 单步 + 双向胜过分布匹配式旧目标（+0.017 / +0.013，双向再 +0.019） |

**我们怎么解释这个"相反"**：两边要推的东西不一样。CDAS 要改的是整段生成的风格 / 概念，目标是整个分布，匹配整个分布当然合适；我们要改的是一个二元判定，把训练信号摊到全词表上反而稀释了，直接押那一个标签词更准。这不是谁对谁错，是任务决定目标。**但这只是解释，不是证明**：要在我们的任务上用 CDAS 式的 JSD 目标训一遍，和新目标头对头比，才能写进论文（`07` 方案 D）。

另一篇预印本（2602.08159）说 11 个模型上均值差、探针、DAS 三者的 AUC 在 ±0.02 内一致；我们 DAS 比均值差 AUROC 高 0.022–0.030，区间不含 0。差别可能来自目标（金标签双向交叉熵）和任务（真假判别的 steering 而不是探针），论文里要点到。

**部署写法的一个副产品**：我们放大而不是夹值，是"E 只提判别、不动作答率"能成立的原因之一——夹值会把所有句子都推向同一个值，放大只放大模型自己已有的倾向。但报告 `15` 发现"固定中心放大在 Qwen 末层解码位置会压平输出分布"，正是这个写法在自由生成里的代价（首页阻碍 1）。
