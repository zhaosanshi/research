# 09 按赵磊的口径重做 C+E：E41（2026-11-07）

赵磊（11-07）："C+E 的方法，我理解应该是找到某层 C 的正结果，然后做所有层的 E，然后看 C+E。"

完整诊断与预声明：[`claude_gpt_review/from_claude/16_E41_固定C全层E_诊断与预声明.md`](../../../claude_gpt_review/from_claude/16_E41_固定C全层E_诊断与预声明.md)（提交 `003627e`，在任何结果出来之前）。E41 是本项目实验编号（E1 … E26 同作答率、E27 生成适配、E28–E40 为 GPT 第 20 / 21 轮的实验），不是"E 方向的第 41 版"。

## 1. 为什么要重做

GPT 第 18–21 轮的 C+E 实验，没有一轮是"验证过的 C + 全部层的 E"：

| | 正式 2×2 验证过的 C | GPT 第 18–21 轮用的 C |
|---|---|---|
| 估计方法 | 提示对比（自信 / 谨慎系统提示下的均值差）或自报（模型说 Yes / No 两组的均值差） | 隐藏态与"Yes 减 No 连续分数"的协方差方向 |
| 提示 | "Do you know the answer to this question?" | 第 20 轮换成新的"能力"提示，C 随之重估——C 的定义变了 |
| 层 | 全层扫描，调参集上按实际效果选 | 每模型只留 1 层，按估计集上的读出相关性选 |
| 力度 | α = 2（乘以两组均值间距） | ±1 倍标准差；第 21 轮再降到实际写入量中位数的 1–2% |
| 实际效果 | Llama 自报作答率 −0.60 / +0.25，Qwen −0.48 / +0.44，Gemma −0.75 / +0.25，J 几乎不动 | 不可比 |

E 侧：2×2 扫了全部层；GPT 的 C+E 只用了旧扫描前 3 名候选层，第 21 轮固定 1 层，且 Qwen 最好的 E35 被排除。

另外两点必须说清：
- **配额口径下只平移门槛的 C 天然无效。** 按分数排序取前 K，C 把门控分整体平移（秩相关 0.96–0.998），前 K 几乎不变。这是设计决定的，不是代码错（Claude 的独立重算：244 格、225 个冻结选择零差异；GPT 第 20 轮复算同样一致）。
- **GPT 自己的原生门控诊断显示门控分挑题差于置信度**（同样数量下 Llama 真假判断 145 对 152）。所以给 C 公平机会的口径是：让模型自己决定答不答，再和"用门槛卡到同样多"比。

## 2. E41 的设计

- **任务**：真假判断（TruthfulQA 陈述 1442 条 = 721 对；调参 192 对、测试 529 对，与 2×2 同一划分、同一种子）。
- **固定 C**（每模型两条，2×2 协议所选的估计器、层、符号、力度）：Llama 提示对比 C，推向弃答 L25 α2、推向作答 L26 α2；Qwen 自报 C，L33 α2 / L24 α2；Gemma 提示对比 C，L25 α2 / L23 α2。方向估计与 2×2 同一代码路径（同一 192 条估计陈述、同一 DAS 文件、对同层 DAS-E 正交）。
- **E**：每一层 × α ∈ {2, 3}；先新 DAS，再均值差各跑一遍。
- **条件**：原模型、C 单独 ×2、每层每力度的 E 单独、E + C 弃答、E + C 作答（Llama 195、Qwen 219、Gemma 207 个条件）。
- **每条陈述保存**：第一遍 Yes / No 及其连续门控分（新增；2×2 没存）；第二遍 p(True) 与 True − False 对数差。
- **自检**：与 2×2 共享的条件（原模型、E 单独、C 单独）必须逐条逐位复现 2×2 的扫描文件，原模型不复现则中止。Llama 48 条试点：67 个共享条件全部逐位相同；固定 C 的间距与夹角（6.29 / 7.05，0.065 / 0.071）与报告 11 一致。
- **代码**：`scripts/e41_fixed_c_all_e.py`、`review_checks/e41_chain.sh`、`review_checks/e41_analysis.py`（快照在 `05_代码/快照/`）。

## 3. 预声明的分析（结果出来之前写定）

全部在测试半（529 对）报告；区间用按题对重抽样 2000 次；每个模型内部 Holm 校正。

- **V1 可加性**：E+C 相对 E 的 Δ作答率 / ΔJ / ΔAUROC / ΔB，以及相对 C。看 C 的作答率位移是否在 E 之上保留、E 的 J 增益是否在 C 之上保留。
- **V2 同样多的自答题（主检验）**："自答" = 第一遍模型说 Yes；K = 自答数；答对 = 自答题里第二遍判对的数量。
  - P1：E+C 自答答对数 − E 按自己的门控分卡到同样 K 的答对数；
  - P2：E+C 自答答对数 − E 按真假置信度卡到同样 K 的答对数；
  - P3：C 自答 − 原模型按门控分卡到同样 K；P4：E 自答 − 原模型卡到同样 K。
  - **主族 = P1、P2 在 2×2 所选 E 层（Llama L11 α3、Qwen L35 α3、Gemma L12 α3）× C 两个符号，共 4 项，Holm 校正。** 正值 = C 挑出来的题比门槛挑的更准。其余层全部按层报表（探索）；调参集上选出的最好层在测试集上报并标明"探索"。
- **V3 配额口径**（与 E26 / GPT 第 20 轮可比）：按真假置信度排序，测试集 25 / 50 / 75% 配额下各臂答对数，E+C − E 带区间。
- **决策规则**：主族 4 项任何一项 Holm 后显著为正 → "验证过的 C 在同作答率下有额外收益"成立，进入自由问答版本；全部不显著且探索表里 P2 > 0 的层不多于一半 → C 的作用就是门槛，论文主张改写为"E 抬曲线、C 沿曲线走"；V1 若在多数层成立，单独作为积极结果报。
