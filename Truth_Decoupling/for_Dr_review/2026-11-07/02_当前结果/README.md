## 1. 实验设置

| 项目 | 真假判断任务（TF 协议） | 自由问答任务 |
|---|---|---|
| 输入 | 陈述，例如 "The answer to the question … is: …" | TruthfulQA 原题，模型自由作答 |
| 读出 | 第一遍"你知道答案吗" Yes / No → 自报作答率；第二遍强制 True / False → J、AUROC、偏置 | 生成的回答由 DeepSeek 按语义打分：对 / 错 / 弃答 |
| 干预位置 | 提示末位，E 与 C 在两遍前向都施加 | 答案末位（v1）；读出改为新用户轮的版本同上 |
| 选择规则 | E：调参集上 \|Δ自报作答率\| ≤ 0.03 下取最大 ΔJ；C：\|ΔJ\| ≤ 0.02 且 \|ΔB\| ≤ 0.05 下取最大 \|Δ作答率\| | 代理筛选每估计器前三层 → 192 题真实生成 → 净答对增加且作答数变化 ≤ 5 / 192 才冻结 → 529 题测试 |
| 估计数据 | 96 对 | 92 对 |

另一种 C（Llama / Gemma 的自报 C、Qwen 的提示对比 C）也列在 [`关键结果文件/真假判断_<模型>/report_2x2_das_tfce.md`](关键结果文件/)。

**不经任何挑选的全扫描**（测试集，全部条件；"明显改作答率" = 动 ≥ 10 个百分点；C 为协议所用的那种）：

| 模型 | E 不碰自报作答率（\|Δ\| ≤ 0.03） | E 提高 J | E 提高 AUROC | C 明显改作答率的条件 | 其中 AUROC 变化 ≤ 0.02 | 其中 J 变化 ≤ 0.02 |
|---|---|---|---|---|---|---|
| Llama | 64 / 64 | 64 / 64 | 64 / 64 | 58 | 58 | 46 |
| Qwen | 55 / 72 | 72 / 72 | 72 / 72 | 59 | 57 | 24 |
| Gemma | 45 / 68 | 64 / 68 | 66 / 68 | 64 | 60 | 44 |

**等价性核对**（按预定容差，用 95% 区间；精确值取自 GPT 复算）：
- E 格自报作答率：Qwen [−0.0038, +0.0151]、Gemma [−0.0227, +0.0076] 落在 ±0.03 内；Llama [−0.0189, +0.0302] 上界超出一题（16 / 529）。
- 协议 C 六格的 J：没有一格的区间完全落在 ±0.02 内。
- 协议 C 六格的偏置：区间**全部不含 0**，其中四格越过 ±0.05（Llama 推向作答 +0.039 [+0.028, +0.051]；Qwen 推向弃答 −0.041 [−0.054, −0.028]、推向作答 +0.044 [+0.030, +0.059]；Gemma 推向弃答 −0.040 [−0.053, −0.027]）。方向一致：推向作答更爱判"真"，推向弃答更少判"真"。

**对论文：积极，但只能写"任务内的近似选择性"。** 限定有四条：① 作答率是第一遍"你知道答案吗"的自报，和真假判断来自两次不同提示的前向，不是自由回答里的真实弃答；② C 有三格伴随判别损伤，Qwen、Gemma 那两格的 AUROC 降幅约为同模型 E 格提升的 56% 和 52%；③ "C 不碰判别"只有点估计支持；④ C 会系统地挪真假判断的偏置（1–4 个百分点）。Qwen 的自报 C 推得狠时，近六成条件的 J 会动但 AUROC 基本不动——这符合"挪门槛"的解释，但这是推断，没有直接测过。

诊断（调参集 192 题上）：直接把正确答案的坐标换进去（金标对照）也不改变生成（Llama 0 [−1.6, +1.6]、Qwen −0.5 [−2.6, +1.0] 个百分点）。v1 的同轮自检读出基线判别很差（下表 F0），换格式能改善，但读出修好后自由生成仍不改善，所以读出不是已证实的根因；DAS 的监督目标本身是金标签。

自检读出格式 †（测试 523 对，AUROC；0.5 = 瞎猜）：

| 模型 | F0 同轮（v1） | F1 新用户轮 | F2 TF 陈述 | F3 候选答案 |
|---|---|---|---|---|
| Llama | 0.506 | 0.651 | **0.781** | 0.708 |
| Qwen | 0.738 | **0.823** | 0.816 | 0.804 |
| Gemma | 0.536 | 0.621 | **0.796** | 0.715 |

**对论文：消极。** 可以下的结论是"这些已测试的问答部署配置没有显示稳定的自由生成收益"，不外推到所有问答方向。作为参照，ICML 2026 的 KAPPA 在选择题上提升很大，但它的自由生成测试只有一个模型（Qwen2.5-7B），TruthfulQA 上只提高约 2.5 个百分点（见 `04`）。

## 6. 更早的结果（旧协议，供参考）

这些线决定了现在的协议与数据集，但不是在统一协议下做的；数字只在汇总报告里（`claude_gpt_review/from_claude/06` 第 3 节），原始文件多数在本地、未上传，未经 GPT 复算；进论文前要重验。

| 线 | 结果 | 极性 |
|---|---|---|
| 写入机制正对照：把金标签写进 E 方向 | AUROC → 1.0、J 0.72 → 1.0 | 积极（机制无 bug） |
| 知识探针门控（E10） | 陈述级纠正 211 / 误伤 39（959 条原本判对的陈述），全题正确率 0.665 → 0.787 | 当时积极；未达"不伤已会题 ≤ 1 个百分点" |
