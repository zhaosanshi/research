## 一、一句话结论

**真假判断任务上的 2×2 在三个模型上成立（近似选择性），新 DAS 目标在两个模型上胜过均值差，E 的提升在相同作答率下保留——这是论文能站住的正结果。自由回答上 E 还没有效果，博士 11-05 的主句"相同作答率下组合胜任何单方向"在已跑的实现里不成立——这两条是要克服的阻碍，不是终局。**

## 二、积极的结果

每条带数字、复算状态、对论文的意义。测试集 = 529 对陈述（1058 条）或 523 道有实质金标的问答题；括号里是配对自举 95% 区间（整道题重抽样 2000 次）。

| 模型 | 放大 E：ΔJ / ΔAUROC / Δ自报作答率 | C 推向弃答：Δ作答率 / ΔJ | C 推向作答：Δ作答率 / ΔJ |

| Qwen3-8B | **+0.070 [+0.038, +0.104] / +0.031 [+0.022, +0.040]** / +0.006 [−0.004, +0.015] | **−0.482** / −0.013 [−0.036, +0.009] | **+0.444** / −0.017 [−0.043, +0.011] |
| Gemma-3-4B | **+0.034 [+0.006, +0.062] / +0.032 [+0.025, +0.039]** / −0.008 [−0.023, +0.008] | **−0.747** / +0.004 [−0.019, +0.026] | **+0.253** / +0.004 [−0.017, +0.023] |

- **E 这一行**：放大 E，三个模型的判别力都显著提高，自报作答率一点没动。不是挑出来的：不经任何规则的全扫描里，E 在 204 个条件里 200 个提高 J、202 个提高 AUROC。
- **C 这一行**：推 C，自报作答率动 48–75 个百分点（Llama 632、Qwen 510、Gemma 790 条陈述的自报翻转），而 1058 条真假判断里只有 13 / 43 / 42 条结论被改，排序判别力 AUROC 的变化 −0.0008 / −0.0010 / +0.0039，区间都含 0；推向作答时 Qwen、Gemma 规则选中层的 AUROC 下降 0.017，换层可消除但偏置挪 5–7 个百分点。**每一层、每个条件的完整数据在 [`10`](10_E逐层扫描与C严格不干扰/README.md)，不设阈值，写"严格"还是"近似"请博士定。**
- **层、强度都在 192 对调参数据上按事先写好的规则选，529 对测试数据上报**；三个模型用同一套规则。E 的每一层提升了多少、规律是什么（前三分之一无效、中段 40–55% 一个峰、末层一个峰且不漏），也在 `10`。
- **复算状态**：GPT 第 17 轮从逐题数组复算 12312 个指标零差异。
- **对论文：积极，是主结果。** 限定只剩两条：作答率是自报（第四节阻碍 4）；Qwen、Gemma 推向作答时有上面那点小代价。

### 2. 新 DAS 训练目标胜过均值差（方法贡献）

把 DAS 的训练目标换成"源陈述的金标签、标签首词元概率的交叉熵、提示末位一步、双向"之后：

| 模型 | 新 DAS 减均值差：ΔJ 之差 / ΔAUROC 之差 | 新 DAS 减旧 DAS（匹配模型自己续写的 KL 目标） |
|---|---|---|
| Llama | **+0.036 [+0.004, +0.070] / +0.030 [+0.022, +0.038]** | **+0.030 [+0.008, +0.055] / +0.031 [+0.024, +0.039]** |
| Qwen | **+0.038 [+0.008, +0.070] / +0.022 [+0.014, +0.030]** | +0.019 [−0.011, +0.049] / **+0.018 [+0.010, +0.027]** |
| Gemma | −0.021 [−0.051, +0.008] / +0.003 [−0.003, +0.009]（打平） | +0.017 [−0.002, +0.036] / **+0.025 [+0.019, +0.031]** |

- **拆分**（Llama）：从旧目标换成"金标签 + 单步交叉熵（单向）"，J +0.017 [+0.004, +0.034]、AUROC +0.013 [+0.010, +0.015]；再加双向，AUROC 又 +0.019 [+0.013, +0.025]。AUROC 同时显著说明是判别力本身变好，不只是门槛挪动。
- **对论文：积极。** 这和 CDAS（ICLR 2026）"标签交叉熵目标做 steering 几乎无效"的报告方向相反，细节见第三节。Gemma 上新目标把 DAS 从明显落后追到与均值差打平。
- **人话版的完整解释**（两种方法各自在干什么、换了什么、为什么胜、和 CDAS 逐项差别、还欠的两个对照）在 [`11`](11_新DAS目标为什么胜均值差_与CDAS的区别/README.md)。

### 3. 相同作答率下，E 的提升保留（真假判断）

固定交付 50% 的实质回答（529 / 1058 条陈述），所有方法用同样的真假置信度挑题，交付集里答对的题数：

| 模型 | 原模型 | 只推 E | 只推 C | E+C |
|---|---|---|---|---|
| Llama（DAS） | 417 | **457** | 425 | 453 |
| Qwen（DAS） | 453 | **470** | 449 | 472 |

- E 对原模型：Llama +40、Qwen +17，按承诺分挑题时两模型 50% / 75% 档也都显著（+26 到 +40 题，Holm 校正后）。GPT 第 20 轮修正门控提示后重跑，数字如上，与 Claude 的 E26 结论一致。E41 用验证过的设置再做一遍：三模型、25 / 50 / 75% 九个格子全正（+5 到 +42 题）。
- **对论文：积极。** 说明 E 提高的是"同样多回答里答对多少"，不是靠多答题。**"交付 / 配额"是什么、为什么这样比、E 为什么留得住而 C 和 E27 留不住，人话版在 [`12`](12_相同作答率这把尺子/README.md)。**

### 4. "相同作答率"这把尺子本身有效（方法论贡献）

GPT 第 18 轮的生成适配（E27）在自然作答率下让 Qwen 多答对 40–50 题；对齐作答率后，三种适配器都不比原模型好（DAS 起步按原判 +13，扣掉乱码后 −2）。表面提升来自"答得更多"，不是"答得更准"。

- **对论文：积极。** 这是"真实性干预的表面提升可能来自改变作答率"的第一个实例，正是博士坚持的口径。同一把尺子下三类干预分出三种结果（E 保留、C 是门槛、E27 消失），见 [`12`](12_相同作答率这把尺子/README.md) 第 3 节。ITI 原文附录里很多"翻成真话"的例子其实是改口"我不评论"，TruthX 的提示自带"不确定就说我不评论"——要把这一条升成普遍主张，需要在相同作答率下重评 ITI、CAA、TruthX（第四节阻碍 5）。

### 5. C 是可用的作答量旋钮，判别代价接近零

- 2×2 里 C 一格就能把自报作答率移动 25–75 个百分点，判别力几乎不动（第 1 条）。
- 让 C 的 Yes / No 真的决定交付（GPT 第 20 轮"原生门控"诊断，192 道调参题）：自由问答交付量从 2 / 192 到 164 / 192（Llama）、0 到 117 / 192（Qwen）；真假判断 0 到 308 / 384、0 到 384 / 384。**之前"C 对实际作答只能改 4–6 个点"的说法要撤回**——那是把 C 写进答案提示后模型自己弃答变了多少，不是让 C 决定交付。
- **E41（11-07，`09`）证明两个旋钮能一起转**：在验证过的 C 之上加 E，E 的 J / AUROC 增益原样保留（Llama +0.106 / +0.048，与 E 单独一样）；在 E 之上加 C，C 的作答率位移原样保留（−0.49 到 −0.74、+0.24 到 +0.42）。六格里五格如此；例外是 Qwen 推作答（C 在 L24、E 在末层 L35）J 掉 0.108、偏置挪 −0.10，是两条方向相互作用的一个实例。
- **对论文：积极。** 和第 3 条合起来是一条可写的主线："E 抬曲线，C 沿曲线走"：E 提高判别，C 以接近零判别代价设定作答率，两者可叠加。

### 6. 自报承诺分是差的挑题依据（新发现）

真假判断上，按"你知道吗"的承诺分挑题，75% 档比随机挑还差（Qwen −49 题，Holm 校正后显著；Llama −42，校正后 0.074）；E+C 配承诺分挑题在 5 个格子里显著输给简单置信度挑题。GPT 第 20 轮的原生门控诊断同样显示：同样交付数量下，C 门控挑出的题答对数低于"固定 E + 置信度门槛"（Llama 真假判断 K = 192：145 对 152；自由问答 K = 155：52 对 64）。

- E41 又加了一组：让模型自己决定答哪些，比不推 C、按真假置信度卡到同样多的题少答对 63 / 92 / 68 题（三模型，区间都不含 0）。
- **对论文：中性偏积极。** 可写的发现，与 Kumaran 等（口头置信跟踪"承诺"、词元概率跟踪"答对"）互证；它也解释了为什么 C+E 在配额口径下不胜 E。一个要测的限定：TruthfulQA 的题多是流行误解，"知道感"和正确性在这里是反的，别的数据集未必如此。人话版与写法建议在 [`13`](13_自报承诺分是差的挑题依据/README.md)。

### 8. 方向是真的、机制是通的（旧协议下的验证，进论文前要在统一协议下重做）

- **标签打乱的空对照**：用打乱标签重估的方向推，AUROC 只 +0.017，真方向 +0.084（Llama，TruthfulQA，旧协议）。
- **写入机制正对照**：把金标签直接写进 E 方向，AUROC → 1.0、J → 1.0；说明写入通路没有 bug。
- **知识缺口诊断**：只有 TruthfulQA 存在"内部探针比嘴准"的差距（0.928 对 0.757，17 个点）；FEVER / CounterFact / GoT 上没有差距，E 无物可放大。这既是 E 的适用边界（第四节），也是对"E 在放大什么"的正面解释。
- **对论文：积极**，但这些是旧协议数字，列为"待在统一协议下重验"（第四节阻碍 9）。

### 9. 旧协议下的跨模型线索（待重验）

门控写入在五个 ≥ 1.7B 的模型上，TruthfulQA（+4 到 +12 个百分点）和 BBQ 都成立，知识集不伤；KAPPA 式转写写入在陈述读出口径的 MC1 上五模型 +8.6 到 +13.7 个百分点。**对论文：积极的线索**，说明方向有跨模型、跨数据集的潜力；但不是统一协议，不能直接写进主表。

### 10. 机制线索：自由回答失败可能出在"写法"，不在"方向"

在 Qwen 第 34 层解码位置，原 DAS 方向用固定中心放大写法写入后，模型答完"I don't know."该出结束符时，结束符的概率只剩 0.06%–0.1%（不加干预约 100%），虽然它仍是最高分词。也就是说这种写法本身会把输出分布压平。

- **对论文：中性偏积极。** 它给第四节阻碍 1（自由回答方法没找对）指了方向：换写法、不换方向。GPT 第 20 轮的"来源状态交换"写法正是去掉固定中心的尝试。

### 11. 文献位置空着

75 篇全文读完（`04`）：没有人在 steering 层面做过同时带判别指标和作答率指标的 2×2；"相同作答率下比较判别方向与承诺方向的组合"基本空着（最近的 LITO 不对齐作答率，YOPO 只在固定 25% 弃答比例做过近似等覆盖率比较）。详细对照见第三节。

### 12. 可审计性

分析计划先于结果提交（E26、E41 都是）；三方独立复算（GPT 复算 Claude、Claude 重跑 GPT，均有逐题证据）；GPU 实验逐字节复现。不是结果，但审稿时是硬度。

### 13. E41 带来的两条积极结果（11-07 / 11-08，`09`）

E41 是按赵磊口径重做的 C+E（2×2 验证过的 C 固定，E 扫全部层，三模型，DAS 与均值差两版）。主检验的答案是"C 是门槛"（阻碍 2），但它同时给出两条正面的东西：

1. **两个旋钮能一起转。** 在 C 之上加 E，E 的判别增益原样保留（Llama J +0.106 / AUROC +0.048，与 E 单独的 +0.091 / +0.048 一样）；在 E 之上加 C，C 的作答率位移原样保留（−0.49 到 −0.74、+0.24 到 +0.42）。DAS 版 6 格里 5 格如此，均值差版类似。例外是 Qwen 推作答（C 在 L24、E 在末层 L35）：J 掉 0.108（均值差版 −0.034），两条方向在这个布局下相互作用——写进限制。**对论文：积极**，是"E 抬曲线、C 沿曲线走"这句话里"两者可叠加"的依据。
2. **DAS 方向比均值差方向更干净。** Llama 上，C 单独把自报作答率压低 0.597；叠上 DAS E 之后仍是 −0.565（几乎原样），叠上均值差 E 之后只剩 −0.272——均值差 E 把 C 的位移推回了一半，说明均值差方向里混着承诺成分，DAS 方向没有。**对论文：积极**，给积极 2（DAS 胜均值差）多了一条机制层面的证据，和 `11` 里"DAS 找的是模型真拿来用的方向"一致。

另外两点可写：E41 的共享条件逐位复现了 2×2 的扫描（67 / 75 / 71 全部一致），以及"模型自选的题 ≈ 按门控分卡阈值选的题"这一事实本身（Llama 差 ±2 题），它把 C 的作用机制钉死了：C 是整体平移门控分，不换题。

## 三、与顶会工作的差别（哪里一样、哪里不一样、对我们是威胁还是支撑）

| 工作 | 他们做了什么 | 我们不一样在哪 | 对论文 |
|---|---|---|---|
| **CDAS**（2602.05234，ICLR 2026） | 把 DAS 的交换干预当 steering 原语；两个方向同训；用全词表 JSD 分布匹配代替原始 DAS 的标签交叉熵目标；报告原始 DAS 的标签交叉熵目标做 steering 几乎无效；在 AxBench 上 DAS 式方法高于均值差；部署用夹值；没有真假判别任务 | 我们的新目标**恰是标签交叉熵**（加金标签、提示末位一步、双向），部署是沿方向放大 h + α·wwᵀ(h − c)，不需要来源；在真假判别上胜过均值差，也胜过我们自己的"匹配模型续写分布"的旧目标（第二节 2 的拆分）。任务不同（概念 steering 对真假判别），不是一对一复现 | **要正面讨论的差异**：结论方向相反。我们的解释：任务决定目标——改整段生成的风格要匹配整个分布，改一个二元判定则直接押标签词更准；只是解释，要补头对头对照（在我们的任务上跑 CDAS 式 JSD 目标）。详见 `11` |
| **2602.08159**（预印本） | 11 个模型上均值差、探针、DAS 三者 AUC 在 ±0.02 内一致 | 我们 DAS 比均值差 AUROC 高 +0.022 到 +0.030，区间不含 0 | 与它的结论不同；差别可能来自目标（金标签双向交叉熵）与任务（真假判别 steering 而非探针） |
| **KAPPA**（2509.23782，ICML 2026） | 知识子空间与预测子空间在深层近乎正交；把预测坐标换成知识坐标，TruthfulQA 选择题 Llama 56.7 → 73.5；自由生成只测一个模型（Qwen2.5-7B）+2.5 | 与 E 同构但没有弃答轴（没有 C），没有作答率控制；它是转写坐标，我们是放大学出的方向；效应量不可直接比（选择题准确率对 J） | **审稿人一定会拿来比效应量**。我们的卖点必须是"相同作答率下的干净提升 + 两个方向的分工"，不是绝对数。旧协议下我们的转写式写入 MC1 +8.6 到 +13.7（第二节 9）说明同一机制在我们这边也在 |
| **Kumaran 等**（2606.29490，Google DeepMind 预印本） | 口头置信跟踪"承诺"，词元概率跟踪"答对"；Gemma 上决策探针与正确性探针方向近乎正交（cos −0.01）；沿口头置信分量 steering 能改变弃答率，沿词元概率分量 steering 也会改弃答率；只有图、无数值表、无随机对照 | 同一对术语（证据 / 承诺）。它只做了"C → 弃答率"一格；我们四格都有数字、三模型、事先规则、置信区间；但我们的作答率是自报 | **威胁最高的一篇**（术语和故事都重叠）。我们必须引用并说明：我们补的是四格、三模型、规则选择，以及"E 胜均值差" |
| **Refusal Index**（2510.01782，ICLR 2026） | 行为层面：改提示能大幅挪拒答率，但拒答与答错的秩相关几乎不变 | 它是我们 C 行的行为版；我们找到了实现它的内部方向，并加上了 E 侧 | 支撑。弃答质量可直接用它的指标（拒答指数）与 16 个模型对比 |
| **承诺-弃答电路**（2609.32964，NeurIPS 2026，作者自述接收） | 把幻觉定义为"无依据的承诺"，定位稀疏电路，训练轻量策略决定弃答 | 占住了"承诺 / 弃答"叙事；不处理"可答题答错"，没有证据方向，没有 2×2 | 概念层面"知道 ≠ 说"不能主张为新；要在相关工作里正面放 |
| **LITO**（2405.00301，ACL 2024 Findings）、**YOPO**（2608.14465，预印本） | LITO：多档强度推 ITI 方向 + 学一个判对错的小网络，全判错就说"我不评论"，不对齐作答率，部分数据集输给简单基线；YOPO：写入器提准确率 + 读出器决定弃答，固定弃答 25% 时组合在域内胜单独、跨域不胜；主张弃答该读出、不该推进去 | 博士主句的最近邻。我们的发现（C 等于门槛、门控分挑题差）和 YOPO"弃答该读不该推"一致；我们的增量是相同作答率的框架 + E 在其中保留提升 | 既是先例也是支撑；审稿人会问"为什么要推 C 而不是读出"，答案就是第二节 5：C 是设定作答率的旋钮，不是挑题器 |
| **ITI**（NeurIPS 2023）、**CAA**（ACL 2024）、**TruthX**（ACL 2024） | 真实性 steering 的标准基线；ITI 真且有信息量 30.5 → 43.5；TruthX True×Info 31.9 → 65.5 | 它们都没有在相同作答率下报；ITI 的增益部分来自改口"我不评论" | 必比的基线；我们"相同作答率"口径的最好动机（第四节阻碍 5） |
| **Dr. No**（2611.03862，预印本） | 推稀疏自编码器里的弃答特征；给弃答选项加简单 logit 偏置效果差不多（UNK-VQA 38.0 对 38.7），另一数据集推特征还输给按词元概率设门槛 | 支持"推 C ≈ 设门槛"这个读法 | 支撑我们第二节 5、6 的解释；也提醒必须和门槛比 |
| **ReFT / LoReFT**（NeurIPS 2024）、**RePS**（NeurIPS 2025）、**AxBench 的 SSV**（ICML 2025） | 冻结底座、用监督信号训练少量表示参数或秩 1 向量 | GPT 第 18 轮的生成适配 E27 的算子就是参数绑定的秩 1 LoReFT（取 R = wᵀ、W = (1+α)wᵀ、b = −α·wᵀc，代数验算），训练方式已有先例 | 这是 E27 被叫停的原因之一：没有新东西，收益又来自有监督训练而非 DAS |
| **AxBench**（2501.17148，ICML 2025） | 500 个概念上提示词总分 0.894，远超所有表征 steering | 审稿人一定会问"提示词是否就够" | 基线清单里必须有提示词（自信 / 谨慎系统提示） |

## 四、阻碍与对策

阻碍不是结果，是研究中要翻过去的坎。重要的六条逐条写；其余五条已处理或已写成限制，一张表带过。

### 阻碍 1：自由回答的方法还没找对

- **现状**：放大 E，三模型自由回答答对数不动（523 题，−4 到 +3）；Gemma 连合格配置都没有。之后几轮的"提升"要么来自额外的有监督训练（E27，与 DAS 无关），要么只在调参集上（GPT 第 20 轮 E32 / E34 来源交换），要么对齐作答率后消失。
- **为什么要紧**：博士结构里两个任务各一半；自由回答不成立，"方法对比表"就只剩真假判断，档次直接掉一级。
- **线索**：第二节 10——固定中心放大写法在解码位置把输出分布压平；问题可能在写法。另一条：E 在自由回答里**读得出**对错（`15`，三模型 0.67–0.78，恰在后段读得最准），而 E25 正是在后段写的——读得最准的地方写了却没改变回答。赵磊 11-08 的判断：**"能看得出来，就一定能改得动，现在改不动是没改对"**——这是记事本的第一优先级。
- **对策**：换写法不换方向。候选是去掉固定中心的"来源状态交换"（GPT 第 20 轮已实现，E32 / E34 调参集有小幅正信号，但 Qwen 有截断与裁判问题）。**报任何收益之前必须满足三条**：同作答率评估并报弃答率；尺度匹配的随机方向对照（不训练的随机方向每步只改 1–3%，比 E 小一个量级，不是公平空对照）；无信息来源对照（训练相同、只把来源换成中性指令或别的题）。
- **谁在做**：GPT 第 20 / 21 轮做了 E32 / E34；Claude 审核后决定是否推进到测试集。

### 阻碍 2：博士的主句"相同作答率下组合胜任何单方向"在已跑的实现里不成立

- **现状**：E26 主对比 12 格 0 格显著；GPT 修正门控提示后重跑 0 / 48 格；GPT 第 21 轮固定 E、C 在前 / 后 0 / 72（小幅正差在判分噪声内）。
- **为什么会这样（设计层面）**：配额口径按分数排序取前 K；C 的作用是把门控分整体平移（秩相关 0.96–0.998，实际交付题目只换 2–16 道），平移不改排序，所以 E+C 的交付集 ≈ E 的交付集。另一方面 C 的门控分本身挑题差于置信度（第二节 6）。
- **但已跑的实现还不是赵磊说的那个实验**：GPT 用的 C 不是 2×2 验证过的 C（估计方法、提示、层、力度都不同），E 只有 3 个候选层（`16`）。
- **E41 的答案（DAS 版，11-07 23:05）**：按赵磊的口径重做——2×2 验证过的 C 固定，E 扫全部层，主检验"模型自己决定答不答，E+C 自答的答对数对 E 用门槛卡到同样多"——**0 / 4 项为正**：Llama 上 C 自选的题和按门控分卡阈值选的只差 ±2 题，两者都比按置信度挑题少答对 34–36 题；Qwen 推作答时 E+C 比 E 卡门槛还差 53 题（两条方向相互作用）；全层探索没有一层能救（`09` 第 4 节）。**结论：C 的作用是门槛。**
- **对策**：主张改成"E 抬曲线、C 沿曲线走"（第二节 3、5），它保留博士"相同作答率"的口径，把 C 的角色从"挑题"改成"设定作答率"；E41 同时给出的"两个旋钮可叠加"（五格成立）是这句话的支撑。均值差版 E 明早补。
- **谁在做**：Claude；请博士看 `09` 后定主句。

### 阻碍 3：只有一个数据集，测试集已经被反复看过

- **现状**：TruthfulQA 817 题全部用过（96 估计 / 192 调参 / 529 测试），测试集在多轮里反复出现。所有当前数字严格说是"已看过的测试集上的比较"。
- **为什么要紧**：审稿人会直接问"是不是只在 TruthfulQA 成立"；而且早先旧协议检查显示知识类数据集（FEVER / CounterFact / GoT）没有内外差距，E 无物可放大，所以不是随便换一个就行。
- **对策**：换数据集重做。我们看过、试过的全部候选和各自有没有 E 的空间，列在 [`14`](14_泛化测试的候选数据集/README.md)，**请博士定先测哪个**（我们的首选是 BBQ：坑的性质和 TruthfulQA 不同，有 KAPPA 报告的差距，旧协议上做过）；到时候可行的都测一遍，优先博士推荐的，哪个效果好进论文。改写成真假陈述与问答两种形式，所有规则沿用，不再调。
- **谁在做**：待博士定优先级后由 Claude 做，每个数据集约 2 天。

### 阻碍 4：真假判断里的"作答率"是自报，不是真实弃答；C 推向作答时在两个模型上有小代价

- **现状**：2×2 的作答率来自单独一遍"你知道答案吗"的 Yes 比例，第二遍判真假是强制作答。C 对判别的全部影响见 `10`：推弃答三模型都干净（1058 条判断只改 7–43 条，AUROC 变化区间含 0）；推作答时 Qwen、Gemma 规则选中层 AUROC 下降 0.017（区间不含 0），换层可消除但偏置挪 5–7 个百分点；C 会系统地挪判定偏置（1–8 个百分点）。
- **为什么要紧**：审稿人会说这不是真弃答；"严格"二字要有数据撑着。
- **对策**：措辞由博士看 `10` 后定（写法 A 严格 / 写法 B 保守）；证据上用原生门控（C 的 Yes / No 真的决定交付）把"自报"变成"实际交付"，画风险–覆盖率曲线（E41 的主检验正是这个口径）；弃答质量用拒答指数（ICLR 2026）衡量，可与 16 个模型直接比；"真假结论被改数"作为 2×2 表的一列。
- **谁在做**：Claude（E41）。

### 阻碍 5：概念层面"知道 ≠ 说"已被占；效应量不大

- **现状**：Kumaran、拒答指数、KAPPA、承诺-弃答电路都讲过"知道和说是两回事"；我们 E 的 J 增益 +0.03 到 +0.09，KAPPA 在同一数据集的选择题上报 +17 点。
- **为什么要紧**：新颖性和分量都会被质疑。
- **对策**：卖点定在三处——steering 层面带两类指标的 2×2（没人做过四格）；"相同作答率"这把尺子（第二节 4，需要把 ITI / CAA / TruthX 在相同作答率下重评，证明"表面提升来自多答题"是普遍现象）；金标签交叉熵目标的 DAS 胜均值差（与 CDAS 结论相反，补头对头对照）。
- **谁在做**：ITI / CAA / TruthX 的同作答率重评约 2–4 天（基线实现占大头）；CDAS 目标对照约 1 天。

### 阻碍 6：判分有噪声

- **现状**：DeepSeek 裁判对同一段回答、换一次判分缓存，500 题里会翻 2–3 个标签；"没人来自月球"与"没人登过月球"被判成一样；纯个人拒答曾被判对（GPT 第 20 轮已加守卫）。
- **为什么要紧**：问答上 ±3 题以内的差异都没有意义；GPT 第 21 轮那些"小幅正差"就在这个范围里。
- **对策**：问答差异 ±3 题内不下结论；正式表用两套缓存一致的标签；关键题人工复核；真假判断不受影响（读出是确定性的）。
- **谁在做**：已写入分析规则。

## 六、请博士判断的问题

1. **论文主线选哪一句。**
   - (a) 博士 11-05 原句：在相同作答率下，组合是否比任何单独方向都好。E41 今晚出结果，是最后一次按正确口径的检验。
   - (b) **我们推荐的备选**：在相同作答率下比较，真实性干预的提升里只有判别方向 E 的那一部分保留；C 是设定作答率的旋钮，判别代价接近零——"E 抬曲线、C 沿曲线走"。它保留"相同作答率"的口径，避开"组合胜单方向"在配额口径下的设计硬伤。
   - (c) GPT 第 17 轮主线：DAS 目标组合改善真假判别，并显示与自报承诺的近似选择性。
2. **方向估计**：保留新 DAS（推荐），均值差作对照；还是按建议换成均值差。
3. **自由回答那一半怎么做**：(a) 换写法继续找（来源交换，满足阻碍 1 的三条）；(b) 改为"C 控制作答率 + E 核验自己的答案后弃答"，比风险–覆盖率曲线；(c) 写成适用边界。我们建议 (a) 与 (b) 并行一周，各自先在调参集过关再碰测试集。
4. **第二个数据集**：候选全表在 `14`，推荐 BBQ 先做；请博士定优先级，可行的都会测。
5. **基线清单**：只推 C；只推 E + 门槛；均值差方向（+ C）；不动模型只设门槛（P(True)、答案词元概率、弃答词元 logit 偏置）；提示词；ITI；CAA；TruthX；KAPPA；LITO / CASAL 式组合；CDAS 式目标。按风险–覆盖率曲线与固定作答率下的准确率比较。请增删。
6. **目标会议与时间**：现有材料是 ACL / EMNLP 主会的水平；自由回答做出来、BBQ 复现、基线重评齐了，才有冲 NeurIPS / ICLR 的可能。

## 八、术语

| 术语 | 含义 |
|---|---|
| E（证据方向） | 放大后应只提高真假判别力的方向 |
| C（承诺方向） | 推动后应只改变"答不答"的方向 |
| TF 协议 | 真假判断任务：两遍前向——第一遍问"你知道这题的答案吗"读 Yes / No 得自报作答率与门控分；第二遍强制判断陈述真假得 J、AUROC、偏置 B。E、C 两遍都施加 |
| J | 判别指数：真陈述的判真率减假陈述的判真率 |
| AUROC | 排序判别面积：真陈述的"真"分数排在假陈述前面的概率，不依赖门槛 |
| B（偏置） | 判"真"的比例 |
| 作答率（自报） | TF 协议第一遍里模型说"知道"的比例；**不是**自由回答里的真实弃答率 |
| 门控分 | 第一遍里 Yes 的对数概率减 No 的对数概率 |
| 简单置信 | 真假判断里 True 与 False 对数概率差的绝对值；问答里答案的平均词元对数概率 |
| 配额 / 同作答率 | 按某个分数排序、只交付前 K 个，再比交付集里答对多少 |
| 原生门控 | 让模型自己（被推 C 之后）的 Yes / No 决定交不交付 |
| 风险–覆盖率曲线 | 作答率从低到高变化时，已作答题里答错的比例怎么变；比较"相同作答率"的标准做法 |
| DAS | 分布式对齐搜索：交换模型内部表示的一小部分，训练能改变判断的方向。"新 DAS"指 11-05 改用的目标：源陈述的金标签、双向交叉熵、提示末位一步 |
| 均值差 | 真陈述激活均值减假陈述激活均值（96 对配对数据，等于配对差的均值） |
| 2×2 | 行 = 推 E / 推 C，列 = 判别力 / 作答率。**正对角**（E 动判别、C 动作答率）应大，**反对角**（E 动作答率、C 动判别）应接近 0；两半都成立才叫解耦 |
| 近似选择性 | 正对角显著、反对角点估计很小，但没有统计上证明反对角为 0 |
| 调参 / 测试 | 层、强度一律在 192 对调参数据上按事先规则选，529 对测试数据上报告 |
| 配对自举 | 同一批题重采样 2000 次比较两种条件的差值 |
| Holm 校正 | 同时做很多检验时收紧显著门槛 |
