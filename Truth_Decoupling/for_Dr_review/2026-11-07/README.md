### 4. "相同作答率"这把尺子本身有效（方法论贡献）

GPT 第 18 轮的生成适配（E27）在自然作答率下让 Qwen 多答对 40–50 题；对齐作答率后，三种适配器都不比原模型好（DAS 起步按原判 +13，扣掉乱码后 −2）。表面提升来自"答得更多"，不是"答得更准"。

- **对论文：积极。** 这是"真实性干预的表面提升可能来自改变作答率"的第一个实例，正是博士坚持的口径。同一把尺子下三类干预分出三种结果（E 保留、C 是门槛、E27 消失），见 [`12`](../../claude_gpt_review/博士包候补_2026-11-07/12_相同作答率这把尺子/README.md) 第 3 节。ITI 原文附录里很多"翻成真话"的例子其实是改口"我不评论"，TruthX 的提示自带"不确定就说我不评论"——要把这一条升成普遍主张，需要在相同作答率下重评 ITI、CAA、TruthX（第四节阻碍 5）。

### 5. C 是可用的作答量旋钮，判别代价接近零

- 2×2 里 C 一格就能把自报作答率移动 25–75 个百分点，判别力几乎不动（第 1 条）。
- 让 C 的 Yes / No 真的决定交付（GPT 第 20 轮"原生门控"诊断，192 道调参题）：自由问答交付量从 2 / 192 到 164 / 192（Llama）、0 到 117 / 192（Qwen）；真假判断 0 到 308 / 384、0 到 384 / 384。**之前"C 对实际作答只能改 4–6 个点"的说法要撤回**——那是把 C 写进答案提示后模型自己弃答变了多少，不是让 C 决定交付。
- **E41（11-07，`09`）证明两个旋钮能一起转**：在验证过的 C 之上加 E，E 的 J / AUROC 增益原样保留（Llama +0.106 / +0.048，与 E 单独一样）；在 E 之上加 C，C 的作答率位移原样保留（−0.49 到 −0.74、+0.24 到 +0.42）。六格里五格如此；例外是 Qwen 推作答（C 在 L24、E 在末层 L35）J 掉 0.108、偏置挪 −0.10，是两条方向相互作用的一个实例。
- **对论文：积极。** 和第 3 条合起来是一条可写的主线："E 抬曲线，C 沿曲线走"：E 提高判别，C 以接近零判别代价设定作答率，两者可叠加。

阻碍不是结果，是研究中要翻过去的坎。六条逐条写（已处理或已写成限制的另外五条，在完整版首页第四节末表）。**第一条是第一重要的消极问题（赵磊 11-08），请博士先答。**

### 阻碍 1（第一重要的消极问题）：真假判断里的"作答率"是自报，不是真实弃答；C 推向作答时在两个模型上有小代价

- **是什么**：真假判断对每条陈述跑两遍独立的前向。第一遍问这条陈述对应的**问题**"你知道这个问题的答案吗"（Do you know the answer to this question?），只读第一个词 Yes / No，同一对真假陈述共用一个答案——Yes 的比例就是 2×2 里的"作答率"，log p(Yes) − log p(No) 是门控分；第二遍**强制**它判 True / False，得 J、AUROC、偏置。所以"C 推弃答、作答率 −60 点"的字面意思是 Llama 说"知道答案"的比例从 65% 掉到 5%，而第二遍它照样被迫判了真假——量到的是模型**嘴上说**答不答，不是它**真的**答不答。
- **为什么是第一重要**：审稿人的三句话——"你改的是自我报告不是行为"；"第二遍是强制作答，所谓不干扰判别是因为你没给它弃答的机会"；最狠的一句："632 条自报翻转、13 条判决改变，这是'不碰判别'还是'只碰了一个无关输出'？"**"严格不干扰"和"完全无关"在这组数据上长得一样**，必须拿别的证据分开它们。C 整行的意义、"严格 / 近似选择性"的措辞，都挂在这一条上。
- **手里的反证**（`20` 第 3 节）：① 自报是模型内部连续"把握分"的二值读出，C 推的就是这个分数——E41 里 C 自选的题与按门控分卡到同样多的题几乎同一批（Llama 答对数差 ±2 题，两版一致）；② 但这个把握分和答对的关系弱（挑题差于置信度 34–95 题，`13`）——如实写，这是软肋；③ 推弃答一侧三模型干净：1058 条判决只改 13 / 43 / 42 条（Llama 最干净层 7 条），AUROC 区间含 0。推作答一侧 Qwen、Gemma 规则选中层 AUROC −0.0175 / −0.0165（区间不含 0，约为 E 增益的一半），换层可消除但偏置挪 5–7 个百分点；C 系统地挪偏置 1–8 个百分点。全部 12 行数字在 `20` 第 4 节。
- **能补的证据**（`20` 第 5 节，按成本）：a 拒答指数（ICLR 2026 指标，零 GPU，可与 16 个模型比）；b 2×2 表加"真假结论被改数"与等价边界两列（零 GPU）；c 原生门控交付 + 风险–覆盖率曲线（E41 已做，改称"门控交付率"）；d 第二遍不强制、给 Unknown 选项（半天 GPU，附加实验）；e 自由回答 2×2，弃答是真实输出（与 N0 合并）；f Mistral 第四模型 C 扫描（在跑）。a、b、c 不等博士也做。
- **请博士答**（`20` 第 6 节）：① 自报作答率这个口径论文里能不能站住，还是必须换成 c / d / e 之一；② 推弃答一侧写"严格不干扰"（写法 A）还是整体写"近似选择性"（写法 B）；③ 推作答的代价写成"换层可消除、代价是偏置"还是把推作答降为次要；④ 要不要补 d、e，放主文还是附录。
- **对论文**：消极但可控。口径被接受则 C 行按博士选的写法写、不用重跑；不被接受则 C 行按 d 或 e 重做成行为口径，E 行不受影响（E 不动自报作答率三模型全层成立）。

### 阻碍 2：自由回答的方法还没找对

- **现状**：放大 E，三模型自由回答答对数不动（523 题，−4 到 +3）；Gemma 连合格配置都没有。之后几轮的"提升"要么来自额外的有监督训练（E27，与 DAS 无关），要么只在调参集上（GPT 第 20 轮 E32 / E34 来源交换），要么对齐作答率后消失。
- **为什么要紧**：博士结构里两个任务各一半；自由回答不成立，"方法对比表"就只剩真假判断，档次直接掉一级。
- **线索**：第二节 10——固定中心放大写法在解码位置把输出分布压平；问题可能在写法。另一条：E 在自由回答里**读得出**对错（`15`，三模型 0.67–0.78，恰在后段读得最准），而 E25 正是在后段写的——读得最准的地方写了却没改变回答。赵磊 11-08 的判断：**"能看得出来，就一定能改得动，现在改不动是没改对"**——这是记事本的第一优先级。
- **对策**：换写法不换方向。候选是去掉固定中心的"来源状态交换"（GPT 第 20 轮已实现，E32 / E34 调参集有小幅正信号，但 Qwen 有截断与裁判问题）。**报任何收益之前必须满足三条**：同作答率评估并报弃答率；尺度匹配的随机方向对照（不训练的随机方向每步只改 1–3%，比 E 小一个量级，不是公平空对照）；无信息来源对照（训练相同、只把来源换成中性指令或别的题）。
- **谁在做**：GPT 第 20 / 21 轮做了 E32 / E34；Claude 审核后决定是否推进到测试集。
