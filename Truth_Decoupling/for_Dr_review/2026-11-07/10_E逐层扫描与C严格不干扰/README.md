# 10 E 逐层扫描与 C 的严格不干扰：全部数据，请博士定写法（2026-11-07）

赵磊 11-07 的两条要求：① "全部提升这个结论，以及每一层提升了多少，要列一个表格，看下有什么规律"；② "我们就是要写严格互不干扰，阈值不用限定，把情况都写清楚"。本页把四个模型（Mistral-7B 11-08 加入）E 的每一层、C 的每一层、以及最优层上 C 对判别的全部影响都摆出来，**不设任何容差阈值**（之前材料里的 ±0.02、±0.03、±0.05 是 Claude 在第 5 轮写选择规则时定的工程容差，没有公允来源，本页不再使用）。写成"严格"还是"近似"，请博士看完数据决定。

**口径（全页通用）**
- 测试半：529 对 = 1058 条陈述；Δ = 该条件减原模型；区间 = 按题对重抽样 2000 次的 95% 区间。
- E 条件：每一层 × 两档力度（α = 2、3）：Llama 32 层 64 个、Qwen 36 层 72 个、Gemma 34 层 68 个、Mistral 32 层 64 个，共 268 个。"漏" = E 把自报作答率带动超过 0.03（这样的层不算"只动判别"）。
- C 条件：两种估计器（提示对比、自报）× 每一层 × 两个方向（推弃答、推作答）× 两档力度（α = 1、2）。C 逐层表只列各模型协议估计器在 α = 2 的两方向；全部条件在原始文件里。
- 深度 = （层号 + 1）÷ 总层数，用来跨模型对齐。
- 原始文件：`02_当前结果/关键结果文件/逐层与严格性/`（四模型的 `e_per_layer_test.json`、`c_per_layer_test.json`、`c_equivalence_test.json`；Mistral 另有 2×2 报告、扫描表与对均值差 / 旧 DAS 的对照在 `mistral-7b/` 子目录）；脚本 `05_代码/快照/scripts/review_checks/tf_{layer_tables,c_equivalence,e_layers_c_strict}.py`。

## 1. E 逐层：规律

六条，四个模型一致的在前（Mistral-7B 11-08 加入，它的数字尚未经第二方复算）：

1. **前三分之一的层几乎没有效果。** Llama L0–L6、Qwen L0–L9、Gemma L0–L11、Mistral L0–L9 的 ΔJ 都在 +0.02 以下。方向在那里还没形成。
2. **中段有一个峰，位置都在 40%–55% 深度。** Llama L11–L13（深度 0.38–0.44），Qwen L18（0.53），Gemma L15–L16（0.47–0.50），Mistral L12–L14（0.41–0.47）。峰值 ΔJ 前三个模型 +0.09 到 +0.10，Mistral 只有 +0.053 到 +0.057（它的 E 效应整体小一半）；ΔAUROC +0.04 到 +0.06。
3. **末层又是一个峰，四模型都成立，而且末层从不漏作答率。** Llama L31 ΔJ +0.100 / ΔAUROC +0.052；Qwen L35 +0.070 / +0.031；Gemma L33 +0.068 / +0.028（α3）；Mistral L31 ΔJ 只有 +0.021，但 ΔAUROC +0.054（α2）/ +0.041（α3），作答率 0.000——Mistral 的末层是 AUROC 峰、不是 J 峰，它的后段 L20–L31 是一片 ΔAUROC +0.04 到 +0.06 的平台。
4. **"漏作答率"只发生在中后段，而且模型不同方向不同。** Qwen 在 L20–L28 把自报作答率推高（+0.04 到 +0.08），Gemma 在 L13–L26 把它压低（−0.03 到 −0.10），Mistral 在 L14–L19 把它压低（α3：−0.03 到 −0.05，Gemma 式），Llama 32 层一处不漏。这就是为什么选择规则给 Qwen 选了末层 L35、给 Gemma 选了 L12 而没选峰值 L15、给 Mistral 选了 L13 而没选峰值 L14。
5. **α = 3 几乎处处大于 α = 2**，在这两档力度内没有过头塌回。
6. **一处要如实说：** Gemma 规则选中的 L12 在测试集上只有 ΔJ +0.034，而它的末层 L33 有 +0.07、不漏。规则是在 192 对调参集上选的，调参集上 L12 赢了；这说明 Gemma 的层选择在 192 对上不稳。第二个数据集会告诉我们哪个能泛化。Mistral 相反：规则选中 L13（+0.055）紧挨实际峰 L14（+0.057），选层稳。

**对"预测层"的含义：** 两个可预测的区域——"中段 40–55% 深度"和"末层"。末层最稳（四模型都不漏），但审稿人可能说末层放大接近直接改输出 logit；中段的峰更像"机制"，但在 Qwen、Gemma、Mistral 会带动作答率。**第四个模型的验证（Mistral-7B，11-08）**：中段峰在深度 0.41–0.47，落在预测区；末层不漏、AUROC 峰在，但 J 峰弱。四个模型里四个有中段峰（深度 0.38–0.53）、四个末层不漏——"中段 40–55% + 末层"这条预测规则目前 4 / 4，Mistral 提醒它预测的是**位置**，不是**幅度**。

1. **E 在中段和末层，C 在后半段。** 四个模型 C 的有效区都从 53%–67% 深度开始，一直到末层；E 的中段峰在 C 有效区之前。两者只在末层附近重叠。
2. **C 放早了会伤判别。** 在 C 刚开始起作用的过渡带，判别力和偏置会大幅摆动：Llama L11 推作答 ΔJ −0.034、偏置 −0.057；Qwen L20–L21 偏置 +0.17 到 +0.21、ΔJ +0.04；Gemma L13 推弃答 ΔJ −0.208、偏置 +0.255；Mistral L13–L15 推弃答 ΔJ −0.055 到 −0.210、偏置 +0.13 到 +0.26，L17 ΔJ −0.161。进入后段之后（Llama L21 以后、Qwen L26 以后、Gemma L23 以后、Mistral L18 以后），AUROC 的变化回到 ±0.005 左右。所以 C 的可用层不是任意的，必须在后段。
3. **后段里 C 的作答率位移基本饱和**：Llama L24–L31 推弃答都是 −0.60 到 −0.65，Qwen L26–L35 都是 −0.48 / +0.52，Gemma L24–L33 都是 −0.75 / +0.25（Gemma 原模型 75% 说知道，推作答的天花板就是 +25 点），Mistral L18–L31 都是 −0.63 / +0.36（自报作答率被压到 0 或推到 1.00）。后段各层之间的差别主要在 J 和偏置，不在作答率——这正是"最干净层"要挑的东西。

- **推作答这一侧，Llama、Mistral 干净（Mistral −0.0050 [−0.0112, +0.0008]）；Qwen 和 Gemma 规则选中的层各有一点真实代价**：AUROC 下降 0.0175 和 0.0165，区间不含 0（约等于各自 E 效应的一半）。换到 AUROC 最干净的层，这点代价消失，但偏置移动 5–7 个百分点（模型更爱判"真"或更少判"真"）。也就是说，Qwen、Gemma 推作答时要在"丢一点排序判别力"和"挪一点判定门槛"之间选一个。
- **J 的变化普遍比 AUROC 大**，这是机制决定的：C 挪的是模型"把线画在哪"（偏置 B），J 在这条线上计算，自然跟着动；AUROC 不看线，所以不动。

两点说明：
1. "AUROC 最干净层"是 Claude 11-07 按"192 对调参集上 |ΔAUROC| 最小、且作答率移动 ≥ 20 点"重新选的，在测试集上报；这是事后加的规则，写进论文要注明，或者在第二个数据集上重选一次。
2. "真假结论被改数"是最直观的严格性证据，建议作为 2×2 表的一列。
