# 03 对博士 11-05 建议的评估

## 博士的建议（11-05 晚，原话）

> 上午说的 2×2 用 DAS 出来的结果我看了一下，我认为这不是你做错了，而是这个设计在小模型上本来就容易失效。
> 下一步我建议不要再往 2×2 这个矩阵上加模型了，可以这样：把方向估计从 DAS 换成配对样本 mean-diff + 层间正交化，承诺方向用首 token 的 yes/no logit 差来定义，2×2 保留但只作为验证而不是主实验。
> 主表放 llama-3.1-8b + qwen3-8b，gemma/mistral 全部挪附录。
> 主实验就是一个，在真假陈述判断 + 真实问答这两个任务上做方法对比表，不涉及矩阵。
> 在相同作答率下，组合是不是比任何一个单独方向都好。这一句就是我们这篇文章的主要 contribution，别的都是支撑。

时间线上要说明一点：博士写这段时看到的是 11-05 上午的结果，当时问答上下文里的 DAS 在自由作答上为零。**之后**（11-05 下午到晚上）把真假判断任务里 DAS 的训练目标换掉，得到了现在最强的一组正结果（`02` 第 2–3 节）。

## 2. 正对角与反对角

2×2 的行是"推哪个方向"，列是"看哪个指标"：

| | 判别力（J、AUROC） | 作答率 |
|---|---|---|
| 推 E | **应该大**（正对角） | 应该接近 0（反对角） |
| 推 C | 应该接近 0（反对角） | **应该大**（正对角） |

两半缺一不可：只有正对角，说明两个方向什么都动、没分开；只有反对角，两个方向什么都不动也能满足。两半都成立才叫解耦。

- **正对角：成立，而且不是挑出来的。** 不经任何规则的全扫描里，E 在 204 个条件里 200 个提高 J、202 个提高 AUROC；C 在规则所选的格子里把自报作答率移动 24–75 个百分点。
- **反对角：近似成立。** E 不碰自报作答率在 Qwen、Gemma 上有统计支持（95% 区间落在 ±0.03 内），Llama 区间上界超出一题；C 不碰判别只有点估计支持，三格有显著的小幅判别损伤；C 还会系统地挪真假判断的偏置（协议所用六格区间都不含 0，四格越过 ±0.05）。C 推得狠时常见"J 动、AUROC 不动"，符合"挪门槛"的解释（推断）。

## 3. "组合胜过单一方向"的硬伤，以及怎样才算验证了

全扫描显示 C 推动作答率时 AUROC 几乎不动、偏置会动，符合 **"C 主要在挪'答不答'的门槛"** 的解释。11-06 到 11-07 的实测把这个推断变成了数据（`08`、`09`）：

1. **组合对只推 C：成立，但不算贡献。** E 单独就提高判别力，E+C 自然胜过只推 C（E26：E+C 对 C 的差就是 E 的效果）。审稿人会说这是 2×2 的推论。
2. **组合对"只推 E，再设门槛"：在配额口径下打平，而且是设计决定的。** 按分数排序取前 K，C 把门控分整体平移（秩相关 0.96–0.998，交付题目只换 2–16 道），前 K 几乎不变。E26 12 格、GPT 修正门控后 48 格、第 21 轮 72 格都不显著。GPT 对这句的保留意见——"C 不是严格的纯平移"——数字成立，不改变结论。Dr. No（2611.03862）在另一任务上也发现给弃答选项加简单 logit 偏置和推"弃答特征"效果差不多（38.0 对 38.7）。
3. **要让 C 有机会，口径得换成"模型自己决定答不答"，再和门槛比。** GPT 第 20 轮的原生门控诊断做了一版（C 的 Yes / No 决定交付）：C 能把交付量从 0 拉到 164 / 192，但同数量下答对数低于固定 E + 置信度门槛（Llama 真假判断 145 对 152）——门控分挑题差于置信度。**E41 正在用 2×2 验证过的 C + 全部层的 E 做这个口径的完整版**（`09`）；已跑的实现都不是验证过的 C。
4. **除了单方向，必须与强基线比**：提示词（AxBench 证明提示词常强过所有 steering）、不动模型只按模型自己的把握设门槛（含弃答词元 logit 偏置）、ITI、CAA、TruthX、KAPPA、LITO / CASAL 式组合、CDAS 式目标——即首页第六节第 5 问的统一清单。
5. **"任何一个单独方向"范围太宽。** 必须明确列出比哪几个。
6. **真实问答那一半目前不成立。** E 在自由作答上为零，组合约等于只推 C。两条路：换写法（来源交换）继续找；或"不推 E 改生成、用 E 核验自己的答案再决定答不答"（Llama 已显著 +0.027，Gemma 均值差版 +0.050）。都在 `07` 的计划里。
7. **"作答率"要换成真实弃答。** 真假判断里的作答率是自报；原生门控把它变成实际交付，E41 用的就是这个口径。

**我们建议的改写**（保留博士"相同作答率"的口径，把弱点变成要证明的东西）：

> 在相同作答率下比较，真实性干预的提升里只有判别方向 E 的那一部分保留；承诺方向 C 以接近零判别代价设定作答率，它就是那个"门槛"旋钮——E 抬曲线，C 沿曲线走。

已有支持：E27 自然作答率下 +40 到 +50 题、对齐作答率后归零（`08`）；ITI 原文附录里很多"翻成真话"的例子其实是改口"我不评论"（Vicuna 真实率 88.6 而"真且有信息量"74.0）；TruthfulQA 把"我不评论"算真话；TruthX 的提示自带"不确定就说我不评论"。**"现有方法的提升多来自多答题"这一半还没实测**，计划见 `07` 的 E。

## 4. 两条主线都成立的话，够不够顶会

我们自己和一个独立子代理（只给它主张和证据、不给我们的看法）分别判断，结论一致：

| 情形 | 现实目标 |
|---|---|
| 两个任务都成立，且赢过统一基线清单（门槛、提示词、ITI、CAA、TruthX、KAPPA、LITO / CASAL 等） | ACL / EMNLP 主会；NeurIPS / ICLR 还需更大模型（≥ 27B）、更多模型家族和有"知道却说错"差距的数据集，以及带置信区间的风险–覆盖率曲线 |
| 只有真假判断成立，真实问答不成立（按现有数据可能性最大） | ACL / EMNLP 主会偏保守一侧，或 Findings；取决于 BBQ 复现与基线重评 |

审稿人最可能的反对意见：

1. C 若只挪门槛，"组合在相同作答率下更好"就是 2×2 的推论，除非赢过门槛与 logit 偏置。
2. DAS 用金标签训练，会不会只是把一个分类器写进了模型？需要补打乱标签训练的 DAS、同样大小的随机方向、跨数据集测试三种对照。
3. 相对已有的"信念 / 行为分离"工作（拒答指数 ICLR 2026、承诺-弃答电路 NeurIPS 2026（作者自述接收）、KAPPA ICML 2026、Kumaran 的决策 / 正确性正交方向、LITO、YOPO、CASAL）显得增量。
4. 真假判断的作答率是自报，不是真弃答。
5. 数据集只有 TruthfulQA（真假陈述也由它改写），主表只有 8B 模型。

文献对照细节见 `04` 与首页第三节。
