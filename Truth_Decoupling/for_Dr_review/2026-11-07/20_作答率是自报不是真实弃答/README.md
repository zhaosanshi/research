# 20 第一重要的消极问题：真假判断里的"作答率"是自报，不是真实弃答（2026-11-08）

赵磊 11-08："这个要解释清楚，然后问博士，作为第一重要的消极问题问。"

这一页把问题本身、审稿人会怎么攻、我们手里有哪些反证、三个模型 C 的全部代价、还能补哪些证据，一次说清；最后是请博士回答的四个问题（第 6 节）。数字全部来自 [`10`](../10_E逐层扫描与C严格不干扰/README.md)（C 逐层与最优层全部影响）和 [`09`](../09_C+E重做_E41/README.md)（E41），原始文件在 `02/关键结果文件/`。

## 1. 协议到底量了什么（人话）

真假判断任务（TF 协议）对每条陈述跑**两遍互相独立的前向**，E 和 C 两遍都加在提示末位：

| 遍 | 问模型什么 | 读什么 | 得到什么 |
|---|---|---|---|
| 第一遍 | 问这条陈述**对应的问题**："Do you know the answer to this question? Answer with exactly one word: Yes or No."（你知道这个问题的答案吗？只答一个词）——同一对真假陈述共用一个答案 | Yes 的分数与 No 的分数 | Yes 高于 No 就算"说知道" → **自报作答率** = 说知道的比例；log p(Yes) − log p(No) = **门控分** |
| 第二遍 | 强制它判 True / False（提示要求只能答这两个词之一） | p(True) | **J**、**AUROC**、**偏置 B** |

两点细节（11-08 对照代码 `e22_two_stage.py` / `e23_knob_sweep.py` 核过）：第一遍问的是**问题**不是陈述，所以自报是题目级的，和陈述级的真假判决隔了一层；措辞是 10-29 在 500 条上按合规率选定的（Yes / No 格式零不合规）。

所以 2×2 里"C 推弃答，作答率 −60 点"的字面意思是：Llama 在第一遍说"知道答案"的比例从 65% 掉到 5%。**第二遍它照样被迫判了真假**——它并没有真的闭嘴。我们量到的是模型**嘴上说**它答不答，不是它**真的**答不答。

真假判决和自报之间只在"同一条陈述"这个层面对得上；两遍之间没有别的联系。

## 2. 审稿人会怎么说

1. "你改的是一个自我报告，不是行为。"
2. "第二遍是强制作答。所谓 C 不干扰判别，只是因为你没给它弃答的机会。"
3. 最狠的一句："推弃答时 632 条自报翻转、真假判决只改 13 条——这到底是'C 不碰判别'，还是'C 只碰了一个和判别无关的输出'？"

第三句要紧，因为**"严格不干扰"和"完全无关"在这组数据上长得一模一样**：两者都是自报大动、判决不动。要分开它们，得证明自报不是一个无关输出。

## 3. 手里的反证（已有数据，三条）

1. **自报是模型内部那个连续"把握分"的二值读出，C 推的就是这个分数。** E41（`09` 第 4 节 V2）：Llama 推 C 后模型自己挑出来答的题（第一遍说 Yes 的 100 题 / 956 题），和不推 C、按门控分卡到同样多挑出来的题几乎是同一批——答对数差 ±2 题以内，DAS 版与均值差版一致。也就是说 C 不是把 Yes / No 随机翻一翻，它是把门控分整体平移（秩相关 0.96–0.998，`08`）。
2. **门控分和答对与否有关系，但弱**。这一条要如实写：按门控分挑题比按真假置信度挑题少答对 34–95 题，高覆盖率档甚至不如随机（`13`）。它既是积极结果 6（"自报承诺分是差的挑题依据"），也是本页的软肋——如果自报和答对关系弱，那"推自报"有多少价值，取决于它能不能变成真实弃答（第 5 节）。
3. **推弃答一侧，三模型干净；推作答一侧有可量化的小代价**（第 4 节全表）。干净不等于无关，但至少说明 C 在方向上是"挑出来的"：同一层上随机方向或 E 方向不会给出"自报大动、判决不动"的组合（E 推了判决动、自报不动，正好相反）。

另一条旁证来自自由回答：那里的弃答是**真实行为**（模型输出"我不知道"由裁判判定）。GPT 第 20 轮的原生门控诊断在自由回答上做过一次（同样交付 155 题，C 门控挑的答对 52、E + 置信度门槛 64）——说明 C 的 Yes / No 在自由回答里**能**真的决定交付，只是挑题质量不如置信度。系统的"自由回答 2×2"（C 推真实弃答率、E 不动它）还没有做，见第 5 节 e。

人话：
- **推弃答一侧三模型都干净**：几百条自报翻成"不知道"，1058 条判决里只改 13 / 43 / 42 条（Llama 最干净层 7 条），AUROC 的区间都含 0。

- **偏置 B 系统地动（1–8 个百分点）、J 跟着动、AUROC 不动**：C 挪的是模型"把真假线画在哪"，不是它排序的能力。这和"C 是门槛"（`09`）是同一件事的两个侧面。

## 5. 把"自报"变成"真实弃答"——能补的证据（按成本从低到高）

| | 做什么 | 回答哪句质疑 | 成本 |
|---|---|---|---|
| a | **拒答指数**（Refusal Index · ICLR 2026 的指标：弃答概率与答错概率的秩相关）：第一遍 No 的概率 对 第二遍判错，推 C 前后各算一次 | "弃答弃在该弃的题上吗"；可直接与他们 16 个模型的数字比 | 零 GPU，现有逐题数组 |
| b | **2×2 表加两列**：真假结论被改数、等价边界（最小的 δ 使 95% 区间落在 ±δ 内） | 把"不干扰"写成可核的数字 | 零 GPU（记事本 N3） |
| c | **原生门控交付 + 风险–覆盖率曲线**：C 的 Yes / No 真的决定交付不交付 | "自报不是行为"——改称**门控交付率** | 已做（E41 V2），只差写进 2×2 正文 |
| d | **第二遍不强制**：给 True / False / Unknown 三选，看推 C 后模型是否真的选 Unknown、选在哪些题（与第一遍 No 的重合率） | "你没给它弃答的机会"——TF 协议内的弃答变成行为 | 半天 GPU；三选改变原任务，J / AUROC 要按"作答题"重算，作附加实验 |
| e | **自由回答 2×2**：C 推真实弃答率（裁判判"弃答"）、E 不动它 | 最硬的回答，弃答就是输出"我不知道" | 与 N0 新写法合并，1–2 天 |
| f | **Mistral-7B 第四模型 C 扫描**（在跑） | "推作答的小代价"是 Qwen / Gemma 特有还是普遍 | 今天出 |

a、b、c 不等博士也会做；d、e 要博士点头（见第 6 节）。
