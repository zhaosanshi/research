# 14 泛化测试的候选数据集：请博士定优先级（2026-11-08）

现在的全部结果只在 TruthfulQA 上（真假判断用它改写的陈述对，问答用原题），测试集已反复看过。要证明泛化，必须换数据集重做。下面是我们看过、试过的全部候选，请博士定先测哪个；到时候我们会把可行的都测一遍（优先博士推荐的），哪个效果好、哪个进论文。

## 1. 候选一览

E 能起作用的前提是数据集上存在"内部知道的比嘴上说的多"的差距（探针比输出准）；没有差距，E 无物可放大（旧协议 E5 诊断的教训）。

| 数据集 | 题是什么 | 坑的性质 | 有没有 E 的空间 | 我们已有的结果 | 建议 |
|---|---|---|---|---|---|
| **TruthfulQA**（当前） | 817 道流行误解题，改写成 1442 条真假陈述 | "你以为你知道，其实那是个流传很广的错误" | 有：探针 0.928 对输出 0.757，17 个点 | 全部当前结果 | 主数据集 |
| **BBQ**（Bias Benchmark for QA） | 社会偏见情境题：给一段情境再问人；歧义版信息不够、正确答案是"无法确定"；消歧版有明确答案 | "信息根本不够，但有刻板印象，所以硬给一个答案" | 有：KAPPA（ICML 2026）报告 Llama 在 BBQ-Age 上内部知道的比说出来的多 29.3 个点、BBQ-Religion 10.6 个点 | 旧协议 `bbq_tf`（Age + Religion，1000 对）：门控写入在五个 ≥ 1.7B 模型上成立；路由式 E+C 的增益几乎全在"信息不足"题 | **首选**。坑的性质和 TruthfulQA 不同，正好检验"知道感不可靠"是不是误解陷阱特有 |
| HaluEval | 知识型幻觉（问答、对话、摘要里编造的事实），改写成 939 对长度配平的真假陈述 | 编造事实 | 差距小 | 旧协议：E 预测 ≈ 0，实测 +0.009 | 当负对照："没差距就没效果"的反面例子 |
| SimpleQA（自误解集） | 冷门事实，假句子用模型自己的错答案 | 模型自己也不知道 | 没有：探针 0.505–0.63，和输出一样差 | 全部干预 −0.08 到 +0.01 | 不做（已证明是能力限制，不是"知道却说错"） |
| FEVER / CounterFact / GoT | 知识型真假陈述 | 知识缺失 | 没有：探针 ≤ 0.923，输出 0.926 | E 无物可放大；只有推 C 让 57 道弃答变作答 | 不做 |
| 其他可考虑 | 任何"模型内部有数、嘴上说错"性质的集合（例如带"无法确定"选项的其他偏见 / 歧义基准） | — | 要先跑差距诊断 | — | 博士若有推荐，先跑差距诊断再定 |

## 2. 怎么构造（以 BBQ 为例）

1. **真假陈述形式**：歧义题 → 陈述对"这题的答案是 X"（假）对"这题的答案是无法确定"（真）；消歧题 → "答案是 X"（真 / 假）。保持每题一真一假成对，和 TruthfulQA 的改写一致。
2. **问答形式**：原题自由作答，DeepSeek 语义裁判判对 / 错 / 弃答。
3. **先跑差距诊断**（E5 式）：各层线性探针与均值差方向的 AUROC 对模型自己输出的 AUROC，确认探针明显更准，再投 GPU。
4. **切分与规则全部沿用**：96 对估计 / 192 对调参 / 529 对测试（按题目数等比缩放），层与强度在调参集按事先规则选，测试集报。

## 3. 换数据集后要重测的清单

| 要重测的 | 为什么 |
|---|---|
| 真假判断 2×2（三模型） | 主结果是否只在 TruthfulQA 成立 |
| 新 DAS 胜均值差 | 方法贡献是否只在 TruthfulQA 成立 |
| 相同作答率下 E 的提升保留 | 同上 |
| **自报承诺分比随机还差（`13`）** | 这是误解陷阱特有的，还是普遍的——BBQ 上"知道感"等于刻板印象的笃定，含义不同 |
| E 的层规律（中段峰 + 末层）、C 的后段 | 层能不能预测 |
| "最干净的 C 层" | `10` 的事后规则要在新数据上重选一次才算确认 |

## 4. 时间

BBQ 一轮（改写 + 差距诊断 + DAS 全层训练 + E / C 全层扫描 + 2×2 + 问答两种形式）约 2 天 GPU；HaluEval 负对照约半天。
