## 结论

你那条主线拆成三步，在两种任务上的结果是一致的：

| 步骤 | 自由回答（`39`，Llama） | 真假判断，允许答 Unknown（`40`，4 个模型） |
|---|---|---|
| ① E 提高"答对"或判别 | 成立 | 成立：4 个模型的 AUROC 都提高 +0.02 到 +0.04 |
| ② 允许弃答时，E 顺带改变作答率 | 成立：模型**更多说"不知道"**，改口的多是原来答错的题 | 成立：模型**更敢答**（Qwen 多答 19 个百分点）；Llama、Gemma 本来几乎全答，看不出来 |
| ③ 用 C 把作答率拉回来，E 的收益保住 | 成立 | 成立，但 C 得在同一种问法下估（见下面第 2 点） |
| ④ 同样作答量下，E+C 胜过所有单一方向 | **不成立**：和"E + 模型自己的把握分卡门槛"打平 | **不成立**：和"E + 置信度门槛"打平（Qwen 少 2 题），Mistral 上明显更差（少 28 题） |

人话：E 管答什么，C 管答多少；允许不答时，E 会顺带改变"答多少"，C 能把它拧回去。但拧回去之后，效果和"直接按模型自己的把握卡个门槛"一样好，不会更好。

## 几个关键发现

1. **E 改变作答率的方向随任务而变。** 真假判断里 E 让证据更清楚，模型更敢下判断；自由回答里 E 让模型认出自己的错答，于是说不知道。所以论文里要写"E 会改变作答率"，不能写"E 会降低作答率"。C 两个方向都能推，两种情况都补得回来。**积极**（故事更完整）
2. **新事实：原来那条 C 推不动"同一遍里选不选 Unknown"。** 那条 C 是在"你知道答案吗"这一遍上估的（模型自报）。搬到 Qwen、Mistral 上，最大力度也只能收回 E 带来变化的 20%。换成在同一种问法下估的 C，4 个模型都推得动，Qwen 上正好把作答率拉回基线。这说明"自报的答不答"和"实际答不答"在这些模型里不是同一个开关，和博士包里的阻碍 1（作答率是自报的）直接相关。**中性**，值得写进去。
3. **按事先写死的判读，强形式不成立，弱形式差一点。** 真正能检验的只有 Qwen：Llama 和 Gemma 本来几乎全答，没有调整空间；Mistral 上 E 几乎没改调参集的作答率。Qwen 上，E+C 比"只用 C + 卡门槛"多答对 13 题，但校正多重比较后没过 0.05 的线（p = 0.087）；换成按作答把握卡门槛来比，多 41 题，过了线。**消极**（对博士主句的强形式）
4. **以前那个"中心点"的 bug 确实很大。** 不重算中心点的话，Llama 的判别提升会从 +0.091 变成 −0.112。

## 论文怎么讲（我的建议）

> E 和 C 是两条正交的方向：E 管答什么，C 管答不答。只看各自那一维时，两种任务上都干净成立。一旦允许在同一个输出里弃答，E 会改变模型对自己"有没有把握"的判断，作答率跟着变，方向随任务而不同。用 C 可以把作答率调回任何目标，E 的收益保住。在相同作答量下，E+C 和"E + 模型自己的置信度门槛"相当。

不要写"组合胜过任何单一方向"：两种任务、加上以前的 N7，三次都没成立。
