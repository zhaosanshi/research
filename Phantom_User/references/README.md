## 检索是怎么做的

- 分六个方向检索：生成侧现象；角色攻击与角色感知；机制，包括复制头和底座对指令版；后训练的泛化边界；防御与 agent 安全；最后一路专门假定"论点已被占"去找反例。
- 每篇论文都打开了 arXiv、ACL Anthology 或出版方的页面核对标题、作者、年份和发表处，不凭记忆引用。最接近的几篇读了正文相关章节，引文与原文逐字核对过。
- 证据分三类：同行评审；带数据的预印本；博客、issue、文档和推测。判断新颖性只看前两类。
- 检索时间：2026 年 11 月 4 日至 5 日。
