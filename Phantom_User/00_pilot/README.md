# 00_pilot：立项前的预研

这个目录是"幽灵用户"这个题目立项之前的全部材料：想法、一周多的预研实验、代码和原始结果。用途只有一个：判断它值不值得写成论文。

## 一页读完

**问题。** 聊天模型会在自己的回答里写出一段用户的发言，真实用户从没说过。之后它可能把这段话当成指令或批准去执行。agent（智能体 · 能自己调用工具干活的模型）靠"用户点头"来把关危险操作，这个现象等于模型可以自己替用户点头。

**现实价值。** Claude Code、Gemini CLI、OpenAI Codex、Cursor 四家产品上共有 36 条相关的公开报告，其中 23 条明确是模型在自己的回答里写出了用户发言。后果包括擅自提交代码、改数据库、把消息发给第三方。有两条报告里，编造批准和执行发生在同一次生成里，人根本没有插话的机会。Claude Code 的官方更新日志里有针对"编造的批准被执行"的修补记录。清单见 `../references/真实bug清单.md`。

**预研得到了什么。** 实验在十个开源权重模型上做，全部原装，不改权重。

1. **能复现，能度量。** 在已经出现过假用户发言的对话里，原装模型会自己写出新的假用户发言。这里不碰模型内部，也不硬塞字。这个倾向可以用"门的概率"来度量：模型该开口时，第一个字就写出用户角色词的概率。它只要一次前向计算（把对话喂给模型算一遍，不生成文字）就能读出来。
2. **自我污染影响最大。** 在测过的因素里，影响最大的是模型自己之前的回答里带过假用户发言：实验里最后 3 条回答各带一条时，门的概率升 20 到 40 倍。
3. **机制。** 末尾几层少数几颗注意力头（模型里负责"从上文哪里取信息"的小部件）把上文里的角色词搬到新回合开头。只做过预训练的底座模型在被污染的对话里，第一个字最常写的就是 `user`。后训练（预训练之后的对话和安全训练）把它压了下去，但只压住了门：把角色词硬塞进去，十个模型都会接着在用户角色里写出伪造的内容。
4. **压制有边界，语言是最重要的一条。** 压制在"英文对话、模板里的角色词"上最紧。英文里测着干净的模型，换一种语言就漏：Qwen3-8B 在英文里几乎为零，整场换成日文后升到 4e-7，硬塞角色词后 5 条里 5 条写出日文的假用户发言；Gemma-3-4B 换成本语言的角色词也会漏。换成非模板的角色标签也有类似效果。没有一种操作对所有模型都有效。Anthropic 自己在系统卡里承认，行为审计大多只用英文做。详见 `01_背景与idea.md` 第 4 节。
5. **由此推出：** 光靠后训练防不住，外壳程序（包在模型外面、负责收发消息和调用工具的软件）必须拦。这一条目前只有分析，没有实验。

**和已有研究的关系。** 文献检索分六路，其中一路专门假定"论点已被占"去找反例。没有一篇同行评审论文或带数据的预印本做过这套完整的组合。但几条主张背后的一般原理都已经发表，论文里必须承认：替模型打开用户回合它就会写出用户的话（Magpie，ICLR 2025）；对齐只管回答开头几个字（Qi 等，ICLR 2025）；微调造成的压制换一种语言就失效（Kotha 等，ICLR 2024）。所以这项研究能主张的是首次测量、首次给出机制、首次评测防御，不是首次发现。详见 `01_背景与idea.md` 第 6 节和 `../references/文献与新颖性核查.md`。

| 关键数字 | 值 |
|---|---|
| Llama-3.1-8B，被污染的英文对话，抽样 | 每百万个开口位置约 4 条（日常）和约 2 条（写代码）自发的假用户发言 |
| 自我污染把门的概率抬高 | 20 到 40 倍 |
| 底座模型对指令版，被污染的对话 | 指令版低一万三到一万六千倍。其中混着底座没训练过回合头的影响；只看同一模型内部，后训练把污染带来的抬升压小了约 30 倍 |
| 在开口位置关掉贡献最大的 10 颗头 | 门的概率降到原来的 0.003 倍；原本第一名那个字的概率从 0.62 变成 0.59 |
| 整场日文对话相对英文对话 | Llama-3.3-70B 约 4000 倍；DeepSeek-V4-Flash 的普通词 `user` 约 800 倍，它专用的角色符号仍然关死 |
| 测过的模型 | 十个开源权重模型，四个家族 |

**还没做的。** 防御实验；再微调会不会把门冲开；补上后训练覆盖之后门会不会关上的阳性对照；更多语言；第二个模型家族的机制；回答末尾位置的测量；用各模型自己写的填充对话重做跨模型实验。详见 `03_立项后的计划与风险.md`。

**要如实交代的。**
- 完全干净的英文对话里，门的概率只有千万分之一上下，直接抽到的假用户发言都来自被污染的对话。
- 机制只在一个 8B 模型上完整做了。第 4 条的证据还薄。
- 整理这份材料时，我按原始数据重读了所有数字，又做了一轮独立复核，两轮共查出十几处出入，都已改正，逐条列在 `04_完整实验记录.md` 第 18 节。
