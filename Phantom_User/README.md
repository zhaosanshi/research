# Phantom_User

幽灵用户：聊天模型在自己的回答里编出一段用户的发言，然后把它当真。

"Phantom" 取"幻肢"的意思：东西并不存在，系统却当它是真的。对话里从头到尾没有这句用户发言，模型自己写了出来，之后模型和外壳程序（包在模型外面、负责收发消息和调用工具的软件）都照着它行动。

## 研究什么

- **现象。** 模型在回答里写出用户的角色标记和一段用户口吻的话，真实用户从没说过。之后模型可能把它当成指令或批准去执行。Claude Code、Gemini CLI、OpenAI Codex、Cursor 都有公开报告。
- **机制。** 这段话是怎么写出来的。目前的证据指向末尾几层少数几颗注意力头（模型里负责"从上文哪里取信息"的小部件），以及后训练（预训练之后的对话和安全训练）对它们的压制。
- **预防。** 后训练的压制在哪些情况下失效，外壳程序该怎么拦。
