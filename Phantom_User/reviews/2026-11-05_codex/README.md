## 复跑离线审核

只需 Python 3 与 Bash，无需模型权重。脚本默认读取本仓库 `Phantom_User/00_pilot/`，结果写回本目录。要核查历史结论，应使用上面的基准版本；可设置环境变量 `PHANTOM_PILOT` 指向该版本的 `Phantom_User/00_pilot`。

从仓库根目录执行：

```bash
python3 Phantom_User/reviews/2026-11-05_codex/audit_recompute.py
python3 Phantom_User/reviews/2026-11-05_codex/audit_detector.py
```

[复算输出](audit_recompute_results.json)保存关键数值、逐条人工标签及执行检查。[检测器输出](audit_detector_results.json)保存最小样本和宽松候选；候选不是确认的故障次数。人工标签适用原审核数据，不是通用自动分类器。

`audit_recompute.py` 会用返回固定错误码的无害替身检验原批处理是否吞错；不会启动容器。它还抽取 `vendor/` 内官方源码的配置方法执行，使用替身跳过张量计算；这项检查不是模型推理复现。
